practices on how to shape technical prose go here.

these rules entrain a telegraphic overlay of asd-ste100 (simplified technical english)
onto all technical prose the architect writes — briefs, plans, domain docs, decision records.

goal: max signal per token, one-pass legibility for any-language readers, fewer tokens.

one dialect governs all prose. long-form briefs gain *more* from brevity, not less.
exempt only: verbatim quotes + code blocks. the `ubiqlang/` cluster governs term choice;
this cluster governs prose (sentences).

these mirror the mechanic `lang.prose/` cluster. roles boot separate trees, so each holds a copy.
