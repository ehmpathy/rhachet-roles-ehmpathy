# rule.forbid.term=property.example=demo

a 👎/👍 demo for `rule.forbid.term=property`.

**👎 bad**
```ts
// read each property of the surfer
const value = surfer[property];
// acid names four properties of a transaction
// a property-based test of asSwellHeight
```

**👍 good**
```ts
// read each field of the surfer
const value = surfer[field];
// acid names four traits of a transaction
// a generative test of asSwellHeight: the law is that a cast round-trips
```
