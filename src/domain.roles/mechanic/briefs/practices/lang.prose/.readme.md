practices on how to shape technical prose go here.

these rules entrain a telegraphic overlay of asd-ste100 (simplified technical english)
onto all technical prose — comments, plans, docs, commit messages, error strings.

goal: max signal per token, one-pass legibility for any-language readers, fewer tokens.

scope note: these govern prose (sentences). the neighbor `lang.terms/` cluster governs
term choice (one word per concept); `lang.tones/` governs human-chat tone. prose rules
apply to procedural and long-form prose alike. exempt only: verbatim quotes + code blocks.
