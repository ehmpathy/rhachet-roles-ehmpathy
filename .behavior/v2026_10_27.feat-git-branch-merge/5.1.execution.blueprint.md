## .contract (settled in 1.vision)

```
rhx git.branch.catchup begin [--mode plan|apply]
rhx git.branch.catchup take --whos main|branch <paths…>
rhx git.branch.catchup lock refresh
rhx git.branch.catchup continue
rhx git.branch.catchup abort
```

then `rhx git.commit.push --mode apply`, unchanged.

## .the gate order (vision invariants 4 + 7)

1. a rebase in flight → refuse, both modes (exit 2; F15)
2. on main/master, or a detached HEAD → refuse, both modes (exit 2)
3. global blocker, org blocker → refuse, both modes (exit 2; a corrupt file exits 1)
4. no sponsor found → refuse, both modes (exit 2)
5. a corrupt quota file → refuse, both modes (exit 1)
6. fetch `origin/main` → fails loud, exit 1
7. behind 0 → `already level`, exit 0, no meter spend; free even over a dirty tree
8. a merge in flight, uncommitted work (staged or unstaged), no quota or zero uses → plan flags,
   apply refuses

conflict stop: exit 2 with `✋ ConstraintError`, each file named, next steps `take` / `continue` /
`abort`.

## .commit step (shared by `begin` and `continue`)

header `cont(branch): merge origin/main into <branch>`; author = robot identity; sponsor
`Co-authored-by` trailer; meter `uses − 1` (or stays `infinite`). it calls the leaves lifted into
`git.commit.operations.sh` (F11).

- meter written as json; sponsor via `seedTestSponsor`; identity via `configureTestGitUser`

- clamps proved: each guard reverted → red, restored → green (`rule.require.clamp-edge-cases`);
  the staged-only dirty case `[case4b2]` is the sharpest clamp, since the rebase guard passes it
