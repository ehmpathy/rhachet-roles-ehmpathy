# case=1.catchup-clean

cells: #2 · #5 · #5b (`[case1b]`) · #37 · feel happy · care critipath

## .narrative

beaver's pr reads BEHIND: main took three commits since the branch was cut, and the repo requires
a branch level with main before merge. beaver runs the plan. it sees three
commits behind, two ahead, and its meter: 4 commits left. it applies. one merge commit lands,
authored `seaturtle[bot]`, its trailer names the sponsor, the meter reads 3. beaver pushes with
`rhx git.commit.push --mode apply`. the push is a fast-forward of the remote branch; no history
moved. the pr turns MERGEABLE. no human saw a prompt.

a week later beaver opens a fresh branch for a one-line fix. a day passes before it commits any
work of its own, and main moves twice: the branch is 2 behind, 0 ahead. it runs `begin --mode apply`. a plain git merge
would fast-forward the branch onto main, and HEAD would then be a human's commit, which
`git.commit.push` refuses to push. the verb always makes a real merge commit instead, so HEAD is
seaturtle's, and the push goes through.

## .bdd

```
given('[case1] a feature branch 3 behind origin/main, no overlap in files')
  when('[t0] begin, plan mode (default)')
    then('lists the 3 commits behind and the header of the merge commit to come')
    then('shows the meter would go 4 → 3')
    then('makes no commit; HEAD unchanged; meter unchanged')
  when('[t1] begin --mode apply')
    then('HEAD is a 2-parent commit: old HEAD and origin/main')
    then('author is seaturtle[bot]; message ends with the sponsor Co-authored-by trailer')
    then('meter uses decremented by exactly 1')
    then('the tree is clean; no merge in flight')
  when('[t2] git.commit.push --mode apply')
    then('the remote branch moves by fast-forward; its prior head is an ancestor of the new head')
given('[case1b] a feature branch with 0 commits ahead and 2 behind origin/main')
  when('[t0] begin --mode apply')
    then('HEAD is a 2-parent seaturtle commit, not a fast-forward to origin/main')
    then('git.commit.push --mode apply passes its author guard')
```
