# case=4.refusals

cells, sharp (a refusal): #9–10 · #12 · #16 · cells, happy (plan previews and flags): #11 · #15 ·
cell, happy (infinite quota): #5c · care critipath

each refusal fails safe: fast, loud, `✋ ConstraintError` header, exit 2, the same text on stdout
and stderr, and it names the fix and who holds it (`rule.require.errors-name-the-fix`,
`rule.require.qualified-error-headers`, `rule.require.skill-output-streams`). where a gate guards
only the mutation, plan does not refuse: it previews and flags what apply will refuse.

## .narrative

three slips a clone makes on a long day.

on main: a clone checked out `main` to read it and forgot. it runs `begin`. the verb refuses in
plan and in apply, before any fetch: it never merges into main or master, and a preview of that
would mean naught. the fix is the clone's own: run from the worktree of its feature branch.

dirty tree: a clone has uncommitted edits, staged or not. its plan still previews the merge, and
flags that apply will refuse, with the files named. it runs apply anyway; the verb refuses, since a
merge over those edits would fold half-done work into a merge commit no one reviews. the fix names
`rhx git.stage.add` + `rhx git.commit.set`.

no quota: the meter reads 0. plan still previews the merge (plan is free) and flags the gate; apply
refuses. the lever is a human's, so the output says so and prints the command the human runs.

and the quiet path: a human granted `infinite`. the merge commits and the meter stays `infinite`.

## .sketch (illustrative; refusals print the same text on stdout and stderr)

```
$ rhx git.branch.catchup begin --mode apply
✋ ConstraintError: will not merge into main

🐚 git.branch.catchup begin --mode apply
   ├─ branch: main
   ├─ why: this verb levels a feature branch with main; it never writes to main
   └─ fix: run it from the worktree of your feature branch
```

the fix names only acts a clone may take: a clone cannot switch branches (`git checkout` and
`git switch` are unpaved), so the refusal points it at the worktree that already holds its branch.

```
$ rhx git.branch.catchup begin
🐢 heres the wave...

🐚 git.branch.catchup begin --mode plan
   ├─ merge
   │  ├─ from: origin/main
   │  ├─ behind: 3 commits
   │  └─ ahead: 2 commits
   ├─ ⚠️ apply will refuse: uncommitted changes
   │  └─ src/domain.roles/mechanic/readme.md
   └─ meter
      └─ left: 4 → 3
```

```
$ rhx git.branch.catchup begin --mode apply
✋ ConstraintError: uncommitted changes in the tree

🐚 git.branch.catchup begin --mode apply
   ├─ dirty
   │  └─ src/domain.roles/mechanic/readme.md
   ├─ why: a merge over uncommitted work folds it into a merge commit no one reviews
   └─ fix: commit it first, then begin again
      ├─ rhx git.stage.add <files>
      └─ rhx git.commit.set -m @stdin --mode apply
```

```
$ rhx git.branch.catchup begin --mode apply
✋ ConstraintError: no commit uses left

🐚 git.branch.catchup begin --mode apply
   ├─ meter
   │  └─ left: 0
   └─ fix (a human runs this)
      └─ rhx git.commit.uses set --quant N --push allow
```

## .bdd

```
given('[case4a] HEAD on main')
  when('[t0] begin, plan or apply')
    then('exits 2 with ConstraintError; no fetch, no merge, HEAD unchanged')
    then('stdout and stderr both carry the header and the fix')
    then('the fix names the worktree of the feature branch, never an unpaved branch switch')
given('[case4b] unstaged edits in the tree')
  when('[t0] begin (plan)')
    then('exits 0; previews the merge; flags "apply will refuse: uncommitted changes" with the files named')
  when('[t1] begin --mode apply')
    then('exits 2; names the dirty files; no merge started')
    then('stdout and stderr both carry the header and the fix')
    then('the fix names rhx git.stage.add and rhx git.commit.set')
given('[case4b2] staged-only edits in the tree (the gap the rebase guard leaves open)')
  when('[t0] begin --mode apply')
    then('exits 2; names the staged files; no merge started')
given('[case4c] meter uses = 0')
  when('[t0] begin (plan)')
    then('exits 0; previews the merge; flags "no commit uses left"')
  when('[t1] begin --mode apply')
    then('exits 2; no merge started; meter unchanged')
    then('stdout and stderr both carry the header and the human command rhx git.commit.uses set')
given('[case4d] meter uses = "infinite"')
  when('[t0] begin --mode apply')
    then('merges; meter stays "infinite"')
```
