## .narrative

beaver applies the merge. main edited `src/domain.roles/boot.budget.integration.test.ts` and
`src/domain.roles/mechanic/readme.md`; so did the branch. git stops. the verb does not pretend: it
prints both conflicted files, says the merge is in flight, and names the two exits — settle and
`continue`, or `abort`. exit 2: the caller must act. beaver opens the test file, keeps both hunks,
stages it with `rhx git.stage.add`, and runs `continue` too early, before it settles the readme. the verb refuses again and names
only the file still in conflict. beaver stages it, runs `continue`, and the merge commit lands with
the same author, trailer, and meter spend as case=1.
