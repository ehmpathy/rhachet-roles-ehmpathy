# case=5.already-level

cells: #1 (plan) · #4 (apply) · feel happy · care critipath

## .narrative

a clone runs the merge on every pr before it asks for review, as a habit. most days main has not
moved. the plan fetches, sees zero commits behind, and says `already level`. so does apply: no
commit, no meter spend, exit 0. the habit costs naught, so the clone keeps it. idempotent: a second
`--mode apply` right after a first is the same no-op.

## .sketch (stdout, illustrative)

```
$ rhx git.branch.catchup begin
🐢 already level

🐚 git.branch.catchup begin --mode plan
   ├─ from: origin/main
   ├─ behind: 0
   └─ no merge needed; meter untouched
```

```
$ rhx git.branch.catchup begin --mode apply
🐢 already level

🐚 git.branch.catchup begin --mode apply
   ├─ from: origin/main
   ├─ behind: 0
   └─ no merge needed; meter untouched
```

## .bdd

```
given('[case5] a feature branch that already contains origin/main')
  when('[t0] begin (plan)')
    then('exits 0; prints "already level"; HEAD and meter unchanged')
  when('[t1] begin --mode apply')
    then('exits 0; prints "already level"; HEAD unchanged; meter unchanged')
  when('[t2] begin --mode apply, right after a merge from case1')
    then('the same no-op: idempotent')
```
