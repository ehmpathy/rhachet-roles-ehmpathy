### the repair — one transformer, three strips, one append

`get_clean_pr_body`, applied to every description set and every push-created body:
1. strip every line that holds `Generated with` + `Claude Code` (bare or in a link), any `🤖` prefix
2. strip every `Co-authored-by:` line, any case (closes push's extant leak of `Co-Authored-By:`)
3. strip every prior `---` + `🐢🌊 surfed in by seaturtle[bot]` footer, then blank lines at the tail

then append `\n\n---\n🐢🌊 surfed in by seaturtle[bot]` once. it converges: a set of its own
output is a no-op.

### the contract (settled by prior art + the vision)

- `--mode plan|apply`, plan default · `--auth as-ehmpath|as-human`, as-ehmpath default
- `--from <path|@stdin>` for the body · `--output tree|json`
- apply: PATCH `repos/<o>/<r>/pulls/<n>` via `gh api --input -`, read back, sha256 compare; equal hash = no-op
- refusals before any write: empty input · over-cap (description 65536) · no pull found · unusable
  credential. each prints `✋ ConstraintError:` with a pasteable fix, on stdout and stderr, exit 2
- `--help` on each verb names usage, inputs, and an example
