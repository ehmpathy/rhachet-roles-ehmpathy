## .the repair — strip, then sign once

`as_pr_body_attributed` = `get_clean_pr_body` + `\n\n---\n🐢🌊 surfed in by seaturtle[bot]`. the strip
drops each whole line the classifier marks foreign, with the blanks and `---` rule just above it:
1. a `Co-authored-by:` line, any case (the harness writes `Co-Authored-By:`)
2. a line that IS the harness claude line: optional `🤖`, `Generated with`, `Claude Code` bare or as
   a link, end of line. prose that names the phrase mid-sentence stays (description [case13])
3. a prior footer line
4. blank tail trimmed. blank runs the caller wrote elsewhere stay as written

a set of its own output is a no-op (case 2 [t2]). the plan names each strip it made and shows
the body as it would land, so the edit never surprises.

## .the contract

- `--mode plan|apply`, plan default · `--auth as-ehmpath|as-human`, as-ehmpath default
- target: the open pull of the cwd branch, `--pr <n>` overrides (F1); `--in <owner/name>` for the repo
- title: `--title '<title>'`, one line (F2). body: `--from <path|@stdin>`
- get: `--output tree|json|text`; text is the bare field, for a pipe (F9). set: `--output tree|json`
- apply: PATCH `repos/<o>/<r>/pulls/<n>`, read back, compare; equal = no-op
- refusals before any gh call: empty or wordless body (F10), over the 65536 cap, empty or
  multi-line title, absent flag. before any write: no pull, unusable credential, github's 422 (F8)
- no quota gate (F3); no secret-shaped refusal (F4)
