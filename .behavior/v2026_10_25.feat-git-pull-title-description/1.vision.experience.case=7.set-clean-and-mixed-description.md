# case 7 — set-clean-and-mixed-description · happy · critipath

**narrative**

the driver writes its pull body by hand this time: a summary, a test list, no attribution of any
kind. it sets it. there is naught to strip, so the skill must still append the seaturtle line —
the append is not a side effect of a replace. the pull ends in exactly one footer.

later a human pastes an old body back from a scratch file: it carries the claude line, a prior
seaturtle footer, and a `Co-Authored-By:` trailer with an email, all at once. the driver sets it.
every attribution form and the trailer are stripped, one footer is appended. the email never
reaches the public pull.

critipath: the clean body is the most common set a driver makes. if the append rode only on the
claude-line branch, every hand-written body would ship with no attribution, and no other paved
path sets a body.
