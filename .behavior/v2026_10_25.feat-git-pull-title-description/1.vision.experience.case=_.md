## .forbidden cells — barred attempts, each an invariant

- a set with empty input never reaches github.
- a call that finds no pull (fresh branch, main with no `--pr`, or a number no pull holds) never reaches a write.
- a set over its noun's cap never reaches github.
- a call with an unusable credential never reaches github, and never swaps to the other auth.
- a set on a pull another login opened never reaches a write.
- a `get --to` past the repo root, at a directory, or at a tracked file never writes a file.

## .content invariants — what every allowed description set stores

- never `Generated with Claude Code` on a line of its own, in any form.
- never a `Co-authored-by: name <email>` trailer, in any case.
- exactly one seaturtle attribution, at the end.
- the one exception to the first two: a line inside a closed code fence is quoted text, kept as
  written. an unclosed fence shelters naught.
