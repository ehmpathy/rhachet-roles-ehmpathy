# 1.vision — pin each role's boot budget

## .the outcome world

each registered role's `boot.yml` carries `budget.tokens`, pinned at the next 1,000 above its
measure. a brief added to `always.say` that pushes a role over its pin fails in two places:

1. `npm run build` → `repo introspect` halts with `✋ ConstraintError: over budget`, and names the
   subjects a drop of each recovers (rhachet's own gate, `assertRegistryWithinBudget`)
2. `boot.budget.integration.test.ts` fails, per role and per view (src spec, linked consumer
   spec), with `Expected <= pin, Received <measure>`

before: every role read `unlimited budget`. mechanic grew to 66k tokens with no signal.
after: growth is a deliberate act — the author raises `budget.tokens` in the same diff, and a
reviewer sees the raise.

**aha**: the pin cuts naught today. it makes the next 1,000 tokens a reviewed decision rather than
drift.

## .the measure

`npx rhachet roles cost --all`, 2026-10-20, rhachet 1.50.0, o200k_base, pins in place:

| role | src spec | linked (consumer view) | pin | headroom (src) |
|---|---:|---:|---:|---:|
| mechanic | 66,338 | 65,126 | **67,000** | 662 |
| architect | 17,246 | 17,300 | **18,000** | 700 |
| ergonomist | 9,821 | 9,843 | **10,000** | 157 (linked) |
| ecologist | not registered | — | none | — |
| librarian | not registered | — | none | — |

- the pin sits at the next 1,000 above the largest view. neither view bounds the other: src
  renders a longer `<also>` roster (it lists unshipped test files), linked renders a longer path
  prefix. so the test grades both, and `repo introspect` grades dist
- a declared pin adds 16 tokens of stats chrome (mechanic src `66,322 → 66,338`); every pin
  still clears
- ecologist + librarian: `getRoleRegistry.ts` registers neither (ecologist is commented out;
  librarian has no role definition). no consumer boots them, `roles cost --all` sweeps neither,
  and neither holds a `boot.yml`. they ship no boot to pin

## .mental model

"a weight limit on the boot." the author's word: pin, cap. rhachet's word: `budget.tokens`.

## .the precondition — the install cure, in #1018

rhachet 1.50 `repo introspect` refuses a role hook that boots a role
(`assertRegistryHooksNoRoleBoot`), so `pnpm install` dies. the removal of those four hooks ships
in its own pr, #1018. this pr rebases onto main once #1018 lands and holds only the boot budgets
(F6).

## .evaluation

- pros: two independent gates, both rhachet's own instrument; zero new tool
- cons: headroom is thin (ergonomist 157 tokens linked); a small brief edit trips it — by design
- edge: `roles cost` exits 0 over budget (a report), so the test asserts the numbers, never exit
- edge: the test parses report prose; an unparseable report throws with the full output
