# wish: git.commit reads keyrack.yml org as a scalar or a list

task: ehmpathy/rhachet-roles-ehmpathy#1480

## .the defect

git.commit reads `.agent/keyrack.yml` `org:` as one scalar line. a repo whose keyrack declares `org:` as a list (block form or flow form) reads as no org, so every `git.commit.set` refuses with `.agent/keyrack.yml#org required` and names a remedy that cannot help. keyrack itself accepts the list form, so the commit gate and keyrack disagree on one file.

a second defect: the published package files ship mode 0555, so a consumer cannot hold a local pnpm patch of any file in this package (`ERR_PNPM_PATCH_FAILED`).

## .done means

- git.commit reads `org:` as a scalar or a list (block and flow form)
- the gate rule for several orgs is chosen, and declared in the skill help
- an unreadable `org:` is refused with the shape it read, never a grant to run
- a multi-org suite is green: scalar, block list, flow list, empty list, `org:` absent, a list where one org is blocked; each asserts the gate org and the exit code
- package files ship 0644 / 0755
- a pr on ehmpathy/rhachet-roles-ehmpathy, ready for review: suite green on ci, title final

no merge, no release.
