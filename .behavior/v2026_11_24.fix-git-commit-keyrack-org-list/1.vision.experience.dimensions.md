# 1.vision.experience.dimensions

two behaviors share this wish. each owns its own space.

## behavior A — the org gate reads `org:`

actor: a clone (or human) runs a gated skill in a repo; a human reads the refusal.

| dim | axis | values |
|---|---|---|
| A1 | `org:` shape in `.agent/keyrack.yml` | scalar (bare) · scalar (quoted or with an end-of-line comment) · scalar `@all` (grove scope) · block list · flow list · list with an invalid member (sigil `@all`/`@this`, or a repeat) · empty list · absent · unreadable |
| A2 | member count | 0 · 1 · n |
| A3 | meter verdict, worst member | all allowed · one blocked · one unset with no `@all` · `@all` fallback allowed · meter file absent · meter damaged |
| A4 | gated surface | `git.commit.set` · `git.commit.push` · `git.branch.uses` · `git.branch.cutover --mode plan` (quota preview) |
| A5 | reach of `.agent/keyrack.yml` | readable · file absent · file unreadable (permission) · repo unreadable (git refuses, e.g. dubious ownership) · repo absent (no git repo) |

orthogonality: A1 is the file shape, A3 the human's meter, A4 the caller, A5 whether the file can be reached at all. none constrains another, except as the forbidden cells below note.

A5 ≠ readable fixes A1 unread: the gate never sees a shape. so A5 faults sit beside A1 faults, one row per fault, never crossed with A1 or A3. each refuses with its own lift (a file or repo fix), never a meter grant.

A2 is not fully orthogonal to A1, and is kept as an axis on purpose. a scalar fixes n=1; empty, absent, and unreadable fix n=0. only the two list forms range over 0, 1, or n. the axis stays because member count drives the gate loop (n members → n meter reads), the one place the list forms differ from a scalar.

A3 "meter file absent" differs from "meter damaged". absent fails closed with `no org config for <org>` (`git.commit.operations.sh:2140-2144`), which `allow --org` cures. damaged fails closed as a malfunction (exit 1), which `allow --org` cannot cure.

walked product, reduced:

- A4 collapses for the verdict: all four surfaces call one `check_org_blocker`. it does not collapse for the print: push has its own remedy branch, and the cutover preview folds the refusal into one quota line with the list branches beneath. demo on `git.commit.set`, plus one push / branch.uses demo (case 6); the preview is itemized.
- two moments sit beside the gate walk: a clone reads `--help` before a run, and a human applies the printed remedy after a refusal. both are demoed (cases 6, 2, 3).
- A1 × A2: scalar ⇒ n=1; block and flow ⇒ 1 or n (0 = the empty list); empty, absent, unreadable ⇒ n=0 (A3 never reached).
- scalar `@all`: n=1, the member `@all`. the meter's `@all` verdict decides. extant read, kept (F4).
- list with an invalid member: parses, then fails keyrack's member rules. refused before the meter read, like unreadable, but with keyrack's own words (A.10b).
- A1 ∈ {empty, absent, unreadable} × A3: forbidden. the gate refuses before it reads the meter. one row per shape, not per meter state.
- A1 ∈ {scalar, block, flow} × A3: every cell real. scalar × A3 is the extant behavior (regression row). block and flow differ only in parse, so they share A3 rows; the demo crosses them (case 1 block, case 2 flow).
- A3 = meter damaged, or meter file absent: extant behavior, unchanged by this wish. one regression row each.

## behavior B — the installed package file modes

actor: a consumer repo that installs this package and tries `pnpm patch`.

| dim | axis | values |
|---|---|---|
| B1 | lifecycle stage | packed tarball · fresh install · after `rhachet roles link` · after a re-install from the pnpm store |
| B2 | file kind | role resource (brief, skill) · other dist file (js, boot.yml) |

orthogonality: B1 is when (the lifecycle), B2 is which file. every stage holds both kinds, so neither axis fixes the other. a hidden axis would surface if one stage held only one kind. none does: the link step touches only role resources but leaves the other files in place.

walked product:

- packed × any: modes as on disk at build (0664 / 0775 here). no 0555 source.
- fresh install × any: pnpm writes 0644 / 0755.
- after link × role resource: **0555** (rhachet `setDirectoryReadonlyExecutable`). × other: unchanged.
- after re-install × role resource: **0555** persists. pnpm hardlinks files to its store; the chmod hit the store inode.
- ⇒ only one cell carries the defect, and its cause lives in `ehmpathy/rhachet`, not in this package.
