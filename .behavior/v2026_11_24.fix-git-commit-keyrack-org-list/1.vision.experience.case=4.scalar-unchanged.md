# case=4 — a scalar repo sees no change

feel: happy (t0), sharp (t1) · care: critipath · cell: A.11

## narrative

all 72 local repos declare a scalar `org:` (53 of them `org: ehmpathy`). a clone in any of them commits today and must commit the same way tomorrow. a blocked scalar org refuses with the same words and exit as before. one scalar change rides along: a quoted or commented scalar now reads as its plain org (`[t2]`).

`[t2]` is a scalar fix, not a list one. today the reader strips all whitespace, so this line reads as the org `'ahbode'#main`, matches no meter key, and falls to `@all: allowed`: the same fail-open class as the flow list. the new grammar reads quotes and comments the way yaml does.
