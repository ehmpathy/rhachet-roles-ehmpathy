### the 16 acceptance failures, diagnosed

every one prints `OPENROUTER_API_KEY locked — run: rhx keyrack unlock --owner ehmpath --env prep --key OPENROUTER_API_KEY`, though that exact unlock was in force (`expires in: 540m`). cause, from `getOneGuardBorderBrainCreds.ts:31-46`: the guard prefers the key from the env, and falls back to keyrack, which needs a `keyrack.yml` in the cwd. these cases run the hook from a temp dir with none, so an unlocked session key cannot reach them; only an exported env key can. ci exports it, and all four suites pass there (`gh pr checks 1222`: the three `injection*` explicit shards and `test-acceptance-locally` → `SUCCESS`). a local pass needs the secret value exported into the shell, which this driver does not handle. handed off: `5.3.verification.handoff.v1.to_foreman.md` §3. the `git.commit.push` acceptance suite, the one this change touches, passes: 7/7
