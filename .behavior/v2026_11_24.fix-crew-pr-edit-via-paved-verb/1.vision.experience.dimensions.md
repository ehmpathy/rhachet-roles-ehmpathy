## .forbidden and impossible combinations

- a driver edit via a paved verb lands with no seaturtle footer → **forbidden (nurture)**: an attempt is possible; the verb signs every body it writes (`git.pull.description.set.sh:115`)
- push rewrites an extant pr's title or body → **forbidden (nurture)**: a change to push could attempt it; push must stay a findsert (`git.commit.push.sh:683-690`)
- D5=`absent` × D6=`present` → **impossible (nature)**: the pointer ships in a release after the verbs; no install holds the pointer without the verbs
- D7=`multi-line` × D2=`body` → **impossible (nature)**: a body spans lines by its nature; multi-line is a defect only for a title
