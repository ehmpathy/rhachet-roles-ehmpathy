
### `$GIT_REPO_ROOT`, and why the obvious fix is wrong

never touches the root, so the fold would block a reach nobody made. added only when the var

## the two new items, recorded rather than fixed

**batch multi-file cross-repo read** — verified real. read mode is one file per call

the fix, if the cost proves real, is a shared resident gate for the family, not a benchmark on
the newest member. recorded alongside the 9-copy containment wish, which touches the same
