# 5.1 execution — token-derived seaturtle identity

## goal

`git.commit.set` selects the commit author identity by the active token's kind, so the squash author always equals the PR opener → 2 contributors. human co-author retained.

## design

- **pure transformer** `get_one_seaturtle_identity` (token string → name + email):
  - token prefix `ghs_` (app installation) → **alternative** = `seaturtle-by-ehmpathy[bot]` + `<id>+...@users.noreply.github.com`
  - token prefix `ghp_` / `github_pat_` (pat) → **standard** = `seaturtle[bot] <seaturtle@ehmpath.com>`
  - empty / unknown → **standard** (fail-safe; preserves current behavior)
- lives in `keyrack.operations.sh` (token logic colocated), pure + hermetically testable with fake tokens.
- `git.commit.set` sources it; in real use fetches the token (best-effort) and derives identity; in `NODE_ENV=test` defaults to standard (keeps tests hermetic, no keyrack boundary).
- human `Co-authored-by:` trailer unchanged (retained).
