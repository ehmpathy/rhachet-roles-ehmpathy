## empty cells, answered aloud

every impossible cell carries its reason in the dimensions grid footnotes (1–5). in short:
- **director × cost / edit / rename** — a seat consumes a spec; it never authors one.
- **reviewer × boot / edit / rename / cure** — a reviewer reads and runs proof commands only.
- **ci × boot / cure / edit / rename** — ci runs suites; it observes edits only through the cost column.
- **director × happy alterpath** — none: 101 offers the director one path (boot, then cure).

critipaths: 0, 1, 4, 5, 7, c2, c6, c10, c17, c18, c19 — each demoed, standalone or inside a denser case, and each caught by a real test (`5.3.verification.yield.md`).
