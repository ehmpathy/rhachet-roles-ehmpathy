# case 5 — a director's cure trips a mechanic hook

sharp · critipath · density 1 (B7) · fail-safe spotlight · the main reason 101 exists

## narrative

> a director, in seat, patches a crew verb and writes `echo "$state" > /tmp/crew.state`. the
> `pretooluse.forbid-tmp-writes` hook blocks the write before it lands and names the fix: write under
> `.temp/` in the repo. no brief booted for this; the hook carried the rule at 0 boot tokens. the same
> holds for a gerund in a comment, `2>&1`, a reach into a peer repo, a background test run.

## timeline (sketch)

```
given('[case5] a seat that enrolls role=mechanic at any subject focus')
  when('[t0] a tool call writes to /tmp')
    then('the hook blocks it before the write')                    # fast
    then('the block names the rule and the safe path')             # loud + teaches
    then('the block is identical to a full mechanic seat')         # by construction (c20)
```

## fail-safe

hooks bind to the role, never the subject: `getMechanicRole.ts:68-163` registers 14 hooks on the role;
rhachet's `getSettingsForRoles.js` filters hooks by author only. so 101 cannot drop one, by
construction.
