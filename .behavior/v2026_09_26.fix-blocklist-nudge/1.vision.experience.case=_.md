# 1.vision.experience.case=_ — the inventory

every live cell from `1.vision.experience.dimensions.md`, verdicted. each row is keyed on the tuple
**P · B · A · C · D · K** (actor · shape · kinds present · attempt · mode · concurrency), with only
declared axis values. `*` = any value, because a named collapse rule makes that axis inert for the
row; `—` = the axis does not apply to this actor.

care = freq × cost. freq: how often a bot or human meets it. cost: what a bad experience wastes.
feel = happy (smooth) / sharp (a block, a refusal, an interrupt).
