# case=6 — a known alternative, alone

demos inventory #1 (`single · {alt}`).

## .narrative

a mechanic in the middle of a debug session types `ls src/domain.roles/mechanic/inits/`. no
compound, no typo: just a habit from every other shell. today the block prints ~200 lines, and
`tree` sits on line ~190 between `tail` and `wc`.

with the nudge, the render is five lines. it names `ls`, offers `tree <dir>` and
`rhx globsafe`, and stops. there is no split tip, because there is no second part. the mechanic
reruns as `tree -L 1 src/domain.roles/mechanic/inits/` and never sees the allowlist at all.

this is the commonest block of all — the single habitual command — so its render must be the
shortest one.

## .timeline

```
given('[case6] a single command whose head has an inventory entry')
  when('[t0] the bot runs `ls src/domain.roles/mechanic/inits/`')
    then('exit 2')
    then('the inventory alternatives for `ls` come first: `tree`, `rhx globsafe`')
    then('no split tip renders — there is no other part to name')
    then('the ledger row records { kind: alt, head: ls, verdict: nudged }')
  when('[t1] the bot reruns as `tree -L 1 src/domain.roles/mechanic/inits/`')
    then('exit 0, silent')
```
