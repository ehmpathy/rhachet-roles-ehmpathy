# case=4 — the bust-through retry, from both sides

demos inventory #14 (the bot) and #15 (the sponsor). the headless case (#16) is itemized.

## .narrative — the bot

the mechanic read the nudge for `python3 -c "…"`, judged that no paved path fits and the need is
one-off, and retried the exact command inside the 60s window. the hook lets it through to the
human, and appends a ledger row marked `retried` — the loudest demand signal there is: a bot
that read the alternatives and still insisted.

## .narrative — the sponsor

today the sponsor gets claude code's bare permission prompt: `Bash: python3 -c "…"` — allow or
deny. it does not say that the bot was already nudged, what it was offered, or that it chose to
insist. the sponsor must reconstruct the context from the transcript, or approve blind.

with the change, the hook answers the retry with `permissionDecision: "ask"` and a reason. the
prompt now carries one line of context: *"retried after a nudge — no paved path fits `python3`;
the ledger records this ask."* or, for an `alt` part: *"retried after a nudge — paved
alternatives were offered: `rhx grepsafe`."* the sponsor sees at a glance whether to allow, or to
deny and point the bot at the paved path. the prompt teaches the human what the nudge taught the
bot.

## .the prompt (sketch)

```
Bash: python3 -c "import json; …"

hook reason: 🐢 retried after a nudge
   ├─ no paved path fits `python3`
   └─ the ledger records this ask (retried)

allow?  [y] yes   [n] no
```

## .timeline

```
given('[case4] a command blocked once within the window')
  when('[t0] the bot retries the exact same command')
    then('the hook emits permissionDecision: "ask" — the gate hands the call to the human')
    then('the ledger gains a row { verdict: retried, kind: <alt|typo|novel> }')
  when('[t1] the sponsor sees the prompt')
    then('the prompt reason says the bot was nudged and retried')
    then('for an `alt` part, the reason names the paved alternatives that were offered')
    then('for a `novel` part, the reason says no paved path fits')
    then('the sponsor can deny and redirect without a read of the transcript')
  when('[t2] the ledger write fails (read-only dir)')
    then('the ask still goes to the human — a ledger failure never converts a retry into a block')
    then('the reason text notes the row was not recorded')
```

⚠️ `[t2]` fails open on the **ledger**, never on the **gate**: the gate has already chosen to let
the human decide. the ledger is telemetry, and the loss now shows in the prompt the human reads.
