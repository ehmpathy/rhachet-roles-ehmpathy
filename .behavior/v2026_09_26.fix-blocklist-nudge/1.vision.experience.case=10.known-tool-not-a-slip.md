# case=10 — a known tool is never read as a slip

demos the `alt` kind's rank boundary: a head the inventory knows (`grep`) gets its paved
alternatives, and no fuzzy "nearest" rows. found on the 5.3 live walk; catalog row #62.

## .narrative

a mechanic runs the wish's own example, `git diff --stat && grep -rln 'reef' src/`. `grep` has an
inventory entry, so the nudge already knows what the mechanic meant: search text. it offers the two
paved homes — `rhx grepsafe` and `rhx git.repo.get lines` — and stops.

before the fix, the fzf tier also read `grep` as a slip and found its letters in order inside
`git.repo.test` (g·it, r·e·p·o). nineteen `rhx git.repo.test …` rows followed the two right
answers, under "nearest paved patterns". the mechanic had to read past a wall of test commands
that have no relation to a text search — the same wrong-fit harm case=7 refuses for a weak typo.

the fzf tier exists for slips: `grpsf` (no inventory entry) still finds `rhx grepsafe`, and
`rpotst` still finds `rhx git.repo.test`. a known tool is never a slip, so the tier skips it.
