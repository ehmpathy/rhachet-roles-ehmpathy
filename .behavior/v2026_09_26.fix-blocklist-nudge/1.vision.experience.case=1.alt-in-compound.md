# case=1 — known alternatives, inside a compound

demos inventory #4 (`compound-1 · {alt}`), #7 (`compound-n · {alt}`), and #11
(`compound-n · {alt,novel}`).

## .narrative

a mechanic wants to see which files touch the blocklist. it types
`git diff --stat && grep -rln 'blocklist' src/`. today the hook dumps ~200 allowlist lines, and
the mechanic, unsure what fits, delegates to a subagent instead.

with the nudge, the hook names the one part that failed — `grep -rln 'blocklist' src/` — and says
*"grep has a paved path"*: `rhx grepsafe`, or `rhx git.repo.get lines --words`. it also points out
that `git diff --stat` was fine on its own. the mechanic reruns as two calls and moves on.

next it types `cd src && ls && grep -rn blocklist .` — three parts fail, all of kind `alt`.
the nudge names all three at once, each with its paved form (`cd` → *"pass paths"*, `ls` → `tree`,
`grep` → `rhx grepsafe`), so the mechanic rewrites once instead of three blocks in a row.

later the same mechanic types `cd src && ls && python3 -c "import json; …"`. three parts fail, of
two kinds. the nudge names all three in one render: `cd` → *"run from the cwd, pass paths"*,
`ls` → `tree` or `rhx globsafe`, and `python3 -c …` → *"no paved path fits — pave a skill"*. the
mechanic fixes all three in one pass instead of three blocks in a row, and the `python3` row lands
in the ledger as `novel`.

```
   │

   │  ├─ [p] rhx grepsafe
   │  ├─ [p] npx rhachet run --skill grepsafe
   │  ├─ [p] rhx git.repo.get
   │  └─ …
   │
   ├─ tip: a compound runs only if every part is paved.
   │  └─ `git diff --stat` is paved on its own; split the call.
   │
```

```
   │
   └─ still need this exact command? retry it once; the human will be asked.
```

## .timeline

```
given('[case1] a compound whose second part is grep')
  when('[t0] the bot runs `git diff --stat && grep -rln blocklist src/`')
    then('exit 2, header `✋ ConstraintError: this command is not paved`')
    then('the blocked part names only `grep -rln blocklist src/`')
    then('the first candidates are the grep inventory entries, in inventory order')
    then('the full allowlist is NOT dumped')
    then('total candidates ≤ 21')
    then('a ledger row records { kind: alt, part: grep …, verdict: nudged }')
  when('[t1] the bot reruns as `rhx grepsafe --pattern blocklist --path src/`')
    then('exit 0, silent')

given('[case1n] a compound with three un-paved parts, all `alt`')
  when('[t2] the bot runs `cd src && ls && grep -rn blocklist .`')
    then('exit 2, and all three parts are named in one render')
    then('each part carries its own inventory alternatives')
    then('no pave headline — every part has a paved form; the pave footer stays one line')
    then('the ledger gains three rows, all `alt`')

given('[case1m] a compound with three un-paved parts of two kinds')
  when('[t3] the bot runs `cd src && ls && python3 -c "…"`')
    then('exit 2, and all three parts are named in one render — `cd`, `ls`, `python3`')
    then('`cd` and `ls` carry their inventory alternatives; `python3` reads `no paved path fits`')
    then('the pave nudge names the novel part')
    then('the total candidate count across all parts stays ≤ 21')
    then('the ledger gains three rows — two `alt`, one `novel`')
```
