# case=7 — a weak fuzzy fit is withheld

demos the weak-fit edge of inventory #3 (`single · {novel}`).

## .narrative

a mechanic wants disk usage for the build output and types `du -sh dist`. `du` has no inventory
entry. a naive fuzzy rank would find `[p] diff` — two edits from `du` — and lead with it, as if
*"did you mean diff?"* were a sane answer. a mechanic that trusts the top hit would waste a turn
on a command that has no relation to its goal.

the nudge refuses to guess. `du` is two letters long, and at that length two edits reach almost
any short word, so the typo and fzf tiers do not apply. no other tier matches. the render says
*"no paved path fits"*, offers no candidate, and headlines the pave-a-skill nudge. the mechanic
knows at once that there is no paved answer, rather than chase a false one.

## .the render (a pre-implementation sketch; the hook snapshots pin the shipped render, incl. its 🥥 retry hint)

```
✋ ConstraintError: this command is not paved

   ├─ blocked part
   │  └─ du -sh dist
   │
   ├─ no paved path fits this command
   │
   ├─ 🐚 pave it instead
   │  └─ if this need will recur, pave an rhx skill for it (or ask your human to)
   │
   └─ truly one-off? retry it once; the human will be asked, and the ledger records the ask.
```

## .timeline

```
given('[case7] a novel command with a short head that sits near a paved head')
  when('[t0] the bot runs `du -sh dist`')
    then('exit 2')
    then('the typo and fzf tiers skip `du` — heads under 3 letters are exempt')
    then('the render declares `no paved path fits`')
    then('`[p] diff` is NOT listed — a weak hit is withheld, not shown as a fit')
    then('the ledger row records { kind: novel, head: du }')
```
