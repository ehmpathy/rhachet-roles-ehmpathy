# case=5 — a human types the old `--who @me` (happy alterpath, silent alias)

## .narrative

muscle memory, or an old command in shell history. kai types `@me`. it behaves exactly as
`@self`: same git config read, same roster check, same refusals, same `source: self`. it is
never advertised — no help line, no coconut, no refusal, no nudge names it. `@self` is the one
documented form, so new habits form on `@self` alone while old ones keep to work.
