# case=11 — a damaged global blocker or org meter fails closed (sharp)

## .narrative

a human pauses every clone with `git.commit.uses block --global`, or scopes commits per org with
`--org`. those two files live under `~/.rhachet/…/.meter/`. a write that stops midway, or a
directory at the path, once read as "no blocker set" — so a damaged pause let the fleet commit.
now a damaged global blocker or org meter refuses every commit, names the file, and prints the one
remedy that clears every damaged shape: `rm -r`. a well-formed permissive file still lets the
commit through.

## .timeline

```
given the org meter ~/.rhachet/storage/repo=ehmpathy/role=mechanic/.meter/git.commit.uses.org.jsonc
  will not parse
when [t0] the clone runs rhx git.commit.set -m @stdin --mode apply
then exit 1
  and stdout + stderr:
    🐢 bummer dude...

    🐚 git.commit.set
       └─ 💥 MalfunctionError: org meter file corrupt

       the org meter file cannot be read:
         ~/.rhachet/storage/repo=ehmpathy/role=mechanic/.meter/git.commit.uses.org.jsonc

    until it parses, every commit is blocked. a human may inspect or clear it:
      $ cat ~/.rhachet/storage/repo=ehmpathy/role=mechanic/.meter/git.commit.uses.org.jsonc
      $ rm -r ~/.rhachet/storage/repo=ehmpathy/role=mechanic/.meter/git.commit.uses.org.jsonc
  and "allow --org" is never printed beside it — it cannot write into a file that will not parse

given a directory sits at the org meter path
when [t1] the clone commits
then the same refusal, and the printed remedy is `rm -r` — the one command that clears a directory

given the global blocker file is 0 bytes — or a directory sits at its path
when [t2] the clone commits
then exit 1, "global blocker file corrupt" on stdout + stderr,
  "the global blocker file cannot be read", and the remedy `rm -r` — never `allow --global`

given the global blocker file is well-formed and permissive
when [t3] the clone commits
then exit 0 — the gate is not blanket

when [t4] a human runs rhx git.commit.uses get --global, or get, or allow --org, against a damaged file
then each reads "blocked (file corrupt)" or refuses by name — never "not blocked"
```

## .proof

`git.commit.set` `[case50]` [t0]–[t2] (global) · `[case51]` [t0]–[t2] (org) ·
`git.commit.uses` `[case33]` [t0]–[t8] (global `get` / `get --global`) · `[case37]` [t0]–[t4]
(org `allow` / `block` / `get`).
