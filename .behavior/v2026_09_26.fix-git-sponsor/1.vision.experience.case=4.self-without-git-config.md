# case=4 — a fresh machine with no git identity (sharp)

## .narrative

a new laptop; `git config user.email` is not set yet. the clone tries to commit. there is no bind,
and git config holds no complete identity to fall back on. the commit refuses and names both
fixes: set git config (which also fixes the human's own commits), or bind a sponsor. it never
guesses a half, and never asks gh.

## .timeline

```
given a human's laptop with git config user.email unset
  and no sponsor bound in this worktree
when [t0] the clone runs rhx git.commit.set -m @stdin --mode apply
then exit 2
  and stdout + stderr:
    🐢 bummer dude...
    🐚 git.commit.set
       └─ ✋ ConstraintError: no sponsor for this commit

       no sponsor is bound to this tree, and this machine's git config
       holds no complete identity:
         git config user.email is unset.

    ask your human to set it — then commits name them:
      $ git config --global user.email "you@example.com"
    or to bind a sponsor, in this tree:
      $ printf 'Name <email>' | rhx git.commit.sponsor set --who @stdin
      $ rhx git.commit.sponsor set --who "Name <email>"
  and no gh command ran

given git config user.email is set, user.name is unset
when [t1] the clone commits
then exit 2, the error names "git config user.name is unset"
  and the fix line reads: $ git config --global user.name "Your Name"
  and no half is guessed — the email's local part is never used as a name

given both halves unset
when [t2] the clone commits
then exit 2, the error names both, with one fix line per half

when [t3] the human runs the git config fix, and the clone commits again
then case=1 — the trailer names the human, from: git config (this machine)
```
