## .how care is derived — care = freq × cost

| freq | means |
|---|---|
| **hi** | every human, every fresh worktree |
| **mid** | a real share of hosts or sessions (a new laptop, the clone's machine, a `!` command) |
| **lo** | a rare config — a malformed address, a placeholder name, a damaged file |

| cost if broken | means |
|---|---|
| **hi** | a wrong human in a public trailer, a clone as its own sponsor, or a human blocked with no fix named |
| **mid** | a human or clone is refused but told the fix |
| **lo** | a cosmetic trace (a label), with a live path beside it |

**care:** any freq × hi cost, or hi freq × mid cost → **critipath**. all else → **alterpath**.

## .forbidden cells — rejection invariants

| cell | why forbidden |
|---|---|
| any sponsor path reads gh (`gh api user`, `gh auth status`, `GH_TOKEN`) | wisher: "never to use gh for @self set. only ever git config" |
| a commit uses git config when a bind is present | wisher: explicit bind wins |
| a commit falls back to git config when the bind file is corrupt | a damaged bind hides an intended sponsor; to substitute is a failhide |
| a commit names a roster identity as sponsor | the clone's machine; a clone cannot answer for its own change |
| a guessed half — the email's local part as a name, a hostname-derived email | a guessed identity is a fabrication (case=4) |
| `source: me` in any render | the value renames with the flag (`self`); legacy files map on read |
| `@me` named in any help, refusal, coconut, or nudge | wisher: "we shouldnt even mention that @me works anywhere" |
| a `bang`-channel refusal that reads as a verdict on the human ("only humans can run this") | the wisher met exactly this; it blames the person for the pipe |
