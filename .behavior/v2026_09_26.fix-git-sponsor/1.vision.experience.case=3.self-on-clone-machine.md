# case=3 — the clone's machine: no implicit sponsor (sharp) 🎯

## .narrative

the clone lives on its own machine, where git config names a seaturtle identity. it tries to
commit. there is no bind, and git config names a clone — so, by definition, this is the clone's
machine, and git config cannot answer for the change. the commit refuses and says a human must
bind. kai attaches a terminal and, from habit, tries `@self` — that reads the same git config, and
refuses the same way. he names himself instead, and the clone's next commit carries him.

## .timeline

```
given the clone's machine: git config user.name = "seaturtle[bot]", user.email = "seaturtle@ehmpath.com"
  and no sponsor bound in this worktree
when [t0] the clone runs rhx git.commit.set -m @stdin --mode apply
then exit 2
  and stdout + stderr:
    🐢 bummer dude...
    🐚 git.commit.set
       └─ ✋ ConstraintError: no sponsor for this commit

       no sponsor is bound to this tree, and this machine's git config
       names a clone:
         seaturtle[bot] <seaturtle@ehmpath.com>
       ...so this is the clone's machine, and it cannot answer for the change.

       ⛔ you cannot fix this yourself. a sponsor is bound by a human,
          at a terminal.

    ask your human to run, in this tree:
      $ printf 'Name <email>' | rhx git.commit.sponsor set --who @stdin
      $ rhx git.commit.sponsor set --who "Name <email>"
  and no gh command ran

when [t1] kai, at a terminal on this machine, runs rhx git.commit.sponsor set --who @self
then exit 2
  and the refusal reads "--who @self read a clone's identity on this machine"
  and it names the same two forms

when [t2] kai runs rhx git.commit.sponsor set --who "Kai Nalu <kai@example.com>"
  and the clone commits again
then the trailer reads: Co-authored-by: Kai Nalu <kai@example.com>
  and the plan tree shows from: bound (this tree)
```

the roster is the one `is_identity_robot` already reads (`keyrack.operations.sh`): every seaturtle
bot and clone name and address. fast · loud · teaches the fix, at both the commit and the bind.
