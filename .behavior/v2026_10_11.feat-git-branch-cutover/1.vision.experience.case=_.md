the walked product of `1.vision.experience.dimensions.md`. every cell carries a verdict:
**demoed** · **itemized** · **forbidden** (nurture — the skill rejects it; an invariant) ·

## .D8 source kind — a collapsed axis

D8 is behavior-identical across its three values: cutover reads `HEAD` and the tree, and never
writes the source ref (inv-9). so blocks A–D hold for each value unchanged; only the report's
`from:` line differs. one row per value, each with its verdict and the collapse reason.

| D8 value | verdict | feel × care | collapse reason / what differs |

| `main` (accidental edits on main) | itemized | happy × alterpath | same pipeline; `from:` names `main`. main never moves (inv-9); its dirty tree leaves with the carry |
| detached HEAD | itemized | happy × alterpath | same pipeline; `from:` names the sha, since no branch name exists |

## .invariants (forbidden + rejection rules)

| id | invariant |
|----|-----------|
| **inv-0** | **above all: untracked files are never written, moved, or deleted. a collision with a tracked path refuses; it never resolves** |
| inv-1 | refuse when `--into` exists locally or on origin |
| inv-2 | every `--cherry-pick` names a real commit, checked before any mutation |
| inv-3 | refuse a merge commit as a pick |
| inv-4 | a pick whose change is already on `origin/main` (ancestor, squash, or a duplicate sha) adds no commit; it is dropped and reported, and plan marks it when visible pre-replay |
| inv-5 | no cut without a successful fetch of `origin/main` |
| inv-6 | refuse while any git operation is in flight in the worktree |
| inv-7 | the new branch has no upstream on `origin/main` |
| inv-8 | `continue` / `abort` refuse when no cutover is in flight |
| inv-9 | never push, never force-push, never delete or move the source branch |
| inv-10 | tracked edits are parked in a private ref and byte-verified before any reset; the ref is dropped only after they land or are restored |
| inv-11 | gitignored files are never cleaned or moved by the cut, the carry, or abort |
| inv-12 | apply refuses without a granted `git.branch.uses` quota; an apply cut spends one unit, a refusal / plan / settle spends none |
