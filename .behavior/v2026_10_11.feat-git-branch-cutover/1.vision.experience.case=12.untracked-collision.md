# case=12: an untracked file collides with a path the new base tracks

**cell** A8 `untracked-collision` · sharp × critipath
**actor** mechanic

## .narrative

the mechanic drafted `src/tide/getTideAlert.ts` as a new, untracked file. meanwhile a teammate
merged a file at that same path to main. a branch switch onto fresh main would overwrite the
mechanic's draft — and an untracked file has no copy anywhere, not in git, not in a commit.

the skill sees the collision in preflight, before any mutation, in plan and apply alike. it refuses,
lists each path, and says the draft is untouched. it does not move the file aside, rename it, or
back it up on the caller's behalf — any of those is a write to untracked work. the caller decides
where the draft goes, then reruns.

## .sketch output

```
$ rhx git.branch.cutover begin --from @main --into turtle/tide-alerts-v2 --mode apply

🐢 bummer dude...

🐚 git.branch.cutover
   └─ ✋ ConstraintError: untracked files would be overwritten by the new base
      ├─ untouched, still on disk
      │  └─ src/tide/getTideAlert.ts (also tracked on origin/main @ 3c2b1a0)
      └─ fix: move or rename each file above, then rerun the same command
```

output rides stdout and stderr; exit `2`.

## .bdd

```
given('[case12] an untracked file at a path origin/main tracks', () => {
  when('[t0] cutover runs in plan or apply mode', () => {
    then('it refuses with ConstraintError and lists each path in collision');
    then('the untracked file is byte-identical to before, at the same path');
    then('no ref, index, or file changes; no private ref is written');
    then('exit 2');
  });
  when('[t1] the caller renames the draft and reruns', () => {
    then('preflight passes; the renamed draft stays untracked and untouched on the new branch');
  });
});
given('[case12b] the untracked file collides with a path a pick adds', () => {
  when('[t0] cutover runs', () => {
    then('the same refusal fires, before the cut, and names the pick that tracks the path');
  });
});
```
