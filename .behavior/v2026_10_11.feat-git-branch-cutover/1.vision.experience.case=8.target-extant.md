# case=8: `--into` already exists

**cells** A1 (local) · A2 (origin) · sharp × critipath
**actor** mechanic

## .narrative

the mechanic reuses a name it used last week. the branch still exists locally — or a teammate has
it on origin. a cutover onto it would clobber work or collide on the first push.

the skill refuses before any mutation, in plan and apply alike. it says where the name lives and
offers the fix: pick a fresh name. it does not offer to delete or overwrite the extant branch.

## .sketch output

```
$ rhx git.branch.cutover begin --into turtle/wave-report --mode apply

🐢 bummer dude...

🐚 git.branch.cutover
   └─ ✋ ConstraintError: --into turtle/wave-report already exists
      ├─ local: yes (@ 9f8e7d6)
      ├─ origin: no
      └─ fix: choose a fresh name, e.g. --into turtle/wave-report-v2
```

the origin variant reads `local: no` · `origin: yes (@ <sha>)`. output rides stdout and stderr;
exit `2`.

## .bdd

```
given('[case8] --into names a branch that exists locally', () => {
  when('[t0] cutover runs in plan or apply mode', () => {
    then('it refuses with ConstraintError and names where the branch lives');
    then('it suggests a fresh name');
    then('no ref, index, or file changes');
    then('exit 2');
  });
});
given('[case8b] --into names a branch that exists only on origin', () => {
  when('[t0] cutover runs in plan or apply mode', () => {
    then('it refuses and reports origin: yes');
    then('exit 2');
  });
});
```
