# case=2: single clean carry

**cell** C4 · apply · picks 1 · tree clean · outcome clean · happy × critipath
**actor** mechanic

## .narrative

the old branch `turtle/fix-tide` went stale: its remote was deleted after a squash-merge, and its
local refs point at a history main no longer shares. one commit, `d6e8e97`, holds a fix that
never shipped. the mechanic wants that one commit on a clean branch.

one call: it names the new branch and the one sha. the skill fetches, cuts the branch from the
fresh `origin/main`, replays the commit, and reports what landed — the new sha beside the old.
the mechanic is now on the new branch, one commit ahead of main, ready for `git.commit.push`.

## .sketch output

```

## .bdd

```
given('[case2] a stale branch with one commit worth keep', () => {
  when('[t0] cutover runs in apply mode with one --cherry-pick', () => {
    then('the new branch exists and HEAD is on it');
    then('the new branch parent chain starts at the fetched origin/main');
    then('HEAD carries the same change and message as the picked sha');
    then('the old branch ref is unchanged');
    then('the new branch has no upstream');
    then('exit 0, and the output names old sha → new sha');
  });
});
