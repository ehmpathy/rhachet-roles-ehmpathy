# case=6: pick conflict → settle → continue

**cell** C5 (+ C8, C12, C15) then D1 (+ D2) · sharp × critipath, then happy
**actor** mechanic

## .narrative

the mechanic carries three picks. main has since rewritten a file that pick 2 edits. the skill
replays pick 1, hits the conflict on pick 2, and stops — fast and loud. the tree is left mid-pick
so the mechanic can see the markers. the output names the commit that conflicted, the files, and
the exact paved commands to continue or abort. pick 3 waits; the uncommitted tree stays held
aside in its private ref, untouched.

the mechanic edits the file and stages it with `git.stage.add`. it runs continue too early once,
with a second file still in conflict — the skill refuses and lists that file. it fixes the second
file, stages it, runs continue again. the skill finishes pick 2, replays pick 3, lays down the
tree, and reports every pick that landed.

exit `2` — the caller must act.

## .bdd

```
given('[case6] three picks where pick 2 conflicts with origin/main', () => {
  when('[t0] cutover runs in apply mode', () => {
    then('pick 1 lands; the tree is mid-pick on pick 2');
    then('pick 3 has not been applied');
    then('the output names the conflicted commit, the files, and both settle commands');
    then('exit 2');
  });
  when('[t1] the mechanic settles one file and stages it', () => {
    then('no skill call; state holds');
  });
  when('[t2] the mechanic runs --continue with a second file still in conflict', () => {
    then('it refuses, lists the file still in conflict, and changes naught');
    then('exit 2');
  });
  when('[t3] the mechanic settles and stages the second file, then runs --continue', () => {
    then('pick 2 lands with its original message and author');
    then('pick 3 lands after it');
    then('exit 0, and the report lists all three picks old → new');
  });
  when('[t4] the source had a dirty tree (cell C8)', () => {
    then('the tree is laid down only after the last pick lands');
  });
});
```
