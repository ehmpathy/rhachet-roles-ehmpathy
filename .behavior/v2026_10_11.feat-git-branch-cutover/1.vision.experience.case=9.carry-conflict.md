# case=9: the uncommitted tree conflicts with the new base

**cell** C3 (+ C10, C17) then D4 / D6 · sharp × critipath
**actor** mechanic

## .narrative

the mechanic carries an uncommitted edit to `config.ts`. main rewrote `config.ts` since the old
branch forked. the tree cannot drop cleanly onto the new base.

this is the costliest failure in the space: uncommitted work has no commit to fall back on. so the
skill parks the tracked edits in a private ref and byte-verifies the park *before* it resets the
tree, and keeps the ref until the work lands or is restored. untracked files never enter the park;
no step writes them. on conflict, it stops with conflict markers in the file, names the
ref that still holds the original, and offers continue or abort.

continue, once the file is settled and staged, leaves the work uncommitted on the new branch. abort
returns to the source branch with the tree exactly as before. either way the private ref is then
dropped. no path loses the work.

## .sketch output

```
$ rhx git.branch.cutover begin --from @main --into turtle/config-v2 --mode apply

🐢 hang tight...

🐚 git.branch.cutover begin --mode apply
   └─ ✋ ConstraintError: halted: the carry of tracked edits conflicts
      ├─ into: turtle/config-v2 (checked out, no upstream)
      ├─ tracked edits ✋ conflict on carry
      │  └─ files
      │     └─ src/config.ts
      ├─ safe: original tracked edits held at refs/worktree/cutover/tree
      ├─ stage: ✋ no stage grant, so rhx git.stage.add will refuse
      │  └─ ask your human: git.commit.uses set --quant N --push allow|block --stage allow
      └─ quota: the cutover unit is spent; abort refunds none

🥥 did you know?
   ├─ settle the files above, stage them, then continue — or undo the whole cutover
   ├─ rhx git.stage.add <files>
   ├─ rhx git.branch.cutover continue
   └─ rhx git.branch.cutover abort
```

exit `2`.

## .bdd

```
given('[case9] a dirty edit to a file that origin/main rewrote', () => {
  when('[t0] cutover runs in apply mode', () => {
    then('HEAD is on the new branch; the file holds conflict markers');
    then('a private ref holds the original tracked edits, byte-verified');
    then('each untracked file is untouched');
    then('exit 2, with continue and abort named');
  });
  when('[t3] the file is settled, staged, and `continue` runs', () => {
    then('the settled content is in the tree, unstaged and uncommitted');
    then('the private ref is dropped');
    then('exit 0');
  });
  when('[t4] instead, `abort` runs', () => {
    then('HEAD is back on the source branch at its original sha');
    then('the tree matches the pre-cutover content and status');
    then('the new branch is removed and the private ref is dropped');
    then('exit 0');
  });
});
```
