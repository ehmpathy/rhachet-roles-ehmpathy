# case=7: pick conflict → abort

**cell** C5 then D3 · sharp × critipath
**actor** human

## .narrative

a human hits a conflict on pick 2 and decides the cutover was the wrong call — the conflict is
deep, and they would rather rebase the old branch after all. they abort.

abort undoes the whole cutover, not just the one pick. they land back on the source branch, at its
original sha, with their tracked edits restored from the park, exactly as they were. untracked files were never
touched, so no restore is owed for them. the new branch the skill made
seconds ago is gone, so the name is free to reuse. the source branch was never touched at any step.

## .sketch output

```
$ rhx git.branch.cutover abort

🐢 all good, paddled back

🐚 git.branch.cutover abort
   ├─ back on: vlad/surf-log-old @ 0a0a0a0 (untouched)
   ├─ tracked edits (2) ✓ restored from park
   ├─ untracked: untouched throughout
   └─ removed: vlad/surf-log (made by this cutover, never pushed)
```

## .bdd

```
given('[case7] a cutover halted on a pick conflict, source had a dirty tree', () => {
  when('[t0] the human runs --abort', () => {
    then('HEAD is on the source branch at its original sha');
    then('the uncommitted files match their pre-cutover content and status');
    then('no cherry-pick is in progress');
    then('the branch this cutover made no longer exists');
    then('exit 0');
  });
  when('[t1] the human runs the same cutover again', () => {
    then('preflight passes: --into is free again');
  });
});
```
