# case=4: the nheuron cutover (densest)

**cell** C14 · apply · picks many · tree dirty · outcome clean · happy × critipath
**actor** mechanic
**boundaries crossed** network (fetch) · ref store (new branch) · upstream config · sequencer (n
picks) · work tree (carry; untracked untouched) · `git.commit.set` cont-rule + level ·
`git.commit.push`

## .narrative

this is the 2026-10-11 incident in `uladkasach/nheuron`, replayed with the verb in place.

the branch's first `feat` squash-merged. `git.commit.set` now forces every new commit on it to be
`cont:`, so the next release cannot be a `feat`. the mechanic has two commits worth keep and an
uncommitted tree with the new feature.

by hand, this took a rebase, ten conflicts, a `rebase --quit`, a `switch -c`, a second branch cut,
and — the quiet defect — the new branch tracked `origin/main`. each step was a raw git call off the
paved list, so each was a permission prompt.

with the verb: one plan, one apply. the skill cuts from fresh `origin/main` with no upstream,
replays the two picks, then lays the uncommitted tree back down, uncommitted. the mechanic commits
`feat(...)` — accepted, since the new branch holds no prior behavioral commit — and pushes via the
paved path to `origin/<new-branch>`. the next release is a `feat`.

## .bdd

```
given('[case4] a branch whose first feat squash-merged, two picks, a dirty tree', () => {
  when('[t0] cutover runs in apply mode', () => {
    then('HEAD is on the new branch, cut from the fetched origin/main');
    then('the two picks land in order on top of the base');
    then('the uncommitted files are present and still uncommitted');
    then('the old branch ref and its last commit are unchanged');
    then('the report lists 3a3a3a3 as left behind, not picked');
    then('the report names the effective commit level on the new branch and its source');
    then('no route bind or commit-level bind file is written by the cutover');
  });
  when('[t1] the mechanic commits feat(graph) via git.commit.set', () => {
    then('the commit is accepted: no prior behavioral commit on the new branch');
  });
  when('[t2] the mechanic pushes via git.commit.push', () => {
    then('the push targets origin/turtle/neuron-graph');
  });
  when('[t3] the upstream of the new branch is read', () => {
    then('there is no upstream; it is never origin/main');
    then('a raw `git push` from this branch never targets main: with no upstream, simple/upstream refuse and current targets the same name');
  });
});
```
