# case=13: a stacked branch — `--from @tree`

**cell** E1 (+ E2, E3) · happy × critipath
**actor** mechanic

## .narrative

the mechanic's branch `turtle/reef-map` is under review. it wants to start the next piece — the
shoal labels — on top of it, without a wait for the merge, and it has already begun to edit.

it cuts a stacked branch from the tree it stands on. the new branch starts at HEAD, so every
commit of `turtle/reef-map` is already there; there is no pick to name. no file changes: the
uncommitted edits and the untracked scratch file stay exactly where they are, now on the new
branch. `turtle/reef-map` itself is untouched and still under review.

## .bdd

```
given('[case13] a dirty tree on turtle/reef-map, --from @tree', () => {
  when('[t0] begin runs in apply mode', () => {
    then('HEAD is on turtle/reef-shoals at the same commit as turtle/reef-map');
    then('the new branch has no upstream');
    then('every tracked edit and untracked file is byte-identical, same path; no file was written');
    then('no private ref is written; no reset runs');
    then('turtle/reef-map is unchanged');
    then('one git.branch.uses unit is spent');
  });
  when('[t1] instead, begin runs with --from @tree --pick 7e7e7e7', () => {
    then('it refuses with ConstraintError: @tree already holds every commit — exit 2');
    then('no ref, index, or file changes');
  });
  when('[t2] instead, begin runs with no --from', () => {
    then('it refuses with ConstraintError and names --from @main, --from @tree, --from <branch> — exit 2');
  });
});
```
