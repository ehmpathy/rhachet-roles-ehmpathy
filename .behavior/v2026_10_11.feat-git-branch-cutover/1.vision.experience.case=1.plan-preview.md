# case=1: plan preview

**cell** B6 · plan · picks many · tree dirty · happy × critipath
**actor** mechanic (identical for a human)

## .narrative

the mechanic sits on `turtle/wave-report`. its first `feat` squash-merged yesterday. two commits
since then still matter, plus a half-done edit in the tree. it wants to see the move before it
makes the move.

it runs the bare command. the skill fetches, then prints the base it would cut from, the branch it
would make, each commit in the order it would replay them, and the files it would carry. naught
moves. the last line tells it how to execute.

## .bdd

```
given('[case1] a branch with two picks and a dirty tree', () => {
  when('[t0] cutover runs in plan mode', () => {
    then('it fetches origin/main and prints the base sha');
    then('it prints the new branch and that it has no upstream');
    then('it lists each pick in the order given');
    then('it lists the uncommitted files it would carry');
    then('no ref, index, or file changes');
    then('exit 0');
  });
});
```
