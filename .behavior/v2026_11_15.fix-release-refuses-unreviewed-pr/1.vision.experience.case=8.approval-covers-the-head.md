# case=8 — an approval counts only on the head that merges

## .narrative

the human approves pr #42 at commit A. the clone pushes a fix, commit B, and runs `--apply`. the
skill reads the pr head once: B. the approval is on A, so it reads as stale. refused, exit 2, with
`why: the approval by @reef-keeper is on an older commit; the head needs a fresh review`. the human
re-reviews B; the clone re-runs and it ships.

a second path: the gate reads B and the approval is on B, so it passes. in the seconds before the
merge call, a push lands commit C. the merge is pinned to B (`--match-head-commit B`), so github
refuses it. exit 2: the head moved after the gate read it; naught merged. a re-run makes the gate
judge C.

if the head read itself fails, the gate cannot match any approval to code. `💥 MalfunctionError`,
exit 1, naught merged.

a third path: the gate passes on B and automerge is armed. while the apply watch polls, a push
lands C. the watch holds a lease on B: it sees C, disarms automerge, and refuses. or ci goes red
on B: the watch disarms automerge before it exits, so the fix the clone pushes next cannot merge
until `--apply` gates it again.

## .bdd

```
given('[case8a] pr #42 head B; reviews: human-a APPROVED at A')
  when('[t0] git.release --into main --apply')
    then('exit 2; why names the older commit; gh pr merge never called')
given('[case8b] pr #42 head B; reviews: human-a APPROVED at A, then APPROVED at B')
  when('[t0] git.release --into main --apply')
    then('proceeds; the merge carries --match-head-commit B')
given('[case8c] pr #42 head B, approved at B; a push moves the head to C before the merge')
  when('[t0] git.release --into main --apply')
    then('exit 2; github refuses the pinned merge; naught merged')
  when('[t1] git.release --into main --apply --retry')
    then('exit 2; --retry does not lift it')
given('[case8d] pr #42; the head read fails')
  when('[t0] git.release --into main --apply')
    then('exit 1; MalfunctionError names the head read; gh pr merge never called')
given('[case8e] pr #42 approved at B, automerge armed; a push lands C in the watch')
  when('[t0] git.release --into main --apply')
    then('exit 2; the watch disarms automerge and names both heads')
given('[case8f] pr #42 approved at B, automerge armed; checks go red in the watch')
  when('[t0] git.release --into main --apply')
    then('exit 2; automerge disarmed before exit')
  when('[t1] the disarm fails')
    then('exit 1; says automerge is still on; names the hand fix')
```
