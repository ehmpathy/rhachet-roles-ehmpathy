# 1.vision.experience.case=_ — inventory

care = freq × cost. a path whose failure-open merges unreviewed code costs an irreversible npm
publish; any nonzero frequency there makes it a critipath.

## .actors × feel

| actor | happy | sharp |
|---|---|---|
| clone (mechanic) | E3 approved → apply ships · E5 plan/watch unchanged | E1/E2 unreviewed apply refused · E4/E16 robot, bot, or outsider approval refused · E6/E7/E8 withdrawn, vetoed, or non-decisive review refused · E9 review read fails → fails closed · E15 prior automerge disabled, then refused · E20/E21/E22 stale approval, moved head, unread head → refused or fails closed · E23/E25/E26 the lease disarms on drift, a lost approval, or any exit short of a merge · E24 reads its brief: stop, hand up |
| human reviewer | approves on github; the clone's re-run ships (inside E0, E3) | none worth a demo: the reviewer's act is a github review; the skill never addresses the reviewer, so it has no edge to cut them on |
| human caller, own pr | approved by a peer → ships as E3 | E14 no peer review → refused like the clone |
