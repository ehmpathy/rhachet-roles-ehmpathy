# case=1 — unreviewed apply refused

## .narrative

the clone finishes a route on `turtle/feature-x`. pr #42 is green; no human has reviewed it. the
clone runs `rhx git.release --into prod --apply --dirty allow`. the skill reads the pr's reviews,
finds no human approval, and stops before automerge. it names pr #42, says a human approval is
owed, and exits 2. pr #42 stays open, unmerged. the clone tells its human the pr waits for review.

## .bdd

```
given('[case1] feature pr #42, open, checks passed, no reviews')
  when('[t0] git.release --into main --apply')
    then('exit 2')
    then('stdout + stderr name pr #42 and say a human approval is owed')
    then('gh pr merge is never called')
  when('[t1] git.release --into prod --apply --dirty allow')
    then('exit 2; gh pr merge is never called')
  when('[t2] git.release --into main --mode apply (no --watch)')
    then('exit 2; gh pr merge is never called')
  when('[t3] git.release --into main --apply --watch')
    then('exit 2; gh pr merge is never called; no watch poll begins')
  when('[t4] git.release --into prod --apply --retry')
    then('exit 2; gh pr merge is never called; --retry does not lift')
```
