# case=3 — bot or robot approval refused

## .narrative

a second clone, under `ehm-seaturtle`, approves pr #42. github reports that account as
`type: User`. an app bot (`ehm-a-seaturtle[bot]`, `type: Bot`) approves too. the clone runs
`--apply`. the skill counts neither: a `[bot]` login or `type: Bot` is a bot, and a login on the
seaturtle roster is a robot. no human approval → refused, exit 2, same words as case=1.

## .bdd

```
given('[case3] feature pr #42, open; reviews: ehm-a-seaturtle[bot] APPROVED (Bot), ehm-seaturtle APPROVED (User)')
  when('[t0] git.release --into main --apply')
    then('exit 2; names pr #42; gh pr merge never called')

given('[case3b] public repo; pr #42 reviews: drive-by-surfer APPROVED (User, author_association NONE)')
  when('[t0] git.release --into main --apply')
    then('exit 2; names pr #42; gh pr merge never called')
```

a stranger on a public repo is a human, but holds no authority there. only an OWNER, MEMBER, or
COLLABORATOR approval counts (F6).
