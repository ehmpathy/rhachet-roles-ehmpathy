crosses every boundary the wish names: route complete → apply → review read → refusal → human
review → re-run → merge → release pr → tag → publish.

## .narrative

the clone completes a route in sdk-aws-lambda. pr #79 is green. it runs the same command as on
2026-11-14: `rhx git.release --into prod --apply --dirty allow`. the commit quota passes. the skill
reads #79's reviews: none. it stops before automerge, prints that #79 owes a human approval, and
exits 2. #79 stays open; v0.8.0 is not published.

the clone tells its human: "#79 is green and waits for your review." the human reads the diff and
approves on github. the clone re-runs the command. the skill reads one APPROVED review from a
human login, enables automerge, and the release flows as before: #79 merges, release-please opens
the release pr, it merges, the tag publishes.
