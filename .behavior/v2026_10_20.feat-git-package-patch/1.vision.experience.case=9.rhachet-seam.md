## .narrative

a crew never runs the shell file. it types `rhx git.package.patch …`, and rhachet must find the
skill in the linked role, pass the subcommand and flags through, and hand back the render and the
exit code untouched. a clone that templates its calls also carries rhachet's own selectors —
`--skill`, `--repo`, `--role` — into the argv; those must be stripped, never read as unknown flags.

in a repo linked to the role, the crew asks for help and reads the two subcommands and a
paste-ready example. it runs `begin` in plan mode, sees what would open, then opens it, edits a
line, and seals with `--why` and `--upstream`. the patch, its note, and the lockfile record land,
and the edit dir is gone — the same journey as `case=1`, proven at the seam the crew actually
uses.
