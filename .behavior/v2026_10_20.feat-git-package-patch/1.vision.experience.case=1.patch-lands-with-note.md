# case=1 — a patch lands with its note

feel = happy · care = critipath · covers c5b, c1b, c5c, c1c

## .narrative

kai, on a crew, finds a defect in `rhachet@1.48.1`. he dispatches the fix upstream as
`ehmpathy/rhachet#580`, but his tree must stay alive until that release lands.

he runs `begin` bare, with no `--mode`, half to see what it will do. it names the version it
found and the dir it would open, and touches naught — so he knows the target before a file
moves. he re-runs with `--mode apply`; the dir opens inside his tree, and the output hands him
the exact `commit` command, `--why` and `--upstream` already in it as blanks to fill.

he edits one file with his Edit tool. he runs `commit` bare first: it lists the patch, the
`package.json` entry, and the note it would write. he adds `--mode apply`. all three land, the
edit dir is cleared, and the note says who, when, why, and where the real fix waits. no harness
prompt fired at any step.

## .timeline

```
given a pnpm repo with rhachet@1.48.1 installed
  when [t0] rhx git.package.patch begin --package rhachet
    then plan: names package rhachet@1.48.1, edit dir node_modules/.pnpm_patches/rhachet@1.48.1
    then naught on disk changed
  when [t1] rhx git.package.patch begin --package rhachet --mode apply
    then the edit dir exists inside the tree, with the package source
    then stdout names the dir and the commit command to run next, with --why and --upstream blanks
  when [t2] the crew edits dist/foo.js inside the edit dir
  when [t3] rhx git.package.patch commit --package rhachet --why 'enroll hook leaks' --upstream https://github.com/ehmpathy/rhachet/issues/580
    then plan: names patches/rhachet@1.48.1.patch, the patchedDependencies entry, and the note path
    then naught on disk changed
  when [t4] the same commit, with --mode apply
    then patches/rhachet@1.48.1.patch holds the diff
    then package.json pnpm.patchedDependencies maps rhachet@1.48.1 to it
    then patches/rhachet@1.48.1.patch.note.md holds who, when, why, upstream
    then the edit dir is gone
    then exit 0
```
