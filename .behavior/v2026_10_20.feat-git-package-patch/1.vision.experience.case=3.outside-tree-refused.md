# case=3 — a path outside the tree is refused

feel = sharp · care = critipath · covers c3b, c3c, c14b, c14c

## .narrative

kai's habit is `/tmp` for scratch work, so he types `begin --edit-dir /tmp/rhachet`. the verb
stops him at once and tells him to drop the flag — the default dir sits inside his tree. he tries
a path in the next repo over, `../other-repo/x`; same stop. a link he made weeks ago,
`./scratch`, points out to `/tmp` — he tries that, and it is caught too, since the verb checks
where the path really lands. later, at commit, he passes `--edit-dir /tmp/rhachet` again from
muscle memory; refused the same way, before pnpm runs. last, he reaches for `-g`, the way he
would with a global install — on `begin`, then again on `commit` — and both times it is refused
as a flag that does not exist, with a reminder that the verb patches this tree only. no file
outside his tree ever moved.

## .timeline

```
given a pnpm repo with rhachet@1.48.1 installed, and ./scratch a symlink to /tmp
  when [t0] begin --package rhachet --edit-dir /tmp/rhachet --mode apply
    then exit 2: ✋ ConstraintError: --edit-dir must sit inside the tree
    then the fix names: omit --edit-dir to use node_modules/.pnpm_patches/rhachet@1.48.1
    then /tmp/rhachet does not exist; pnpm never ran
  when [t1] begin --package rhachet --edit-dir ../other-repo/x --mode apply
    then exit 2, same refusal
  when [t2] begin --package rhachet --edit-dir ./scratch/rhachet --mode apply
    then exit 2, same refusal: the real path resolves to /tmp/rhachet
  when [t3] begin --package rhachet -g --mode apply
    then exit 2: ✋ ConstraintError: unknown flag -g
    then the fix names: drop -g; this verb patches the current tree only, and lists its flags
given an open in-tree edit dir for rhachet@1.48.1, with edits
  when [t4] commit --package rhachet --edit-dir /tmp/rhachet --why 'x' --upstream https://github.com/ehmpathy/rhachet/issues/580 --mode apply
    then exit 2, same refusal; pnpm patch-commit never ran; the in-tree dir is intact
  when [t5] commit --package rhachet -g --why 'x' --upstream https://github.com/ehmpathy/rhachet/issues/580 --mode apply
    then exit 2: ✋ ConstraintError: unknown flag -g, with the same fix; the in-tree dir is intact
```
