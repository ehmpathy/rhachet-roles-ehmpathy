# case=4: a typo in the flag fails loud

## .narrative

a human types `BRAIN_LIVE_SCOPE=true`. if that read as off, the live suite would skip and the run would pass green, so the human would think the live check passed. instead, the gate refuses at collection:

```
✋ ConstraintError: BRAIN_LIVE_SCOPE must be 'all' or unset

{
  "value": "true",
  "hint": "unset it, or set BRAIN_LIVE_SCOPE=all to run the live-brain suites"
}
```

(the shape helpful-errors gives a ConstraintError with metadata, as pinned in `src/.test/__snapshots__/isBrainLiveScopeAll.test.ts.snap`)

the human fixes the value and reruns.

## .bdd sketch

```
given('[case4] the live-scope gate')
  when('[t0] it is read with BRAIN_LIVE_SCOPE=true')
    then('it throws a ConstraintError')
    then('the message names the one valid value: all')
  when('[t1] it is read with BRAIN_LIVE_SCOPE empty')
    then('it reads as off')
```
