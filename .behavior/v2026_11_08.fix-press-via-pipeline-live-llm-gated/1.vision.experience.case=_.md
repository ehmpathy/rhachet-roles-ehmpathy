forbidden:
- live brain call on ci with the flag unset. this is the rejection invariant of the wish: a ci run never pays a brain or flakes on one
- deterministic suite reads a credential or the network. it must pass offline
- a cache hit or miss in the live suite. a hit would pass a live run on a stale stored reply, with no brain asked. rejection invariant: every live ask case passes `force: true` (today at `pressViaPipeline.integration.test.ts:26,53,94`), and the execution keeps it

impossible:
- D5 or D6 with D2 unset: the live suite body never runs, so no key is read and no brain replies
- D5 with D6 locked or absent: the ask fails on the key before any brain is reached
- D8 in the deterministic suite: the fake is injected in place of `compressViaBhrain`, and the cache wraps only `compressViaBhrain`. no path from the test reaches the cache, so no hit or miss can be attempted
- D7 empty content or empty pipeline in the live suite: both return before any ask, so they would prove no brain behavior; they live only in the deterministic suite
- the fake compressor drifts from the real one's shape: `context.compressor` is typed `typeof compressViaBhrain`, so a fake that returns a stale `CompressionResult` shape fails `tsc` (`npm run test:types`) on ci
