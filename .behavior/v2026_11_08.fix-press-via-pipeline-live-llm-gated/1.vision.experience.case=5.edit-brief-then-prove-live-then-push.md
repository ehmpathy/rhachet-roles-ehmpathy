# case=5: a mechanic edits a compression brief, proves it live, and pushes (dense journey)

## .narrative

a mechanic tightens the `sitrep-aggressive` brief. they run the unit suite on their box. it is green in milliseconds, but it uses a fake, so it says naught about the new brief. they want proof on a real brain, and type `BRAIN_LIVE_SCOPE=true`. the gate refuses: the flag must be `all` or unset. they fix it to `all`. the run now reaches the brain, but their keyrack is locked. the ask fails loud and names `rhx keyrack unlock --owner ehmpath --env test`. they unlock and rerun. the three live cases go green, and each shape still compresses. they push. ci runs the deterministic suite green and shows the live suite as one todo row. no brain is asked on ci.

## .boundaries crossed

1. fake vs real compressor seam (t0, t3)
2. flag closed set: typo refused (t1)
3. credential boundary: locked keys fail loud (t2)
4. live strict-compression proof (t3)
5. crew vs ci seam: the gate off on ci by default (t4)

## .bdd sketch

```
given('[case5] a mechanic who edited the sitrep-aggressive brief')
  when('[t0] the unit suite runs on the crew box')
    then('pressViaPipeline.test.ts is green; no brain is asked')
  when('[t1] the integration suite runs with BRAIN_LIVE_SCOPE=true')
    then('a ConstraintError names the one valid value: all')                        # closed-set boundary
  when('[t2] it reruns with BRAIN_LIVE_SCOPE=all and a locked keyrack')
    then('the ask fails loud and names rhx keyrack unlock --owner ehmpath --env test') # credential boundary
  when('[t3] it reruns after unlock')
    then('single-step, multi-step, and req-kernels each yield tokens.after < tokens.before')
  when('[t4] the branch is pushed and ci runs')
    then('the deterministic suite is green')
    then('the live suite shows as a todo row that names BRAIN_LIVE_SCOPE=all')       # crew/ci seam
    then('no brain is asked')
```
