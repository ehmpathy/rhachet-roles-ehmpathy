# case=3: a human runs the live suite on demand

## .narrative

a human swaps the brain slug or edits a compression brief, and wants proof that a real model still compresses. they run the suite with the flag:

```
BRAIN_LIVE_SCOPE=all rhx git.repo.test --what integration --scope pressViaPipeline --mode apply
```

the live suite runs. its cases are the ones that ran ungated on ci before: single-step, multi-step, and req-kernels. each asserts strict compression on the real brain. the human sees green, or sees which shape the brain failed on. ci is untouched.

## .bdd sketch

```
given('[case3] a crew env with BRAIN_LIVE_SCOPE=all and unlocked keys')
  when('[t0] the integration suite runs scoped to pressViaPipeline')
    then('the live describe runs against openrouter/deepseek/flash')
    then('tokens.after < tokens.before for single-step, multi-step, and req-kernels')
```
