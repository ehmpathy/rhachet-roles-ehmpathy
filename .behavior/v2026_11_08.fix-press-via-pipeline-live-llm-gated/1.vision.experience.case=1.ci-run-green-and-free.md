# case=1: a ci run stays green and pays no brain

## .narrative

a pr shard picks up the librarian tests. the pressViaPipeline suite finishes in milliseconds, green, and asks for no key and no network. its first check is the plainest shape: one sitrep-aggressive step over a short brief, which comes back smaller, with one step on record. in the verbose report, the shard sees one line where the live checks used to run: `[gated: live brain] pressViaPipeline (live) — run with BRAIN_LIVE_SCOPE=all`. it reports green and moves on. a main publish run sees the same, so a slow or odd brain reply can no longer redden a release.

## .bdd sketch

```
given('[case1] a ci env with no BRAIN_LIVE_SCOPE, and a fake compressor that halves its input')
  when('[t0] pressViaPipeline runs a single-step pipeline [[sitrep-aggressive]] over an inline brief')
    then('tokens.after < tokens.before')
    then('steps has 1 entry, with mechanisms [sitrep-aggressive]')
    then('no brain is asked')
  when('[t1] the integration suite is collected')
    then('the live suite is skipped under its own title')
    then('a todo row names BRAIN_LIVE_SCOPE=all')
```
