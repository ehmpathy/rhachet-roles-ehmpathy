# case=4 · two clones share one daemon

covers: L2 (solo × live), L6 (two clones × distinct prs), L8 (two clones × same pr). happy · critipath.

## .narrative

the box runs two mechanics on v1.41.0: `@:mechanic` in worktree `beav.feat-a` and `@:mechanic` in worktree `beav.feat-b`. clone A pushed first, so a daemon (pid 48122) already lives.

clone B pushes pr #1221. its push findserts the daemon: it finds pid 48122 alive at v1.41.0, and registers a watch with it. no second process starts.

```
🐢 shell yeah, pushed
   ├─ pr: #1221 (findserted)
   └─ watch: set → @:mechanic (daemon v1.41.0 pid 48122, found)
```

`rhx git.pull.watch get` from either worktree shows the one daemon and both watches:

```
🐢 pr watch
   └─ daemon v1.41.0 · pid 48122 · last tick 40s ago
      ├─ #1220 → @:mechanic (beav.feat-a)
      └─ #1221 → @:mechanic (beav.feat-b)
```

later the foreman asks clone A to review #1221 too, so clone A watches it. the daemon still polls #1221 once per tick, and alerts each watcher once.
