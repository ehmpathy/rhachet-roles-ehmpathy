# case=2 · a new comment reaches the mechanic

covers: A2 (comment.new), A4 (changes requested), A9 (burst), A18 (author human), F5. happy · critipath.

## .narrative

pr #1220 is under watch. a human reviewer leaves a review: state `CHANGES_REQUESTED`, body "the gerund in the header slipped past the hook", plus two inline comments on `output.sh`.

the daemon's tick reads all three since its cursor. it groups them into one alert, because they landed in one tick:

```
🐢 pr watch — 3 new comments on #1220
   ├─ pr: ehmpathy/rhachet-roles-ehmpathy#1220
   ├─ review by @uladkasach — changes requested
   │  └─ "the gerund in the header slipped past the hook"
   ├─ comment by @uladkasach on output.sh:42
   │  └─ "this branch never fires"
   ├─ comment by @uladkasach on output.sh:58
   │  └─ "same here"
   └─ next: rhx git.pull.comment get --pr 1220
```

the mechanic reads them whole with `git.pull.comment get`, fixes, pushes, and replies with `git.pull.comment set`. its own 🐢 reply lands on the pr. the next tick sees it, knows it as the mechanic's own, and stays silent (F5).
