# case=10 · the watch ends, and the last one takes the daemon with it

covers: A7 (merged), A8 (closed, no merge), A17 (clone dead), L27 (zero watches → exit), F3. happy · critipath.

the guard against the keyrack orphan defect (ehmpathy/rhachet#489): a daemon with no client exits on its own.

## .narrative

#1220 merges. the daemon's tick reads `merged`, sends one closure note, and deletes the watch:

```
🐢 pr watch — #1220 merged; watch ended
```

#1222 is closed by the commander, not merged — the approach was wrong. the note says so, so the mechanic does not mistake it for a ship:

```
🐢 pr watch — #1222 closed without merge; watch ended
   └─ by: @uladkasach
```

clone B's session ended at lunch. the daemon's next tick probes each watch's clone, sees clone B is gone, and drops the #1221 watch (and its outbox), since no session can receive it. the probe runs each tick, so a dead clone on a quiet pr is still found — no event has to arrive first.

now the v1.41.0 daemon holds zero watches. it removes its pid record and exits. no process lingers, no reparent to pid 1.

the next push on the box spawns a fresh daemon (case=1).

## .bdd sketch

```ts
given('[case10] a daemon with watches on #1220, #1222 (clone A) and #1221 (clone B)', () => {
  when('[t0] #1220 merges', () => {
    then('clone A gets one `merged` closure note', ...);      // A7
    then('the #1220 watch is deleted', ...);
  });
  when('[t1] #1222 is closed without merge', () => {
    then('clone A gets one note that says `closed without merge` and who closed it', ...); // A8
    then('the #1222 watch is deleted', ...);
  });
  when('[t2] clone B is dead at the next tick, no event on #1221', () => {
    then('the #1221 watch and its outbox are deleted', ...);  // A17
  });
  when('[t3] the daemon holds zero watches', () => {
    then('it removes its pid record and exits', ...);         // L27, F3
    then('no pr-watch process of that key remains', ...);
  });
});
```
