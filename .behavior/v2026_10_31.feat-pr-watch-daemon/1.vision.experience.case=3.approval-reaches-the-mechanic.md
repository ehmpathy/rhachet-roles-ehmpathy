# case=3 · approval reaches the mechanic

covers: A3 (review.approved), A19 (author human). happy · critipath.

## .narrative

pr #1220 is green and under watch. the commander approves it. the daemon's tick reads the new review with state `APPROVED`:

```
🐢 pr watch — approved #1220
   ├─ pr: ehmpathy/rhachet-roles-ehmpathy#1220
   ├─ by: @uladkasach
   ├─ ci: passed
   └─ next: rhx git.release --mode apply
```

the mechanic runs `git.release`, which enables automerge and watches it in. the director did not have to say "it's approved, ship it".

the alert carries the ci state at approval time, so the mechanic knows if an approval sits on a red build (then `next` is `rhx show.gh.test.errors`).
