# case=14 · an upgrade moves the watch

covers: L15 (key change × new key absent), L16 (key change × new key live), F9, L26, L27. sharp · critipath.

freq: medium — every role upgrade mid-pr. cost: high — without the move, both daemons alert the clone, and every event arrives twice.

## .narrative

clone B in `beav.feat-b` watches #1221 under the v1.41.0 daemon (pid 48122). the human runs `rhx upgrade`; the worktree now holds v1.42.0.

clone B pushes again. its findsert runs under the v1.42.0 key. no v1.42.0 daemon lives, so it spawns pid 61500 (L15). then it moves the watch: it writes #1221 under v1.42.0, with the cursors carried over, and deletes #1221 under v1.41.0.

```
🐢 shell yeah, pushed
   ├─ pr: #1221 (found)
   └─ watch: moved v1.41.0 → v1.42.0 (daemon pid 61500, spawned)
```

the v1.41.0 daemon's next tick reads its watches. #1221 is gone; if that was its last, it exits (L27).

a second clone that upgrades later finds pid 61500 alive and joins it (L16), with the same move.

the move carries the cursors, so an event already alerted under the old key is not alerted again under the new one.
