# case=1 · ci failure reaches the mechanic

covers: L1 (solo × absent), A1 (ci.failed), A13 (idle), A26 (reach ok), A5 (push.new), F7. happy · critipath. t3 is a de-dup check inside the happy path: its failure mode is a duplicate alert, which F7 forbids.

## .narrative

the mechanic `@:mechanic` in `rhachet-roles-ehmpathy` commits and pushes. `git.commit.push` findserts pr #1220. no pr-watch daemon lives on the box for v1.41.0, so the push spawns one and registers a watch: pr #1220 → this clone.

the mechanic moves on — it starts the next stone, then ends its turn and idles.

seven minutes later `test-unit` fails. the daemon's next tick reads the check run, sees a new failure, and says into the clone:

```
🐢 pr watch — ci failed on #1220
   ├─ pr: ehmpathy/rhachet-roles-ehmpathy#1220
   ├─ check: test-unit (failure)
   └─ next: rhx show.gh.test.errors
```

the mechanic wakes, runs `rhx show.gh.test.errors`, fixes the snapshot, and pushes. no director typed a word.
