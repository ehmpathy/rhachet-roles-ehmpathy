# wish: a pr-watch daemon for mechanics

task: ehmpathy/rhachet-roles-ehmpathy#1215

## .the outcome

once a mechanic opens a pr, the mechanic is alerted on its own of:

- (a) ci failures
- (b) new comments
- (c) approval

no director relays any of it.

the alert runs through one daemon per machine per rhachet-roles-ehmpathy version. the daemon is findserted: a clone that needs it finds the one already live for that version on the box, and starts it only if none lives. every clone on the box shares that one daemon. never one daemon per clone.

## .done means

- a mechanic that opens a pr receives an alert for each of ci failure, new comment, and approval, with no relay from a director
- two clones on one box, on one rhachet-roles-ehmpathy version, share exactly one daemon
- a second version on the same box gets its own daemon; a version never shares a daemon with another version
- a clone that starts a daemon twice finds the first, so a restart never leaves a second daemon behind
