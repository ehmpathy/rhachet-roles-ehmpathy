# 5.1.execution.blueprint — pr-watch daemon

for the commander. built on the approved vision (`1.vision.yield.md`) and the director's verdicts on Q1–Q12. open questions sit at the end, each with options and a lean; none is built until he rules.

## .contract

| surface | shape |
|---|---|
| `rhx git.pull.watch get` | daemons per key (pid, last tick, home) and their watches; read-only |
| `rhx git.pull.watch set --pr N [--mode apply]` | findsert a watch for this clone; findsert the daemon of this clone's key |
| `rhx git.pull.watch del --pr N [--mode apply]` | delete this clone's watch; a no-op if absent |
| `git.commit.push` | after its pr findsert (`git.commit.push.sh:645-715`), calls the `set` operation; prints one `watch:` line |
| `git.pull.comment set` | appends each comment id it posts to this clone's ledger |
| exit codes | 0 ok · 1 malfunction · 2 constraint (`rule.require.exit-code-semantics`) |

`set` and `del` follow the repo's plan-by-default rule; `git.commit.push` calls the operation in apply mode, since the push itself is the deliberate act.

## .state (per key)

`~/.rhachet/storage/repo=ehmpathy/role=mechanic/skill=git.pull.watch/v=$version+$hash/`

| path | holds |
|---|---|
| `bin/` | the daemon's own copy of the skill dir, findserted at spawn (Q7) |
| `daemon.pid` | pid + the command line it was started with (pid-reuse guard, F11) |
| `daemon.lock` | `flock` target for every findsert and the daemon's own boot check |
| `daemon.heartbeat` | mtime = last tick; wedged = older than 3 intervals |
| `daemon.log` | stdout + stderr of the daemon |
| `watches/$owner.$repo.pr=$n.clone=$serial.json` | `{ pr, repo, repoRoot, cloneSerial, cursors: { headSha, checkRunIds[], commentIdMax, reviewIdMax }, etags }` |
| `outbox/$watch.$eventKey.json` | a refused alert, retried each tick |
| `ledger/clone=$serial.ids` | comment ids this clone posted (F5, Q9) |

key = `$version+$hash`, where `$hash` is a short hash of the skill dir's bytes (Q8). a release install of one version has one hash, so "one per version" holds.

## .the findsert (set, and git.commit.push)

1. take `daemon.lock` (`flock -w 10`)
2. read `daemon.pid`; probe `kill -0` and the command line; live and fresh → found
3. stale (dead or foreign pid) or wedged (old heartbeat) → stop only a verified own daemon, clear the record
4. absent → copy the skill dir into `bin/`, spawn `setsid nohup bin/git.pull.watch.daemon.sh` with cwd in the state dir, write the pid, check it lives after a short settle (boot survival)
5. write the watch record; delete this clone's watch on the same pr under any other key (F9, case=14)
6. release the lock; print `watch: set → @:<slug> (daemon <key> pid <n>, spawned|found|replaced)`

## .the tick (every 60s, Q3)

1. touch the heartbeat
2. read every watch; for each distinct pr, one etag read per endpoint: `pulls/$n`, `commits/$sha/check-runs`, `issues/$n/comments`, `pulls/$n/comments`, `pulls/$n/reviews`
3. diff against the watch's cursors → events: `ci.failed`, `comment.new`, `review.*`, `pr.merged`, `pr.closed`; a new head sha moves the check cursor
4. drop the clone's own comment ids (ledger) — F5
5. for each watch: `rhachet clone list --output json` with cwd at its `repoRoot`; DEAD → delete the watch and its outbox
6. render one grouped alert per watch; `rhx clone say @:<serial> --what @stdin --output json` with cwd at `repoRoot`; branch on the verdict (QB4): `enqueued`/`released` → advance cursors · `withheld`/`buffered`/`absent`/`unreadable` → outbox · reach error → drop the watch
7. retry the outbox (QB6)
8. zero watches → remove the pid record and exit (F3)
9. token: `rhachet keyrack get --key EHMPATHY_SEATURTLE_GITHUB_TOKEN --env prep --json` with cwd at a watch's `repoRoot` (R3 trap 1). `status: locked` → one paused alert per watcher with the unlock fix; `absent` → one with the human fill fix; no github calls until `granted` (case=8)

## .etag on every endpoint

verified by hand, 2026-10-31: `pulls/$n/reviews` returns a strong etag and a 304 that leaves the rate budget unspent (vision groundwork). `commits/$sha/check-runs` returns a weak etag (`W/"7378…cd88"`) and `Cache-Control: private, max-age=60`; `If-None-Match` honors weak etags for GET, so the same 304 path holds. the daemon stores each etag verbatim, `W/` prefix included.

## .the probes (R1–R3)

read from the installed rhachet@1.50.1 dist, 2026-10-31. paths are relative to `node_modules/.pnpm/rhachet@1.50.1_zod@4.3.4/node_modules/rhachet/dist/`.

### R1 — `clone say` reach from another repo: works, at the exact root

- the registry is per repo: `join(repoPath, '.agent', '.actors')` (`domain.operations/actor/enrolled/getActorsRootDir.js:52`)
- `repoPath` is `realpath(process.cwd())`, with no walk up to a git root (`contract/cli/invokeCloneSay.js:78`, `infra/host/getOneRepoPath.js:19-30`)
- a serial is a uuid (`genCloneSerial.js:64`), found via `.agent/.actors/.serials/<serial>` (`getOneCloneByRef.js:39-58`)
- ⇒ the watch record stores `repoRoot` as the **realpath of the clone's repo root**. the daemon runs `clone say @:<serial>` with cwd exactly there, and always addresses by serial, never slug

### R2 — `clone say` per clone state: busy enqueues; three states refuse; exit 2 is ambiguous

| clone state | verdict | exit |
|---|---|---|
| busy (mid-turn, box drawn) | `enqueued` — claude code holds it, lands next | 0 |
| idle | `released` | 0 |
| at-modal | `withheld` (`modal-holds-focus`) | 2 |
| screen unrecognized | `withheld` (`focus-unrecognized`) | 2 |
| dirty-input | `withheld` (`input-region-dirty`; `--force` overrides — never used) | 2 |
| dead / deaf / unknown address | ConstraintError (`asCloneReachError.js:102`) | 2 |
| text still in the box, absent, unreadable | `buffered` / `absent` / `unreadable` | 1 |

sources: `socket/computeCloneDispatchPrecheck.js:45-54`, `socket/computeCloneSayVerdict.js:95-170`, `computeCloneSayReport.js:116-188`.

⇒ **exit 2 means both "hold and retry" and "the clone is gone".** the daemon must call `clone say --output json` and branch on the verdict, never on the exit code alone (QB4). bhrain's reminder reads every exit 2 as a dead session — the misread this design must not copy.

⇒ case=7 narrows, as the vision allowed: a busy clone needs no outbox. the outbox serves `withheld`, `buffered`, `absent`, `unreadable`.

liveness, for the per-tick clone probe: a socket clone is LIVE when a connect to its socket succeeds within 1s; a socketless one by `kill(pid, 0)` (`getCloneReachState.js:28-40`, `isCloneLive.js:226-237`). no heartbeat, no tmux. the daemon reads it via `rhachet clone list --output json` from the watch's `repoRoot`.

### R3 — `keyrack get` from a detached daemon: works within the login session, with two traps

- grants live only in the keyrack daemon's memory, reached over `${XDG_RUNTIME_DIR}/keyrack.<sessionId>.<homeHash>[.<owner>].sock` (`daemon/infra/getKeyrackDaemonSocketPath.js:27-45`)
- `sessionId` is `/proc/<pid>/sessionid`, and the server refuses another session (`verifyCallerLoginSession.js:124-125`). children inherit it; `setsid` and `nohup` do not change it. so a daemon spawned by a clone reads that clone's login session's keyrack. (the sweep's read of the kernel field; to confirm by a clamp)
- unlock lasts 9h by default (`session/unlockKeyrackKeys.js:59`)
- `--json` prints `status: locked | absent | blocked | granted`, and exits 2 for each non-granted status (`invokeKeyrack.js:653-656`). case=8 maps `locked` → unlock fix, `absent` → human fill fix

trap 1 — **cwd**: a locked key that is not in the repo manifest reads `absent` (`asResolvedAttempt`, `invokeKeyrack.js:608`), and the manifest is found from the git root of cwd. the daemon's cwd (the state dir) has none, so a locked key would read `absent` and case=8 would print the wrong fix. ⇒ read the token with cwd at a watch's `repoRoot`.

trap 2 — **login session**: the daemon reads the keyrack of the session that spawned it. a clone in another login session (another ssh, a cron) that unlocked its own keyrack does not unlock the daemon's (QB5).

## .open questions for the commander

| # | question | options | lean |
|---|---|---|---|
| QB1 | which boxes must run the daemon? the lock (`flock`) and the detach (`setsid`) are util-linux; verified present on this box (`/usr/bin/flock`, `/usr/bin/setsid`), absent from a stock macOS | (a) linux only, refuse loud on a box without them · (b) portable: a `mkdir` lock + `nohup … &` with `disown` | (b): `mkdir` is atomic on every posix fs, so the findsert stays race-safe; the cost is a stale-lock check (pid in the lock dir) |

| QB2 | the daemon's language | (a) bash, like every skill in `src/domain.roles/mechanic/skills/` (zero `exec node` dispatch found) · (b) node/ts, like bhrain's route.reminder daemon | (a): one language per role, and the peer tests' PATH fakes for `gh` and `rhx` carry over. a bash loop re-reads its own file as it runs, which makes the per-key copy (Q7) required, not only a guard |
| QB3 | a live delivery test tier | (a) none — the fake `rhx` on PATH covers delivery; a one-time human check proves it · (b) one opt-in tier that enrolls a haiku clone and delivers a real alert, under $0.50, no oauth token, off by default | (a) for this pr, (b) caught as a dream: delivery is `clone say`'s contract, tested in rhachet |
| QB4 | how the daemon reads a `clone say` result | (a) exit code only · (b) `--output json`, branch on verdict: `enqueued`/`released` → done; `withheld`/`buffered`/`absent`/`unreadable` → outbox; reach error (dead, deaf, unknown) → drop the watch | (b): exit 2 covers both "retry" and "gone" (R2); (a) would drop live watches at every modal |
| QB5 | the daemon reads the spawner's login-session keyrack | (a) accept: the paused alert names the unlock, and any clone in that session can run it · (b) key the daemon by login session too — one per machine per version per session | (a): (b) breaks "one per machine per version". on a box with one human login, the two are the same |
| QB6 | a held alert whose verdict stays `buffered`/`unreadable` (a malfunction, exit 1) | (a) retry each tick until delivered or the watch ends · (b) retry N ticks, then one log line and keep the alert | (a), with a log line each 10th retry: F6 forbids a drop, and the watch end bounds it (Q11) |
