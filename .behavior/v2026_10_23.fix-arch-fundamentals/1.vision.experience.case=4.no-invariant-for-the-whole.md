# case 4 — no-invariant-for-the-whole · sharp critipath (fails safe)

cell: family A · `design × compose × once × unstatable` · lessons I01, I02, I05

## .narrative

the school wants a dawn planner: it takes surfers, instructors, boards, tide, and permits, and emits the day's lessons. an architect clone, with I02 booted, tries to state the planner's invariant first. it cannot. the surf conditions, the instructor rosters, the surfer moods: the wisher's t08 doubt is real, and no single invariant spans the whole.

an architect without I05 stops there, or writes a vague invariant ("the plan is valid") that no test can clamp. with I05, the clone decomposes until each part owns an invariant it can state:

| part | its local invariant |
|---|---|
| `getAllOpenSlots` | each slot falls inside daylight and inside a permit window |
| `getAllCertifiedPairs` | each instructor pair holds the level the group needs |
| `setLessonReservation` (case 2) | held boards ≤ stock; one board per surfer per slot |

the planner orchestrator reasons only on those three promises (I05: additive, not multiplicative). and I05's test half names the composer's own test: given a fixed day, the plan uses each instructor at most once, and every lesson it emits passes all three local invariants.

the clone ships no fake whole-system invariant. it states which parts it can prove and which seam it tests.
