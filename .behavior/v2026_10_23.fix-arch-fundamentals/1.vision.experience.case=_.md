## .legend

`D<n>` = demoed in case n · `I` = itemized (real, on record, not demoed) · `F` = forbidden (nurture: the behavior rejects it) · `X` = impossible (nature: it cannot occur). feel: **h** happy · **s** sharp. care: **c** critipath · **a** alterpath.

**the review lane**, in every demo and cell, is a reviewer clone that boots the architect or mechanic role: the forbids boot as `say`, so the clone reads them before it reviews. this route ships no dedicated rubric in `architect/briefs/reviews/rubrics.yml` and no `.evals/` case for the new forbids — F12 scoped both to a wish of their own, caught as `dreams/v2026_11_24.feat.rubric-and-evals-for-constraint-forbids.md`. until it lands, a forbid bites through the booted brief alone, unmeasured.

**covered by** names, for each itemized critipath, the demo that exercises the same boundary (coverage-subsumption, `define.experience._.metric=boundary-density`). a critipath row with no `covered by` would be an absent critipath; none is left so.

### item = fulcrum (3 reachable of 24)

a fulcrum's taken fork is always a call to adopt it, and the fulcrum summary has no blanket line; the other 21 cells are impossible (X). the three reachable:

| proposed | ruled = agree | ruled = disagree | ruled = blank |
|---|---|---|---|
| adopt (the taken fork) | I — execution builds the taken fork · h · c · covered by D5 (the wisher rules a fulcrum "the same way") | **D5**'s handler — the wisher picks the other fork; execution builds it and cites the verdict · h · c | I — the rework column decides: `clean` → execution builds the taken fork and lists the fulcrum at the close for the council (`rule.always.defer-fulcrums-to-last`); `dirty` → execution halts the rows it governs, named — D6's handler · s · c · covered by D6 |

forbidden: **execution builds a row whose verdict is neither ruled nor swept by a set blanket** — the `ruled` cell, or a blanket the wisher wrote, is the only license to build. D5, D6, and D8 demonstrate it.

itemized, not demoed (alterpath): **two ruled rows conflict** — e.g. I01 ruled `reject` while I02, which cites it, is ruled `adopt`. the execution clone names the pair and the cite, and asks which gives. its fallback is the peer review at `5.1`, which would flag a cite to a brief that does not exist, so the care is alterpath · s · a.
