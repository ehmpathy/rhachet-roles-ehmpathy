# case=12 · a glob reads from the root it names

> cells A4a–A4b · `slashed × rg × pattern-hits`, split by tail shape T · braced compositions · the
> dot-dir zero (#780) · **sharp** before · **critipath**

## .why a critipath

A4 was graded happy on a probe whose tail held no slash. the grade was wrong for both tail shapes:
rg reads `--glob` from its cwd, and grepsafe ran rg from the caller's cwd, not from the root the
glob named.

- a tail with no slash (`docs/*.md`) matched at any depth — an over-match, a wrong answer that looks
  like a right one
- a tail with a slash (`p/*/a.md`) matched no file — a false zero
- a braced glob (`{src/**,.behavior/**}`) had no literal prefix, so it named no root, and its dot
  alternative was never walked — a false zero

found by the driver in this route, on its own reference search, while `#780` was still open.

## .the narrative

a dev asks for every brief in two trees:

```
rhx grepsafe --pattern 'bounded context' --glob '{src/**,.behavior/**}' --files-only
```

before: `src/` answers, `.behavior/` is never walked, and the header says naught of it. the dev
concludes no route doc mentions the term.

after: two legs, one per root. the header reads `paths: src, .behavior`, and both trees answer.

the same dev narrows to one dir:

```
rhx grepsafe --pattern 'bounded context' --glob 'docs/*.md'
```

before: `docs/sub/deep.md` came back too. after: `docs/` alone, as `.gitignore` would read it.

## .the aha

**a glob has one sense: the one `.gitignore` gives it, relative to the root it names.** an engine
that reads it from anywhere else answers a different question, and both wrong answers — too many and
none — look like right ones.

## .the bdd sketch

```gherkin
given [case41] 'docs/a.md', 'docs/sub/b.md', '.hid/c.md', 'src/d.ts', each holds the pattern

  when [t0] --glob 'docs/*.md'
  then only 'docs/a.md'                                  # A4a

  when [t1] --glob 'p/*/a.md' over 'p/docs/a.md'
  then 'p/docs/a.md'                                     # A4b

  when [t2] --glob '{docs/*.md,.hid/*.md}'
  then '.hid/c.md' and 'docs/a.md'                       # braced, dot dir named
    and the header reads 'paths: docs, .hid'

  when [t3] --pattern '-v marks'
  then it is the pattern, never an rg flag

  when [t4] the only match sits in '.behavior/', --glob '*.md'
  then 'matches: 0 — none in the walked trees, but 1 hidden file(s) hold a match'
    and a 🥥 names '--path .behavior --glob '*.md''      # #780

  when [t5] no match exists anywhere
  then a plain 'no line matched the pattern', no 🥥
```
