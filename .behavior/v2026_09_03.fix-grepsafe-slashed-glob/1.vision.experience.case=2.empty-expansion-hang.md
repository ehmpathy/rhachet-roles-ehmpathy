# case=2 · a glob that matches no file returns at once, and says so

> cells A2 + C5 · `{slashed, bare-path} × glob-empty` · **sharp** · **critipath** · the hang is cured
> by deletion (F9); the legible zero is acceptance 7 (F7)

## .why this case exists

the defect did not cause this experience; the obvious repair did. a repair to case=1 that expands a
slashed glob into a file list hands `grep` an empty operand list on a typo, and `grep` with no
operands reads stdin. a wrong answer becomes an indefinite hang: a wrong answer costs a conclusion; a
hang costs the session.

F9 deleted the grep arm, and `rg` filters a walk rather than take an operand list, so the hang cannot
arise. the half that remains is the zero itself.

## .the narrative

a dev typos a directory:

```
rhx grepsafe --pattern 'paddleOut' --glob 'nosuchdir/**/*.ts' --files-only
```

a bare `matches: 0` is true, and byte-identical to case=6's true zero. the dev cannot tell a typo
from a real no-match, and the typo is far likelier. that moves the defect the wish exists to kill.

so the zero names its kind:

```
└─ matches: 0 — no file matched the glob
🥥 did you know?
   └─ check the path: rhx globsafe --pattern 'nosuchdir/**/*.ts'
```

case=6's true zero reads `no line matched the pattern`. the answer carries what it did — the same
move as the `engine:` line.

## .the aha

case=1 and case=2 are one lesson from two sides: never let the caller confuse "I looked and found
none" with "I could not look." case=1 is that confusion in the answer; case=2 is it in the wait, and
without the zero-kind, in the answer too.

## .the bdd sketch

```gherkin
given [case2] a repo with no 'nosuchdir/' tree

  when [t0] a slashed glob selects no file
    rhx grepsafe --pattern 'paddleOut' --glob 'nosuchdir/**/*.ts'
  then it returns within a second, exit 0
    and the zero reads 'no file matched the glob'

  when [t1] a bare path glob names an absent file           # cell C5
    rhx grepsafe --pattern 'paddleOut' --glob 'nosuchdir/gone.ts'
  then the same

  when [t2] the process is given a closed stdin
  then behavior is identical                                 # no stdin dependence
```

a hang clamp needs a timeout, so a regression is a timely red rather than a stalled suite.
