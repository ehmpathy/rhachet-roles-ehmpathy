# case=6 · a true zero still reads as true

> cell A3 · `slashed × glob-hit-pattern-miss` · **happy** · **critipath**

## .why a critipath

it is the other half of the wish, and the half a narrow repair forgets. the caller cannot part "no
match exists" from "I could not ask the question". a repair that makes the false zero find files, but
makes the true zero look like an error or a stall, has only moved the confusion.

## .the narrative

a clone checks that a term was fully renamed. it expects, and wants, zero:

```
rhx grepsafe --pattern 'oldTermName' --glob 'src/**/*.ts' --files-only

🐢 crickets...

🐚 grepsafe
   ├─ pattern: oldTermName
   ├─ glob: src/**/*.ts
   ├─ engine: rg
   └─ matches: 0 — no line matched the pattern
```

the glob selected real files and the pattern matched no line. the rename is clean, and the clone can
say so.

## .the zero-kinds make it readable

| the zero reads | it means |
|----------------|----------|
| `no line matched the pattern` | a real search, a real absence — trust it |
| `no file matched the glob` | the glob selected no file — check the path (case=2) |
| `…but N hidden file(s) hold a match` | the walk skipped a hidden path — name it (case=12 `[t4]`) |

the wisher ruled the legible zero in as acceptance 7
([F7](./.fulcrums/inventory.of=fulcrums.case=F7-files-count-branch.md)). case=2 and case=6 stand or
fall together.

## .the aha

a zero is only as good as the evidence that the question was asked. every zero grepsafe emits names
its kind, and none is a silent failure to look.

## .the bdd sketch

```gherkin
given [case6] a repo with files under 'src/', none holds 'oldTermName'

  when [t0] a slashed glob selects files but the pattern misses
    rhx grepsafe --pattern 'oldTermName' --glob 'src/**/*.ts' --files-only
  then the zero reads 'no line matched the pattern'
    and exit code is 0

  when [t1] one file is then given the term
  then the SAME command returns that file    # proves [t0]'s zero was a real look
```

`[t1]` gives `[t0]` its weight. a test that asserts only "zero was returned" passes under the defect;
miss, plant, hit is the only shape that proves the zero came from a real search
(`rule.forbid.failhide` applied to the test).
