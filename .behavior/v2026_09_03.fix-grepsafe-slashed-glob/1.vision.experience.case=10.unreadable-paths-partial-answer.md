# case=10 · a path that cannot be read makes the answer partial, and says so

> outside the product — path readability, an axis the walk does not hold · **sharp** · **critipath**

no cell of the 384 names this world; a reviewer found it after the behavior was built and clamped.
it is the backward drift `rule.require.experience-catalog-evolution` checks for.

## .why a critipath

it is a false zero of its own kind. D5, D6, and D7 each describe a path the walk declines to enter. here the
walk tries and is refused, so the result is a partial, and a silent partial is the most dangerous
shape in the wish's family:

| the shape | what the caller concludes |
|-----------|---------------------------|
| a silent partial | "the term does not appear" — false, and it reads like a clean search |
| a partial that names its gap | "the term does not appear in what I could read" — true, and actionable |

a `matches: 0` whose cause is withheld leads a verification clone to delete correct work — the loss
the wish opens with.

## .the narrative

a clone greps a tree; one subdirectory is mode `000`:

```
rhx grepsafe --pattern 'KNOWN_TERM' --glob 'probe/**/*.txt'

🐢 crickets...

🐚 grepsafe
   ├─ pattern: KNOWN_TERM
   ├─ engine: rg
   └─ matches: 0 — could not tell which zero — the file probe failed

🫧 unread — these paths could not be searched
   ├─ probe/locked: Permission denied
   └─ fix: grant read access, then re-run
```

the zero is still zero, but it no longer claims to be an honest kind; it declares that the search
could not complete. this world is why acceptance 7 needs more than two zero-kinds: a file count parts
glob-empty from pattern-miss, but not either from could-not-read.

## .the aha

a skip is not a zero. every other false zero here came from a path the engine never visited; this
one comes from a path it visited and could not open. D5–D8 all model reach — "does the walk go
there?" — and none models permission. a tree can be visible, real, tracked, and named, and still be
unreadable, so no combination of the walked axes expresses this cell.

## .the bdd sketch

```gherkin
given [case10] a readable tree that holds the term, plus one unreadable subtree

  when [t0] every match sits UNDER the unreadable subtree
    rhx grepsafe --pattern 'KNOWN_TERM' --glob 'probe/**/*.txt'
  then the tally does NOT read 'matches: 0 — no file matched the glob'
    and it reads 'could not tell which zero'
    and the unread block names the path and 'Permission denied'
    and the remedy reads 'grant read access'

  when [t1] SOME matches are readable and some are not
  then the results are shown
    and the caveat is shown BESIDE them   # a partial answer, declared as partial

  when [t2] --path names a symlink loop
  then it refuses with 'search path could not be opened'

  when [t3] CONTROL — the same tree, fully readable
  then the ordinary frame renders and no unread block appears
```

`[t3]` gives the rest teeth: a repair that printed the caveat unconditionally would pass `[t0]`–`[t2]`
and make every clean search look compromised. `[t1]` is the easiest to omit: a partial with some
results looks complete, and its caveat rides beside a non-empty body — a different render path.

## .where it is proven

| step | clamp |
|------|-------|
| `[t0]` | `grepsafe [case39][t0]` — the zero-kind and the surfaced cause |
| `[t1]` | `grepsafe [case39][t1]` — a readable match beside the unreadable subtree |
| `[t2]` | `grepsafe [case38][t2]` — the symlink-loop refusal |
| `[t3]` | `grepsafe [case39][t2]` — the readable control |
| two unreadable paths under one glob | `grepsafe [case39][t3]` |
| a `--glob` prefix under an unreadable parent, vs merely absent | `grepsafe [case38][t0]`, `[t1]` |
| the engine's own diagnostic is not counted as a match | `grepsafe [case31][t0]`–`[t2]` |

each pointer is checked against the suite; a wrong pointer is worse than none, since a reader who
follows it concludes the coverage is fictional.
