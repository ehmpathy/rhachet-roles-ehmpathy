# case=7 · a broad glob returns a set a caller can trust

> the latent cell · `slashed × pattern-hits`, breadth unbounded · **sharp** · **critipath** · the
> `ARG_MAX` hazard is cured by deletion (F9); the breadth guards remain

## .why this case exists

the grid produced it. a repair that expands a glob into a file list forces a question the wish never
asks: how big is the list? like case=2, the repair creates the hazard, not the defect.

| probe (bash expansion, repo root) | operands |
|-------|----------|
| `**/*.ts` | 218 — `rg`'s policy walk selects 154 |
| `node_modules/**/*` | 416 |
| `node_modules/.pnpm/**/*.js` | 31,926 |

bash `globstar` crosses no symlinked dir and `**` enters no dot dir without `dotglob`, so a broad
glob stays small, while a caller who names `node_modules/.pnpm/**/*.js` would pass `ARG_MAX`. F9
deleted the expansion arm: `rg` filters a walk and takes no operand list, so no glob can overflow it.

the issue's patch also set `dotglob`, which pulls `.git/` into every `**/*`, and `--exclude-dir=.git`
governs descent, never explicit operands. the wish's repro needs no `dotglob`: `.agent/**/*.md` spells
`.agent` literally.

## .the narrative

a dev audits every use of a price type before a shape change, and casts wide:

```
rhx grepsafe --pattern 'IsoPriceWords' --glob '**/*.ts' --files-only
```

on one box: a clean page of source files. on another: a wall of vendored noise, an
`Argument list too long`, or worst, a quietly truncated list that looks exactly like the clean page.
the second dev sizes the change against a short list, and the unlisted call sites break in prod.

a confident, well-formed, incomplete answer is the defect this round exists to kill — delivered by
the repair.

## .the aha

the repair must not merely find files; a caller must be able to trust the set it found.

## .the bdd sketch

```gherkin
given [case7] a repo with a gitignored 'vendor/' tree that holds the pattern
  and tracked source that also holds the pattern

  when [t0] a broad glob runs
    rhx grepsafe --pattern 'IsoPriceWords' --glob '**/*.ts' --files-only
  then the ignored tree is absent from results   # '**' names no ignored path (case=9 [t3])
    and the output reads 'engine: rg'

  when [t3] a glob of '**/*' is used
  then '.git/' internals are absent from results
```

`[t1]` (grep equals rg's ignore set) is retired: F3 made rg's policy the wrong target, since it
excludes files a caller named. an assertion no correct implementation can satisfy is unfounded, not
dated. `[t2]` (the `ARG_MAX` guard) is retired with the expansion arm. their numbers are not reused.
