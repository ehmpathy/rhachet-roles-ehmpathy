# 1.vision.yield — grepsafe answers the question it was asked

**every zero grepsafe emits is an honest zero, and every answer names its engine.**

the wisher's test: **the headline command returns real results when the work is done — by whatever
set of causes stands between it and that.** measured: a basename match under `grep`, plus three `rg`
walk skips (hidden, linked, gitignored). the headline's own subtree trips all three skips at once.

---

## the outcome

```
rhx grepsafe --pattern 'the bar was MET' --glob '.agent/**/*.md' --files-only
```

| | before | after |
|---|--------|-------|
| `--glob '.agent/**/*.md'` under grep | `matches: 0` — false (basename match) | the grep arm is deleted (F9) |
| `--glob '.agent/**/*.md'` under rg | `matches: 0` — false (hidden + linked skip) | the real files |
| a visible symlinked dir, named literally, under rg | `matches: 0` — false (link not followed) | the real files |
| `--glob 'node_modules/…'` — a path the caller typed | `matches: 0` — false (gitignored) | the real files |
| `--glob '{src/**,.behavior/**}'` — alternatives with their own roots | `.behavior/` never walked | each alternative walks its own root |
| `--glob 'docs/*.md'` | also `docs/sub/*.md` (read from cwd, unanchored) | `docs/` alone |
| a match only behind a dot dir the walk skipped | `no line matched the pattern` | the zero says so, and names the `--path` |
| `--glob '*.md'` | matches found | unchanged |
| `--glob 'nosuchdir/**/*.md'` | (naive repair) hangs on stdin | `matches: 0`, at once |
| which engine answered? | unknowable | `engine: rg`, the only engine (F8+F9); no `rg` ⇒ failfast |
| a zero means | *"either none exists, or I could not look"* | *"none exists"* — one sense |

**the last row is the deliverable. the others are how it is earned.**

same false zero, independent causes: cure any two and the headline still returns 0 while the report
closes. `--glob 'node_modules/**'` is an everyday call, and it false-zeroed while
`--path node_modules` found the files.

### three barriers on the headline path

`.agent/repo=ehmpathy/role=mechanic/briefs/**/*.md`, measured 2026-09-04:

| the path | barrier | evidence |
|----------|---------|----------|
| `.agent` | D5 hidden | dot-prefixed |
| `…/briefs` | D6 linked | `symbolic link to ../../../dist/…/briefs` |
| `…/briefs` | D7 ignored | `.agent/repo=ehmpathy/.gitignore:6:*` — a nested gitignore |
| its target `dist/` | D7 ignored again | `.gitignore:25:dist` |

| call | result |
|------|--------|
| `--path .agent/repo=ehmpathy/role=mechanic/briefs` | ✔ 3 files |
| `--glob '.agent/repo=ehmpathy/role=mechanic/briefs/**/*.md'` | ❌ `matches: 0` |

each barrier is independently sufficient, one control per axis:

| isolation | D5 | D6 | D7 | `--glob` | `--path` |
|-----------|----|----|----|----------|----------|
| `.agent/repo=.this/role=any/briefs` | hidden | real | tracked | ❌ 0 | ✔ 1 file |
| `probefixture/link/**` | visible | linked | tracked | ❌ 0 | ✔ finds it |
| `dist/**` | visible | real | ignored | ❌ 0 | ✔ finds it |

the ignore rule on the `ehmpathy` subtree is nested inside a hidden directory, so a repair that reads
only the root `.gitignore` fails that path.

### to name a path is to opt into it

> *"if someone says glob/grep `node_modules`, then they know it's gitignored already."*

the argument holds for all three skips: a caller who types `.agent/…` knows it is hidden; a caller
who types a symlinked path means to follow it. ⇒ to NAME a path lifts every skip that would hide it —
`--hidden`, link resolution, and `--no-ignore` together, scoped to what was typed. one rule, not three.

the wish's fixture text is absent from this checkout; the defect reproduces on an in-repo fixture:

| call | result |
|------|--------|
| `--pattern 'repo structure: rhachet-roles-ehmpathy' --glob '.agent/**/*.md'` | `matches: 0` — false |
| `--pattern 'repo structure: rhachet-roles-ehmpathy' --path .agent` | 1 real file |

the clamps use hermetic fixtures; `.agent/`'s contents are not this route's to pin.

### the aha

**the zero was not a miss. it was an argument.** a trusted tool that silently cannot ask the question
does not withhold a fact — it argues for the opposite one, and the repair it invites is to delete
correct work. in the session that found this, a cited brief line was almost graded invented.

⇒ `rule.forbid.failhide` is not about crashes. a confident wrong answer is the loudest hide.

### what the walk found that a free-list would have missed

- **case=6** — a narrow repair makes case=1 return files and looks done, but half the ambiguity the
  wish names lives in the true zero
- **case=7** — `rg` honors `.gitignore`; a bash expansion does not. with two engines they would
  disagree after the repair — the argument for acceptance 4, and for F8
- **case=8** — a second, more general defect that fires under `rg` with no glob at all
- **the D6 discriminant is `**` traversal, not the link** under bash: a symlink named literally
  resolves, and only a `**` asked to cross a link fails. under `rg`, a literal name rescues no linked
  path (probes 12–14), and a slashed glob fails under `grep` by C1's basename defect whatever the
  linkage. each defect row holds only its `pattern-hits` third (the D3 carve-out): where the pattern
  misses or the glob selects no file, the barrier conceals no match
- **divergence 5**, on a hermetic fixture:

  | probe | engine | result |
  |-------|--------|--------|
  | control `--glob 'probefixture/real/**/*.md'` | rg | ✔ finds it |
  | `--glob 'probefixture/link/**/*.md'` | rg | ❌ `matches: 0` |
  | `globsafe --pattern 'probefixture/link/**/*.md'` | bash | ✔ finds it |

  same tree, same text, one path through a link
- **forbidden = 2**, graded on outcomes: `.git/` internals must not appear in results; the walk must
  not descend a symlink into a gitignored tree it merely meets

## mental model

> "grepsafe would tell me there were no matches, when there were. not an error — just zero. and zero
> looks like an answer."

- **a scale that reads zero because it is unplugged.** the number looks real. the weight is not.
- **two translators, one badge.** two could have answered, they disagree on what your words mean,
  and neither signs their work. that is acceptance 4.

| they say | we say |
|----------|--------|
| "it didn't find my file" | the glob was matched against the basename |
| "it just hung" | empty operand list ⇒ grep reads stdin |
| "it works on my machine" | `command -v rg` saw a zsh alias, or did not |
| "zero results" | a true zero, or a false one — the wish exists to part them |

⇒ the term: **`false zero`** — not an error, not a crash, but a well-formed answer that is untrue.

## evaluation

| # | acceptance | met by |
|---|-----------|--------|
| 1 | slashed glob finds matches | case=3 (rg, visible) · case=8 (hidden) · case=9 (ignored). one engine (F8+F9): the grep basename cause is cured by deletion of the arm |
| 2 | unslashed unchanged | case=4, plus three extant snapshots |
| 3 | empty glob returns 0, no hang | case=2, with a test timeout |
| 4 | engine named in output | case=5 |
| 5 | a clamp with teeth | case=1 `[t0]`, revert-to-red · case=8's rg clamp |
| 6 | the `rg` arm checked, not assumed | case=3 (six runs, `/usr/bin/rg`) · case=8 (eight more, which found the second defect) |
| 7 | every zero reads apart, from the answer alone (F7, 2026-09-08) | case=2 glob-empty · case=6 pattern-miss · case=1/8/9 could-not-run |
| 8 | one engine: `rg` found wherever it exists; failfast where absent (F8 2026-09-08, F9 2026-09-11) | the grep arm is deleted — "zero synonymous codepaths" |

acceptance 1 is outcome-scoped: to cure the reported symptom is not a widened surface, however many
causes sit behind it.

acceptance 7, as adopted, on the trait:

> **a caller can tell WHICH KIND of zero they got, from the answer alone:** no file matched the
> glob · no line matched the pattern · the search could not run.

### pros

- acceptance 6 is discharged at the vision: `rg` is on PATH here, so the arm was measured, and that
  measurement found the second defect
- one engine is a cure, not a mitigation: the divergences cannot arise
- provenance outlives the fix: the `engine:` line turns a future divergence into a one-glance read

### cons

- a PATH-based rg force-off is a trap: `PATH=/usr/local/bin:/bin` silently still finds rg, since
  `/bin` → `/usr/bin` on merged-`/usr`. the clamp shadows the binary with a stub
- three snapshots shift from the `engine:` line; a blind resnap could swallow a regression
- three skips stack on the headline, so a repair that clears two ships a false zero

### the edge cases

| edge | what keeps the caller safe |
|------|---------------------------|
| glob expands to no file | returns 0 at once, never reads stdin (case=2); reads apart from a true zero (acceptance 7) |
| glob is a typo'd bare path | the same guard (C5) |
| glob is broad (`**/*.ts`) | one engine reads it; the expansion was 218 under bash vs 154 under rg |
| glob would pull in `.git/` | `-g '!.git'` rides with the lifts |
| rg present but invisible to bash | the finder runs `rg --version`, so a vendored or aliased rg is seen; genuinely absent ⇒ failfast |
| a genuine zero | stays a plain, trustworthy zero (case=6) |

| A1 | GNU `grep --include` matches basenames only | documented; argv dump in #620; reporter's validation | low; not re-run here (the permission guard refused a direct `grep --include=`) — moot once F9 deleted the arm |

## what is awkward

1. **the glob anchor.** grepsafe anchors a `--glob` prefix under `--path`; globsafe anchors at cwd.
   two peer skills, two anchors. out of scope to unify; pinned by a clamp
2. **the clamp sabotages its own environment.** the failfast test shadows a present binary — a test
   that asserts a fact about the machine
3. **the walk is complete only over the axes named and the mechanisms measured.** `--path` was
   modelled by no axis until probe 18b found a false zero reachable only through it (`--path
   .reviews/peer` → 0, bash → 6), in cells the grid graded "the skip is the contract". it is now D8.
   a blind spot named is not a blind spot closed: the repair for an unwalked discriminant is an axis
4. **equivalence is only as good as the set both sides equal.** F3's tracked-files bind would have
   shipped "the engines agree" over a set that excluded files the caller named

## the definition of done

1. a slashed glob finds its matches — case=3 (visible) · case=8 (hidden) · case=9 (ignored); the
   grep cause (case=1) is cured by deletion
2. an unslashed glob is byte-identical but for the `engine:` line — case=4
3. an empty expansion returns 0 at once, under a timeout-guarded test — case=2
4. the output names the engine — case=5
5. a clamp with teeth on the arm the defect lived in, red on revert — case=1 `[t0]`
6. a true zero stays trustworthy — case=6
7. a gitignored path the caller NAMES is searched; the walk still skips an ignored tree it merely
   MEETS — case=9 `[t1]`/`[t3]`. the constraints each clamp must hold:
   - `[t3]`'s fixture is unreachable by `--path`, or a correct implementation reads as broken
   - pairwise compositions are their own step (`[t5]`: `hidden × ignored`, `linked × ignored`) —
     one lift and three lifts do not prove two
   - `--path` is the other form a caller names a path (`[t6]`); a repair must read the invocation,
     never the tree
   - the search reaches the contents of a named path: rg's explicit-root override covers the root
     alone (`.reviews/peer` → 0 by `--glob` and by `--path`)
8. a dot-directory is searchable, with a control that isolates D5 from D7 (`.agent/repo=.this/…`,
   hidden, real, tracked); the headline subtree that stacks all three barriers is clamped (case=9 `[t4]`)
9. the two hazards the repair opens are measured: `.git/` stays excluded; the walk does not descend a
   met symlink into a gitignored tree
10. `dist/` is rebuilt locally so a byhand `rhx grepsafe` shows the fix, and is not committed
11. a link named literally resolves under `rg` — case=8 `[t5]`, on a hermetic fixture with a
    real-path control
12. the `grep -r` symlink residual — 8 cells in `D8 = default` — moot once F9 deleted the grep arm
13. every zero reads apart — acceptance 7. the trait binds; the shape is execution's
14. `rg` is found wherever it exists, and grepsafe failfasts where it is absent — acceptance 8. the
    `command -v rg` selector let a live ripgrep go unseen on the reporter's box, so every measurement
    in #620 measured the fallback. find `rg` properly; delete the grep arm; exit non-zero and name
    the fix, never a `0`

item 10 is a trap:

| fact | measured |
|------|----------|
| `rhx` reads `dist/` | `.agent/…/skills` → `symbolic link to ../../../dist/domain.roles/mechanic/skills` |
| the clamp reads `src/` | `grepsafe.integration.test.ts:11` → `path.join(__dirname, 'grepsafe.sh')` |
| `dist/` is not committed | `.gitignore:25:dist` · `git ls-files dist` → no rows |

after the repair lands in `src/`, the clamp goes green while a byhand `rhx grepsafe` still shows the
defect, until `npm run build`. a clone that sees the pair could wrongly conclude its own fix failed.
