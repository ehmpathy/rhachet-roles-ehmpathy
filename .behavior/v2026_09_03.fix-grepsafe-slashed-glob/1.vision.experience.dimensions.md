# 1.vision.experience.dimensions

## .what

the axes the `grepsafe --glob` experience varies over. their product is the experience space;
`1.vision.experience.case=_.md` walks it.

## .the product

`D1 × D2 × D3 × D5 × D6 × D7 × D8` = `4 × 2 × 3 × 2 × 2 × 2 × 2` = **384 cells**. D4 (actor) is
dropped.

- `D8 = default` — 192 cells: a `D7 = tracked` half (96) and a `D7 = ignored` half (96)
- `D8 = named` — 192 cells, walked in its own block of the inventory

the arithmetic is written as a factored expression so a reader can re-derive it from the axis list.
a factored form makes a stale total legible; it does not make one impossible.

## .the axes

### D1 · glob shape — 4 values

| value | example | note |
|-------|---------|------|
| `none` | (no `--glob`) | the unfiltered search |
| `unslashed` | `*.md`, `*.ts` | a basename pattern |
| `slashed` | `src/**/*.ts`, `.agent/**/*.md` | a path pattern — most real calls |
| `bare-path` | `src/index.ts` | a literal path, no wildcard |

`bare-path` splits from `slashed` because an expansion-based repair treats it differently: it names
one extant file or none.

two refinements, neither a new value:

- **T · tail shape**, a sub-property of `slashed`: the tail after the literal prefix holds a slash
  (`p/*/a.md`) or not (`docs/*.md`). rg reads `--glob` from its cwd, so each misfired from the wrong
  cwd — a false zero and an over-match. it splits cells, like `R`, and multiplies none
- **a braced glob** is a composition: `{docs/*.md,.hid/*.md}` is one cell per alternative. each
  alternative names its own root, or none

### D2 · engine — 2 values

| value | when it runs | `--glob` matches against |
|-------|--------------|--------------------------|
| `rg` | `command -v rg` succeeds under bash | the path, read from rg's cwd — grepsafe runs rg from each leg's root |
| `grep` | rg absent, or invisible (a shell alias) | the basename only |

the box picks the engine, never the glob.

D2 = 2 diagnoses the tool as found; the delivered solution has D2 = 1. F8 + F9 delete the grep arm:
`rg` is found wherever it exists, and grepsafe failfasts where it is absent. every `D2 = grep` cell
documents a defect cured by deletion.

### D3 · world state — 3 values

| value | sense |
|-------|-------|
| `pattern-hits` | the glob selects files, and the pattern matches inside them |
| `glob-hit-pattern-miss` | the glob selects files, the pattern matches no line — a true zero |
| `glob-empty` | the glob selects no file — the hang hazard lives here |

at `D1 = none` the names read as `pattern-miss` (the whole root searched, no line matched) and
vacuous (`glob-empty` has no glob to come back empty; those cells are impossible).

### D4 · actor — dropped

`robot` vs `human`. every cell's feel was identical across D4 and the drop moved no verdict: a cost
multiplier, not a discriminant. the one real difference is the next move — a human re-asks, a robot
concludes and writes the conclusion down, so only a correct answer reaches it. that argument lives in
case=5, where it bears on what the output must carry. ruled at
[F4](./.fulcrums/inventory.of=fulcrums.case=F4-actor-as-a-dimension.md); a restore doubles every
count and moves no verdict.

### D5 · path visibility — 2 values

| value | example |
|-------|---------|
| `visible` | `src/`, `bin/` |
| `hidden` | `.agent/`, `.behavior/`, `.github/` |

`rg` skips hidden paths by default, so every `hidden × rg` cell returns a false zero whatever the
glob shape, even with no glob (case=8). the wish's own repro (`.agent/**/*.md`) sits in a hidden
cell. orthogonal to D1: `*.md` can target a hidden tree via cwd.

### D6 · path linkage — 2 values

| value | example |
|-------|---------|
| `real` | `src/`, `.fulcrums/` |
| `linked` | `.agent/repo=ehmpathy/…/briefs` → `dist/…` |

under bash, three shapes against the same link:

| glob shape | the link is… | result |
|------------|--------------|--------|
| `…/briefs/*.md` | named literally | ✔ found |
| `…/briefs/**/*.md` | named literally, `**` below it | ✔ found |
| `…/role=mechanic/**/*.md` | crossed by `**` | ✘ only `readme.md` |

⇒ under bash, `**` does not traverse into a symlinked directory; a literal name resolves through it.

under `rg`, a literal name rescues no linked path: probe 12 (hidden, `matches: 0`) and probes 13–14
(visible, hermetic `probefixture/link → real`, with a control on the real twin). the mechanism:

> bash **expands** a glob into path operands, so a literal name resolves through a link.
> `rg` **filters a walk**, so a path the walk never enters cannot be rescued by any glob text.

the discriminant is the engine, not visibility.

D6 is orthogonal to D5; all four combinations exist in this repo:

| path | hidden | linked |
|------|--------|--------|
| `node_modules/typescript` → `.pnpm/typescript@5.4.5/…` | no | yes |
| `.agent/repo=ehmpathy/…/briefs` → `dist/…` | yes | yes |
| `.fulcrums/` | yes | no |
| `src/` | no | no |

the barriers stack: clear the symlink barrier and a hidden path is still unsearchable under `rg`;
clear the hidden one and a `**` still will not cross a link.

### D7 · path ignorance — 2 values

| value | example |
|-------|---------|
| `tracked` | `src/`, `bin/` |
| `ignored` | `dist/`, `node_modules/`, `.agent/repo=ehmpathy/` |

`rg` has three independent default skips:

| skip | the flag that lifts it | axis |
|------|------------------------|------|
| dot-prefixed paths | `--hidden` | D5 |
| symlinked dirs, on traversal | `-L` | D6 |
| gitignored paths | `--no-ignore` | D7 |

`dist/` is visible and real, and still false-zeros:

| probe | gitignored | result |
|-------|------------|--------|
| control `--glob 'src/**/*.sh'` | no | ✔ finds the file |
| `--glob 'dist/**/*.sh'` | yes | ❌ `matches: 0` |
| `--glob 'node_modules/domain-objects/package.json'` | yes | ❌ `matches: 0` |
| `--path node_modules/domain-objects` | yes | ✔ 2 files |

the last row shows the contract contradicted itself: `--path <ignored>` searched it, because
`realpath` hands `rg` an explicit root; `--glob '<ignored>/**'` did not.

the wisher's rule settles D7:

> **"if someone says glob/grep `node_modules`, then they know it's gitignored already, so we still
> want to open it up and search it. it's an automatic opt-into gitignore-ignore."**

the ignore rules govern what a walk wanders into, never what a caller typed. forbidden invariant F2
reads: incidental traversal into an ignored tree is forbidden; an explicitly named one is required.

D7 is not a pure multiplier: `ignored × rg` is a false zero where `tracked × rg` is correct. the
ignored half collapses on one mechanism — `rg` skips it unless the path is named and opened.

### D8 · search root — 2 values

| value | what it is |
|-------|-----------|
| `default` | no `--path`; the walk starts at cwd |
| `named` | `--path <dir>` names a root |

`--path` is grepsafe's second way to name a search target. its value flips verdicts:

| cell | `default` | `named` | measured by |
|------|-----------|---------|-------------|
| `hidden` | ❌ skipped | ✔ searched | `--path .agent` → files |
| `linked` | ❌ skipped | ✔ searched — `realpath` resolves the link first | probes 12b, 19b |
| `ignored`, rule on the named root | ❌ skipped | ✔ searched | probes 17, 19b |
| `ignored`, rule nested beneath it | ❌ skipped | ❌ still 0 — a false zero | probe 18b |

every `alterpath` grade in the grid rests on *"`--path <the dir>` reaches the goal"* — a claim about
`D8 = named`. the last row is a false zero reachable only through `--path`, in cells otherwise graded
"the skip is the contract". a discriminant owes an axis, not an annotation.

## .the collapses

the `D7 = tracked` half, by quadrant:

| quadrant (D5 × D6) | cells | walk depth |
|--------------------|-------|------------|
| `visible × real` | 24 | per cell |
| `hidden × real` | 24 | per sub-block, twin by twin |
| `visible × linked` · `hidden × linked` | 48 | split eleven ways — below |

a collapse is legitimate only where one mechanism gives every D1 × D2 × D3 value the same outcome,
and it must be checked against every axis it spans. `hidden × real` is inherited twin by twin
because `grep` has no hidden skip, so its half behaves as its visible twins.

### the linked block — 48 cells

| family | cells | verdict |
|--------|-------|---------|
| `**` must cross a link (slashed × linked) | 12 | demoed critipath in the `pattern-hits` third (4); the grep half by C1, the rg half by case=8 + probes 13–14 |
| named literally, bare-path × visible × grep | 3 | demoed / sharp / critipath — C1's basename defect |
| named literally, unslashed × visible × grep | 3 | itemized / sharp (provisional) / alterpath |
| named literally, visible × rg | 6 | demoed / sharp / critipath — probes 13–14 |
| named literally, bare-path × hidden × grep | 3 | demoed / sharp / critipath — twin of the visible row |
| named literally, unslashed × hidden × grep | 3 | itemized / sharp (provisional) / alterpath — twin of the visible row |
| named literally, hidden × rg | 6 | demoed / sharp / critipath — probe 12 |
| `none × glob-empty × linked` | 4 | impossible |
| `none × pattern-hits × linked × rg` | 2 | demoed / sharp — a false zero with no glob (`--path .agent` → 0) |
| `none × pattern-hits × linked × grep` | 2 | provisional residual |
| `none × pattern-miss × linked` | 4 | itemized / happy / alterpath — a true zero |

rows 1–7 state their `pattern-hits` third only (the D3 carve-out). where the pattern misses or the
glob selects no file, the barrier conceals no match, and the cell inherits its visible twin:

| third | cells | verdict |
|-------|-------|---------|
| `pattern-hits`, rows 1–7 | 12 | the row's defect verdict |
| `pattern-miss` + `glob-empty`, rows 1–7 | 24 | inherit the visible twin |
| the `D1 = none` families | 12 | 4 impossible · 4 itemized · 2 demoed · 2 provisional |
| **total** | **48** ✔ | |

a D6 walk barrier fires with no glob too: the root is walked, and a linked directory met on the walk
is not descended (`--path .agent` → 0, `--path .agent/…/briefs` → 2).

each row names the probe that exercised its own engine; after any split, every row the split's rule
reaches is re-read. the falsifiable form: find one case where a `**` asked to cross a symlinked
directory does descend it.

### the provisional residual — 8 cells

`{none, unslashed} × grep × linked × pattern-hits`, both visibilities, both D7 values (grep reads no
`.gitignore`, so D7 cannot change a grep cell), all in `D8 = default`. at `D8 = named`, `realpath`
resolves a linked root before grep runs, so those cells are measured happy.

| axis | status |
|------|--------|
| feel | provisional, predicted `sharp`: grepsafe hands grep the search root and always passes `-r`, never `-R`, so the link is met on the walk, where GNU `-r` does not follow it |
| care | `alterpath`, measured: `--path <the link>` works because `realpath` resolves it first |

one probe settles all eight, and needs the grep arm forced on. moot once F9 deleted the arm.

## .the dependency

`D1 = none` cannot co-occur with `D3 = glob-empty`. the void is
`D1=1 × D2=2 × D3=1 × D5=2 × D6=2 × D7=2 × D8=2` = **32**:

| where | cells |
|-------|-------|
| `D8 = default` · `D7 = tracked` — `visible × real` | 2 |
| `D8 = default` · `D7 = tracked` — `hidden × real` | 2 |
| `D8 = default` · `D7 = tracked` — linked block | 4 |
| `D8 = default` · `D7 = ignored` | 8 |
| `D8 = named` | 16 |
| **total impossible by nature** | **32** ✔ |

one level of decomposition only, so the rows sum to the total. every other combination is reachable.

## .a property, not an axis — expansion breadth

`rg` skips gitignored paths; a bash glob does not. so one `**/*.ts` query selects a different file
set per engine — measured 154 under `rg`, 218 under a bash expansion. it is an output of a cell, not
an input the caller varies, so it multiplies no cell and lives in case=7.

| | expansion breadth | D7 · path ignorance |
|---|---|---|
| what varies | how many files one query returns | whether the searched path is ignored |
| where it lives | an output of a cell — case=7 | an input the caller controls — case=9 |
| the defect | two engines disagree on a count | a named path returns a false zero |

the `ARG_MAX` leg is gone with the expansion arm (F9): `rg` takes no operand list, so a named
`node_modules/.pnpm/**/*.js` is a supported call with no limit to pass.
