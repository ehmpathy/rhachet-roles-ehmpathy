# case=11 · the one engine is absent, or present and broken

> the world D2's collapse created · **sharp** · **critipath**

a reviewer found this world: F8 + F9 collapsed D2 to one engine, and no cell was added for "the one
engine is unavailable". it is the backward drift `rule.require.experience-catalog-evolution` checks
for.

## .why the collapse created this world

with two engines, an absent `rg` was a fork: the selector fell to `grep`, and "no engine" could not
arise. F9 deleted `grep`, so "no `rg`" became a terminal state a caller lives through — the most
consequential surface the fold-in introduced. a collapsed axis is not a deleted axis; it is an axis
with one value and a new failure mode.

## .why a critipath

the alternative to a loud refusal is the defect the round exists to kill. `command -v rg` false is
the condition behind the whole wish: on the reporter's box a live ripgrep was invisible to bash, the
selector fell through, and every measurement in #620 measured a fallback nobody knew they had.

| if rg is unavailable and grepsafe… | the caller gets |
|---|---|
| returns `matches: 0` | a false zero with no engine at all |
| falls back in silence | #620 again: an answer from an engine the caller cannot see |
| failfasts, and names the fix | a constraint they can act on in one step |

acceptance 8 chose the third; this case is its caller-met surface.

## .the narrative

### the absent engine

```
rhx grepsafe --pattern 'KNOWN' --glob 'src/**/*.ts'

🐢 bummer dude...

🐚 grepsafe
   └─ error: ripgrep (rg) is required but was not found
      └─ grepsafe searches with rg only; there is no fallback engine

🥥 did you know?
   ├─ install ripgrep, then re-run
   └─ https://github.com/BurntSushi/ripgrep#installation
```

exit 2 — a constraint, never a malfunction and never a zero.

### the broken engine — a different sentence

```
🐢 bummer dude...

🐚 grepsafe
   └─ error: ripgrep (rg) is on PATH but could not run
      ├─ grepsafe searches with rg only; there is no fallback engine
      └─ rg said: rg: symbol lookup error: undefined symbol pcre2_compile_8

🥥 did you know?
   ├─ repair or reinstall the rg on your PATH, then re-run
   └─ https://github.com/BurntSushi/ripgrep#installation
```

the two must not share a frame: "install ripgrep" is the wrong remedy for a caller who has it. they
would install it, meet the same failure, and conclude the tool lies. the discriminant is `command -v`
succeeds and the invocation fails; the remedy swaps from install to repair, and rg's own words are
relayed so the cause is not laundered.

## .the aha

a tool with one engine owes a louder answer than a tool with two. the fold-in bought its cure — no
divergence can arise — at the price that the engine's absence is unrecoverable at runtime. the honest
form of "we simplified" names the new edge the simplification created.

## .the bdd sketch

```gherkin
given [case11] grepsafe, and an rg that cannot serve

  when [t0] rg is absent from PATH entirely
  then exit code is 2
    and the output names 'ripgrep' and 'install'
    and it does NOT read 'matches: 0'      # the false-zero guard

  when [t0.5] rg is on PATH but exits non-zero on invocation
  then the frame says 'on PATH but could not run'
    and it relays rg's own reason verbatim
    and the remedy reads 'repair or reinstall', never 'install'

  when [t1] the absent-rg case runs under --output pipeable
  then the machine-read shape carries the same refusal

  when [t2] the broken-rg case runs under --output pipeable
  then likewise

  when [t3] CONTROL — rg is present and healthy
  then an ordinary search runs and no engine refusal appears
```

`[t0]` and `[t0.5]` stay separate because their remedies differ; a repair that merged them would pass
a naive read of either.

## .where it is proven

| step | clamp |
|------|-------|
| `[t0]` | `grepsafe [case24][t0]` — exit 2, names the fix, asserts no `matches: 0` |
| `[t0.5]` | `grepsafe [case24][t0.5]` — the broken-rg frame, both streams, snapped |

| `[t3]` | implicit — every other green given runs with a real rg on this host |

## .the gap in `[t3]`

the control is implicit. a repair that always refused would redden 400+ other steps at once, but no
single step states "rg present ⇒ no engine refusal" as its own claim. a nitpick by the harm test, so
itemized, not repaired at this gate.
