# case=1 · a slashed glob finds what it matches

> cell A1 · `slashed × grep × pattern-hits` · **sharp** · **critipath** · cured by deletion: F9
> removed the grep arm, so grepsafe failfasts where `rg` is absent (case=11)

## .the narrative

a clone is at a verification stone. a brief cites a guarantee, and the clone must confirm the line is
real before it grades the claim.

```
rhx grepsafe --pattern 'the bar was MET' --glob '.agent/**/*.md' --files-only
   └─ matches: 0
```

the clone reads the zero as evidence. it does not know that `.agent/**/*.md` went to
`grep --include`, which matches basenames only, so the glob selected no file and the pattern was
never asked of any file. the answer looks exactly like a clean search.

the clone concludes the brief invented the line, and the repair it invites is the deletion of a true
claim. the file is real; the string sits on line 69.

after the repair, the same question returns the matched files, and the brief keeps its line.

## .the aha

a zero was an argument. grepsafe was not merely wrong, it was persuasive: a trusted tool that
silently cannot ask the question talks you into the deletion of correct work.

## .the repro string is absent from this worktree

`rhx grepsafe --pattern 'the bar was MET' --files-only` — no glob — returns 0: the reporter's box
carried other `.agent/` content. the clamp builds its own fixture in a temp repo; the wish's
`4 matches` is the reporter's figure.

## .one symptom, four causes

| tree | engine | cause | owner |
|------|--------|-------|-------|
| any | `grep` | basename `--include` | this case — cured by F9 |
| hidden `.agent/` | `rg` | hidden skip + symlink skip | case=8 |
| ignored path | `rg` | gitignore skip | case=9 |
| slashed tail, braced roots | `rg` | glob read from rg's cwd | case=12 |

acceptance 1 is discharged by case=3 + case=8 + case=9 + case=12 together, never by one alone.
