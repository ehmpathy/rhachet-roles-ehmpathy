## `ARG_MAX` (A4, refuted)

| probe | operands |
|-------|----------|
| `**/*.ts` at repo root | 218 (vs 154 under `rg`) |
| `**/*.js` at repo root | 61 |
| `node_modules/**/*` | 416 |
| `node_modules/.pnpm/**/*.js` | 31,926 |

bash `globstar` does not descend a symlinked dir (every top-level pnpm package is one), and `**`
skips dot dirs without `dotglob`, so a caller must type `.pnpm` to reach `ARG_MAX`. neither engine
lets `**` cross a symlinked dir; probes 9–11 falsified a broader claim.
