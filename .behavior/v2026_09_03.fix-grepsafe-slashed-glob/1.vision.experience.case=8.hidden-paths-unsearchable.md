# case=8 · a dot-directory is searchable at all

> `any glob × rg × pattern-hits`, path **hidden** or **linked** · **sharp** · **critipath**
> in scope — F6, wisher, 2026-09-03, option A. not in the wish; it subsumes the wish's own repro.

scope:

- the `hidden × rg` pattern-hits cells, every glob shape
- `visible × linked × rg` and `hidden × linked × rg` (probes 12–14)
- `none × pattern-hits × linked × rg` — `--path .agent` → 0 with no glob, `--path .agent/…/briefs` → 2
- not the grep half of the linked block: a slashed or bare-path glob hits case=1's basename defect
  first. the `{none, unslashed} × linked × grep × pattern-hits` residual (8 cells) is provisional in
  feel only
- D3 carve-out: where the pattern misses or the glob selects no file, the skip conceals no match, and
  the cell inherits its visible twin

## .the discovery

under `rg`, grepsafe could not see inside any dot-directory: `rg` skips hidden paths by default and
grepsafe passed no flag to change that. `.agent/`, `.behavior/`, `.github/`, `.claude/`, and
`.fulcrums/` were invisible.

## .the rule — traversal, not the path handler

| # | probe | result | reads as |
|---|-------|--------|----------|
| 1 | `--pattern 'the fulcrum council'` (path `.`) | 0 | `.fulcrums` skipped on the walk |
| 2 | `--pattern 'the fulcrum council' --path .fulcrums` | 6 files | an explicit root is searched |
| 3 | `--pattern 'slashed-glob-false-zero'` (path `.`) | 0 | `.behavior` skipped on the walk |
| 4 | `--pattern 'slashed-glob-false-zero' --path .behavior` | 4 files | an explicit root is searched |

an explicit root is searched, hidden or not; a hidden entry met on traversal is skipped. the repair
belongs at the walk.

## .the wish's headline, reproduced locally

| call | result |
|------|--------|
| `--pattern 'repo structure: rhachet-roles-ehmpathy' --glob '.agent/**/*.md'` | `matches: 0` — false |
| `--pattern 'repo structure: rhachet-roles-ehmpathy' --path .agent` | 1 real file |

own peer-review artifacts.

## .the barriers stack

`.agent/` mixes kinds:

| path | kind |
|------|------|
| `.agent/repo=.this/role=any/briefs` | real directory |
| `.agent/repo=ehmpathy/role=mechanic/briefs` | symlink → `dist/domain.roles/mechanic/briefs` |
| `.agent/repo=bhrain/role=driver/briefs` | symlink → `node_modules/.pnpm/…/driver/briefs` |

and `rg` does not follow symlinked directories on traversal:

| # | probe | result |
|---|-------|--------|
| 5 | `--pattern 'slow and steady builds reliable software' --path dist` | 2 files |
| 6 | same string, `--path .agent` | 0 — link not descended |
| 7 | same string, `--path .agent/repo=ehmpathy/role=mechanic/briefs` | 2 files — an explicit link root is followed |

two independent barriers stack on the corpus a clone searches to verify a citation. a one-flag repair
satisfies neither the headline nor acceptance 1.

### under bash, `**` does not cross a link; a literal name resolves

| # | glob shape (bash arm) | the link is… | result |
|---|------------|--------------|--------|
| 9 | `.agent/…/role=mechanic/briefs/*.md` | named literally | ✔ found |
| 10 | `.agent/…/role=mechanic/briefs/**/*.md` | named literally, `**` below | ✔ found |
| 11 | `.agent/…/role=mechanic/**/*.md` | crossed by `**` | ✘ only `readme.md` |

under `rg`, a literal name rescues no hidden path — the skip fires on traversal, before the glob:

| # | probe | engine | result |
|---|-------|--------|--------|
| 12 | `--glob '.agent/repo=.this/role=any/briefs/repo.structure.md'` | rg | `matches: 0` ❌ |
| 12b | `--path .agent/repo=.this/role=any/briefs` | rg | 1 file ✔ |

the fixture is a real directory, so probe 12 isolates the hidden barrier.

### the `visible × linked` narrative

a maintainer keeps shared briefs as a symlink, linked into each package that reads them — no dot, no
gitignore:

```
packages/api/briefs -> ../../shared/briefs
```

```
rhx grepsafe --pattern 'retry policy' --glob 'packages/api/briefs/**/*.md' --files-only
   └─ matches: 0
```

the file is there, the path is visible and tracked, and the editor shows the string. they conclude
grepsafe is broken or they mistyped; both are wrong. this story holds no special path: the defect is
how the walk treats a link, and a caller who learned the dot-directory lesson still gets burned.
`--path packages/api/briefs` works (`realpath` resolves the link first), so these cells grade
critipath on freq × cost, not on the absence of an escape.

### probes 13–14 — the link barrier alone, on a visible path, with a control

```
probefixture/real/deep/brief.md      ← holds the string; not gitignored (git check-ignore exits 1)
probefixture/link -> real            ← a visible symlink, named literally in the glob
```

| # | probe | engine | result |
|---|-------|--------|--------|
| control | `--glob 'probefixture/real/**/*.md'` | rg | ✔ finds it |
| 13 | `--glob 'probefixture/link/**/*.md'` | rg | ❌ `matches: 0` — a false zero |
| 14 | `globsafe --pattern 'probefixture/link/**/*.md'` | bash | ✔ finds it |

the only difference between control and probe 13 is the link.

> bash **expands** a glob into path operands, so a literal name resolves through a link.
> `rg` **filters a walk**, so a path the walk never enters cannot be rescued by any glob text.

the execution stone clamps this shape, not `.agent/`, which stacks barriers and so cannot show which
repair it proved. D5 and D6 are each a property of the walk, which points the repair at one place.

## .the hazard the wider repair opens — breadth

follow links out of `.agent/` and the walk reaches `dist/` and `node_modules/.pnpm/…`:

| probe | result |
|-------|--------|
| 8 · `--pattern 'routes are gardened' --path .agent/repo=bhrain/role=driver/briefs` | 1 file, named as `node_modules/.pnpm/…/define.routes-are-gardened.[philosophy].md` |

an explicit root bypasses the gitignore filter. a repair that follows links on traversal must not
descend an unnamed ignored tree, or it re-creates case=7's breadth detonation by a new route — the
forbidden invariant F2, clamped by `[t4]`.

## .a provenance wart

the caller asks about `.agent/…` and the answer names `dist/…` or `node_modules/…`: the path is
resolved, not echoed. defensible — it is where the bytes live — but a reader may believe they
searched the wrong tree. out of scope; recorded so it is seen.

## .why a critipath — it subsumes the wish's repro

the wish's headline, `--glob '.agent/**/*.md'`, targets a dot-directory. on a box with `rg` — every
box Claude Code ships — that command returned a false zero for this reason, and a repair to the grep
fallback would not move it. this defect needs only a dot-directory, fires under the preferred
engine, and needs no glob.

| engine | why the headline returned 0 | closed by |
|--------|-----------------------------|-----------|
| `rg` | `.agent` skipped on the walk; briefs also behind links | this case, F6 |
| `grep` | `--include` matches the basename (A1) | case=1; the arm is deleted (F9) |

one symptom, two causes, one deliverable (F6).

## .the narrative

a clone three stones into a drive must verify that a brief it cited really says what it claimed. it
knows where the line lives:

```
rhx grepsafe --pattern 'errors carry context' --glob '.agent/**/*.md' --files-only
   └─ 🐢 crickets...
      └─ matches: 0
```

no error, no caution, no hint of a filter — the same tidy tree as every clean search. the clone
concludes the line is not there, believes it caught a fabricated citation, deletes a true claim from
the brief, and records the "correction" in its yield with confidence. the next traveler trusts the
yield. the false zero has laundered itself into a fact.

## .the aha

the false zero surfaced while this document about false zeros was written: a link-check with
`--glob '.behavior/**/*.md'` returned zero, and zero looked clean. `.agent/` holds the briefs and
`.behavior/` holds the routes — the two trees an agent searches to check its own work. the defect aims
at the act of verification.

## .the bdd sketch

```gherkin
given [case8] a hermetic repo with '.hidden/deep/file.md' that holds 'paddleOut'
  and a visible 'src/deep/file.md' that also holds it
  and '.hidden/linked' as a symlink to a peer tree that also holds it

  when [t0] a search runs with no glob, under rg
    rhx grepsafe --pattern 'paddleOut' --files-only
  then BOTH real files are returned
    and the output reads 'engine: rg'       # a live rg is not proof it ran

  when [t1] a slashed glob targets the hidden tree
    rhx grepsafe --pattern 'paddleOut' --glob '.hidden/**/*.md' --files-only
  then the hidden file is returned
    and the output reads 'engine: rg'

  when [t3] '.git/' internals are in range
  then they are still absent from results   # forbidden invariant F1

  when [t4] a hidden tree holds a symlink into a gitignored tree
  then the walk does NOT descend into it    # forbidden invariant F2 — the breadth guard

  when [t5] a glob names a VISIBLE symlinked directory, under rg
    rhx grepsafe --pattern 'paddleOut' --glob 'probefixture/link/**/*.md' --files-only
  then the file behind the link is returned # probe 13
    and a control on the REAL twin agrees
    and the output reads 'engine: rg'
    # isolates D6: no dot, no gitignore, so a green here cannot be credited
    # to --hidden or --no-ignore. hermetic fixture, never .agent/.
```

`[t5]` is the bdd for the 6 `visible × linked × rg` cells; `[t0]`–`[t4]` all name hidden paths. a
probe is evidence; a `[tn]` is the commitment a builder reads, and a demoed cell owes both.

every step asserts `engine:`: a clamp that cannot name its engine can pass on the wrong one (case=1's
`PATH` trap). the grep-equivalence step is gone with the grep arm (F9).

a hidden path the caller does not name stays skipped, and the answer says what it skipped:

| the walk found | the answer reads | clamp |
|---|---|---|
| no match; a hidden file holds one | `matches: 0 — none in the walked trees, but N hidden file(s) hold a match` | case=12 `[t4]`, `[case42][t10]` |
| matches; a hidden file holds one too | `skipped: N hidden file(s) also hold a match` beside the count | `[case42][t9]` |
| a hidden root named as `--path` | no skip line — it was searched | `[case42][t11]` |

each names the `--path` that reaches it: the dot dir, or the dot file itself (#724, #725). a partial
answer that reads as whole is the same false report as a false zero, one row up.
