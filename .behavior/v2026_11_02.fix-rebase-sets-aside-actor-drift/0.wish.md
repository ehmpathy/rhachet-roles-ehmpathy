# wish: a clone can rebase a tree that holds unstaged ambient files

task: ehmpathy/rhachet-roles-ehmpathy#1189

## .the gap

`rhx git.branch.rebase begin` refuses whenever the tree holds an unstaged edit. a clone tree always holds two: the regenerated ambient settings files under `.agent/.actors/actor.via.repo=ambient/brain/.claude/` (settings.of.grove.json, a symlink, and settings.of.repo.json). the clone must keep them out of every commit, and it has no safe way to set them aside (the stash stack is shared across worktrees). so a conflicted pr waits on a human.

## .outcome

- `git.branch.rebase begin` takes `--unstaged ignore|include`, the same shape `git.commit.set` has
- `ignore` sets each unstaged path aside, rebases, and puts each back byte for byte and link for link; `continue` and `abort` put them back too
- with no flag, the refusal names the paths and the flag that cures it
- a clamp: a tree with an unstaged symlink and an unstaged file rebases cleanly and both read back identical; with the cure reverted, the same tree refuses
