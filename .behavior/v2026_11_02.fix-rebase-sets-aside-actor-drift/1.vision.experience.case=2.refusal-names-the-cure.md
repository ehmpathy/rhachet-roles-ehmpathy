# case=2 — no flag: the refusal names the cure

sharp · critipath

## .narrative

the clone runs `rhx git.branch.rebase begin --mode apply` out of habit. today it reads `unstaged changes found` and `commit or stash your changes first` — both wrong for a clone: it must not commit the ambient files and must not touch the shared stash. after the fix the refusal lists each unstaged path and names `--unstaged ignore` as the cure. the clone reruns with the flag. one round trip, no human.
