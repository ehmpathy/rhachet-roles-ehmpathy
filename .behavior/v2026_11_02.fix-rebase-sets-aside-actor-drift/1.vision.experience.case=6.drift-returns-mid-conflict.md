# case=6 — a fresh edit appears while a conflict waits

sharp · critipath (part a, densest: set-aside × conflict × regeneration × two commands × put-back) · alterpath (part b)

## .narrative — part a: at a held path

`begin --unstaged ignore` set the ambient files aside and the rebase stopped on a conflict. while the clone settles it, a session hook regenerates the ambient files, so they show as unstaged again. the clone runs `continue`. the skill sees that each fresh edit sits at a path it already holds aside. the held copy is the pre-rebase state the clone asked to keep, and the put-back would overwrite the fresh edit anyway. so `continue` resets those paths to HEAD, continues, and puts the held copies back. the output names each path whose fresh edit the held copy superseded, and how to recover it if it was deliberate: inspect with `git diff <path>`, then re-apply the edit. for regenerated ambient files there is naught to recover; they regenerate next session.

the end state is identical whichever way Q1 resolves: if git would refuse `--continue` on the drift, the reset clears the way; if git would not, the put-back overwrites the drift. execution confirms Q1 by test first.

## .narrative — part b: at a path NOT held

this time the ambient files were clean at `begin`, so naught was held. mid-conflict, a hook regenerates them. the clone runs `continue`. the skill sees unstaged edits at paths it does not hold, so it cannot know whether they are drift or deliberate work. it refuses before git acts: exit 2, the paths listed, and the cure — `rhx git.branch.rebase continue --unstaged ignore`. the clone reruns with the flag; the fresh edits join the store, the rebase continues, and every held path is put back. `abort` behaves the same: it refuses before `git rebase --abort` can touch the edit, and takes the same flag (F5). the clone is never stuck, and no edit is lost without a flag that asked for it.

## .timeline

```
given('[case6a] a rebase stopped on a conflict, paths held aside, and a held path edited again')
  when('[t0] the conflict is settled and staged, then continue')
    then('the rebase completes')
    then('each held path reads back as its held copy, byte for byte and link for link')
    then('the output names the held paths whose fresh edit was superseded')
    then('the output names the fix: git diff <path> to inspect; re-apply the edit if it was deliberate')
given('[case6b] a rebase stopped on a conflict, and an unstaged edit at a path NOT held aside')
  when('[t0] continue, no flag')
    then('continue refuses before git acts, exit 2, ✋ ConstraintError')
    then('the output lists the path and names the cure: rhx git.branch.rebase continue --unstaged ignore')
    then('the held copies stay aside; the fresh edit is untouched')
  when('[t1] continue --unstaged ignore')
    then('the fresh edit joins the store; the rebase completes')
    then('every held path, old and new, reads back byte for byte')
  when('[t2] abort, no flag, in place of continue')
    then('abort refuses before git rebase --abort runs, and names abort --unstaged ignore')
```
