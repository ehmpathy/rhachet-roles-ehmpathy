# case=1 — ambient drift, clean rebase (the clamp)

happy · critipath

## .narrative

the clone's pr shows "this branch has conflicts". its tree holds two unstaged edits it never authored: `settings.of.grove.json` (a symlink, retargeted to `/home/camper/.claude/settings.json` — a path absent on this machine, so the link is broken) and `settings.of.repo.json` (regenerated). it runs `rhx git.branch.rebase begin --unstaged ignore --mode apply`. the skill copies both aside into the worktree's own git dir — the link as a link, never followed — resets them to HEAD, rebases onto origin/main, then puts both back. the tree reads exactly as before, now on the new base: the link still points at its absent target, the file holds the same bytes. the clone pushes. no human was paged.

## .timeline

```

    then('the output lists each path set aside and put back')

    then('the stash stack is unchanged')

    then('begin refuses with exit 2 and names both paths')
```
