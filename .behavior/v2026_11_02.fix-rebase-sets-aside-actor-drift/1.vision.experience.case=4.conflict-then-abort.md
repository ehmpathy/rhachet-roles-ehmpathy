# case=4 — conflict, then abort

happy · critipath

## .narrative

the rebase stops on a conflict the clone cannot settle alone. it runs `rhx git.branch.rebase abort`. the branch returns to its pre-rebase state, and the ambient files read back as before. the tree is exactly what the clone had before it ran `begin`.

## .timeline

```
given('[case4] a rebase stopped on a conflict, with paths held aside by begin --unstaged ignore')
  when('[t0] abort')
    then('the branch returns to its pre-rebase head')
    then('each set-aside path reads back byte for byte and link for link')
    then('the output lists the paths put back')
    then('the set-aside store is gone')
```
