# case=3 — conflict, then continue

happy · critipath

## .narrative

the clone runs `begin --unstaged ignore --mode apply`. the rebase stops on a conflict. the ambient files stay aside; the output says so, and says `continue` or `abort` will put them back. the clone settles the conflict, stages it, runs `rhx git.branch.rebase continue`. the rebase completes and the ambient files read back as before.

## .timeline

```
given('[case3] a feature branch whose commit conflicts with main, plus unstaged file + symlink edits')
  when('[t0] begin --unstaged ignore --mode apply')
    then('the rebase stops on the conflict')
    then('the output names the paths held aside, and that continue or abort puts them back')
  when('[t1] the conflict is settled and staged, then continue')
    then('the rebase completes')
    then('no set-aside edit enters any rebased commit')
    then('each set-aside path reads back byte for byte and link for link')
    then('the set-aside store is gone')
```
