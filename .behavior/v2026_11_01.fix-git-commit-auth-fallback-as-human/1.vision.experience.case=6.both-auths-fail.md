# case=6 — fallback attempted, seat gh login absent too

cells g4a (`[t0]`) + g4b (`[t1]`) · sharp · alterpath

## .narrative

a clone on a fresh seat runs `git.commit.push --mode apply`. the seat has no ehmpath keyrack and no `gh auth login`. the clone sees the push land, then a `bummer dude` guide instead of a pr. the guide tells it the commit is safe on origin, that the skill already tried the bot and then the seat's login, and that each failed. it offers two fixes, each a copy-paste command: unlock the keyrack, or log in gh. the clone picks the one it can do and reruns `git.commit.push --mode apply`. no raw gh trace, no guesswork.

the refused flavor reads the same, one line apart. on another seat the keyrack does hand over a token, but the target org lacks the ehmpath app install. the clone sees the same guide, and its `cause:` line names the real snag: `ehmpath bot refused (http 403); fell back to as-human; gh: not logged in`. so it knows a keyrack unlock alone won't help that org, and it logs in gh.

## .sketch

```
🐢 bummer dude...

🐚 git.commit.push
   └─ ✋ ConstraintError: no usable gh credential to open the pr

🥥 your commit is pushed; to open its pr, either:
   ├─ 1. unlock the ehmpath keyrack, so the seaturtle can open the pr:
   │     $ rhx keyrack unlock --owner ehmpath --env prep --key EHMPATHY_SEATURTLE_GITHUB_TOKEN
   │
   └─ 2. or log in the human's github, so the as-human fallback works:
         $ gh auth login

cause: ehmpath bot token unavailable; fell back to as-human; gh: not logged in
```

## .bdd

```
given('bot token unavailable, gh not logged in, default auth')
  when('[t0] git.commit.push --mode apply')
    then('exit 2; the push landed')
    then('the guide names both fixes and the bot-token cause')
    then('exactly one as-human attempt')

given('bot token present but refused by gh (403), gh not logged in, default auth')
  when('[t1] git.commit.push --mode apply')
    then('exit 2; the push landed; the same two-fix guide')
    then('cause: ehmpath bot refused (http 403); fell back to as-human; gh: not logged in')
```
