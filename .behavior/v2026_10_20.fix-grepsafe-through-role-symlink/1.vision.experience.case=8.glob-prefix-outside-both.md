# case=8 — a `--glob` prefix typed outside both trees (g5, sharp × critipath)

## narrative

the clone tries to reach past the repo with a glob alone: `--glob '../../**/*.md'`. no `--path`
was typed, so it may think the boundary sits only on `--path`. it does not: the glob's literal
prefix `../..` expands and faces the gate, lands outside both trees, and is refused before any
file is read. the refusal says `named by: --glob`, and the 🥥 hint gives the in-repo search.

## timeline

```

[t1] when  grepsafe --pattern 'wave' --glob '../../**/*.md'
[t2] then  exit 2, on both streams
[t3]   and the refusal reads "search path must be within the git repository"
[t4]   and it reads "named by: --glob"

```
