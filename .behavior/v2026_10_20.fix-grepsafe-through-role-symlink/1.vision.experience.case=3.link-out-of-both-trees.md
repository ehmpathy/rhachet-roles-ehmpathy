# case=3 — a link out of both trees (p3, sharp × critipath)

## narrative

the clone sees a dir named `escape` in its worktree and asks grepsafe to search it. it does not
know the dir is a link to a tmp dir that belongs to neither tree. grepsafe says no at once — no
partial results, no silent zero. the refusal shows the repo root beside the place the link really
led, so the clone sees why. the 🥥 hint hands it a command it can run next: the same search, aimed
at the repo root. the clone runs that and moves on.

## timeline

```
[t0] given a linked worktree with dir `escape` -> /tmp/<elsewhere>
[t1] when  grepsafe --pattern 'wave' --path escape
[t2] then  exit 2, on both streams
[t3]   and the refusal reads "search path must be within the git repository"
[t4]   and it names the resolved /tmp path, so the clone sees where the link led
[t5]   and the 🥥 hint names `grepsafe.sh --pattern 'wave' --path <repo root>` — the fix to run
```
