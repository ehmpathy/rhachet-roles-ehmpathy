# case=4 — a typed `..` into the main checkout (p4, sharp × alterpath)

## narrative

the clone knows its main checkout sits beside the worktree and types `../<main-checkout>/src`. it
expects the new rule to let it in. it does not: the clone walked no link that the tree holds — it
typed its way out. grepsafe refuses with the extant frame, and the 🥥 hint points back at the
worktree root. this is the sharp edge of F1: the gate opens for a role link, never for a typed
escape.

## timeline

```
[t0] given a linked worktree beside its main checkout
[t1] when  grepsafe --pattern 'wave' --path ../<main-checkout>/src
[t2] then  exit 2, "search path must be within the git repository"
[t3]   and the 🥥 hint names the worktree root as the path to search
```
