# case=5 — a path typed outside both trees (p5, sharp × critipath)

## narrative

the clone, mid-hunt, types `--path ../..` to search wider. that reaches above both the worktree
and the main checkout. grepsafe refuses fast, on both streams, before any file is read; the
refusal names the repo root and the path it was handed, and the 🥥 hint gives the in-repo search
to run instead. the fix changed naught here — this is the guard's teeth, proven still sharp.

## timeline

```
[t0] given a linked worktree
[t1] when  grepsafe --pattern 'wave' --path ../..
[t2] then  exit 2, on both streams
[t3]   and the refusal reads "search path must be within the git repository"
[t4]   and no result row prints
[t5]   and the 🥥 hint names `--path <repo root>`
```
