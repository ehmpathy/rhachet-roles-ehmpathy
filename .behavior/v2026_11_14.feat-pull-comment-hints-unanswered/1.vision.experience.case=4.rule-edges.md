# case=4 — the rule's edges: who answers, and what is closed

feel: happy · care: critipath

## .narrative

the robot picks up ehmpathy/surf-demo#7 mid-round. sam-tide, a human, opened the pr. the robot does not know the history; it posts its `status` note and reads the coconut.

the coconut names two rows. kai's re-ask "and the cache?" waits, since the robot answered kai once and kai asked again. kai's question on `src/tide.ts:9` also waits: reef-nalu's "+1" under it is no answer, and the row names kai's question, not the "+1".

what the robot does not see matters as much:
- the thread it answered earlier is quiet: answered
- the thread sam-tide answered in-line is quiet: the pr author's reply counts
- kai's thread a reviewer resolved is quiet: resolved awaits naught
- sam-tide's own self-note is quiet: an answerer does not await itself
- the `rhelease[bot]` release note is quiet: an app bot asks no question

the robot runs `get --unanswered` to double-check and sees the same two ids. one operation computes both, so it never has to wonder which to trust. it answers the two rows and moves on.

  - thread A: kai asks (701); the robot replies (702)                         → answered
  - thread B: kai asks (703); sam-tide, the pr author, replies (704)          → answered
  - thread C: kai asks (705); no reply; thread resolved                       → resolved
  - thread D: kai asks (706); the robot replies (707); kai asks again (708)   → awaits, row 708
  - thread E: kai asks (709, src/tide.ts:9); reef-nalu replies "+1" (710)     → awaits, row 709
  - thread F: sam-tide self-note (711); no reply                              → never awaits
  - issue G: rhelease[bot] (type Bot) release note (712)                      → never awaits
  when('[t0] set --key status --mode apply')
    then('the hint names exactly rows 708 and 709, oldest first')
    then('row 709 names kai, not the +1 by reef-nalu')
    then('each row suggests --key answer-<row id>')
  when('[t1] get --unanswered --output json')
    then('the ids equal [708, 709], the ids the hint named')
