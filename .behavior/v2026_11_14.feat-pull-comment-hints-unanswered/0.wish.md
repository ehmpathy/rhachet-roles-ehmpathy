wish =

# wish: each git.pull.comment post names the review comments that still await a reply

## .the outcome

after `rhx git.pull.comment.set` posts (or edits) a comment on a pr, its output ends with a hint: every review comment on that same pr that awaits a response, one line each (author, path:line or the top-level thread, the first words, its id), and the command that answers it (`rhx git.pull.comment.set --pr <n> --reply-to <id> --key <k> --from <file>`).

- none await → one line says so
- a comment awaits a response when no reply in its thread comes after it from the pr author or the robot. a resolved thread awaits naught
- the hint reads the same source `git.release` reads to refuse a release on unanswered comments (#1171), so the two never disagree; if that read does not exist yet in a shared operation, extract it once and use it in both
- the hint is a read: it never posts, edits, or fails the set. a read that fails prints one warn line and the set still exits 0
- `--help` names the hint

## .bounds

nano. one tree, one pr. the release gate itself (#1171) is a separate tree and stays out of scope.

## .done

a green pr; the clamp tests carry the proof of the hint.

the real-pr demo (the hint shown in the pr body on a real pr with one answered and one unanswered comment) is a follow-up. the commander's review of the pr supplies the real comments that demo needs, so the demo lands after that review, not before.
