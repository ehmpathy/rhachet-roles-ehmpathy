## what changed

### 1. ref rule brief
`src/domain.roles/mechanic/briefs/practices/lang.tones/rule.forbid.shouted-readme.md`
- forbids repo-local `README.md`, teaches `readme.md`
- cross-references `rule.forbid.shouts` as parent (avoids synonym-rule trap)
- scopes out `node_modules/**` and `.git/**`
- documents the redirect + hook enforcement
- readme-only (per wisher 2026-07-18); other shouted docs stay with `rule.forbid.shouts`

### 2. the hook
`src/domain.roles/mechanic/inits/claude.hooks/pretooluse.forbid-shouted-readme.sh`
- modeled on `pretooluse.forbid-tmp-writes.sh`
- reads json stdin, extracts `.tool_name`
- **Write/Edit/Read**: blocks if `basename(file_path) == README.md` and path is repo-local
- **Bash**: extracts each `*README.md` token; blocks the first repo-local one
- **excludes** `node_modules/**` and `.git/**` (vendored, third-party — allowed)
- redirect target = the lowercase `readme.md` in the same directory
- `exit 2` + guidance to stderr; cites `rule.forbid.shouted-readme`

### 3. registration
- `getMechanicRole.ts` — new `onTool` entry, filter `Write|Edit|Read|Bash`, `when: before`,
  right after the tmp-writes hook
- `boot.yml` — brief added under `always.briefs.ref` (ref-only: the hook enforces, the
  brief is the fetched-on-demand authority)

### 4. test
`pretooluse.forbid-shouted-readme.integration.test.ts` — 32 tests, all pass:
- Write/Edit/Read block for root + nested `README.md`
- allow for `readme.md`, `node_modules/**/README.md`, `.git/README.md`
- Bash `cat`/`echo >`/`head` block for repo-local, allow for vendored + no-readme
- edge cases: `README.md.bak`, `MYREADME.md`, `Readme.md` all allowed (not exact match)
- empty stdin → exit 2; non-matched tools → passthrough
- guidance + snapshot coverage
