  executed and blocked correctly. same worktree, same `.agent`→`dist` chain. the only
  variable is the file mode: the peer is git-mode **100755**; my hook lacks owner `+x`.
- the integration suite is green because it spawns `bash scriptPath` — `bash <file>` does
  **not** need `+x`. so tests pass while the runtime is broken. this is why the gap slipped
  past the earlier stones.
