# experience case 5: the caller stops the run

cells c19 (single type, caller abort → sharp), with c20 (multi-mode) and c21 (watchdog host) as its alterpaths. care = critipath.

## .narrative

a clone runs `rhx git.repo.test --what integration` from a shell call capped at 120s. the suite is slow; at 120s the harness kills the clone's shell call with SIGTERM. the skill's trap fires, stops the suite's whole process group within a second, and keeps what the suite wrote so far. the clone's next read shows where the partial log sits, so it can Read the log and find the slow file. no suite runs on for the other 180s of its bound; a retry starts on a free seat.

a human at a terminal hits ctrl-c on `--what all` mid-integration. the parent forwards the stop to the child in flight; the child stops its suite. exit 130.

## .timeline

```
given('[c19] a single-type run whose suite is still at work', () => {
  when('[t0] the caller sends SIGTERM to the skill alone', () => {
    then('the suite and every child in its group stop within a second');
    then('the status tree closes with 🌙 stopped by the caller, then a partial log branch with the stdout and stderr paths');
    then('exit 143 (SIGINT → 130, SIGHUP → 129)');
  });
});

given('[c20] a multi-mode run (alterpath)', () => {
  when('[t0] the caller sends SIGTERM to the parent alone', () => {
    then('the parent forwards it to the child in flight, whose trap stops its suite');
    then('exit 143, no suite left');
  });
});

given('[c21] a host with no fuse tool (alterpath)', () => {
  when('[t0] the caller sends SIGTERM mid-run', () => {
    then('the watchdog stops too, so it never signals a stale group later');
  });
});
```
