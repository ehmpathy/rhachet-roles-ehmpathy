# experience dimensions: git.repo.test default 5m bound

actors = a driver (clone or human) who runs `rhx git.repo.test`, and a system caller (a stop hook, `--when hook.onStop`). the actor is itself an axis (D7); the rest vary what the actor meets.

## .dimensions

| # | dimension | values | why orthogonal |
|---|---|---|---|
| D1 | bound source | `default` (no `--timeout`) · `explicit` (valid `--timeout N` or `--timeout=N`) · `invalid` (`--timeout abc`, `0`, `-5`, `5m`) | the caller's flag choice; independent of how long the suite runs |
| D2 | run length vs bound | `under` · `past` | a property of the suite, not of the flag |
| D3 | breadth | `single` (`--what unit`) · `multi` (`--what all`, `--what lint,unit`) | multi-mode spawns one child per type (`git.repo.test.sh:1438-1477`); a separate code path |
| D4 | mode | `apply` · `plan` | plan lists files, runs no suite (`git.repo.test.sh:1491-1555`) |
| D7 | actor | `driver` (clone or human at a shell) · `system` (`--when hook.onStop`) | who meets the halt; the bound acts the same, but the system actor's caller meets a blocked stop, not a watched run |
| D6 | fuse tool on the host | `gnu-timeout` (linux) · `gtimeout` (macOS + coreutils) · `non-gnu` (busybox `timeout`, as on alpine → bash watchdog) · `none` (stock macOS → bash watchdog) · `broken` (a fuse that cannot run or hold the suite) | a property of the host, not the call or the suite; it picks which fuse enforces the bound |
| D8 | how the run ends | `by itself` (any exit code, 124 included) · `by the bound` · `by the caller` (SIGINT, SIGTERM, SIGHUP to the skill) | who ends the run; independent of the flag and the host. D2 already splits `by itself` from `by the bound`; `by the caller` is the third end |
| D5a | halt aftermath: snapshots | `whole` · `partial` (`--resnap` was on) | set by the caller's `--resnap`, not by the bound. only has a value when D2=`past` |
| D5b | halt aftermath: teardown | `ran` · `skipped` (suite has a jest `globalTeardown`) | set by the suite's own config, independent of D5a. only has a value when D2=`past` |

collapsed, with reason:
- **test kind** (types/format/lint vs unit/integration/acceptance): all go through one `run_single_test`; the bound wraps `npm run` the same for each. it varies only the cut's lessons (a tool run: "time the tool alone"; a jest suite: find the slow suite, bisect, resnap), so it splits the text of a `past` cell, not the experience
## .the walked product

D4=`plan` runs no suite, so no bound is enforced. but `--timeout` is checked at parse, before the plan branch, so D1 still splits it: `plan × valid-or-absent` → 1 cell (c11, impossible to halt); `plan × invalid` → 1 cell (c18, halts at parse even in plan). → 2 cells.
D1=`invalid` halts before any run, so D2 has no value → 2 cells (× D3).
the rest: 2 (D1 default|explicit) × 2 (D2) × 2 (D3) = 8 cells.

total = 2 + 2 + 8 = 12 cells. each is verdicted in `1.vision.experience.case=_.md`.

D5a × D5b split only the `past` cells: 2 × 2 = 4 combos. `whole + ran` is c2 itself; the other three are new: `partial + ran` c12, `whole + skipped` c13, `partial + skipped` c17. the product is sampled once against a single-run `past` cell, not crossed with D1 or D3: a multi-mode halt is one child's single-type halt (the parent stops on that child, `git.repo.test.sh:1467-1470`), and the bound source changes only the `bound:` line. so every `past` cell (c2, c4, c5, c6) × D5a × D5b is covered by these representatives: +3 cells.

D6 matters only on a run that starts (D4=`apply`, D1≠`invalid`). `gnu-timeout` is the cells above. `gtimeout` is the same binary under another name, so it folds into them. `none` crosses D2: +2 cells (c14 under, c15 past). breadth and bound source fold the same way as D5a × D5b (each child is one run with the same fuse).

D7=`system` adds +1 cell (c16). it folds over D1 and D3 like D5a × D5b: a hook halt is one single-type halt.

total = 12 + 3 + 2 + 1 = 18.

D8=`by the caller` applies to any run that starts. it splits on breadth (the parent must forward the stop) and on fuse (the watchdog must stop too): +3 cells (c19 single on a gnu fuse, c20 multi, c21 watchdog). bound source folds: the stop does not read it.

D6's further values each add one cell against a single run: `gtimeout` past (c24, its own lookup branch), `non-gnu` under and past folded into one (c25, it falls through to the watchdog), `broken` (c22, exit 1). `by itself` with exit 124 (c23) must not read as a cut: +1 cell.

two aftermath cells sharpen D5a and D5b: a cut mid jest output that holds the no-tests phrase (c26, under c12) and a suite child that detaches and outlives the cut (c27, under c13).

total = 18 + 3 + 3 + 1 + 2 = 27.

D4=`plan` splits on test kind: lint, types, and format run as in apply (so a single tool type in plan is c1-c4), and only a jest type previews. a multi-mode call that mixes the two in plan mode runs some types and previews others, and the parent's run-wide figure must count only the ones that run: +1 cell (c28).

D8=`by the caller` also splits on when the stop lands: mid-run (c19) or in the scope preview, before any suite runs: +1 cell (c29).

total = 27 + 1 + 1 = 29.

## .forbidden combinations (invariants)

- a run with no `--timeout` that lasts past 300s and exits 0 = forbidden. the default bound must halt it
- a halt that exits 1 (malfunction) = forbidden. a slow suite is the caller's defect → exit 2
- `--what all --timeout N` where a child runs with the 300s default instead of N = forbidden
- an invalid `--timeout` that reaches `npm run` = forbidden. it fails fast first
- a run that fails only because the host lacks `timeout` = forbidden. the watchdog takes over
- a run on a host with no fuse tool that goes past its bound unhalted = forbidden
- a run that fails only because the host's `timeout` is not gnu = forbidden. the watchdog takes over
- a caller's stop that leaves the suite at work = forbidden
- a suite that exits 124 by itself read as a cut = forbidden
- a fuse that never ran the suite read as a red suite = forbidden. it is a malfunction, exit 1
