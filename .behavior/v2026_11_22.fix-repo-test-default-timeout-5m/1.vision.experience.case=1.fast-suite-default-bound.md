# experience case 1: a fast suite under the default bound

feel = happy · care = critipath

## .narrative

a driver runs the unit suite for the operation it just changed. the suite takes 40s. the driver passes no `--timeout` and thinks naught of a bound. the run looks as it does today, plus one line at the start: `bound: 300s (default)`. inflight ticks, then `🎉 passed`. the bound is visible from the first second, so a driver who watches a run near 4 minutes knows the fuse before it blows.

## .timeline

```
given('[c1] a repo whose unit suite finishes in 40s', () => {
  when('[t0] rhx git.repo.test --what unit --mode apply  (no --timeout)', () => {
    then('the suite runs under a 300s bound');
    then('stdout shows bound: 300s (default) before the first inflight tick');
    then('stdout ends with 🎉 passed (40s)');
    then('stdout carries no "too slow" line');
    then('exit 0');
  });
});
```
