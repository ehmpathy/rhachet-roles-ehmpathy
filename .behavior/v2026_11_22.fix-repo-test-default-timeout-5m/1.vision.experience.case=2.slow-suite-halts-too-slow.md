# experience case 2: a slow suite halts at 5 minutes

feel = sharp · care = critipath

## .narrative

a driver runs the integration suite with no `--timeout`. one suite spins up a real server per test and the run drifts past 5 minutes. today it would run 14 minutes, hold the crew seat and a box core, then pass — and no one learns it is slow.

with the bound, the run halts at 300s. the tree says `⏱️ too slow (300s)`, the header says "woah, too slow", and the body says plainly: this speed defect is yours to root cause. it names the bound it hit (the 5m default), keeps the logs, and points at the next move: find the slow suite, fix why it is slow. a wider `--timeout` is offered last, only for a suite that is long by nature.

the driver gets exit 2 — a constraint, its own to fix — not exit 1, which would read as "the tool broke, retry".

## .timeline

```
given('[c2] a repo whose integration suite runs past 300s', () => {
  when('[t0] rhx git.repo.test --what integration --mode apply  (no --timeout)', () => {
    then('the run is halted at 300s; the suite process tree is gone');
    then('stdout shows ⏱️ too slow (300s)');
    then('stdout says "woah, too slow"');
    then('stdout names the bound as the 5m default');
    then('stdout names the speed defect as the driver\'s own to root cause');
    then('stdout + stderr carry the halt; logs are persisted');
    then('exit 2 (constraint)');
  });
});

given('[c15] the same repo, on a host with no gnu timeout (stock macOS)', () => {
  when('[t0] rhx git.repo.test --what integration --mode apply  (no --timeout)', () => {
    then('the bash watchdog enforces the 300s bound; the run does not fail for want of timeout');
    then('the run is halted at 300s; the suite process tree is gone');
    then('stdout + exit are the same as [c2]: "woah, too slow", owner named, exit 2');
  });
});
```

on a stock macOS host, a second driver meets the same halt. it never learns the fuse tool differs; the bound and the lesson are the same.

## .fails safe

- fast: halts at the bound, not at the suite's natural end
- loud: header, tree leaf, and exit 2 all say it
- teaches the fix: names who owns it and the next move; a wider bound is the last resort, not the first
