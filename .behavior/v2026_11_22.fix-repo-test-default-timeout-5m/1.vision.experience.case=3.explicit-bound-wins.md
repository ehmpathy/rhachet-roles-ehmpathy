# experience case 3: an explicit bound wins

cells c3 (explicit, under → happy) and c4 (explicit, past → sharp). care = critipath.

## .narrative

a driver knows the acceptance suite boots a local server and runs 7 minutes by nature. it passes `--timeout 600`. the run goes 7 minutes and passes; the 5m default never fires, because the caller's number replaced it.

later, the same suite regresses to 11 minutes. the run halts at 600s with the same "woah, too slow" halt — but the tree names `bound: 600s (--timeout)`, so the driver sees it was its own number that was crossed, not a default it never chose.

a second driver passes `--timeout 30` on a unit suite it expects to be fast. the bound is tighter than the default, and it wins all the same.

## .timeline

```
given('[c3] a repo whose acceptance suite runs 420s', () => {
  when('[t0] rhx git.repo.test --what acceptance --against local --env test --timeout 600 --mode apply', () => {
    then('the suite runs under a 600s bound, not 300s');
    then('stdout ends with 🎉 passed');
    then('exit 0');
  });
});

given('[c4] a repo whose acceptance suite runs past 600s', () => {
  when('[t0] same call with --timeout 600', () => {
    then('the run is halted at 600s');
    then('stdout says "woah, too slow" and names bound: 600s (--timeout)');
    then('stdout renders the full [c2] halt: "this speed defect is yours to root cause", find the slow suite, a wider --timeout only for a suite long by nature');
    then('exit 2');
  });
});

given('[c4.tighter] a repo whose unit suite runs 45s', () => {
  when('[t0] rhx git.repo.test --what unit --timeout 30 --mode apply', () => {
    then('the run is halted at 30s — a tighter explicit bound wins too');
    then('stdout renders the full [c2] halt with bound: 30s (--timeout)');
    then('exit 2');
  });
});

given('[c9] a driver who types a bound the skill cannot read (alterpath)', () => {
  when('[t0] rhx git.repo.test --what unit --timeout 5m --mode apply', () => {
    then('the skill halts at parse, before any suite runs');
    then('stdout + stderr say ✋ --timeout must be whole seconds, e.g. --timeout 300');
    then('exit 2');
  });
});
```

the invalid bound fails safe: fast (no suite starts), loud (`✋` on both streams), and it teaches the fix (the valid shape, with an example).
