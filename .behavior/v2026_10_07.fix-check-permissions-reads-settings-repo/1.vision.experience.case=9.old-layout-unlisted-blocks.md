# case=9 — old layout, unlisted command still blocks

cells #14, #28 · sharp · critipath

## .narrative

a repo not yet on the split runs `curl https://example.com`. no layer lists it. the hook blocks
once and lists the repo's real allows from `<repo>/.claude/settings.json`. this is today's block.
the new reads must not soften it: a home dir or an actor dir that holds no `curl` allow adds
patterns to the list, never a pass.

under a hash actor (`[t1]`), the message also names the config dir it read (F5), since it differs
from the walk-up dir. the human then sees that the actor dir held no list, and the repo's
`.claude` did.

## .bdd sketch

```ts
given('[case9] old layout: allows in a real <tmp>/.claude/settings.json', () => {
  // <tmp>/.claude/settings.json   allow: Bash(npm run build:*)
  // env: HOME=<tmp>/home (empty)
  when('[t0] CLAUDE_CONFIG_DIR unset; the clone runs curl', () => {
    then('exit 2', () => {});
    then('stderr lists npm run build', () => {});
    then('stderr is byte-identical to the pre-change block message', () => {});
  });
  when('[t1] CLAUDE_CONFIG_DIR=<tmp>/actor/.claude (empty); the clone runs curl', () => {
    then('exit 2', () => {});
    then('stderr lists npm run build', () => {});
    then('stderr names the config dir <tmp>/actor/.claude', () => {});
  });
});
```

`[t0]`'s byte-identical check is the clamp: the extant suite's stderr snapshots must not churn.
