# case=13 — under the split layout, init writes settings.repo.json by name

cells #41, #42, #43 · critipath (#41) + alterpaths

## .narrative

a human runs `rhx init` in a repo on the split layout. today `init.claude.permissions.sh` writes
`<repo>/.claude/settings.json` via `jq … > tmp && mv`. the `mv` replaces the grove link with a real
file; rhachet later absorbs that file into `settings.repo.json` and relinks. it works, but only by a
repair path, and between the two steps the home defaults are cut off.

after: the init sees the split layout (`settings.json` is a link, or `settings.repo.json` exists)
and writes `settings.repo.json` by name, via a temp file in the same dir and a rename. the link is
never touched (#41). a fresh actor with no `settings.repo.json` gets one created; there is no prior
file, so no backup (#42). if the grove target is absent, the link is broken; the init still writes
`settings.repo.json` and leaves the link as found. a broken link is rhachet's to repair, not the
role's (#43). today's `[[ ! -f settings.json ]] → echo {} >` seed would write through that link and
create the human's home file; after, the init never writes through the link.
