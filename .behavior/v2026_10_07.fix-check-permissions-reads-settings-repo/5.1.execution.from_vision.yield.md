  (next item)

  .claude/settings.enroll.9366365e.local.json` (rhachet 1.48.1, `asBrainCliSpawnArgs.js`). claude
  loads that copy, not the project `settings.json`. the copy matches `settings.json` line for line,
  so the allowlisted commands that ran with no prompt came from the copy. moved to 5.3
- **does claude honor a user-scope-only allow?** not probed in 5.1. the probe needs one allow
  written into this session's own `$CLAUDE_CONFIG_DIR/settings.json`, and the auto-mode classifier
  refused that write as self-modification. it moves to 5.3, which runs a live session anyway. if
  claude does not honor it, the hooks over-allow. for check that is benign (claude still prompts).
  for decide it is not: decide auto-approves at the PermissionRequest prompt, so a layer claude
  ignores would grant a command no claude source allows
