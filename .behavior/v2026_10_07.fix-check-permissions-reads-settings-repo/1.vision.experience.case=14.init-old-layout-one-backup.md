# case=14 — old layout init, one backup or none

cells #44, #45, #46 · critipath (#44) + alterpaths

## .narrative

a human runs `rhx init` in a repo on the old layout: a real `<repo>/.claude/settings.json`, no
`settings.repo.json`. the init writes `settings.json` via temp + rename, as today (#44). the change
is the backup count. today `init.claude.sh` copies `settings.json` to a backup, then
`init.claude.permissions.sh` copies it again under its own stamp: two backups of one file per run.
after: only the file writer makes a backup, and only when the permissions change, so one run leaves
at most one `.bak.json`.

a fresh repo with no settings file gets `settings.json` created. there was no prior file, so no
backup; today it backs up the `{}` seed it just wrote, a file no human ever held (#45). a rerun
whose permissions already match writes no file and no backup, and says "already configured" (#46);
this holds on either layout.
