# case=10 — local grants pass; a corrupt layer reads as absent

cells #5, #12, #16, #19, #23, #24, #26, #29, #30 · alterpaths (happy + sharp)

## .narrative

a human clicks "always allow" on a prompt, and claude writes the grant into a
`settings.local.json`. on the next call, the hook reads that file wherever the contract names it:
- the project's (`<walk-up dir>`): cells #5, #12, #19, #26
- the actor's (`<config dir>`): cells #16, #23

so the grant passes at once. the human never sees the same nudge twice for a command they already
allowed. under a hash actor, `$CLAUDE_CONFIG_DIR/settings.json` is the user layer (#24). it passes
just as #17 does in case=2.

then a box loses its grove target: `~/.claude/settings.json` is absent, so `<repo>/.claude/settings.json`
is a broken link (#29). or a hand edit leaves one file as invalid json (#30). either way the hook
reads that one file as absent and keeps the rest. a command whose allow lived in another layer still
passes. a command whose only allow lived in the corrupt file blocks once, and the block lists the
valid layers' allows. if no valid layer holds one, case=7's diagnostic names the corrupt file as
`absent` or `unreadable`. claude cannot read that file either, so the block is
never stricter than claude.
