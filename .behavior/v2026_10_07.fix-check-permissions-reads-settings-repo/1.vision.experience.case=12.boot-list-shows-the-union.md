# case=12 — the boot list shows the union the gate checks

cells #38, #39, #40 · critipath (#38) + alterpaths

## .narrative

a clone boots. `sessionstart.notify-permissions.sh` prints "these bash commands run without a
permission prompt". today it reads only `<walk-up>/.claude/settings.json`, so under the split layout
it lists the human's home defaults and omits every repo allow. the clone then believes
`rhx git.repo.test` needs a prompt, and reaches for a workaround. after: the list is the union of the
same five layers the check hook reads, so the boot list and the gate agree (#38).

a hash actor's clone sees its own layers plus the project's, never the repo actor's
`settings.repo.json` (#39). with no allows anywhere, the boot says so in one line and names each
path it sought (#40); today it prints no line at all, and the clone cannot tell "no list" from "no
hook".
