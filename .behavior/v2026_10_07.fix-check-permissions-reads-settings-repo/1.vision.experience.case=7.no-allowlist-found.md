# case=7 — no allowlist found: say so, name the files sought

cells #31, #32 · sharp · alterpath

## .narrative

issue #895 measured it: the block listed **no** patterns, and peer clones read that as "zero
pre-approved commands — even `pwd` is rejected", then gave up rather than retry. after: when every
layer yields zero Bash allows, the hook still blocks once (same HARDNUDGE), but the message says no
allowlist was found and names each path it read, so the clone (or human) sees a config fault, not an
empty toolkit.

## .bdd sketch

```ts
given('[case7] no layer holds a Bash allow', () => {
  // <tmp>/.claude/settings.json  allow: []    <tmp>/home/.claude/  (empty)
  // env: HOME=<tmp>/home
  when('[t0] CLAUDE_CONFIG_DIR unset; the clone runs any command (cell #31)', () => {
    then('exit 2', () => {});
    then('stderr says no allowlist was found', () => {});
    then('stderr names <tmp>/.claude/settings.repo.json, <tmp>/.claude/settings.json, <tmp>/home/.claude/settings.json', () => {});
    then('stderr holds no empty bullet list', () => {});
    then('stderr matches snapshot', () => {});
  });
  when('[t1] CLAUDE_CONFIG_DIR=<tmp>/actor/.claude (empty); the clone runs any command (cell #32)', () => {
    then('exit 2', () => {});
    then('stderr names <tmp>/actor/.claude/settings.repo.json and <tmp>/.claude/settings.json', () => {});
    then('stderr matches snapshot', () => {});
  });
});
```

sketch of the stderr:

```
🛑 BLOCKED: no pre-approved Bash permissions were found.

the hook looked for allowlists in:
  • <tmp>/actor/.claude/settings.repo.json   (absent)
  • <tmp>/actor/.claude/settings.local.json  (absent)
  • <tmp>/actor/.claude/settings.json        (absent)
  • <tmp>/.claude/settings.json              (0 Bash allows)
  • <tmp>/.claude/settings.local.json        (absent)

this is likely a config fault, not an empty toolkit. if you still need this command, retry it.
```

each path carries one state: `absent` (no file, or a broken link) · `unreadable` (malformed json) ·
`N Bash allows`. a human who sees `unreadable` knows to fix that file; a bare empty list told them
naught.
