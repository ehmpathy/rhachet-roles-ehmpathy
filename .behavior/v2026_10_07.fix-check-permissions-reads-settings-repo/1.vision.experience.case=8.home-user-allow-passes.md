# case=8 — a human's home allow passes, as claude passes it

cells #3, #10 · happy · critipath

## .narrative

a human allows `Bash(kubectl get:*)` once in `~/.claude/settings.json`, for every repo. a clone
launched without `$CLAUDE_CONFIG_DIR` runs `kubectl get pods`. claude reads user scope from
`~/.claude`, so it allows the call. before: the hook never read `~/.claude`, so it blocked the call
on both layouts. after: with the env unset, the user dir is `$HOME/.claude`. the hook reads it,
matches, and exits 0. (F6)

## .bdd sketch

```ts
given('[case8] an allow that lives only in the home user settings', () => {
  // <tmp>/home/.claude/settings.json   allow: Bash(kubectl get:*)
  // env: HOME=<tmp>/home, CLAUDE_CONFIG_DIR unset, cwd=<tmp>/repo
  when('[t0] split layout: <tmp>/repo/.claude/settings.repo.json lists only rhx git.repo.test', () => {
    then('kubectl get pods exits 0', () => {});
  });
  when('[t1] old layout: <tmp>/repo/.claude/settings.json lists only npm run build', () => {
    then('kubectl get pods exits 0', () => {});
  });
});
```

hermetic note: `HOME` is set to a temp dir in every case of the suite, never only in this one.
otherwise the runner's real home allows leak into "blocked" assertions.
