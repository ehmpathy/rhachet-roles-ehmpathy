# case=6 — split layout, unlisted command still blocks, with the real list

cells #7, #21 · sharp · critipath

## .narrative

the clone runs `curl https://example.com`. no layer lists it. the hook blocks once (HARDNUDGE) and
lists the patterns the clone CAN use. those now come from `settings.repo.json` too, so the list is
the repo's real toolkit, not the home defaults alone.

- a repo-actor clone (`[t0]`) sees the repo's allows
- a hash-actor clone (`[t1]`) sees its own actor's allows, never the repo actor's, plus the name of the config dir it read
- a retry inside the window (`[t2]`) passes through to claude's prompt, as today
