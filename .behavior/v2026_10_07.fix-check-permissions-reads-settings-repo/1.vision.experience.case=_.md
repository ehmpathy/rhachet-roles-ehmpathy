## .forbidden — rejection invariants

- **F1**: the hook must never block a command claude's own merged allowlist permits. a hook stricter than claude = the defect this wish closes (#1, #3, #10, #11, #15, #17, #18, #25).
- **F2**: no reader may pass or approve a command because another actor's `settings.repo.json` lists it (#20, #35).
- **F3**: no reader may print an empty pattern list as though the allowlist were empty (#31, #32, #36, #40).
- **F4**: `decide` must never approve a segment that any read layer denies (#34).
- **F5**: an init must never replace the `settings.json` link with a real file (#41, #43).
- **F6**: one init run makes at most one backup (#44, #46).
