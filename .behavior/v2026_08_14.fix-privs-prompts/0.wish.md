## amendment — the spike pivot (2026-08-14)

> the original wish above is preserved verbatim. this block records what the spike proved and
> how the design pivoted as a result. evidence lives in `probe/findings.md`, the decider in
> `probe/permissionrequest.auto-approve-rhx.sh`, the clamp in
> `probe/permissionrequest.clamp.integration.test.ts`.

### what the spike proved on claude-cli 2.1.87 (the wish's exact target)

1. **the `PermissionRequest` hook DOES fire** for a suspicious-classified command. the original
   doubt ("prior tests said no") is refuted — but see (2) for WHY prior tests failed.
2. **the blocker was SCHEMA DRIFT, not a dead seam.** the flat shape this wish proposed —
   `{ hookSpecificOutput: { permissionDecision: "allow" } }` — does **NOT** suppress the prompt
   on 2.1.87. the **nested** shape does:
   `{ hookSpecificOutput: { decision: { behavior: "allow" }, ... } }`. prior tests used the flat
   shape, which is why they reported "allow does not stick." (Q0 = yes; Q2 = nested.)
3. **the oracle is the harness line `Allowed by PermissionRequest hook`** — the hook is blind to
   the prompt, so "the command ran" is NOT proof (it can mean the human clicked approve). this
   measurement trap produced one false positive mid-spike before it was caught.
4. **suspicious syntax OVERRIDES the `permissions.allow` bypass** — an allowlisted `rhx` command
   with parens still reaches the seam; a non-suspicious `rhx list` never does.

### the pivot — from reviewer-clone to in-hook decider

the wish's target architecture routed every verdict through a warm **reviewer clone** over the
say/get socket. the spike showed we **do not need the clone** for the core value:

- the super-suspicious injection forms (`$()`, backticks, `<()`, `>`) are already **hard-blocked
  upstream** by the extant `pretooluse.forbid-suspicious-shell-syntax` hook (exit 2).
- what reaches the seam is the benign-but-flagged tail. a **deterministic in-hook decider**
  clamps it: a clean single `rhx`/`npx rhachet` call auto-approves (rhx is safe by design); an
  unquoted chain (`&& || ; &` newline) is denied; every other case lifts to a brain.
- the **brain layer is deferred** — human now, an inline **haiku** call later (dream caught:
  `.dream/2026_08_14.auto-approve-permissions-brain-layer.dream.md`). the clone becomes an
  optional phase-3 latency swap, not a dependency.

### what remains open

- **Q4 (the race)**: whether a slow (~3s) hook still suppresses on 2.1.87 — gates whether an
  inline haiku call is viable without a pre-warm. a `slow`-mode probe is run; the human's
  prompt-vs-silent observation is pending (`probe/findings.md`).
