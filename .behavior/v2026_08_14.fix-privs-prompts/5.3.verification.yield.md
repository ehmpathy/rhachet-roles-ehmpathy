### blockers

- **the one open blocker — human-only, cannot be climbed by the driver**: the feature files are
  untracked (`??`); to register a `PermissionRequest` hook that points at a file present in git,
  the feature must be committed. a commit needs commit quota, granted only by a human via
  `git.commit.uses set` — the EXACT privilege escalation this whole feature denies to the mechanic
  (and the one the decider + settings.deny now hardened). `rhx git.commit.uses get` = "no quota
  set." i cannot self-grant it without becoming the rubber-stamp the design forbids. this is a
  genuine foreman-only key.
  - **(a)** local commit only: `rhx git.commit.uses set --quant 1 --push block`, or
  - **(b)** commit + push + PR: `rhx git.commit.uses set --quant 1 --push allow`
  - then i run `rhx git.stage.add` + `rhx git.commit.set` on the feature (decider + both tests +
    snapshot + the settings/jsonc deny additions + the boot-banner update) and re-arrive.
