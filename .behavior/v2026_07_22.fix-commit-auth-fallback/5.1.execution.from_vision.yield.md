# 5.1 execution — from vision

## contract (approved)

`git.commit` push gains `--auth as-ehmpath | as-human`, default `as-ehmpath`.
- **as-ehmpath** (default): PR opened by the seaturtle bot via the ehmpath keyrack token.
- **as-human**: PR opened by the human via ambient `gh` login (no `GH_TOKEN` override).
- on an `as-ehmpath` keyrack failure → a guide that names the fix: retry with `--auth as-human`.
- the push is **un-gated** from the token fetch: `git push` runs first, only PR-open needs auth.
- scope: `git.commit` push only; `git.release` excluded.
