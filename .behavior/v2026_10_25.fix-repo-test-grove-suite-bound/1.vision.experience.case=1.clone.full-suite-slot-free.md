# case=1 — clone · full suite · slot free

**feel:** happy · **care:** critipath · **cells:** stage 1 `full × single`; stage 2 `free × exits`; stage 3 `default`; stage 4 `flock present × writable`, `flock present × absent`

## .narrative

a clone on a quiet grove runs its integration suite before it arrives at a stone. the box has
12 cores, so the bound is 2 slots, and both are free. the skill claims one, says which, and
runs. the only new line is the `grove` branch — one glance tells the clone the bound exists and
that it did not wait.

the grove rebooted overnight, and `/run/lock` is tmpfs, so the pool dir is gone. the first run
after the boot creates it (mode `1777`, so every user's runs can share it), creates the slot
file, claims it, and runs. no error, no setup step — the same output as any other run.

## .bdd

```
given('[case1] a 12-core grove: bound 2 slots, both free')
  when('[t0] a full integration suite runs')
    then('it claims a slot at once, with no wait')
    then('stdout names the bound and its derivation from the core count')
    then('stdout names the slot it claimed')
    then('the slot frees when the suite exits')
  when('[t1] the pool dir is absent, as after a reboot')
    then('the run creates the pool dir with mode 1777 and the slot file with mode 0666')
    then('it claims a slot and runs, with output identical to [t0]')
```
