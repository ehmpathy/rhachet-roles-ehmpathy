# case=5 — grove operator · override the bound

**feel:** sharp · **care:** alterpath · **cells:** stage 3 `env`, `invalid` · **actor:** a human in the operator seat (stage 5 `human`; the act itself is axis D)

## .narrative

the grove operator watches a 12-core box sit at load 4 while a third suite queues behind 2
slots — their crew runs light unit suites. they raise the bound for every shell with one env
var; `--what all` children inherit it with no extra flag. the `bound` line names its source, so
a clone who sees 4 slots knows why. a typo (`0`) refuses loud and names the valid range, so no
run silently goes unbounded or deadlocks on zero slots.

## .sketch

```
$ GIT_REPO_TEST_SLOTS=4 rhx git.repo.test --what unit --mode apply
   ├─ grove
   │  ├─ bound: 4 slots (GIT_REPO_TEST_SLOTS)

$ GIT_REPO_TEST_SLOTS=0 rhx git.repo.test --what unit --mode apply
✋ ConstraintError: GIT_REPO_TEST_SLOTS must be a whole number ≥ 1
   ├─ got: 0
   └─ fix: export GIT_REPO_TEST_SLOTS=2, or unset it to derive from the core count
exit 2
```

## .bdd

```
given('[case5] a box with 12 cores')
  when('[t0] GIT_REPO_TEST_SLOTS=4 is set')
    then('the bound is 4 and stdout names the env var as its source')
    then('--what all children inherit the same bound')
  when('[t1] GIT_REPO_TEST_SLOTS is 0, -1, or abc')
    then('exit 2 with ConstraintError on stdout and stderr')
    then('the error names the value and the fix')
```
