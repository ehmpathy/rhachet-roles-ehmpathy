# case=4 — clone · scoped run · bypasses the bound

**feel:** happy · **care:** critipath · **cells:** stage 1 `scoped × single`, `non-jest × single`

## .narrative

a clone iterates on one test file: `--scope path://invoice --scope name://case3`. it runs the
loop twenty times in ten minutes. while three full suites hold every slot, a wait here would
stall the tightest feedback loop the clone has.

a scoped run is small by construction, so it bypasses the bound. it says so in one line, so the
clone knows why it did not queue, and knows `--thorough` would.

between loops the clone edits a type and runs `--what types`, then `--what lint`. both slots are
still held by other trees' integration suites. neither check waits: each prints
`grove: bypass (not a jest suite)` and returns in seconds, the same as on an idle box. the clone
never learns the grove was full, because for a quick check it never matters.

## .bdd

```
given('[case4] a grove with every slot held')
  when('[t0] a scoped run starts, without --thorough')
    then('it runs at once, with no wait')
    then('stdout names the bypass and its reason')
  when('[t1] a scoped run starts with --thorough')
    then('it is bounded, as case=2')
  when('[t2] a clone runs --what types, lint, or format while every slot is held')
    then('it runs at once, with no wait and no lock taken')
    then('stdout names the bypass: not a jest suite')
  when('[t3] the same quick check runs with --when hook.onStop')
    then('it bypasses the same way; a hook that runs a quick check never waits for a slot')
    then('a hook that runs a jest suite is bounded like any caller (stage 5 `system`)')
```

## .the quick checks

`--what types`, `lint`, and `format` are the commonest calls a clone makes — before each commit,
after each edit burst (pre-approved at `init.claude.permissions.jsonc:294-296`). none is a jest
suite. a 10-second lint queued behind a 10-minute integration suite would tax every clone on the
grove many times an hour, so the bypass is load-critical, not a nicety. a consumer that wires the
skill into a stop hook (`--when hook.onStop`, `git.repo.test.sh:1008`) gets the same bypass.
