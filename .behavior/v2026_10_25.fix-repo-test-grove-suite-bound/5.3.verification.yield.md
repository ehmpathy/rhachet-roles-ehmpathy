### the guardBorder acceptance flake, root cause and repair

- **symptom:** `guardBorder.onWebfetch [case2] [t0]` hit the suite-wide `jest.setTimeout(90000)`;
  its five `then` blocks failed after it (`useThen: tried to access value before test ran`)

  38s (fails at `JSON.parse`), no api key 45s, private IP 59s, localhost 82s

  `npx rhachet roles link --role mechanic` (`blackbox/.test/invokeHook.ts:35`). setup and the hook
  call shared one 90s budget; under grove load the link alone cost ~35–45s, so a slow brain answer
  pushed the sum past 90s

  jest times on its own; the `useThen` now times the hook call alone. suite timeout and every
  assertion unchanged; no timeout number to guess

  (junk stdin), log `what=acceptance/2026-10-26T23-16-54Z`; the full rerun is the row above

  different kind remains there: `pretooluse.check-permissions` timed hook calls that take 1–2s on
  most paths took 38–58s on four (fzf tier, novel-command retries) in the same run — passed, but
