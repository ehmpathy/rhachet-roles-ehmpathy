# case=6 — clone · `--what all` on a busy grove 🎯

**feel:** happy · **care:** critipath · **cells:** stage 1 `full × multi`, `thorough × multi`, `non-jest × multi`; stage 2 `free × exits`, `full × exits`, `full × terminated` · **boundaries:** B1 B2 B3 B6

## .narrative

a clone runs `--what all --against local --env test` to close a verification stone. the grove
holds one of two slots: tree kai's integration suite. the `lint` child runs at once (not jest —
bypass). the `unit` child claims the second slot, runs, and frees it.

by now tree jo has taken that slot. the `integration` child finds both held, names kai and jo,
and waits. four minutes in, kai's human sees their own suite stall and hits ctrl-c. kai's trap
kills its own jest tree and exits; the kernel drops kai's lock. within a second the clone's integration child
claims kai's freed slot and runs. `acceptance` waits on jo the same way, then runs.

the parent never holds a slot: each child is one suite, so `--what all` costs the grove one slot
at a time, never four. the run completes; no row reads red for load.

this one walk crosses the gate (lint bypasses, jest children bound), the wait, a holder's death
mid-wait, and the child-to-child handoff. the densest path in the catalog; the spotlights
(`case=2` wait, `case=3` death, `case=4` bypass) keep each fail-safe legible on its own.

## .bdd

```
given('[case6] a grove with 2 slots: one held by tree kai')
  when('[t0] --what all runs')
    then('the lint child runs at once, with no lock taken')
    then('the unit child claims the free slot, runs, and frees it')
  when('[t1] tree jo claims the slot the unit child freed')
    then('the integration child waits and names both holders')
  when('[t2] tree kai's run is killed mid-run')
    then('the integration child claims slot.0 within one poll, and runs')
    then('no two children of this run ever hold a slot at once')
    then('the parent holds no slot')
  when('[t3] the same run with --thorough')
    then('each jest child is bounded the same way')
```
