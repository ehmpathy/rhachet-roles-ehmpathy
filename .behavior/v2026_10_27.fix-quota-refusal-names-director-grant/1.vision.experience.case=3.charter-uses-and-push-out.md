# case 3: a director governs the tree, uses AND push both spent

feel: sharp · care: critipath (C14)

## .why this is its own case

a quota file holds two fields, `uses` and `push`. `push` is fixed at grant time; `uses` counts
down. any grant made with `--push block` reaches uses = 0 and push = block once its uses run out.
the surfaces check them in different orders:

- `git.branch.rebase begin` checks push first (`begin.sh:87`), then uses (`:98`)
- `git.commit.set` checks uses first (`:789`), then push (`:800`)
- `git.release --mode apply` checks uses only (`:294`)
- `git.commit.push` checks push only (`:360`)

so one meter state shows two different refusals, by surface. the #141 incident itself was uses-out
with push allowed (C1); this state is its neighbor on the same surface. a fix of "no commit uses
left" alone would leave it on "ask your human", which is why F2 widened scope to the push refusal.

## .narrative

a driver under a director has spent its last use, and its grant never allowed push. it runs
`git.branch.rebase begin --mode apply`. rebase checks push first, so the refusal is about push, not
uses. a director governs this tree, so the refusal names the director, with one line that sets both
fields:

```
🐢 hold up dude...

🐚 git.branch.rebase begin
   └─ error: rebase requires push permission

a director governs this tree; ask your director to grant push. the director runs:
  $ rhx git.crew.grant --tree svc-quotes.beav.fix-ask-for-details-survives-crash --quota <n> --push allow --why '<why>'
```

the driver relays it; the director runs it once; both refusals clear.

## .bdd sketch

```
given('[case3] a tree a director governs, uses = 0 and push = block')
  when('[t0] git.branch.rebase begin --mode apply')
    then('exit code unchanged from main (1 on this surface)')
    then('stdout names "rebase requires push permission"')
    then('stdout names "ask your director" + the git.crew.grant line with the real tree slug and --push allow')
    then('stdout does NOT name "ask your human"')
  when('[t1] git.commit.set --mode apply --push')
    then('exit 2; the uses refusal (uses is checked first); the director line carries --push allow, since the command pushes')
  when('[t1b] git.commit.set --mode apply (no --push)')
    then('exit 2; the uses refusal; the director line keeps the meter push, --push block: a uses grant never widens push (F11)')
  when('[t2] git.commit.push --mode apply')
    then('exit 2; "push not allowed"; the director line with --push allow, in tree output')
  when('[t3] the director runs the printed line once, then the driver re-runs [t0]')
    then('neither refusal fires; the rebase proceeds')
```

## .fail-safe

loud (exit; the refusal on stdout on every surface, with each surface's stderr unchanged from main),
fast (first guard), and it teaches one line that clears every field the driver's command needs.
