## .invariants

- a review comment raises a reply task ⟺ a human wrote it ∧ (it is first seen ∧ its thread reads unanswered at the read ∨ its body changed since the read that last saw it)
- a third-party bot's comment never raises a reply task and never answers; a ledgered comment is the crew's own, under any login
- a review comment takes at most one alert path: a reply task, or (peer clone) today's `comment.new` — never both
- in an alert that holds a reply task, the reply task section comes first
