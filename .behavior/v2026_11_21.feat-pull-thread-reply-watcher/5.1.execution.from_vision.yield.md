# 5.1 · execution from the vision

## .what landed

the pr-watch daemon raises a **reply task** for each human review comment the crew has not answered. top-level comments keep today's `comment.new` (F10, out of scope). a task sits first in its read's alert (A9 holds), carries each comment whole up to 2000 chars, and names the command that answers it. answered threads, bots, and the crew's own words raise naught. comments are tracked by id and body print, so a draft review that lands late raises (F8) and a human's edit raises again (F9).
