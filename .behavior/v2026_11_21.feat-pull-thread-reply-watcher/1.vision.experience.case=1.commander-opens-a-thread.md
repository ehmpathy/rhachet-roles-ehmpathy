# case=1 · the commander opens a thread while the crew is mid code work

covers: C1, C7, T2, S2. happy · critipath.

## .narrative

the crew pushed `ehmpathy/surf-demo#7` an hour ago; `git.commit.push` set its watch. now it is deep in a route stone, a fix for an unrelated test.

the commander reads the diff and leaves an inline comment on `src/wave.ts:42`:

> basically, i dont want to slam github every hour for no reason.
> we should be able to read a quiet pr for free via etags.

the pr changed a minute ago, so the daemon reads it on the next tick. the thread is new, its author is a human, and naught follows it: the thread is unanswered. the daemon queues one alert with the reply task, and hands it to `clone say`. the crew is mid-turn, so `clone say` enqueues it.

when the crew's turn yields, it reads:

```
🐢 heads up dude...

🐚 git.pull.watch — reply task on #7
   ├─ pr: ehmpathy/surf-demo#7
   ├─ thread 4601234567 · new · by @uladkasach
   │  ├─ file: src/wave.ts:42
   │  ├─ url: https://github.com/ehmpathy/surf-demo/pull/7#discussion_r4601234567
   │  └─ says
   │     ├─ basically, i dont want to slam github every hour for no reason.
   │     └─ we should be able to read a quiet pr for free via etags.
   └─ next: reply first, then resume: rhx git.pull.comment set --which 7 --in ehmpathy/surf-demo --reply-to 4601234567 --key answer-4601234567-c<clone> --from <file|@stdin> --mode apply
```

the whole comment is there; the crew needs no second read to know what was asked. it writes two lines — what it will change and where — and replies. then it returns to its stone. the fix, when it lands, earns a second reply in the thread under a fresh key — the printed key plus `-done` — so it notifies the commander; a rerun under the printed key would edit the first reply, and an edit sends no notice. the crew brief names this act.

on the commander's side: he left the comment, went to the next file, and when he scrolls back the reply sits under his thread. he relayed naught, and asked no director to.

seventeen seconds after the root, the commander had added "vibes matter!" in the same thread. both landed before the read, so both sit under the one section, in order.
