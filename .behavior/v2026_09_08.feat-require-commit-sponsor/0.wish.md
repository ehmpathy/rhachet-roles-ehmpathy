# wish: require a human sponsor on every commit

## .the outcome

every commit a clone makes names the **human who authorized it**. where that human cannot be
inferred, the commit skill **refuses** rather than guesses.

today it guesses. `git.commit.set` reads `git config` and calls whatever it finds a human. on a
local grove that is a lucky proxy; on a cloud grove **the git config IS the clone**, so the skill
writes the clone into its own co-author slot and the commit records zero humans while it looks
fully attributed.

## 🔴 .the seeds — read BOTH before you design

they carry the evidence, the live citation, and the constraint. do not work from this file's
summary; it is a pointer, and the issues are the record.

```sh
gh issue view 645 --repo ehmpathy/rhachet-roles-ehmpathy   # the defect + the ask
gh issue view 646 --repo ehmpathy/rhachet-roles-ehmpathy   # the followup — it constrains the shape
```

⚠️ **#646 is the one that changes the design.** it reports that the defect blocks its own repair —
`git.commit.set` closes both routes to a human identity. read it before you pick an approach, not
after.

## .the bounds

| bound | why |
|---|---|
| the **word** is unsettled — `sponsor` · `patron` · `authorizer` | #645 says so explicitly and defers it to the architect. settle it, and record the reason in `domain.terms/` |
| ⛔ **no silent fallback to `git config`** | that fallback **is** the defect. it fails invisibly on every cloud grove, which is how it survived |
| an explicit, one-time seed from `git config` on a LOCAL grove is fine | the local ergonomic is worth a keep — only the implicit path is forbidden |
| the guard must establish a **human**, never enumerate known-bad names | the extant placeholder guard already reaches for this class and catches two literals |

## .what would make this wrong

- a commit that still records zero humans
- a refusal with no copy-paste command to fix it
- a rename with no repair — the value must be **established**, whatever it ends up called
