# 1.vision.yield — require a human sponsor on every commit

## .the outcome

**every commit names the human who authorized it. where none is bound, the commit is refused.**

the value is **bound by a human act**, never inferred from the host. `git config` is no longer an
oracle for "who is the human here" — a question it answers correctly on a laptop and falsely on a
cloud grove, with no way to tell which from the code.

the word for that human is **`sponsor`** — evidence at
[`domain.terms/sponsor.md`](../../.agent/repo=.this/role=any/briefs/domain.terms/sponsor.md).

### 🔴 the defect is an expired premise, not a slip

the origin wish that created `git.commit` — `.behavior/v2026_02_03.git-commit/0.wish.md:12`:

> "it should simply give co-authorship to **the parent git user** … while it still attributes the
> human user that delegated the action with credit, **like a sponsor**"

**the wish assumed the git user IS the parent human.** in 2026-02 that held — every grove was
local. it inverted when cloud groves arrived, and the code kept the premise.

⇒ that is why no guard caught it: **the code faithfully implements a wish whose world changed.**
a review of the code against its intent would have passed every time.

⇒ and note the word: **the origin wisher said `sponsor`.** `patron` is the drift. this vision
restores the wish's own vocabulary (`F1`).

## 🎯 .the aha

> **the grove no longer matters.**

today the answer to *"does this commit name a human?"* depends on which machine ran it. under a
bound sponsor, a cloud tree and a local tree emit the **identical trailer**, because both read the
same bound value.

that collapse is the measure of the fix. the `grove` axis
([dimensions](1.vision.experience.dimensions.md) → D) is an artifact of the defect **at `commit`**,
and it goes inert there.

🔴 **it does not go inert at `bind`** — `Q2′` moved its whole weight there. a cloud grove as
provisioned today carries no human `gh auth login` session, so the grove decides **which value form
resolves**: `--who @me` works where your own session is, `--who @stdin` works everywhere.

⚠️ the grove decides a **value form**, never a flag — there is one flag (`F10`) — and it decides it
as a matter of **fact** about how cloud groves are provisioned today, never as a rule the skill
enforces.

## .the day in the life

**the supervisor**, once per tree, in the same breath as the quota grant:

```sh
rhx git.commit.uses set --quant 5 --push allow
#   🥥 no sponsor is bound to this tree, so commits will refuse
#      rhx git.commit.sponsor set --who <@me | @stdin | "Name <email>">
printf 'Ada Lovelace <ada@example.com>' | rhx git.commit.sponsor set --who @stdin
```

⇒ **one moment, two lines.** the quota grant **nudges** when no sponsor is bound, so the new step is
discoverable at the one act where a human is provably present (`case=1` `[t0]`, `F8`). the nudge is
a coconut, never an error — the grant still exits 0, because a sponsor is required to *commit*, not
to *grant*. ✅ **`Q6` ruled one moment is enough**, which is what makes the nudge a **required
behavior** rather than a polish item.

⇒ the supervisor reads the requester's identity on the machine they dispatched from and pipes it —
the wisher's own mechanism, and the reason `@stdin` is a contract requirement.

**on a laptop**, the same moment is shorter, because the human sponsors their own work and their own
session is the one on the host:

```sh
rhx git.commit.sponsor set --who @me
```

**the mechanic**, every commit, unchanged — it types the same command it types today and the
trailer names a human.

**the mechanic on a tree nobody sponsored** hits a wall that tells it who can take it down:

```
   ⛔ you cannot fix this yourself. a sponsor is bound by a human, at a tty.
   ask your human to run, in this tree:
     printf 'Name <email>' | rhx git.commit.sponsor set --who @stdin
     rhx git.commit.sponsor set --who "Name <email>"
```

⚠️ **note which form is ABSENT: `@me`.** a mandatory block prints only the value forms that hold on
every grove, and `@me` reads the host's session — which on a cloud grove is the clone's, so it would
hand the human a second refusal (`case=3`, `case=1` `[t3]`). ⇒ `@me` rides the **coconut** instead,
where an optional route belongs.

## .the contract

```sh
rhx git.commit.sponsor set --who <value>                    # bind the sponsor — ONE flag
rhx git.commit.sponsor get                                  # read
rhx git.commit.sponsor del                                  # clear
```

**`--who` takes three value forms**, and they are one enumerable set — `--help` and every refusal
list all three:

| value form | supplies | needs |
|---|---|---|
| `@me` | your own github session (`gh api user`, as-human) | 🔴 **your own** `gh auth login` on this host |
| `@stdin` | a piped `Name <email>` | — |
| `"Name <email>"` | a literal | — |

```sh
rhx git.commit.sponsor set --who @me                              # the sponsor is me
printf 'Name <email>' | rhx git.commit.sponsor set --who @stdin   # piped — paved for a dispatch
rhx git.commit.sponsor set --who "Name <email>"                   # literal
```

🔴 **ONE flag, ruled at the third council (`F10`).** the drive carried two — `--from me` beside
`--who` — for eight review rounds. the wisher asked why in one line, and the answer is that
`@`-sigil-**as-a-value** is the repo's extant pattern (`-m @stdin`, `--org @all`, `--into @this`),
never a separate flag.

⇒ and two flags asserted a distinction the design does not have: **`Q8` ruled the sponsor is the
requester**, so every form answers one question — *who is the requester?* ⚠️ `--from me` even parsed
as *"the **source** is me"*, which is the **pre-`Q8`** model (assumption `H2`) still spoken by the
surface after the prose had struck it.

⛔ **there is no `--from git-config`, and no `--from` at all.** the wish permits an explicit local
seed; the design declines it, so no path reads `git config` for an identity. `F9`.

### 🔴 `@me` refuses when the session is not yours — it never substitutes

✅ ruled at the second council (`Q2′`): a cloud grove as provisioned today carries no human
`gh auth login` session. measured on this host:

```sh
$ gh api -X GET user --jq '{login, name}'
{"login":"ehm-seaturtle","name":"Seaturtle of'Ehmpathy"}
```

⇒ so `--who @me` there exits **2** and names the fix (`case=1` `[t3]`). **a fallback to the session
it found would be the original defect under the paved path's own flag.**

⚠️ **the guard sits on the VALUE, never the grove.** the skill runs no grove-detect (`case=5`). a
human who ssh'd in with **their own** session would pass — `Q2′` is a fact about how cloud groves are
provisioned today, not a rule about where `@me` may run.

🔴 **and the detector is `F3`'s deferred predicate.** a real human at a real tty runs `@me` on a
cloud grove, so the **act** check passes and only the **identity backstop** refuses. ⇒ that is why
the backstop is owed rather than optional, and it is a `2.1.criteria` dependency rather than a
vision-stage mechanism.

⇒ and `@stdin` is a **requirement**, not a convenience: the wisher's mechanism is *"grab it from
the machine they dispatched from and pipe it in"*, and a name+email in `--who "…"` lands in shell
history and the process arg list — the same PII `get_clean_pr_body in git.commit.push.sh` already strips from pr
bodies. it matches the extant `-m @stdin` pattern.

| act | actor | note |
|---|---|---|
| `set` | 🔴 human only | tty guard + permission denylist. both extant patterns |
| `del` | 🔴 human only | same guard — a permissive `del` is a permissive `set` plus one step |
| `get` | anyone | a read is not a mutation; the clone needs it to explain its state |

and in `git.commit.set`:

- sponsor bound → `Co-authored-by: <sponsor>`
- sponsor absent → **exit 2**, with the fix, addressed to the human

## .the eight invariants

⚠️ **this heading read "the five" while the body carried seven items** — flagged at peer review r6,
and it had been stale since invariant 6 was added. ⇒ renumbered to a flat **1–8**: the orphan `4b`
became **5**, and the two second-council decisions are now stated rather than implied.

1. **a sponsor is a human.** a robot or placeholder value is refused **at bind**, where a human is
   present to fix it — not at commit, where only a clone reads the complaint.
2. **only a human mutates the sponsor.** `set` and `del` alike — and 🔴 **the state FILE carries
   its own guard**, not only the commands. a clone that never runs the skill can still `Write` the
   file, so the state must live flat inside an extant denied directory (`.meter/`), where
   `Write(.meter/*)` already covers it. ⚠️ that glob does **not** cross a `/`, so a nested
   "tidier" path silently loses the guard (`case=4` → the third guard).
3. **a clone may read it.** `get` carries no actor guard.
4. **the sponsor is a snapshot, never a pointer.** it does not track its source after the bind.
5. 🔴 **"per-tree" means per-WORKTREE, and the command that resolves it carries load.**
   **measured at r4:** `git rev-parse --show-toplevel` returns the worktree root;
   `--git-common-dir` returns the shared parent `.git`. ⇒ `git.commit.bind.sh:30` already uses
   `--show-toplevel` and is correct. ⚠️ a design that reached for `--git-dir` or
   `--git-common-dir` would make one sponsor cover **every worktree of a clone** — the `F2`
   fabrication at smaller scale, and invisible to every test.
6. **the sponsor never travels in a commit message.** the adhoc `Co-authored-by` guard stays
   exactly as strict.
7. 🔴 **the sponsor state is never committed.** it holds a human's **name and email** — PII, and
   the most sensitive value any of these meters has held. the state dir self-bootstraps its own
   `.gitignore` on first write, as `.branch/.bind/` does (`git.commit.bind.sh:127-130`).
8. 🔴 **`git config` is never read for an identity, on any grove** (`F9`) — **and a bind that
   cannot establish a human REFUSES rather than substitutes** (`Q2′`, `case=1` `[t3]`).
   ⚠️ **the two halves are one invariant on purpose:** a fallback is what turns an absent source
   into a wrong record, and every defect this wish exists to remove is a substitution that looked
   reasonable at the moment it happened.

### 🔴 why invariant 7 is not mere tidiness

this repo already treats a co-author email as a leak to be prevented: `get_clean_pr_body in git.commit.push.sh`
strips `Co-authored-by` trailers from every pr body, commented *"privacy: avoid email leak"*.

⇒ a design that persists that same email to a file and forgets to ignore it would **publish, in
the repo, the exact value the push skill goes out of its way to keep out of a pr.** the quota is an
integer and the bind is `fix|feat`; the sponsor is a person. the state is the same shape, the
sensitivity is not.

verified: `git ls-files .meter .branch` → empty. the paved pattern is a self-bootstrapped
`.gitignore` inside the state dir, and the origin wish asked for it by name (*"bootstrap `.meter/`
with a `.gitignore`"*).

## 🔴 .how this settles `#646`

`#646` reports that the defect blocks its own repair: the skill derives the co-author from
`git config` (the clone) **and** refuses a hand-supplied `Co-authored-by`. both routes closed.

`#646` then asks that the adhoc guard *"learn to tell a bound sponsor from an invented one."*

⇒ **it does not have to, and this design gives it no new lesson.**

| route | verdict |
|---|---|
| derived from `git config` | **removed** — the defect |
| supplied in the message by hand | **still refused** — the guard is untouched |
| read from the bound sponsor | **new, and the only route** |

the sponsor never enters the message, so the guard never faces the question. it keeps its one job.
⇒ a **third route** rather than a loosened second one: smaller change, smaller blast radius, and
the invention guard stays at full strength.

### 🔴 what the walk found that a free-list would not

**1. the refusal hands the clone the loaded gun.** cell 44 refuses and prints the fix. cell 9/10 is
the clone that runs that exact fix on itself. the two cells are adjacent in the box, and the first
one's error text is the second one's recipe.

⇒ the refusal must say **"ask your human to run"**, never "run" — and the guard behind it must hold
when the clone tries anyway. that demand came from the grid, not from the wish.

**2. the `robot` column propagates.** refused at `bind` (by nurture) ⇒ **unreachable by
construction** at every other act — **18** cells. the bind guard is what makes them unreachable.
drop it and the whole column flips back to live.

⚠️ **never *"by nature"*, and never *"12"*.** *by nature* would claim the state cannot exist at all,
which is false — a robot sponsor is entirely possible in a world without the bind guard, and that
world is where the defect lives. the count is 18 because the box grew 48 → 72 with the dispatcher
row.

**3. `read` owes no demo — and two of its cells carry one anyway.** every reachable read cell has a
costless fallback (the commit refusal already reports the state), so **no read cell is a critipath**.
⇒ an honest alterpath result, not an oversight.

⚠️ **cells 19/20 are nonetheless demoed**, inside `case=4` `[t3]`, because that journey needs the
clone's permitted read to prove the actor guard sits on the **mutations only**. 🔴 *owed* and *shown*
are independent — the first is about care, the second about what an `[tn]` walks — and the inventory
had them collapsed until peer review r9.

**4. 🔴 the sponsor must be read PER COMMIT.** the dense walk (`case=7` `[t5]`) clears a sponsor
mid-tree and commits again. a design that read the sponsor once — at process start, or cached for a
session — would let a **cleared** tree keep its commit, on a value no longer bound.

⇒ that is a **stale authorization**, which is the defect's own shape: a record that reads
authorized and is not. the cell-by-cell walk cannot surface it, because it is a property of the
transition between two commits rather than of either one. ⇒ invariant candidate for `2.1.criteria`.

**5. 🔴 a refused commit must spend no quota.** the same walk grants a quota and is refused at its
first commit. if the refusal decremented the meter, a tree would burn its grant on refusals and
then need **two** human grants to recover — the sponsor guard would manufacture a second blocker
out of the first.

✅ **verified: the order is already correct, under either candidate site.** the meter write is the
**last act of the skill** (`git.commit.set.sh:849-865`); the identity read the sponsor guard
replaces is at `:586`, and the other guards sit at `:511-531`. both are hundreds of lines ahead of
the decrement.

⇒ so this is a **preservation, and a cheap one** — the risk is low precisely because the meter
write is last. it is written down anyway because the property is *invisible* in the code (no
comment marks the write as order-sensitive) and because the walk is what raised the question at
all. an invariant nobody states is one a later refactor may move. ⇒ `2.1.criteria`: **the sponsor
guard runs before the meter write.**

## .the mental model

**how a human would describe it to a friend:**

> "the robot can't commit until someone puts their name on it. not a credit line — a signature."

**the analogy that fits: a bill's sponsor.** a legislator sponsors a bill they did not draft. the
drafter wrote the text; the sponsor answers for it on the floor. that is exactly a commit — the
clone wrote the code, a human stands behind it.

**the analogy that does not fit: a patron.** a patron funds an artist and answers for none of it.
that is the word in the code today, and its wrongness is a tell — the code named who *supported*
the work where it meant who *answers* for it.

| they say | we say |
|---|---|
| "whose commit is this?" | the sponsor |
| "who signed off?" | the sponsor |
| "the co-author" | the `Co-authored-by` trailer — the *render*, not the concept |
| "my git config" | 🔴 a host config, and no longer an input to a commit |

## .evaluation

### how well it solves the goal

| the wish asks | how it lands |
|---|---|
| every commit names the human who authorized it | ✅ the trailer reads the bound sponsor, only |
| refuse rather than guess | ✅ exit 2, `case=3` |
| ⛔ no silent `git config` fallback | ✅ **exceeded** — no code path reads `git config` for an identity at all, so the fallback is unreachable rather than merely guarded (`F9`) |
| explicit local seed is fine | 🔴 **declined.** *"is fine"* is a licence and the design did not spend it — the wisher struck it at the second council. the local bind is `--who @me` (`case=6`), and the git-config value stays reachable via the `@stdin` one-liner. ⇒ recorded at `F9`, because a blessed affordance that is absent must not read as an oversight |
| establish a human, do not enumerate | ✅ **the mechanism is named** — `case=4`'s **act** guards (tty + a permission the clone lacks) are what establish the human. three identity-attribute predicates were measured and refuted (`Q10`), so `case=5`'s list is a **backstop**, never the primary check. ⚠️ the backstop's own contents stay deferred — `F3` |
| a rename with no repair is wrong | ✅ the value is *established*; the rename rides along, and `sponsor` is now **ruled** over `patron` / `authorizer` |

### pros

- **the defect becomes unreachable by construction**, not by a better guess (18 such cells)
- **it rides an extant seam** — the sponsor binds where the quota is granted, which is already the
  moment of authorization. one new line in a workflow humans already run
- **every guard is a paved pattern** — tty check, permission denylist, `.meter` state, `set/get/del`
  verbs. no new mechanism is invented
- **it shrinks `#646`'s ask** — a third route beats a loosened guard

### cons

- 🟡 **a hard cutover.** every extant tree loses its commit until a human binds once (`F4`). ✅
  **ruled acceptable** — the fleet is small
- 🟡 **a new human step per tree**, forever. small, but it is friction on the paved path. ✅ **ruled
  acceptable** (`F2`, `Q7`) — ⚠️ and it scales linearly with the fleet, which is the re-open trigger
- ✅ **automated dispatch would stall** (`case=8`) — 🔴 **but no automated dispatch exists**
  (`Q1`, ruled), so the whole 24-cell dispatcher band sits at **severity zero today**. the walk is
  kept, and its care grades are **conditional**: they state what each cell becomes the day dispatch
  arrives, so the analysis is already done rather than begun
- **the snapshot baseline moves** — `patron` → `sponsor` across 20+ snapshot lines

### the edge cases, and the pit of success

| edge | how the contract keeps the pit |
|---|---|
| the clone reads the refusal and runs the fix | refused at two guards; the text addresses the human first |
| a human seeds from `git config` on a cloud grove | refused, and the error **names the grove** — it corrects the mental model, not just the input |
| a human names a real person who did not act | refused when the actor is a clone. ⚠️ a *human* who names another human is **not** refused — that is delegation, and it is legitimate |
| `git config` changes after the seed | the sponsor does not track it. a tracked value is the implicit fallback, renamed |
| the sponsor is cleared mid-tree | the **very next** commit hits `case=3` — the sponsor is read per commit, never cached (`case=7` `[t5]`) |
| the sponsor goes **stale** — supervisor A bound, supervisor B now drives | ⚠️ **accepted, by design.** the sponsor is per-**tree** (`F2`), so it names who authorized the *tree*, not each commit. a finer grain would demand a bind per commit, which is the ceremony the paved path exists to avoid. B rebinds when B wants the record to say so |
| a placeholder identity (`Test User`) | refused at bind — the extant commit-time guard, moved earlier and generalized |

## 🔴 .the hidden assumptions, surfaced at self-review r3

these were taken as requirements without a decision. each is now named, with its counter.

### H1 — the sponsor is **exactly one** human

never questioned. `Co-authored-by` supports **many** trailers, so git imposes no cardinality; i
inherited "one" from the wish's singular phrase (*"the human who authorized it"*).

⇒ **counterexamples that are real:** two supervisors jointly authorize a risky change; a tree is
handed over mid-flight and both parties answer for their halves.

⇒ **taken: one, deliberately.** a sponsor **answers** for the change
(`domain.terms/sponsor.md`), and shared accountability is famously no accountability. one name is
the whole value of the record. ⇒ but the wish's singular is now a **decision**, not an inheritance.

### H2 — the sponsor is the human who **granted the quota**

`case=1` has ulad grant the quota and bind himself, so the two collapse into one person and the
question never surfaces.

⇒ **they can differ:** a supervisor dispatches work a *requester* asked for. who answers — the one
who authorized the spend, or the one who wanted the change?

⇒ **the contract admitted both**, on two flags at the time: `--from me` named the supervisor,
`--who "…"` named the requester. ⇒ but the vision never said **which is right**, and *"a supervisor
can sponsor on behalf of the human who actually asked"* implied the requester without a decision.
⇒ raised as **Q8**.

✅ **RULED, 2026-09-09: the REQUESTER.** the term's own evidence settles it — a sponsor *answers
for* the change, which is the requester's relation to it. the supervisor's relation is to the
**budget**, and the quota meter already records that, in a different mechanism, for a different
question.

⇒ 🔴 **and the decision makes `@me` wrong for a dispatch**, which the artifact had treated as a free
ergonomic choice. the wisher added the mechanism: *"the supervisor should grab it from the machine
they dispatched from and pipe it in"* ⇒ **`--who @stdin`**, now a contract requirement.

⇒ 🎯 **round 2 then made it IMPOSSIBLE rather than merely wrong.** `Q2′` established that a cloud
grove has no human github session, so `@me` does not hold there. ⚠️ **two independent decisions, one
command** — H2 said a supervisor *should not* read their own session for a dispatch; `Q2′` says on a
cloud grove they *cannot*. a design whose ergonomic advice and whose mechanism point the same way is
one where the pit of success is built rather than asked for.

⇒ 🔴 **and round 3 collapsed the two flags H2 had lived between.** `Q8` ruled both name one party,
so the second flag asserted a distinction the domain does not have (`F10`). ⚠️ **H2 was struck in

distinction between two. ⇒ the escalation was the entire value; no further analysis in-tree would

### H3 — a clone **would** act on the refusal's command

`case=4` calls it *"the natural next move of a competent agent that just read an error"*. that is an

⇒ **taken: the guard stands**, on an asymmetric payoff rather than on a probability. the guard

## .what is awkward

**1. `@me` has two meanings and the human cannot see which.** it resolves to the human on a laptop
and to the **clone** on a cloud grove. the guard catches it, so the outcome is safe — but the *value
form* is ambiguous by construction, and `rule.forbid.ambiguous-labels` would rather it were not.

🔴 **this wart has now moved twice, and the trail is the point.** it began on `--from git-config`;
`F9` struck that flag and the ambiguity moved to `--from me`; `F10` folded that flag into `--who`
and it moved again, to the `@me` **value**. ⇒ each removal made the surface smaller and left this
one hazard standing.

⇒ that is the tell: **it cannot be designed away.** `@me` means *"the identity this host says is
me"*, and a cloud grove genuinely answers that with the clone. ⚠️ the seed was removable and the
flag was foldable; the ambiguity is neither — only guarded (`case=5`), and refused rather than
degraded (`case=1` `[t3]`). ⇒ 🔴 **it is why `F3`'s backstop is owed rather than optional.**

**2. `--global` would carry inverted precedence across two neighbor skills.** for `git.commit.uses`,
global is a circuit breaker — most restrictive wins. for the sponsor it is a default — most specific
wins. one word, two precedences, in commands that sit side by side (`F2`).

**3. a human must bind themself to sponsor their own work.** on a local grove where `git config`
already holds their name, the act is pure ceremony from the human's point of view. the ceremony is
the point — a record of a decision is what a cloud grove cannot forge — but it will feel like
bureaucracy at the moment it is asked for, and that is where a cutover generates complaints.

**4. the refusal's pronoun does safety work.** a design where an error message's *grammar* carries
load is fragile — a future edit that shortens "ask your human to run" to "run" reopens a critipath,
and no test would obviously catch it. ⇒ this wants an explicit test, and the guard behind it must
hold regardless of the text.
