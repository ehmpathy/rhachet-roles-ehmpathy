## .the narrative

the mechanic finishes its work and reaches for a commit. no sponsor is bound.

**today** it reads `git config`, finds the clone, and writes the clone into its own co-author slot.
the commit lands. the trail reads complete and names zero humans. `ahbode/svc-jobs@a1635ea` is that
commit — **verified first-party**, author and co-author both the clone (`#645` reports six of them
on a branch that shipped to prod; the branch is since deleted).

**under the sponsor** it refuses. the mechanic cannot proceed, and the refusal says so plainly:
the sponsor is absent, a commit needs one, and here is the one command that fixes it —
**for the human to run.**

⇒ 🔴 **the pronoun is the design.** the refusal is read by a clone, and a clone can run commands.
if the text says *"run this"*, the clone runs it and sponsors itself — the defect restored through
the front door of its own fix (`case=4`). the text must address the **human**, and the guard behind
it must hold even when the clone tries anyway.

✅ **and this pronoun is extant, not invented here.** the skill already refuses a clone this way
when the *quota* runs out — also a human-only grant:

```
🐚 git.commit.set
   └─ error: no commit uses left

ask your human to grant more:
  $ git.commit.uses set --quant N --push allow|block
```
> `git.commit.set.integration.test.ts.snap` — `[case3] no uses left … [t0]`

⇒ the sponsor refusal is the **same situation** — blocked on an act only a human may perform — so
it copies the same shape rather than invents one. what this case adds is the explicit
*"you cannot fix this yourself"* line, because the sponsor's fix is a command the clone could
plausibly believe is its own.

### 🔴 the refusal prints the value forms that work on EVERY grove — a `Q2′` consequence

this `[t0]` previously printed `$ rhx git.commit.sponsor set --from me`. ⇒ **on a cloud grove that
command itself refuses** (`case=1` `[t3]`), so the refusal would hand the human a second refusal.

⚠️ **that is a listed failure of the wish**, near enough to count: *"a refusal with no copy-paste
command"*. a command that is present and does not work is worse than an absent one — the human runs
it, fails, and now doubts the whole feature rather than their own grove.

⇒ 🎯 **the rule this settles: a MANDATORY block prints only the value forms that hold on every
grove.** `@stdin` and the literal both **supply** the value, so neither can misfire; `@me` **reads**
one from the host, and what the host answers is what `Q2′` measured.

⇒ 🔴 **`F10` sharpened this rule rather than changed it.** the flag is now universal — one `--who`
on every grove — so the rule moved from *"which flag does a refusal print?"* to *"which value forms
does it print?"*. ⚠️ a rule written about a flag name would have quietly gone stale at `F10`; this
one is about a **property of the form** (supplied vs read), and that property is what actually
decides it.

⇒ ⚠️ and the skill still runs **no grove-detect** — it does not need one. it prints the forms that
cannot misfire, which is a cheaper way to be right than a host guess (`case=6`).

⇒ 🔴 **and `@me` is ABSENT from this refusal entirely** — on every grove, with no coconut beside it.
clamped: `git.commit.set.integration.test.ts` `[case6][t0]` asserts
`not.toContain('--who @me')`, beside the two `toContain` that pin the forms that do print.

### 🔴 why `@me` earns no coconut here, though it is the local shorthand

an earlier draft hung an ungated `🥥 did you know? … --who @me` off this refusal. it never shipped,
and it should not: **a grove-invariant render cannot carry a grove-specific shorthand.**

⇒ the draft's own defence was that `@me` refuses on a cloud grove *"so the human learns the split
from the guard"*. ⚠️ that trades a real human's time at the worst moment — they are mid-unblock of
a stalled tree, they copy the line the tool offered, and it refuses. **the wish lists *"a refusal
with no copy-paste command"* as a failure, and a command that is present and does not work is
worse**, because the human then doubts the feature rather than their grove (`[t0]`'s rule).

⇒ ⚠️ **and the reader here is a CLONE** — that is this whole case's thesis. a coconut marks
*"optional guidance you may act on"* (`rule.require.coconut-hints`), and this reader may act on
**none** of it. so the mark would be false for the party that actually reads the block.

⇒ 🎯 **`@me` stays discoverable where its reader is a human and its grove is known**: the
`git.commit.uses set` nudge (`case=1` `[t0]`, where it carries its own
`# reserve for YOUR OWN work` caveat), `--help`, and `case=6`. **discoverability is satisfied by a
surface a human meets, never by every surface.**

## .what makes it a critipath

| term | value |
|---|---|
| frequency | the first commit on **every** fresh tree, until a sponsor is bound |
| cost if it fails open | a zero-human commit reaches prod, and it looks fully attributed → ∞ |
| cost if it fails closed but badly | the clone self-sponsors from the refusal text → the same ∞, laundered |
| workable fallback | **none.** the refusal is the sole barrier between the defect and prod |

⇒ **critipath.** and note both failure modes are ∞: a refusal that leaks the fix to the clone is no
safer than no refusal at all.

✅ **the prose-vs-coconut call is SETTLED, by the rule's own test rather than by taste.**

## 🟡 the migration cost is real and must be paid deliberately

cell 43 says every extant local tree loses its commit until a human binds once. that is a hard
cutover for a fleet mid-flight.

- **why no grace period:** a grace period is an implicit `git config` fallback with a timer on it,
  and the wish forbids the implicit fallback outright. a timer does not make it truthful — it makes
  the defect harder to notice.
- **what carries the cost instead:** the refusal itself. it is a one-line fix, it explains itself,
  and it fires on the first commit rather than after a merge.

⇒ this is a deliberate trade, and it is a fulcrum — `F4`.
