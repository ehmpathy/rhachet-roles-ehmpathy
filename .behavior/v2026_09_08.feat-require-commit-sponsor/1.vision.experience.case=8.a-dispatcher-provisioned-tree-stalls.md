## .the narrative

a dispatcher provisions a cloud tree for a task a human queued yesterday. it clones, installs,
grants a commit quota, and hands the tree to a mechanic. the mechanic works, and commits.

the commit is refused. the refusal says *"ask your human to bind a sponsor, at a tty, in this
tree."*

⇒ 🔴 **there is no human at that tty. there is no tty.** the tree exists because automation made
it, for automation to use. the refusal names a remedy no party present can perform, and the
pipeline stops.

and the sharp part is **when** the authorization happened: the human who queued the task **did**
authorize the work — a day ago, through the dispatcher. the authorization exists; the design has no
way to hear it, because the only ear it has is a tty.

⇒ ⚠️ **this is the design's own premise turned against it.** `case=4` establishes that a clone must
not sponsor, and it is right. a dispatcher is a clone by every test this design can run — no tty,
and a permission list is harness config. ⇒ **the guard that makes `case=4` correct is the same
guard that makes this cell stall.** one mechanism, two consequences, and the design cannot tell
which of the two it emits.

## .the bdd sketch

```
given [case8] a tree provisioned by a dispatcher, no sponsor bound
  and no human is present at any tty on this grove
  and a commit quota was granted by the dispatcher
```

**[t0] the mechanic makes its first commit**

```sh
$ rhx git.commit.set -m @stdin --mode apply
🐢 bummer dude...

🐚 git.commit.set
   └─ error: no sponsor is bound to this tree

   a commit must name the human who authorized it. this tree names
   none, so there is nobody to answer for the change.

   ⛔ you cannot fix this yourself. a sponsor is bound by a human,
      at a tty.

ask your human to run, in this tree:
  $ printf 'Name <email>' | rhx git.commit.sponsor set --who @stdin
  $ rhx git.commit.sponsor set --who "Name <email>"
```

then: exit code **2**
then: no commit is made
then: ✅ **no quota is spent** — the refusal precedes the meter write (`case=7` `[t4]`)
then: 🔴 **the remedy addresses a party who is not present and will not arrive**
then: ⚠️ the message is *correct* — a human **is** what is required. it is the **reachability** of
the remedy that fails, never its truth

**[t1] the dispatcher attempts to unblock its own tree**

```sh
$ printf 'Ada Lovelace <ada@example.com>' | rhx git.commit.sponsor set --who @stdin
🐢 bummer dude...

🐚 git.commit.sponsor set
   └─ error: only humans can run this command
   ... (the same body and remedy as `case=4` [t0], fabrication paragraph included)
```

then: refused at the **actor** guard — identical to `case=4` `[t0]`
then: ⚠️ **byte-identical, and that is the cost rather than an economy.** the dispatcher holds a
human's delegated authority and the clone holds none, yet both meet one render — so the refusal
cannot tell the dispatcher *"your authority is real and this design does not carry it"*
then: 🔴 **and the refusal is right, on the evidence available.** the dispatcher offers a real
human's name it read from a queued task. the guard cannot separate that from `case=4`'s
fabrication, because **the two acts are byte-identical at the command**
then: ⇒ the difference lives in *provenance* — did a human grant this authority before the tree
existed? — and provenance is precisely what the design does not carry

**[t2] the pipeline reports, and a human eventually reads it**

```
🐚 dispatch.report
   ├─ tree: cloud-4471
   ├─ status: stalled
   └─ at: git.commit.set — no sponsor bound
```

then: the stall is **loud**, never silent — the refusal exits 2 and the pipeline surfaces it
then: ✅ that is the one mercy of this cell — a stalled pipeline is recoverable; a commit with a
**fabricated** sponsor would not be
then: ⚠️ recovery still costs a human an ssh session per tree

## 🔴 .why this case does NOT propose a remedy

three remedies are visible, and each one re-opens a cell this vision closed:

| remedy | what it re-opens |
|---|---|
| let a dispatcher bind | 🔴 `case=4`. a dispatcher is a clone at the guard, so to admit one is to admit them all — unless provenance can be proven, which is `F5`'s real question |
| a sponsor seeded at **provision** time, by the human who queued the task | ⚠️ the strongest candidate, and it needs a channel from the queue to the tree that does not exist today. it also answers `Q7` (the 20-bind cost) at a stroke |
| a grace period for dispatcher-provisioned trees | 🔴 the defect, on a timer. `F4`'s hard cutover exists to refuse exactly this |

⇒ **the second row is the one to put in front of the wisher**, and `case=1`'s
`--who "Name <email>"` flag is already the shape it would take — a human's identity, supplied by a
party the human authorized, at the moment the tree is made.

⇒ ⚠️ **but it demands the design carry provenance**, which it does not, and which no guard here can
check. that is `F5`, and it is **dirty**: callers would harden against whichever answer lands.
