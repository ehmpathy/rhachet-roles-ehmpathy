# case=7: text piped via @stdin — the rerun pipes it again

## .narrative
a clone pipes a title in: `echo 'feat(reef): map the kelp beds' | rhx git.pull.title set --from @stdin --mode apply`. the stdin is spent once read. the nudge's rerun line names the paved round-trip file, as the plan hint already does (`cat ./.temp/title.md | ...   # pipe the same title in again`), so a paste of the line does not post an empty title.

## .[tn]
```
given('[case7] a public repo, a title piped via --from @stdin')
  when('[t0] title.set --from @stdin --mode apply, no --promise')
    then('exit 2; the rerun line opens with a pipe and closes with the "pipe the same title in again" note')
    then('no PATCH')
```
