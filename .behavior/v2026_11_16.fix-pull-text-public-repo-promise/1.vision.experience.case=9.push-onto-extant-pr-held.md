# case=9: a later push onto an extant pr, in a public repo — held too

## .narrative
the clone's pr is open. it makes a second commit, `fix(reef): drop the stale kelp row`, and pushes. no new pr text is written: the pr exists, so push only finds it. yet the commit message goes public with the push. under F1, push holds this too. the clone checks the one new commit message and reruns with the promise.

this is the most frequent cost of F1: one rerun per push into a public repo. under the other branch of F1 (gate only `pr create`), this push would pass ungated.

a careful clone that plans first meets the same nudge in plan, so it learns of the promise before apply.

```
$ rhx git.commit.push --mode apply
🐢 hold up — this text goes to a public repo
   ├─ repo: ehmpathy/rhachet-roles-ehmpathy (public)
   ├─ check the commit messages, which become the pr title and description, hold none of
   │  ...
   └─ once checked, rerun with
      └─ rhx git.commit.push --mode apply --promise text-to-public-repo-is-anonymized
```

## .[tn]
```
given('[case9] a public repo, a branch with an open pr, a new seaturtle commit')
  when('[t0] commit.push --mode apply, no --promise')
    then('exit 2; the nudge')
    then('no git push ran; the gh log holds no pr list and no pr create')
  when('[t1] the same command plus --promise')
    then('one git push; the pr is found, not created; exit 0')
  when('[t2] commit.push (plan, the default), no --promise')
    then('exit 2; the nudge; the rerun line keeps --mode plan')
    then('no git push ran')
```
