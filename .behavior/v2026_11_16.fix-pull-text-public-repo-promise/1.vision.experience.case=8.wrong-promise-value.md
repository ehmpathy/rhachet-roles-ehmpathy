# case=8: a wrong --promise value — refused

## .narrative
a clone fresh from a bhuild radio push types the radio's promise: `--promise task-to-public-repo-is-anonymized`. the skill refuses at arg parse, before any credential or gh call, and names the one value it accepts (F7). the refusal is the same in plan and apply; a json caller gets it as the family's refusal object.

```
✋ ConstraintError: --promise must be text-to-public-repo-is-anonymized, got 'task-to-public-repo-is-anonymized'
```

## .[tn]

  when('[t1] the same, with --output json')
