# case=6: plan shows the nudge

## .narrative
a careful clone previews first. the plan, too, reads the visibility and shows the nudge, exit 2 (F3). its rerun line keeps `--mode plan`, so the clone previews again with the promise, sees the usual plan tree, then applies.

## .[tn]
```
given('[case6] a public repo, a pr by self, a title that differs')
  when('[t0] title.set (plan, the default), no --promise')
    then('exit 2; the nudge; the rerun line keeps --mode plan')
    then('no PATCH')
  when('[t1] the same plan plus --promise')
    then('exit 0; the usual plan tree; the apply hint carries --promise')
```
