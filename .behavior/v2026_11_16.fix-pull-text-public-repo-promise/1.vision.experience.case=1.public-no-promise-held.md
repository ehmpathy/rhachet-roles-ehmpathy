# case=1: public repo, no promise — held

## .narrative
a clone posts a round-two status comment on its pr in `ehmpathy/rhachet-roles-ehmpathy`. the repo is public. the skill reads the visibility, sees public, and stops before any write. the clone reads the nudge, checks the comment for a private repo name or route path, finds `see reefco/svc-tides#412` in it, cuts the line, and reruns with the promise.

```
$ rhx git.pull.comment.set --which 1366 --key status --from ./.temp/status.md --mode apply
🐢 hold up — this text goes to a public repo
   ├─ repo: ehmpathy/rhachet-roles-ehmpathy (public)
   ├─ check the comment holds none of
   │  ├─ a private org, repo, route path, or pr / issue numbers
   │  ├─ internal endpoint, service, table or product names
   │  └─ customer, revenue or other business detail
   └─ once checked, rerun with
      └─ rhx git.pull.comment.set --which 1366 --key status --from ./.temp/status.md --mode apply --promise text-to-public-repo-is-anonymized
$ echo $?
2
```

## .[tn]
```
given('[case1] a public repo, a pr by self, a comment body')
  when('[t0] comment.set --mode apply, no --promise')
    then('exit 2')
    then('stdout and stderr show the nudge, snapped')
    then('the rerun line is the exact command plus --promise text-to-public-repo-is-anonymized')
    then('the gh transport saw no POST and no PATCH')
  when('[t1] the same command plus --promise text-to-public-repo-is-anonymized')
    then('exit 0; the gh transport saw one POST')
```
