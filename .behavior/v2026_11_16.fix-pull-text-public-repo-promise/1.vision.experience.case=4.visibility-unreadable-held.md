# case=4: visibility unreadable — held as public

## .narrative
github answers the visibility read with a 502. the skill cannot tell public from private, so it holds the write as if public. the nudge says so, so the clone does not believe a private repo turned public.

```
🐢 hold up — this text goes to a public repo
   ├─ repo: reefco/svc-tides (visibility unreadable, held as public)
   ├─ check the comment holds none of
   ...
```

the clone either checks the text and reruns with the promise, or reruns bare once github recovers; a private answer then writes ungated.

## .[tn]
