# case=5: git.commit.set --push into a public repo — held before the commit

## .narrative
a clone commits and pushes in one call, in a public repo. set reads the visibility before it makes the commit (F6). no promise: set halts, the stage stays as it was, no commit exists, no push ran. the nudge names set's own command; since the piped message is spent once read, the line pipes from the paved file and says to pipe the same message again (the case=7 convention). the clone checks the commit message (the pr title and body come from it), then reruns the exact line with the promise. set commits and passes the promise to push; push makes no second read.

later, the same clone commits a local checkpoint without `--push`. no text leaves the machine, so set makes no visibility read and asks for no promise; the commit lands as it always has (case5b).

```
$ printf 'feat(reef): map the kelp beds\n\n- add the kelp map' | rhx git.commit.set -m @stdin --mode apply --push
🐢 hold up — this text goes to a public repo
   ├─ repo: ehmpathy/rhachet-roles-ehmpathy (public)
   ├─ check the commit messages, which become the pr title and description, hold none of
   │  ...
   └─ once checked, rerun with
      └─ cat ./.temp/commit.md | rhx git.commit.set -m @stdin --mode apply --push --promise text-to-public-repo-is-anonymized   # pipe the same message in again
```

## .[tn]
```
given('[case5] a public repo, staged changes, push granted')
  when('[t0] commit.set --mode apply --push, no --promise')
    then('exit 2; the nudge is snapped')
    then('HEAD is unchanged; the stage is unchanged')
    then('no git push ran; no gh pr create ran')
  when('[t1] the same command plus --promise')
    then('a commit lands; one push; one pr create')
  when('[t2] commit.set --push (plan, the default), no --promise')
    then('exit 2; set's own nudge, with the commit messages check line; no plan tree follows it')
    then('the rerun line keeps --mode plan; HEAD and the stage are unchanged')
given('[case5b] commit.set without --push')
  when('[t0] commit.set --mode apply')
    then('no visibility read; the commit lands as today')
```
