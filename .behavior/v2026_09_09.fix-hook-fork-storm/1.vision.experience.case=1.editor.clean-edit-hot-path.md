# case=1 — editor lands a clean edit

**actor** editor (clone or human) · **feel** happy · **care** critipath
**cell** `editor × clean × healthy`, both ends of `box load`

this is the highest-frequency cell in the whole grid. most edits trip no term at all, and today
that common case pays the full parse ahead of the moment it learns there was none to check.

## .the narrative

kai drives a mechanic clone on `grove-ahbode-v20260901`. sixteen peer clones share the four cores.
kai's clone edits a `.ts` file — a plain rename, no forbidden vocabulary anywhere in it.

**today.** the Edit stalls. not for long, and not every time, but often enough that kai has stopped
to watch it. two hooks each boot a runner, each re-read a word list from disk, each re-parse it,
each fork a tally of small tools — and then each learn the content trips none of their terms and
exit 0. the wait is not arithmetic; it is a queue. every fork sits behind twenty-seven runnable
tasks, and the grove is busiest exactly when kai wants the edit to be cheap.

**after.** the Edit lands. kai does not notice the hooks at all, which is the correct amount to
notice a gate that had no verdict to render. the hook still reads the same content and still
reaches the same answer — it simply learns "none matched" ahead of the work it used to do first.
under a quiet box the change is small. under a contended box it is the whole difference, because
the cost it removed was the cost that grew with the queue.

**the aha.** the gate did not get weaker. it got *lazy in the right order* — cheap test first,
expensive parse only where the cheap test says a parse is owed.

## .the bdd sketch

```
given('[case1] an editor drives a Write/Edit whose content trips no term', () => {
  given('the word lists are healthy on disk', () => {

    when('[t0] the box is quiet', () => {
      then('the hook exits 0', ...);
      then('stdout and stderr are both empty', ...);
      then('no nudge record is written', ...);
      then('the hook forks under 10 processes', ...);   // acceptance #1
    });

    when('[t1] the box is contended — ~17 peer clones, runq ~27', () => {
      then('the hook exits 0, same as [t0]', ...);
      then('the fork count is identical to [t0]', ...);  // cost is load-independent
    });

    when('[t2] the same edit is driven a second time', () => {
      then('the hook exits 0 again', ...);              // no state accrues on a clean path
      then('the fork count is identical to [t0]', ...);
    });
  });
});
```

|---|---|

## 🔴 .the pre-scan is available to ONE hook, not both

the phrase *"cheap test first"* was written as though it applied to both hooks. it does not, and
the asymmetry is structural:

| hook | is a list-free necessary condition available? |
|---|---|
| **gerunds** | ✅ **yes.** `grep -qE '[a-zA-Z]+ing'` needs no list at all. no `-ing` word ⇒ no gerund ⇒ exit 0 **without ever a read of the allowlist** |
| **blocklist** | 🔴 **no.** you cannot scan for the terms without knowledge of the terms. any pre-scan must first read the list — which *is* the cost we came to remove |

⇒ **the "skip the parse" lever is a gerunds-only lever.** to have claimed it for both was circular
reasoning: a pre-scan for unknown words is not a thing that can exist.

### so the blocklist's win comes from a different shape

not *skip* the parse — **collapse** it:

| today | after |
|---|---|
| `sed \| jq` to read terms, then a `for` loop with **3 `jq` + 1 `grep` per term** (9 terms ⇒ 27 `jq`, 9 `grep`) | **one** `sed \| jq` that emits a single alternation, then **one** `grep -iqE "\b(a\|b\|c…)\b"` |
| the per-term detail (`why`, `alt`) is read for **every** term, ahead of any match | the detail is read **only for the terms that matched** — and on the clean path, none did |

⚠️ **that last row is where the clean path is truly won for the blocklist.** it still reads its
list, and it stops paying `3 × 9` for detail it will discard.

⇒ **two hooks, two different levers.** a design that assumes one shape fits both would over-promise
on the blocklist and under-deliver — which is exactly what the first draft of this case did.

## 🔴 .the trap this case hides

a hook that reaches "none matched" cheaply is easy to build **and easy to build wrong**: a
pre-scan that is cheaper than the real scan can disagree with it. if the cheap test says "no
match" where the real scan would have matched, the gate silently stops to block — an acceptance #2
break that ships as a speed win.

⇒ so the pre-scan must be a strict **over-approximation**: it may say "maybe" where the truth is
"no", never "no" where the truth is "yes". `case=2` is the paired demo that catches the inverse.

## ✅ .the over-approximation, checked against the real scan (review r5)

the real scan is `gerunds.sh:87-92`:

```
sed 's/\([a-z]\)\([A-Z]\)/\1 \2/g' | grep -oE '\b[a-zA-Z]+ing\b' | sort -u
```

the proposed pre-scan is `grep -qE '[a-zA-Z]+ing'` — and it is looser on **both** axes, which is
what makes it safe:

| the real scan has | the pre-scan drops it | effect |
|---|---|---|
| `\b … \b` anchors | no anchors | matches a **superset** of positions |
| a camelCase split ahead of it | no split | `existingUser` still matches, since no `\b` demands the boundary the split would have made |

⇒ **every string the real scan flags, the pre-scan also flags.** it can only over-report, so a
`0` from it is a sound "no gerunds here" — and the allowlist is never read on that path.

## 🔴 .the trap this hot path hides — it flags every `-ing` WORD, never every gerund

the allowlist holds **one** word (`string`). so `sibling`, `ceiling`, `during`, `thing`, and `bring`
are gerunds as far as this hook is concerned.

⚠️ **not a claim from a read — the write of this very section was refused**, and the refusal named
six of those words back at us. it took a HARDNUDGE retry to land, which is `case=2` `[t1]` observed
from the inside.

⇒ that class is **policy** under acceptance #2 (*"no policy change either direction"*), so the fix
must keep the false positives. 🔴 **a collapse that swaps the `-ing` scan for a real-gerund
dictionary would read as a cleanup and silently break acceptance #2.** the cheap test must stay
cheap *and* stay wrong in exactly the way it is wrong today. raised as **Q10**.
