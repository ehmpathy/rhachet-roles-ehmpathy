# 1.vision.experience.case=_ — the inventory

## .what

the walked product from `1.vision.experience.dimensions.md`. every cell carries a verdict; every
real experience carries a feel and a care.

**verdicts:** `demoed` (a case file exists) · `itemized` (real, on record, no demo) ·
`forbidden` (attemptable, the behavior must refuse) · `impossible` (no attempt can occur).

**feel:** happy · sharp. **care:** critipath · alterpath, where care = `freq × cost`.

## .how axis D binds

axis D (`config state`) names the state of **the list the cell's verdict depends on** — the
blocklist for a `trips-blocklist` cell, the allowlist for a `trips-gerunds` cell, and **both** for
a `clean` cell. one axis, applied to the relevant list.

## .boundary density — the rank

per `define.experience._.metric=boundary-density`, density counts **how many of the behavior's
boundaries one walk exercises** — where a boundary is an edge at which the system's response
changes (a rejection, a limit, a seam handoff). it is **not** a count of axis edges, and it is
independent of care: it sets *priority and scrutiny*, never severity.

### the behavior's boundaries

| id | boundary | the edge |
|---|---|---|
| B1 | self-reference refusal | the list is written in the vocabulary it forbids |
| B2 | nudge window (300s) | refuse ⇄ permit |
| B3 | cache freshness seam | list changed ⇒ verdict must follow |
| B4 | term match | permitted ⇄ refused |
| B5 | word boundary | `\bterm\b` — a fragment is not a match |
| B6 | additions only | `new_string` scanned, `old_string` not |
| B7 | two-hook seam | two clocks, two lists, two messages |
| B8 | fork budget | the cost under contention |
| B9 | config degraded | inert (blocklist) ⇄ stricter (gerunds) |
| B10 | stale sweep (3600s) | a record is dropped |
| 🔴 B11 | **pattern fidelity** | a term guards what it claims ⇄ a term does not |

🔴 **B11 was absent until review r5.** B4 (*term match*) presumes the term **is** a pattern; B9
(*config degraded*) presumes the **file** is the unit that degrades. a term that is valid json and
invalid regex sits between them, and neither edge names it. ⇒ it is also the **only boundary whose
response the fix would change** — today it costs one term's guard, after the collapse it costs all
nine. clamped at `case=5` `[t5]`.

🔴 **and its NAME was wrong until verification i003-r005 — it read *"pattern validity — a term
compiles ⇄ a term does not compile"*.** that form puts the worst term on the SAFE side of its own
boundary:

| the term | compiles? | guards what it claims? |
|---|---|---|
| `kook(swell` | 🔴 no ⇒ loud, exit 2 | no — and you can see it |
| 🔴 `)swell(` | ✅ **yes** | 🔴 **no.** `\b(deploy\|)swell()\b` parses as `(deploy\|)` then `swell` ⇒ `deploy` goes silently unguarded, exit 0, stderr empty |

⇒ **`compiles` was only ever a proxy for the property the walk cares about**, and the proxy fails
on exactly the case that costs the most. the boundary is now named for the property itself.

⚠️ **this is why the one-line remedy is not a closure.** part grep's exit 1 from exit 2 and you
catch every term on the top row and **none** on the bottom — a valid pattern raises no error to
part. clamped both ways at `[case23][t0]` (the innocent neighbor lost) and `[case27][t1]` (the
live-list clamp, with a metacharacter term injected), and deferred with its arithmetic stated: a
per-term compile check costs N execs on the clean path and breaches acceptance #1.
