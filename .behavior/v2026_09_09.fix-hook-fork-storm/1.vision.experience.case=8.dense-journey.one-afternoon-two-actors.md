# case=8 — the dense journey: one afternoon, two actors, eight boundaries

**actors** ana (list-maintainer) → kai (editor) · **feel** mixed · **care** critipath
**boundary density** rank 1 — **eight boundaries in one realistic walk**

per `define.experience._.metric=boundary-density`, this is the demo to **center**: it exercises
the widest edge surface of the behavior in one session, and it is therefore both the highest-value
demo and the path most likely to break — the interactions compound where the boundaries pile up.

`case=1..7` remain as the focused spotlights. this journey buys breadth; they keep each sharp
critipath's fail-safe legible. that is the split the metric's guardrail demands.

## .the boundaries it crosses

| # | boundary | where the system's response changes |
|---|---|---|
| B1 | **self-reference refusal** | the word list is written in the vocabulary it forbids |
| B2 | **nudge window** | 300s open ⇒ the retry permits |
| B3 | **cache freshness seam** | the list changed ⇒ the next verdict must reflect it |
| B4 | **term match** | a word crosses from permitted to refused |
| B5 | **word boundary** | `\bterm\b` ⇒ a fragment is not a match |
| B6 | **additions only** | an Edit scans `new_string`, never `old_string` |
| B7 | **two-hook seam** | both hooks fire; **two clocks, two lists, two messages** |
| B8 | **fork budget** | the cost holds while the grove is contended |

## .the narrative

**14:10 — ana tunes the vocabulary.** a review turned up a word worth a ban. ana opens
`terms.blocklist.jsonc` and adds the entry with its `why` and its `alt` list.

her write is refused **(B1)**. the file she edits *is* the list of forbidden words, so her addition
contains the word she just forbade. she reads the refusal, agrees, and drives the identical write
again. it lands **(B2)**. the entry is in.

**14:12 — kai meets the new term.** kai, on another clone, writes the new word into a `.ts` file.
it is refused **(B3, B4)** — **the hook re-read and re-parsed the list, as it does on every single
invocation.** had it trusted a stale cache, kai's write would have landed and ana's afternoon
would have been silently undone. this is the single most valuable moment in the walk.

> 🔴 **corrected at peer i010-r008.** this paragraph read *"it saw the list's witness had changed
> and re-read"* — it narrated a witness-keyed cache as shipped. **no cache shipped** (F3 leans
> reject), so the hook consults no witness; freshness holds because the read is unconditional.
> ⇒ **B3 is still crossed and still the most valuable moment here** — what changed is that the
> shipped hook clears it by construction rather than by a mechanism that could be wrong.
>
> ⚠️ this is the **centered** demo, so a stale claim here is the costliest kind: it is the one
> artifact a future maintainer reads first, and it would have sent them to look for a cache that
> was deliberately never built.

**14:13 — kai writes a near-miss.** kai needs a longer word that *contains* the banned term as a
fragment. it lands **(B5)**. no refusal, because the match is word-bounded — the same guarantee
the extant `blocklist.test.sh` `[case7]` pins.

**14:15 — kai removes an old offender.** kai Edits a line to take a forbidden word *out*. the term
sits in `old_string` and not in `new_string`. it lands **(B6)**. the gate refuses additions, never
removals — otherwise a cleanup would be unrepairable, which is the pit-of-failure this boundary
exists to avoid.

**14:18 — kai trips both gates at once.** kai writes a line whose word is both a gerund and a
blocklist term. **two refusals arrive**, each with its own detected term, its own alternatives,
its own rationale **(B7)**. kai decides the word is genuinely owed and retries once. **both** gates
permit — because each kept its own clock, and kai's one retry opened both.

🔴 **had the two clocks been merged into one, kai's single retry would have opened only one, and
the second gate would have refused a second time — or worse, the first block would have stamped a
clock the second gate then read as already-open, and the term would have landed unrefused.**

**14:20 — the grove is at full tilt.** all of the above happened while sixteen peer clones drove
their own edits over four cores. kai noticed no stall **(B8)**. the fork budget is not a quiet-box
number.

**16:40 — ana retires the term.** the ban was too broad. ana removes the entry; kai writes the
word; it lands **(B3, inverse)**. the retirement binds as fast as the addition did.

## .the bdd sketch

```
given('[case8] one afternoon, ana tunes the list while kai edits', () => {
  given('a contended grove — ~17 clones on 4 cpu', () => {

    when('[t0] ana writes a NEW term into terms.blocklist.jsonc', () => {
      then('the write is refused — the list holds the words it forbids', ...);      // B1
      then('stderr names that very term, with its why and alt', ...);
    });

    when('[t1] ana drives the identical write again, within 300s', () => {
      then('it lands', ...);                                                        // B2
      then('the nudge record is NOT re-stamped — the window does not extend', ...);
    });

    when('[t2] kai writes the new term into a source file', () => {
      then('it is refused — the new term binds at once', ...);                      // B3, B4
      then('stderr names the new term with ITS why and alt', ...);
      then('the hook re-read the list, as it does on every invocation', ...);
      // ⚠️ read 'only because its witness changed' until peer i010-r008. no
      //    cache shipped (F3), so there is no witness to have changed.
    });

    when('[t3] kai writes a longer word that CONTAINS the term', () => {
      then('it lands — the match is word-bounded', ...);                            // B5
    });

    when('[t4] kai Edits a term OUT — it sits in old_string only', () => {
      then('it lands — additions are scanned, removals are not', ...);              // B6
    });

    when('[t5] kai writes a word that is both a gerund and a blocklist term', () => {
      then('BOTH hooks refuse', ...);                                               // B7
      then('each message carries its own term, alt, and rationale', ...);
      then('two nudge records land, in two separate files', ...);
    });

    when('[t6] kai drives that identical write once more', () => {
      then('BOTH hooks permit on the single retry', ...);                    // 🔴 the two-clock proof
    });

    when('[t7] every step above is measured under the fork meter', () => {
      then('each hook stayed under its budget, contended or not', ...);             // B8
    });

    when('[t8] ana REMOVES the term, and kai writes it again', () => {
      then('it lands — the retirement binds at once', ...);                    // B3, inverse
    });
  });
});
```

## 🔴 .the two interactions only this walk exposes

a set of single-boundary demos cannot reach either of these, because each is an **interaction**
between two boundaries:

1. **`t0 → t2` — the freshness race.** ana's list edit and kai's next verdict are separated by two
   seconds and two processes. every single-actor demo holds the list constant, so no single-actor
   demo can catch a stale cache. `case=4` names this defect; **only this journey lives it.**
2. **`t5 → t6` — the one retry that must open two clocks.** each hook tested alone passes its own
   HARDNUDGE test. the defect appears only where **one human act** must satisfy **two independent
   clocks** — the exact seam a merge is most likely to weld shut.

⇒ per the density brief, this is where "the vision's vague prose gets exposed", and both exposures
land on the merge (F1).

## ⚠️ .the guardrail this journey respects

a boundary *brushed* is not a fail-safe *proven*. this walk crosses B1, B4, and B7 — all sharp —
and it does not stop on whether each failed fast, loud, and taught the fix.

⇒ that proof stays in the spotlights: `case=2` (`.how it fails safe`), `case=4`, `case=5`. the
journey buys breadth; it does not discharge their obligation, and it is not meant to.
