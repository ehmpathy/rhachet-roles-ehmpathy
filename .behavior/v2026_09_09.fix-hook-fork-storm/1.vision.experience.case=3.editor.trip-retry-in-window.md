# case=3 — editor retries a deliberate term, inside the window

**actor** editor · **feel** happy (relief) · **care** critipath
**cell** `editor × trips-* × healthy`, nudge `retry-in-window`

the override. a refusal with no escape hatch is a wall, and some words are genuinely owed — a
library api name, a quote, a brief that documents the very vocabulary it forbids. HARDNUDGE makes
the second attempt pass.

## .the narrative

kai's clone was refused. it re-reads the message, decides the word is owed — this file is a demo
of the refusal itself, and cannot omit the word it refuses — and drives the identical Write again.

**today.** the hook boots, reads stdin, reads the word list off disk, parses it, walks every term
with three `jq` calls each, detects the same term, hashes the path, reads the clock, sees 4
seconds elapsed against a 300-second window, and exits 0. **every one of those steps was wasted.**
the verdict was settled by the clock, and the clock was read last.

**after.** the hook reads the clock **early**, sees the window open for this path, and permits.
the retry is the cheapest path in the whole grid rather than the most expensive one — which is the
right shape, because a retry is by definition a decision the human or clone already made.

**the aha.** the old order was backwards. the retry — the one case where the answer is already
settled — paid the full price to derive an answer it would then discard.

## 🔴 .the early clock read did NOT ship — and it should not have

⚠️ **the two paragraphs above narrate a design the execution rejected.** they are kept verbatim
rather than rewritten, because the reason for the rejection is the useful artifact and it only
reads against the proposal it replaced (raised by peer i005-r008).

the shipped order is: **full detection walk, then the clock.** the early read loses on acceptance
#1, and the arithmetic is one-sided:

| | the early clock read | the shipped order |
|---|---|---|
| the retry path | ✅ cheapest in the grid | the same cost as a block, minus the stamp |
| 🔴 **the CLEAN path** | 🔴 **pays a `sha256` + a nudge-file read on every write that trips no term** | ✅ pays neither — it exits before the clock is ever reached |

⇒ **the clean path is nearly every path** (the hot path, `case=1`), so a reorder that makes the
rare retry cheap by making the common write costlier is a net loss against the wish's own target.
the hash is keyed to `file_path`, so it cannot be hoisted above detection without being computed
unconditionally.

✅ **what the case pins is unaffected.** its `[tn]` list grades the HARDNUDGE *contract* — the
window permits, the record is not re-stamped, the two clocks stay parted — and every one of those
holds under the shipped order. the reorder was the vision's guess at HOW; the contract was its
claim about WHAT, and only the guess was wrong.

⇒ the full correction, with the fork counts either order costs, is in
`5.1.execution.from_vision.yield.md`.

## ⚠️ .the constraint this reorder must respect

read the clock early and you change **when** the record is stamped, which is observable.

- the record is written **only on a block** — and that still holds in the shipped hook
- the stale sweep ran, when this was written, on **every** invocation that reached it

⇒ an early clock read must not skip the sweep, or stale records accrue without bound; and it must
not stamp on a permit, or the window would extend itself on each retry and never close.
