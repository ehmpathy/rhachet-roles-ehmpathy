# 1.vision.experience.dimensions

## .what

the axes the experience space varies over, and the product walked from them.

the wish reads as a pure cost change, so the temptation is to declare "no experiences — internal
only". that would be wrong. two hooks stand between an actor and every file edit. change how they
spend, and you change what that actor waits for, what they read when blocked, and what a
maintainer must do to keep the gate honest.

## .the axes

five axes. each is a small closed set. **each varies independent of the rest — except at three
declared collapses, itemized below and verdicted, never hidden:**

| collapse | where |
|---|---|
| **B × D** — an absent or empty blocklist makes `trips-blocklist` and `trips-both` **impossible**; the hook exits ahead of one term read | `.why the axes are orthogonal` |
| **axis C void** — nudge state has no value for `clean` content; both hooks exit ahead of any clock read | stage 2 |
| **axis E void** — box load has no value for the `grove-operator` row, which submits no content at all | the `gated?` walk |

⚠️ **this header read *"each varies independent of the rest"* flat until peer review r1 round 2**,
while the section immediately beneath it flagged `B × D` as *"⚠️ not fully"*. ⇒ **the artifact
contradicted itself one screen apart**, and a reader who trusts a header over a table would have
believed orthogonality where the document itself denies it.

✅ **no experience was hidden by it** — every collapsed cell is verdicted `impossible` with its
reason. the defect was the **claim**, never the walk. 🔴 **and that is the harder kind to catch**: a
decomposition hole leaves an unverdicted cell a reviewer can point at, while an overstated header
leaves a grid that is correct and a sentence that is not.

### A. actor — who meets the gate (4)

| value | who | what they came for |
|---|---|---|
| `editor` | a clone or a human who drives a Write/Edit | land the edit |
| `list-maintainer` | a mechanic who edits `terms.blocklist.jsonc` / `terms.gerunds.allowlist.jsonc` | change what the gate forbids |
| `hook-maintainer` | a mechanic who edits the hook itself | change how the gate decides, at what cost |
| `grove-operator` | the human who watches box load | reclaim cpu |

⚠️ `editor` deliberately fuses clone and human. **the gate cannot tell them apart** — it reads one
json payload either way. to split them would invent a distinction the behavior does not hold.

### B. verdict — what the content trips (4)

`clean` · `trips-gerunds` · `trips-blocklist` · `trips-both`

the two hooks read separate word lists (`terms.gerunds.allowlist.jsonc` vs
`terms.blocklist.jsonc`), so a payload can trip one, the other, both, or neither. four values, not
two.

### C. nudge state — where the HARDNUDGE clock stands (3 healthy + 🔴 1 degraded = 4)

`first` · `retry-in-window` (< 300s since the block) · `after-window` (>= 300s, blocks afresh)
· 🔴 `nudge-broken`

source: `pretooluse.forbid-terms.gerunds.sh:25,148` and
`pretooluse.forbid-terms.blocklist.sh:26,144`.

#### 🔴 the fourth value was absent until verification i003-r005, and it is a BACKWARD drift

the three healthy values factor the clock by *where it stands*. they have no value for *the clock
is broken*, and the verification tests exercise three distinct ways it breaks — each with a real
editor experience and a committed clamp:

| sub-state | what the editor meets | clamped at |
|---|---|---|
| the state file is **unparseable** | the deliberate retry **re-blocks forever**, and exit stays 2 ⇒ the loss is silent | blocklist `[case21]` · gerunds `[case17]` |
| the file is valid, the **write cannot land** (read-only dir) | same re-block-forever. ⚠️ the pre-repair shape exited **1** ⇒ fail-OPEN | blocklist `[case26]` · gerunds `[case19]` |
| the file **cannot be created** | without `\|\| true` the hook exits 1 and the gate fails **OPEN** | blocklist `[case29]` · gerunds `[case21]` |

⚠️ **the two failure directions are opposite, and that is the point of the row.** an unparseable
record fails **closed** (the editor is stuck, permanently, with no message that says so); an
uncreatable record failed **open** until the `|| true` repair landed. ⇒ a reader who knows only
that "the nudge broke" cannot predict which, so the value is itemized with its sub-states rather
than as one cell.

⇒ **verdict `itemized`, alterpath.** a broken nudge file is rare (it needs a corrupted write or a
read-only `.claude`), it owes no `case=N` demo, and its verdicts are already pinned six ways. what
it owed was a **row**, and the absence of that row is what
`rule.require.experience-catalog-evolution` calls backward drift: *"no test exercises a path the
catalog never named."*

### 🔴 C′. the payload state — what reached the hook on stdin (3)

`well-formed` · `stdin-empty` · `payload-unparseable` · `content-non-string`

a second axis the walk never named, surfaced by the same review. axis D is the config state of the
word **lists**; this is the state of the **payload**, and they are independent:

| value | the verdict, as clamped | clamped at |
|---|---|---|
| `stdin-empty` | exit **2** + a message that names the fix | blocklist `[case10]` · gerunds `[case10]` |
| `payload-unparseable` | 🔴 declared **PERMIT** — exit 0, silent on both streams | blocklist `[case22]` · gerunds `[case18]` |
| `content-non-string` | scanned as any other string; `null` permits | blocklist `[case30]` |

🔴 **`payload-unparseable` earns its explicit name because it is a declared failhide.** the hook
permits, silently, by design — and `[case22]`'s own comment names the trap: *"make the payload
read loud and this reads 2, which is precisely the policy move acceptance #2 bars."* ⇒ it belongs
in the inventory **as declared contract**, so a later reader cannot mistake it for an oversight
and "fix" it into a breach.

⇒ **verdict `itemized`, alterpath.** these are defensive edges a hand-runner meets more often than
an editor; each is clamped, none owes a demo.

### D. config state — the word lists on disk (5)

`healthy` · `absent` · `empty` · `malformed` · 🔴 `parses-but-a-term-is-a-bad-regex`

🔴 **the fifth value was absent until review r5, and it hid in the seam between two others.** the
file parses, so the axis called it `healthy`; a term inside it does not compile as a regex, so it
behaves like a partial `malformed`. **neither extant value describes it**, which is exactly how a
walked product still leaves a hole — the axis was factored by *file* state when the hook consumes
*term* state.

it matters far past its rarity, because the fix moves its blast radius:

| | one term holds a regex metacharacter |
|---|---|
| today — a grep **per term** (`blocklist.sh:116-129`) | that grep errors, **the other eight still guard**. a small, silent hole |
| 🔴 after the collapse — one `\b(a\|b\|c…)\b` | the **only** grep errors ⇒ **all nine permit, silently** |

⇒ **verdict `itemized`, and it constrains the design rather than a case of its own.** low
frequency (nine curated terms, no metacharacters today), catastrophic cost after the collapse, and
the remedy is one line: part grep's **exit 1** (no match) from **exit 2** (bad pattern) and fail
loud on 2. clamped at `case=5` `[t5]`, raised as **Q11**.

#### 🔴 the value splits in TWO, and the second half is strictly worse — found at verification i003-r005

*"a term that does not compile"* is only half of what the tests found. the other half **compiles**:

| sub-shape | the term | what happens |
|---|---|---|
| **does not compile** | `kook(swell` | the grep errors ⇒ exit 2 ⇒ the guard is loud, and the one-line remedy above catches it |
| 🔴 **compiles into the WRONG SENSE** | `)swell(` | `\b(deploy\|)swell()\b` parses as `(deploy\|)` then `swell` ⇒ **`deploy` goes silently unguarded**, exit 0, stderr empty |

🔴 **and the second half defeats the remedy the first half earned.** part exit 1 from exit 2 and
you catch every term that fails to compile — you catch **none** of the re-parse shape, because its
pattern is perfectly valid. ⇒ an exit-code guard cannot reach it, by construction.

it is pinned both ways: `[case23][t0]` shows the innocent neighbor lost (exit 0, stderr empty), and
`[case27][t1]` is the clamp's own clamp — it injects a metacharacter term into the live-list check
and shows the guard sees the loss.

⚠️ **B11's boundary text must move with it.** the boundary reads *"a term compiles ⇄ a term does
not compile"*, and that wording puts `)swell(` on the SAFE side of its own boundary. the honest
form is *"a term guards what it claims ⇄ a term does not"*, which is the property the walk cares
about and `compiles` was only ever a proxy for.

⇒ **verdict `itemized`, deferred with the arithmetic stated.** a per-term compile check costs N
execs on the clean path and breaches acceptance #1, so the deferral is recorded as a dream plus a
fulcrum rather than paid for here. what it owed the catalog was an accurate **name**, and that is
what this row supplies.

⚠️ **this is the one axis value whose worst cell the fix would CREATE.** every other cell in the
grid describes behavior that exists today.

🔴 **this axis is per-hook, and the two hooks fail in opposite directions.** an absent
`terms.blocklist.jsonc` makes the blocklist hook **inert** (`blocklist.sh:67-69` exits 0); an
absent `terms.gerunds.allowlist.jsonc` makes the gerunds hook **stricter** — `ALLOWLIST` stays
empty (`gerunds.sh:66-71`), so the one allowlisted word starts to block. one absence permits more,
the other permits less.

### 🔴 the per-hook fail direction, resolved for EVERY value

⚠️ **the paragraph above resolved only `absent`, for both hooks, and `malformed` for the blocklist
alone. peer review r1 caught the gap:** the gerunds × `malformed` cell carried a verdict no artifact
grounded. read from source, cell by cell:

| value | blocklist hook | gerunds hook |
|---|---|---|
| `absent` | **inert** — `blocklist.sh:67-69` exits 0 | **stricter** — `ALLOWLIST` empty, `string` blocks |
| `empty` | **inert** — no term to read | **stricter** — same empty array |
| `malformed` | **inert** — `blocklist.sh:72` ends `\|\| echo "[]"` (fail-open) | 🔴 **stricter** — `gerunds.sh:69` pipes to `jq … 2>/dev/null … \|\| true`, so a parse failure yields an **empty** `ALLOWLIST` and `is_allowed()` (`:74-84`) returns false for every word |
| `bad-regex` | 🔴 **the collapse's hazard** — one term, then all nine (`case=5` `[t5]`) | **stricter by one word** — `:69` filters entries through `grep -E '^[a-zA-Z]+$'`, so a non-alphabetic entry is dropped and silently fails to allowlist |

⇒ 🔴 **`malformed` is NOT a milder `absent` for the gerunds hook — it is the identical fail-closed
path**, and `string` is a ubiquitous typescript identifier. so that cell carries the same severity
as `absent`, which the grid already grades a **demoed critipath**. re-graded accordingly.

✅ **and the blocklist's two fail-open values are the mirror**, which is the asymmetry `case=5`
exists to pin: **every degraded state makes one hook laxer and the other stricter.**

### E. box load — the runqueue beneath the fork (2)

`quiet` · `contended`

this is the axis the wish's core insight lives on. `pcpu 8%` means the hook sits blocked ~92% of
its wall clock; the cost is fork latency, not arithmetic, so it grows with the queue. the same
code yields two distinct experiences at the two ends.

## .the product

the full box is `4 × 4 × 3 × 5 × 2 = 480` cells. a 480-row table is unreadable, so the walk runs
in two stages. both stages are complete; the split is presentational, never a skip.

### stage 1 — the gate box: actor × verdict × config state

`4 × 4 × 5 = 80` cells. this is the shape of **what the gate decides**. walked in
`1.vision.experience.case=_.md`, section `.stage 1`.

### stage 2 — the cost box: nudge state × box load, over the cells stage 1 left live

`3 × 2 = 6` refinements over **tripped** content, plus a `1 × 2` strip over **clean** content —
where axis C is void, because both hooks exit ahead of any clock read (`gerunds.sh:103`,
`blocklist.sh:133`). **8 cells displayed, 6 of them the product.** this is the shape of **what the
decision costs**. walked in `1.vision.experience.case=_.md`, section `.stage 2`.

## 🔴 .the latent axis the walk surfaced

axes C and E go void across whole actor rows, and per `howto.experience.decompose` a void row means
a hidden dimension sits beneath:

> **`gated?` — does this actor's act pass through PreToolUse at all?**

| actor | `gated?` | so |
|---|---|---|
| `editor` | yes, per edit | C and E both live |
| `list-maintainer` | yes — **their list edit is itself a Write** | C and E live, and a second-order effect appears (below) |
| `hook-maintainer` | yes, same reason | C and E live |
| `grove-operator` | **no** | C and E void; they observe the aggregate, never a single decision |

⇒ the grove-operator row is the one row where the fork count is felt as a **sum over all clones**
rather than as a wait. that is a distinct experience, and a free-list would have dropped it — the
wisher is an actor here, not merely the requester.

## 🔴 .the second-order effect the grid forced

the `list-maintainer` row is not a duplicate of `editor`. it carries a demand no other row does:

> **the maintainer edits a word list. the very next edit must honor the new list.**

today that holds by construction — both hooks re-read and re-parse their list on **every**
invocation (`blocklist.sh:72`, `gerunds.sh:68-70`). that waste is precisely what the wish asks us
to cut. so any cache we add opens a defect this grid names in advance: **a stale cache silently
reverts a policy change**, which is an acceptance #2 violation delivered by the cost fix itself.

⇒ this is the sharpest constraint the decomposition produced, and it did not come from the wish.

## .why the axes are orthogonal

| pair | independent because |
|---|---|
| A × B | any actor can author any content; the gate reads the payload, never the author |
| A × D | the lists sit on disk ahead of any actor's turn |
| B × C | the clock is keyed on `file_path`, never on which word tripped |
| B × D | ⚠️ **not fully** — see the collapse below |
| C × E | the clock is wall time; the queue is scheduler state |
| A/B/C/D × E | load is a property of the box, set by ~17 peer clones |

**the one collapse:** `verdict × config state` is not free. with `terms.blocklist.jsonc` absent or
empty, `trips-blocklist` and `trips-both` cannot occur — the hook exits before it reads a term.
those cells are **impossible by nature**, not forbidden by nurture, and the inventory marks them so.
