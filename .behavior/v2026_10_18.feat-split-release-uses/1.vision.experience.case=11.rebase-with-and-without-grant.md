# case=11 — rebase without a commit grant, then with one, then revoked mid-rebase

cells: 3.2 · 3.12 · 3.5 · 3.14 · 3.6. feel 🔪 → 😊. care 🔴.

the rebase journey on both sides of the commit grant. there is no rebase meter: rebase rides the
commit grant, so "rebase allowed, commit blocked" cannot be said, by construction.

## .narrative

a crew on `feat/reef-map` has two commits; main moved. it holds no commit grant. `begin` refuses
and names the commit grant — not a push grant, not a rebase grant, since neither exists. stage
refuses too, out of a rebase. the human grants one commit. the rebase halts on a conflict. mid-merge,
the human revokes the grant to pause the crew. the crew must still be able to finish what it began:
stage and `continue` read no meter, so the rebase completes. the crew's next commit refuses, and so
does its push — the pause holds where it should.
