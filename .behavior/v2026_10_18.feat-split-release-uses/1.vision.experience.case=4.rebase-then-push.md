# case=4 — rebase with commits ahead, then push the result

cells: 3.3 · 3.4. feel 😊 → 🔪 → 😊. care 🔴.

## .narrative

a crew has three commits on `feat/tide-chart`; main moved. with commit granted and push blocked,
the rebase runs locally and succeeds — the crew can test against fresh main right away. the push of
the rewritten branch is a separate act: it refuses until the push meter is granted, then
force-with-leases the crew's own branch. release never enters.

## .timeline

```
given branch `feat/tide-chart` 3 ahead, 5 behind `origin/main`
given `git.commit.uses` at quant 2, `git.push.uses` blocked
  when [t0] crew runs `rhx git.branch.rebase begin --mode apply`
    then the rebase lands clean; HEAD sits atop `origin/main`
    then the tail reads `🌊 ready to push └─ rhx git.commit.push (needs git.push.uses)`

  when [t1] crew runs `rhx git.commit.push --mode apply`
    then it exits 2 and names `rhx git.push.uses allow   # ask your human`

  when [t2] human runs `rhx git.push.uses allow`; crew re-runs `rhx git.commit.push --mode apply`
    then `git push origin HEAD --force-with-lease` lands on `feat/tide-chart`
    then `git.release.uses` was never read
```
