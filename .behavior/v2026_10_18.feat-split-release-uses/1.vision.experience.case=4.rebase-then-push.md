# case=4 — rebase with commits ahead, then push the result

cells: 3.3 · 3.4. feel 😊. care 🔴.

## .narrative

a crew has three commits on `feat/tide-chart`; main moved. on one commit grant the rebase runs
locally and succeeds — the crew can test against fresh main right away — and the push of the
rewritten branch rides the same grant: force-with-lease onto the crew's own branch. neither act
spends a use. release never enters.

## .timeline

```
given branch `feat/tide-chart` 3 ahead, 5 behind `origin/main`
given `git.commit.uses` at quant 2, no `git.release.uses`
  when [t0] crew runs `rhx git.branch.rebase begin --mode apply`
    then the rebase lands clean; HEAD sits atop `origin/main`
    then the tail reads `🌊 ready to push └─ rhx git.commit.push --mode apply`

  when [t1] crew runs `rhx git.commit.push --mode apply`
    then `git push origin HEAD --force-with-lease` lands on `feat/tide-chart`
    then `git.commit.uses get` still reads `left: 2`
    then `git.release.uses` was never read
```
