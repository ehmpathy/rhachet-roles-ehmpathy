# case=5 — revoke or deplete one meter; the other holds

cells: 1.9 · 1.10. feel 😊. care 🔴.

## .narrative

a human grants both meters. the crew spends its last commit use — and still pushes it, since
depletion holds the grant; only `block` or `del` revoke. today the reverse bite exists: when a
commit quota depletes, `git.commit.push.sh:722` rewrites `"push": "block"`, so the last commit
silently takes push with it. then the human pulls the release stamp mid-day; commit and push carry
on untouched. depletion or revoke of one meter writes only that meter.

## .timeline

```
given `git.commit.uses` quant 1, `git.release.uses` quant 1
  when [t0] crew commits once
    then `git.commit.uses get` reads `left: 0 (held — push allowed, commit owed a grant)`

  when [t1] crew runs `rhx git.commit.push --mode apply`
    then the push lands — depletion did not revoke push

  when [t2] human runs `rhx git.release.uses del`
    then `git.commit.uses get` reads as before
    then `git.release --mode apply` refuses; `git.commit.push` still pushes
```
