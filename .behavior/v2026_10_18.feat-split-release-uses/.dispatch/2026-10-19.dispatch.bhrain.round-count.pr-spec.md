## pr spec: a scope-drop round does not count toward budget

one pr, two halves:
1. **no-spend** — a live round whose scope trace drops files its own `--paths` globs matched grades
   `💥 malfunction`, so it spends no budget and is never cached (diff at the end of this spec)
2. **un-count** — rounds already burnt that way no longer count, read-only (diff below)

target: `ehmpathy/rhachet-roles-bhrain`, on top of `0.42.1`. lands upstream as a pr; never as a local
patch in a tree whose lanes it frees (`rule.forbid.self-grant-human-gates`).

### the defect

a round whose scope trace drops files its own `--paths` globs matched reviewed less than its lane
binds. it is a malfunction, never a verdict. yet the meter counts it.

measured on rhachet-roles-ehmpathy @ beav/feat-split-release-uses, route
`v2026_10_18.feat-split-release-uses`, stone `1.vision`: rounds i001-i003 of both lanes read 1 of
13 matched files. the meter reads 3/3, both lanes `exhausted 🌙, cached`. the fixed bind cannot run
a fresh round.

pairs with the held task *"fix(review): stage lanes review only the yield; a scope-drop round still
spends budget"* (cause 1 + cause 2 stop new burnt rounds). this pr un-counts the rounds already burnt.

### the contract

- a round counts toward budget only if its own scope trace shows no matched target dropped
- read-only: no given, cache, meter line, or budget line is written or moved. the raw meter stays as
  written
- every meter reader sees one effective count; only the spend reads raw, so a discount is never
  written back
- the window is the lane's latest `rounds` completed givens, so a clean round is never un-counted,
  and a burnt given from before a meter reset discounts naught
- a fresh round still blocks: the gate and the exhaustion check are unchanged; they read effective

const getOneRoundCountBurntByScopeDrop = async (input /* { route, stone, slug, rounds } */) => {
  // a lane with no metered rounds has none to discount
  if (input.rounds <= 0) return 0;

  // this lane's givens on this stone, newest first
  const slugWanted = asSanitizedPeerReviewSlug({ slug: input.slug });
  const givens = (await enumRouteGuardReviewPeerFiles({ route: input.route, stone: input.stone }))
    .map((filePath) => ({ path: filePath, meta: getRouteGuardReviewPeerPathMeta({ path: filePath }) }))
    .filter((candidate) => candidate.meta.slug === slugWanted)
    .map((candidate) => ({ path: candidate.path, iteration: candidate.meta.iteration }))
    .sort((a, b) => (isLaterByIterationThenPath({ candidate: a, incumbent: b }) ? -1 : 1));

  // grade each, newest first, until the window holds `rounds` completed rounds
  const repoRoot = await getRepoRootWithFallback({ from: input.route });
  let windowSize = 0; // .note = deliberate mutation, scoped to this loop
  let burnt = 0; // .note = deliberate mutation, scoped to this loop
  for (const given of givens) {
    if (windowSize >= input.rounds) break;
    const content = await getOneReviewArtifactContent({ path: given.path });
    if (content === null) continue;
    const verdict = asPeerReviewVerdictFromContent({ content });
    if (!isReviewRoundCompleted({ review: verdict })) continue;
    windowSize += 1;
    const reason = await getOneScopeDropMalfunctionReason({ stdout: content, repoRoot });
    if (reason !== null) burnt += 1;
  }
  return burnt;
};

### the two-way test

`.log/bhrain/review/<run>/input.scope.debug.json` (`targetFilesFromPaths` = the 13,
`targetFilesDropped` = 12 demos or `[]`) and its given

stdout carries `│  │     ├─ logs: <run>` and a `└─ tallied` block of 0 blockers, 1 nitpick. meter
lines go to `$route/.route/reviewPeerMeters.jsonl`.

| three clean | 3 × all kept | 1,2,3 | 3 | **3** (no false un-count) |
