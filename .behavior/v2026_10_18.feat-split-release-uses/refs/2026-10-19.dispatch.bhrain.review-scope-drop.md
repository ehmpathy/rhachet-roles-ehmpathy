## defect: a stage's peer lanes review only its yield, and burn the budget on it

`rhachet-roles-bhrain@0.42.1`. measured on rhachet-roles-ehmpathy @ beav/feat-split-release-uses,
route `v2026_10_18.feat-split-release-uses`, stone `1.vision`:
- the bhuild `1.vision.guard.light` lanes bind `--diffs since-main --paths-with '$route/1.vision.*.md' --join intersect`
- the glob matched 13 files, the join kept 13. then the polluter filter dropped 12
  (`input.scope.debug.json` → `targetFilesDropped`)
- three rounds, two lanes each, read `targets: 1` (the yield alone), were graded approved, spent
  the whole budget (3/3), and are now served as `exhausted 🌙, cached`

### cause 1 — the asked-for-by-name exemption is voided by the yield

`domain.operations/review/getAllTargetsAskedForByName.js`, `isGlobSpecificToPolluters`: a glob is
exempt only when EVERY file it matched is a polluter. `$route/1.vision.*.md` also matches
`1.vision.yield.md`, which is allowed (not a polluter), so the glob never earns the exemption and
the stage's experience demos, inventory, and dimensions drop. the jsdoc's own example
(`$route/3.3.blueprint.*.md`) has the same shape and the same hole.

### cause 2 — a round that reviewed less than it bound still counts as a verdict

a round whose scope dropped files its own `--paths` globs matched is graded on what remained,
spends a budget round, and is served from cache.

## fix (applied downstream as a pnpm patch)

1. `isTargetPolluter.js`: export `isTargetInsideRoute` (`<variant>/<slug>/<file>`, same variant set).
   `getAllTargetsAskedForByName.js`: a glob is specific when every match is a polluter **or inside a
   route**. a catch-all still fails (it matches source outside any route)
2. new `route/guard/review/getOneScopeDropMalfunctionReason.js`: read each `logs:` dir from the run's
   stdout, load `input.scope.debug.json`, and return a `💥 MalfunctionError` that names each file in
   `targetFilesDropped ∩ targetFilesFromPaths`. absent/denied trace → pass through; unparsable trace
   → malfunction. `runOneStoneGuardReview.js` sets `exitCode = 1` and appends the reason to stderr
   when it returns one. via the extant links: `isReviewRoundCompleted` → no budget spent;
   `getAllCachedPassedReviews` → never cached

## clamps downstream (teeth proven: each red with its cure removed)

- `src/infra/patches/rhachet-roles-bhrain.review-scope.integration.test.ts` — the 13 files: the single
  stage glob keeps 13; a catch-all over source + route still drops the 12 demos
- `src/infra/patches/rhachet-roles-bhrain.scope-drop-malfunction.integration.test.ts` — the i003 trace
  (12 of 13 dropped) grades malfunction; a full keep, and a `--diffs`-only drop, do not; a malfunction
  spends no budget and is never cached
