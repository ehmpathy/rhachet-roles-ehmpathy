## .canonical premises the code does not bear out (reported, not changed)

- **"every extant caller that read `--push` as 'may release'"** — no caller reads `--push` as
  release. `git.release` reads the **commit quota** (`git.release.sh:292-303`): today a commit
  grant is a release grant. the vision moves that caller, which is the wish's intent.
- **"a push is held as tightly as a release"** — sharper than that: a release is held only as
  tightly as a commit. the vision's before/after table states it so.
- **"a director, freely"** for commit and push — every grant passes the tty guard
  (`git.commit.operations.sh:1015`); a director grants today under it (the bhuild incident shows
  one did), so "freely" is ceremony, not a new mechanism. F11 ruled.
- **"a default-allow on either meter"** — the wish's two-meter word; the vision applies it to all
  three.
