# case=5 — revoke one allowance; the other two hold

cells: 1.9 · 1.10. feel 😊. care 🔴.

## .narrative

a human grants all three, then wants the crew to stop new code while a release finishes. one
`git.commit.uses del` stops commits; push and release stay as they were. today the reverse bite
exists: when a commit quota depletes, `git.commit.push.sh:722` rewrites `"push": "block"`, so the
last commit silently takes push with it. after the split, depletion of one meter writes only that
meter.

## .timeline

    then `git.push.uses get` still reads `push: allowed`

    then `git.release --mode apply` refuses; `git.commit.push` still pushes
