# case=1 — grant each meter alone (the done test)

cells: 3.11 · 1.1 · 3.3 · 1.4 · 1.3 · 1.11 · 2.2 · 4.4. feel 😊 with a 🔪 refusal. care 🔴.

the canonical done test: one commit grant → stage, commit, rebase, push all proceed, release
refused; the release stamp → ships. each step reads back on its own meter.

## .narrative

a director stands up a crew on `feat/wave-report`. the crew must stage, commit, and push its pr;
it must never ship. the director grants commits and naught else. the crew stages on that one grant,
commits twice, rebases onto fresh main, and pushes — no second grant for any of it, and the push
spends no use. it tries `git.release --mode apply`: refused, by meter, and the refusal names the
release meter. later the human stamps one release; the crew ships. each `get` reads back only its
own meter.

## .timeline

```
given a tree with no meters
  when [t0] human runs `rhx git.commit.uses set --quant 3`
    then the render reads `git.commit.uses set ├─ granted: 3 ├─ covers: stage, commit, rebase, push`
    then it names no release; `rhx git.release.uses get` reads `└─ no grant set`

  when [t1] crew runs `rhx git.stage.add src/wave/getWaveReport.ts`
    then it proceeds on the commit grant; `git.commit.uses get` still reads `left: 3`

  when [t2] crew runs `rhx git.commit.set -m @stdin --mode apply`
    then the commit lands as seaturtle[bot]; `left: 2`

  when [t3] main moves; crew runs `rhx git.branch.rebase begin --mode apply`
    then the rebase lands on the commit grant; release was never read; `left: 2`

  when [t4] crew runs `rhx git.commit.push --mode apply`
    then the branch pushes with force-with-lease and the pr findserts
    then `left: 2` — a push spends no use

  when [t5] crew runs `rhx git.release --mode apply`
    then it exits 2 with `✋ ConstraintError: release not allowed`
    then it names `rhx git.release.uses set --quant N   # ask your human`
    then a 🥥 note reads `a commit grant never covers a release`

  when [t6] human runs `rhx git.release.uses set --quant 1`; crew re-runs [t5]
    then the release proceeds; `git.release.uses get` reads `left: 0`
    then `git.commit.uses get` still reads `left: 2` — release spent no commit
```
