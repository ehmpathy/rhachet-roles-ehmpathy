# case=1 — grant each allowance alone (the done test)

cells: 3.11 · 1.1 · 3.4-local · 1.2 · 1.3 · 1.4 · 1.5 · 1.11 · 2.2 · 4.4. feel 😊 with 🔪 refusals. care 🔴.

the canonical done test, step for step: commits alone → stage + commit + rebase locally, push refused;
push → push lands, release refused; release → ships. each step reads back on its own meter.

## .narrative

a director stands up a crew on `feat/wave-report`. the crew needs to commit; it does not yet need
to push; it must never ship. the director grants commits and naught else. the crew stages its
files on that one grant — no second grant for stage — and commits twice.
its first push refuses, and the refusal names the push meter. later the director grants push; the
crew pushes; its commit quota does not move. the crew then tries `git.release --mode apply` — it
refuses, and names the release meter. each `get` reads back only its own allowance.

## .timeline

```
given a tree with no meters
  when [t0] human runs `rhx git.commit.uses set --quant 3`
    then the render reads `git.commit.uses set ├─ granted: 3` and names no push, no release
    then `rhx git.push.uses get` reads `└─ no grant set`
    then `rhx git.release.uses get` reads `└─ no grant set`

  when [t0.5] crew runs `rhx git.stage.add src/wave/getWaveReport.ts`
    then it proceeds on the commit grant: `└─ staged: src/wave/getWaveReport.ts (commit grant)`
    then no `--stage` grant was asked for; `git.commit.uses get` still reads `left: 3`

  when [t1] crew runs `rhx git.commit.set -m @stdin --mode apply`
    then the commit lands as seaturtle[bot]; `git.commit.uses get` reads `left: 2`

  when [t1.5] main moves; crew runs `rhx git.branch.rebase begin --mode apply`
    then the rebase lands locally on the commit grant alone; push and release were never read

  when [t2] crew runs `rhx git.commit.push --mode apply`
    then it exits 2 with `✋ ConstraintError: push not allowed`
    then it names `rhx git.push.uses allow   # ask your human`

  when [t3] human runs `rhx git.push.uses allow`
    then the render reads `git.push.uses allow └─ push: allowed`
    then `git.commit.uses get` still reads `left: 2`

  when [t4] crew runs `rhx git.commit.push --mode apply`
    then the branch pushes and the pr findserts
    then `git.commit.uses get` still reads `left: 2` — a push spends no commit

  when [t5] crew runs `rhx git.release --mode apply`
    then it exits 2 with `✋ ConstraintError: release not allowed`
    then it names `rhx git.release.uses set --quant N   # ask your human`

  when [t6] human runs `rhx git.release.uses set --quant 1`
    then `git.release --mode apply` proceeds; `git.release.uses get` reads `left: 0` after it
```
