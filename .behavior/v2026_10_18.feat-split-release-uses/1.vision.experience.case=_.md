## forbidden cells (rejection invariants)

| # | cell | why forbidden |
|---|---|---|
| X1 | a commit grant that permits a release | commit ⟂ release — the commander's goal |
| X2 | a release that pushes local commits | a release ships only what a commit grant already pushed |
| X3 | a release that spends or checks the commit meter | release needs no commit grant |
| X4 | an unset meter read as allowed | fails closed |
| X5 | a corrupt meter read as allowed | fails closed |
| X6 | a push to `main` / `master` via the commit grant | a push to the base branch IS a release; `git.commit.push` refuses it |
| X7 | one command that grants both meters at once | each meter grants alone |
| X8 | a depletion that revokes push | only `block` / `del` revoke; a crew must push the commit that spent its last use |
