## forbidden cells (rejection invariants)

| # | cell | why forbidden |
|---|---|---|
| X1 | a commit grant that permits a push | commit ⟂ push |
| X2 | a push grant that permits a release | push ⟂ release |
| X3 | a release that spends or checks commit quota | release needs no commit quota |
| X4 | an unset meter read as allowed | fails closed |
| X5 | a corrupt meter read as allowed | fails closed |
| X6 | a push to `main` / `master` via the push meter | a push to the base branch IS a release; `git.commit.push` already refuses it |
| X7 | one command that grants two meters at once | each meter grants alone |
