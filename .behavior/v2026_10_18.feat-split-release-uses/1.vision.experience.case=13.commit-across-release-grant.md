# case=13 — commit journeys with and without a release grant, with push held and revoked

cells: 1.1 · 1.12 · 1.7 · 2.11 · 1.9. feel 😊 / 🔪. care 🔴.

the commit journey on both sides of the release grant, and on both sides of push. one meter carries
commit + push, so "with push" and "without push" are the held and revoked states of that one grant.

## .narrative

**without a release grant.** a crew on `feat/sandbar` holds `git.commit.uses set --quant 2` and no
release. it commits and pushes in one command — the push spends no use. the release meter was never
read; the commit did not need it.

**with a release grant.** the human stamps one release. the crew commits again; the release meter
stays at `left: 1` — a commit spends no release, and a release spends no commit.

**without push.** the human types `git.commit.uses block` to pause the crew. commit and push both
refuse; the release meter stays untouched, and the crew may still ship the pr it already pushed.

**release only, no commit grant.** a release grant alone never lets a crew commit.

## .timeline

```
given `feat/sandbar`; `git.commit.uses` quant 2; no `git.release.uses`
  when [t0] crew runs `printf ... | rhx git.commit.set -m @stdin --mode apply --push`
    then the commit lands, then the branch pushes; `left: 1` — one use, for the commit       # 1.12
    then `git.release.uses` was never read                                                   # 1.1

  when [t1] human runs `rhx git.release.uses set --quant 1`; crew commits again
    then `git.commit.uses get` reads `left: 0`; `git.release.uses get` reads `left: 1`

  when [t2] crew runs `rhx git.commit.push --mode apply`
    then the push lands at `left: 0` — held

  when [t3] human runs `rhx git.commit.uses block`
    then `git.commit.set` and `git.commit.push` each exit 2, name `rhx git.commit.uses allow` # 2.11
    then `git.release.uses get` still reads `left: 1`; `git.release --mode apply` proceeds   # 1.9

given a tree with `git.release.uses` quant 1 and no commit grant
  when [t4] crew runs `rhx git.commit.set -m @stdin --mode apply`
    then it exits 2, names `rhx git.commit.uses set --quant N` — a release grant never commits # 1.7
```
