# case=12 — push ⟂ release, both ways

cells: 5.1 · 5.2 · 5.3 · 5.4 · 5.5 · 5.7 · 5.8 · 1.8. feel 😊 / 🔪. care 🔴.

the boundary the commander ranks first: *"a crew can be granted commit + push quota while any
release (merge, git.release --apply) stays refused, by meter, not by habit."* push without release,
and release without push, each hold by meter.

## .narrative

**push without release.** the human types `git.commit.uses allow && git.release.uses block`. the
crew on `feat/kelp-index` has never pushed. its release attempt refuses — there is no pr yet, and
the release meter is blocked anyway. it pushes: the pr opens. it tries to release again: refused,
by meter. the crew can push its pr all day and never ship.

**release with unpushed commits.** the human lifts the block and stamps one release. the crew has
two new local commits the pr lacks. release refuses and names them — it will not ship a pr that
lacks the branch, and it never pushes on the crew's behalf. the crew pushes; release proceeds.

**release without push.** on a second tree, `feat/tide-pool`, another crew already pushed the pr.
this crew holds no commit grant. the human stamps one release; it proceeds — no push was needed. if
that tree held a local commit the pr lacks, release refuses and names the commit grant the push needs.
