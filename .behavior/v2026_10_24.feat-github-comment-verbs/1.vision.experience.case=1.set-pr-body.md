# case=1 · set the pr body

feel: happy · care: critipath

## .narrative

a crew finishes a declapract upgrade on ahbode/svc-service-providers pr #69. it wrote a 13156-byte body to `.agent/.notes/pr.md`. today `gh pr edit` is refused at the permission prompt, so the body sits local and the reviewer reads a stub.

with the verb, the crew plans first. the tree shows the target, the endpoint, the current and the new byte counts, and both sha256. it reads right, so the crew applies. the verb PATCHes the pr, reads it back, and the hash matches. a second apply prints `no-op`.

## .timeline

```
given a pr #69 whose body is a 550-byte stub
  and a 13156-byte body at ./pr.md

when [t0] rhx git.pull.comment.set --pr 69 --kind body --from ./pr.md
  then exit 0
  then the tree names `PATCH repos/ahbode/svc-service-providers/pulls/69`
  then it shows current bytes 550 and new bytes 13156, each with sha256
  then the verdict reads `would edit (plan; rerun with --mode apply)`
  then the pr body is unchanged

when [t1] ... --mode apply
  then exit 0
  then the verb reads the pr back; sha256 equals the new sha256
  then the verdict reads `edited, read back, hash matches`

when [t2] ... --mode apply (again)
  then exit 0
  then no PATCH is sent
  then the verdict reads `already there — no-op`
```
