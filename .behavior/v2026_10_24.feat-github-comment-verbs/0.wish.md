# wish: a mechanic reads, writes, and deletes a github pr comment through one paved verb family

## what

ehmpathy/rhachet-roles-ehmpathy#996 seeds `show.gh.pr.comments` and `answer.gh.pr.comment` for the mechanic role. a crew that must post a pr body, a review reply, or a fix-up comment (ahbode/svc-service-providers #69: the pr body, comment #702, five replies) had no verb to do it, and fell back to local copies in `.agent/.notes`.

this amends #996: the verb family `github.comment.get | set | del`, one contract for a pr comment, plus its suite.

## done means

- `rhx github.comment.get` reads one comment or all comments on a pr
- `rhx github.comment.set` upserts a comment (idempotent on a key the caller names), and edits a pr body
- `rhx github.comment.del` deletes a comment; a no-op if absent
- each verb takes `--auth as-ehmpath | as-human`, like git.commit.push
- a 15-case suite, red without the verbs; at least one case runs against the real github api in a test repo
- the pr says "folds into ehmpathy/rhachet-roles-ehmpathy#996." and leaves #996 itself untouched
