# case=4 · read every comment on a pr

feel: happy · care: critipath

## .narrative

a fresh clone picks up pr #69 mid-review. it needs to see what is there before it writes: the body, the conversation, the inline threads, and which of them it already answered. one call shows all three kinds in time order, each row with its id, kind, author, reply-to, key (if any), and sha256.

## .timeline

```
given pr #69 with a body, 3 issue comments, and 19 review comments over 2 pages

when [t0] rhx github.comment.get --pr 69
  then exit 0
  then gh reads repos/<in>/pulls/69, issues/69/comments, pulls/69/comments, each list with --paginate
  then counts read `1 body, 3 issue, 19 review`
  then each row names kind, id, author, created_at, in_reply_to, key, bytes, sha256, url, body

when [t1] ... --output json
  then exit 0
  then stdout is one json array of the same rows

when [t2] rhx github.comment.get --pr 69 --key round-2-status
  then exit 0 with the one row
  or, absent, exit 2 with the hint `rhx github.comment.get --pr 69` to list them
```
