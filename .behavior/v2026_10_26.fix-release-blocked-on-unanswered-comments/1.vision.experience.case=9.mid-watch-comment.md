# case=9 — a reviewer comments mid-watch

feel: sharp · care: critipath · boundaries: gate read, mid-watch re-read, automerge disable

## narrative

the clone answered every comment, ran `--apply`, and passed the gate. automerge went on; it watches ci, ten minutes to go. the commander, still in the diff, leaves one more review comment.

on its next poll the watch re-reads comments, sees the new unanswered row, turns automerge off, and stops with exit 2 — the same refusal it would have shown at the gate. ci finishes green a minute later; with automerge off, github does not merge. the clone answers and runs `--apply` again.

## timeline

```
given pr #700 with every comment answered, checks inflight, automerge unfound

when [t0] rhx git.release --apply
  then `💬 all comments answered`
   and automerge enabled [added]; watch begins

when [t1] @commander leaves review thread 803, no reply, while checks are still inflight
  then automerge is still on; no poll has read the new comment yet

when [t2] the next watch poll runs
  then the poll re-reads comments and finds row 803
   and `gh pr merge --disable-auto` is called
   and stdout shows `🌴 automerge disabled [removed] — 1 comment(s) unanswered` + row 803
   and ✋ ConstraintError + the answer verbs
   and exit 2

when [t3] checks finish green
  then the pr stays open — no automerge left to merge it

when [t4] the clone answers 803 and reruns `rhx git.release --apply`
  then `💬 all comments answered`, automerge enabled [added], watch, merge
```

## residual, named

a comment that lands in the seconds between the last poll and github's own merge is not catchable client-side. accepted in F6; the window is one poll interval wide.

## fail-safe proven
fast: the next poll · loud: exit 2, qualified header · teaches: the answer verbs · safe: automerge off before ci lands.
