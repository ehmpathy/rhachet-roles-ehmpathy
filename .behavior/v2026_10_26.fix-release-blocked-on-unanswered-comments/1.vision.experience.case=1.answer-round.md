# case=1 — an answer round, end to end (the densest walk)

feel: sharp → happy · care: critipath · boundaries: preview, refusal, review answer, issue answer, re-open, resolved

## narrative

the clone pushes its fix for #700. the commander approved with "predicated on comments addressed" and left two review comments and one top-level note.

the clone runs `rhx git.release`. the tree shows checks green and `💬 3 comment(s) unanswered`, with a hint that apply will refuse. it knows before it tries.

it runs `--into prod --apply` regardless. refused, exit 2, automerge untouched. the refusal names `get --unanswered` and the two set verbs. the clone answers both review threads with `set --reply-to` and the top-level note with `set --key`.

it reruns apply. while it worked, the commander read one answer and asked a follow-up in that thread. refused again: `💬 1 comment(s) unanswered` — the follow-up, since the thread's latest comment is no longer the robot's.

the commander reads the answer to the other thread and marks it resolved. the clone answers the follow-up. apply: `💬 all comments answered`, automerge added, merged, tagged, published.

  then `get --unanswered` lists row 801 again — its latest comment is unsigned
