# 1.vision.experience.dimensions

## the dimensions

| # | axis | values | why orthogonal |
|---|---|---|---|
| A | release actor (who runs `git.release`) | robot driver (clone) · human driver (by hand) | the read login differs by mode (`git.release.sh:334-347`); the answer test must not depend on it (F10) |
| R | reviewer act | none · comments · re-asks after an answer · marks resolved | the reviewer never runs the verb; each act flips a row's state. split from A, since a reviewer × mode cell is a category error |
| B | mode | plan · watch · apply | apply enables automerge and refuses; watch never enables it, and only disables it for safety (F11); plan only reports |
| C | comment state at read | none · all answered (signed) · review thread unanswered · issue comment unanswered · resolved, no reply · bot-authored only | each value maps to one clause of the rule. "review thread unanswered" = latest comment unsigned — the reviewer's ask, or a by-hand reply (F8); one clause, two sub-cases, walked under one value |
| T | when a comment lands | before the gate read · after the read, before merge (mid-watch) · after merge | the race axis: the gate reads at one instant, github merges at another |
| D | automerge | unfound · found | found means github merges past a refusal unless disabled |
| E | transport | feat pr open · feat pr already merged · release pr (`--from main`) | which pr the gate reads |
| F | read | ok · gh read fails | a failed read must never read as 0 |
| S | comments per thread | ≤100 · >100 | the graphql state map caps at 100 comments per thread (`git.pull.comment.operations.sh:588`). thread count is not an axis: the outer `reviewThreads` cursor paginates (`--paginate`, `:591`) and rest rows paginate fully (`:565-570`), so no experience varies with it |
| M | automerge disable (the gate's one mutation) | ok · fails, automerge still on · fails, automerge already off | split from F: F is the read, M the write the refusal depends on. found at 5.3.verification (case=12) |
| K | other pr constraint | none · checks failed · needs rebase | a pr can carry a second blocker beside the comment; the order of the two in the tree is an experience. found at 5.3.verification (row 21) |
| G | comment surface | review thread · issue comment · review summary body | where the reviewer wrote. the gate reads the first two; a review summary body (the "approved, given…" text of #693 often lives there) is outside the gate by F1, a wisher call |

## the walked product

full product = 2 × 4 × 3 × 6 × 3 × 2 × 3 × 2 × 2 × 3 × 3 = 93312 cells (M and K each add a factor of 3; most M cells are inert, since M varies only where the gate disables: D=found × an unanswered row × B∈{apply,watch}. S counts comments per thread only; G is not multiplied in: its first two values are C's review and issue values, and its third is one out-of-scope cell). most collapse — the walk groups cells by the boundary they hit; each group is verdicted in `1.vision.experience.case=_.md`.

| boundary | cells that hit it | collapse reason |
|---|---|---|
| refusal at the gate (exit 2) | B=apply × C∈{review unanswered, issue unanswered} × T=before read × E=open | one gate; splits on D below |
| refusal mutates: disable at the gate | B=apply × C=unanswered × D=found | an extant automerge is turned off before exit 2 (F5) |
| refusal mutates: disable on any watch read | B∈{apply,watch} × any unanswered row, found at the watch's first read or at any poll × D=found | every read applies one rule: automerge off, exit 2 (F6, F11). covers a `--watch` that starts with automerge already on and a row already unanswered — disabled at its first read, no poll-interval gap. under B=apply, D=found always holds mid-watch, since apply set it |
| watch report only | B=watch × any unanswered row × D=unfound | no automerge to disable and none will be enabled; the row is shown, exit per checks (F11) |
| residual race | T=after the last read, while automerge stays on: the seconds between the last poll and github's merge, or the span after a watch ends (15-minute timeout, ctrl-c, a killed call) | not closable client-side: no process reads once the watch ends; accepted (F6). the window is one poll wide while the watch runs, and open-ended after it. the exit names the open window and both cures (rows 23–24, case=14) |
| pass-through | B=apply × C∈{none, all answered, resolved, bot-only} | the rule returns 0 rows; flow as today |
| preview | B=plan × any C | report only; exit unchanged |
| malfunction | F=fails × any | read fails before any rule runs; exit 1 |
| blind gate fails closed | F=fails × D=found | apply and watch turn automerge off before exit 1; plan never mutates, and names `gh pr merge <n> --disable-auto` (row 22, case=13) |
| disable refused | M=fails, automerge still on × D=found × an unanswered row × B∈{apply,watch} | the refusal cannot be enforced, so it is not claimed: malfunction, exit 1, names `gh pr merge <n> --disable-auto` (case=12) |
| disable converges | M=fails, automerge already off × D=found × an unanswered row | the goal holds; the ordinary refusal, exit 2, never a false malfunction (case=12 [t1]) |
| two blockers | K∈{checks failed, needs rebase} × C=unanswered | each blocker prints; the comment refusal prints last; exit 2 (rows 10, 21) |
| answer signature | A=human driver × C=review unanswered (by-hand sub-case) | an unsigned reply is not an answer (F8, F10) |
| issue answer link | C=issue unanswered × a signed issue comment whose key is not `answer-<id>` | only an id-linked answer clears an issue comment (F9) |
| re-open | R=re-asks × C=review thread unanswered (state after the re-ask; all answered before it) | the latest comment flips back to unsigned |
| same-key trap | R=re-asks × a second answer under the same `--key` | upsert edits the old answer; the follow-up stays latest. prevented on the printed path: each row names `answer-<its id>`, unique per ask; only a key typed by hand can reuse the old one |
| scale cap | S=>100 | a comment past the cap gets no thread state → reads as not-resolved → blocks: fails closed |
| past the gate | E=feat already merged, or T=after merge | no open pr to refuse (F3) |
| release pr | E=release pr × C=unanswered | same gate; rare in practice |

forbidden cells (rejection invariants):
- B=apply × C=unanswered × exit 0 — the gate's whole purpose
- B∈{apply,watch} × any unanswered row at a watch read × D=found × automerge left on — the refusal would be theater
- F=fails × "0 unanswered" in output — a silent pass
- F=fails × D=found × B∈{apply,watch} × automerge left on — a blind gate that fails open
- M=fails, automerge still on × exit 2 or exit 0 — a refusal claimed while github can still merge
- any flag that skips the gate — the wish forbids a bypass

impossible cells:
- E=feat already merged × D=found — github clears automerge on merge
- C=none × "unanswered" line with a count > 0 — the count is derived from the rows
- B=plan × T=mid-watch — plan reads once and exits; it has no watch window
- B=apply × T=mid-watch × C at read ≠ pass — an unanswered row at read refuses at the gate, so no watch begins

## hidden-dimension check — correlated axes

three axis pairs correlate. each correlation is causal (a state is the result of an act), not a latent axis, so the axes stay as declared:

| correlation | why | verdict |
|---|---|---|
| T=mid-watch ⇒ C at read = pass, under B=apply | the gate refuses any unanswered read before a watch starts | benign: causal order of the flow. the impossible cell above records it |
| C=bot-authored only ⇒ R=none | a bot comment is not a reviewer act | benign: author type is folded into the bot amendment (F4); no experience varies on it beyond C |
| C=resolved, no reply ⇒ R=marks resolved | the resolved mark is the reviewer's act | benign: C is the state, R the act that produced it; both read the same github field |
| R=re-asks ⇒ C=review thread unanswered | a re-ask makes the thread's latest comment unsigned | benign: the mirror of the row above — act produces state |
