# case=13 — the comment read fails while automerge is on: the blind gate fails closed

feel: sharp · care: critipath · boundaries: malfunction, automerge disable

found at 5.3.verification (`rule.require.experience-catalog-evolution`). case=6 walks a failed read with automerge off; this is the same failed read with automerge on, where a silent exit would let github merge past a comment no one read.

## narrative

the clone set automerge on pr #42 an hour ago; checks still run. it runs `rhx git.release --apply`, and github answers the comment read with `HTTP 502`. the gate cannot know whether a comment waits, so it assumes one might: it turns automerge off, then fails loud — `💥 MalfunctionError: could not read pr comments`, the gh detail, `automerge: disabled [removed], so github cannot merge past an unread comment`, and the fix: rerun, since the read is safe to repeat. exit 1.

in plan mode the skill never mutates, so it says instead that automerge is still on: its `fix:` is `gh pr merge 42 --disable-auto`, and a `then:` line names the rerun. if the apply-mode disable fails too, it says so, with the same `fix:`.

## timeline

```
given a feat pr with automerge found, checks inflight
  and the comment read fails (HTTP 502)

when [t0] rhx git.release --apply
  then `gh pr merge --disable-auto` is called
   and `💥 MalfunctionError: could not read pr comments`
   and `automerge: disabled [removed], so github cannot merge past an unread comment`
   and `fix: rerun the same command: the comment read is safe to repeat`
   and exit 1

when [t1] rhx git.release   (plan)
  then no disable call
   and `automerge: still on — github may merge past an unread comment`
   and `fix: turn it off now: gh pr merge 42 --disable-auto`
   and `then: rerun …`
   and exit 1

when [t2] rhx git.release --apply, and the disable fails too
  then `automerge: still on, and the disable failed`
   and `fix: turn it off now: gh pr merge 42 --disable-auto`
   and `then: rerun …`
   and exit 1

when [t3] rhx git.release --watch, and a later poll read fails
  then the poll turns automerge off, then the same malfunction, exit 1
```

## fail-safe proven
fast: automerge goes off before the exit · loud: exit 1, `💥 MalfunctionError` with gh's own detail · teaches: rerun (safe to repeat), or the exact disable command where the skill could not act. a blind gate never fails open.

proof: p9 case13 [t0]–[t4], each snapped.
