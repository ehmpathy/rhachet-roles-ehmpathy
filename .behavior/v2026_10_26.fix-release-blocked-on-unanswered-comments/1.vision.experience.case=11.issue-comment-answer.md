# case=11 — a top-level issue comment, answered by its own id

feel: sharp · care: critipath · boundaries: issue refusal, unrelated robot comment, id-linked answer

## narrative

the commander leaves a top-level note on pr #700: "also: the readme still names the old flag." no thread, no reply button. the clone posts its usual `status` comment for an unrelated reason, then runs `--apply`.

the gate still lists the note. a `status` comment answers no one; only a signed reply keyed to the note's own id does. the refusal row prints that key for the clone: `--key answer-6407563822`. the clone fixes the readme, posts the answer under that key, and the next apply passes.
