# case=7 · a daemon born while keyrack is locked re-reads on the poll gap

covers: E11. sharp · critipath.

## .narrative

a clone pushes at 07:00, before any human has unlocked keyrack. the daemon boots and its first due read finds the token `locked`. it pauses and each clone hears one note with `rhx keyrack unlock …`, as today.

today it then reads keyrack each minute until unlock. with the fix it re-reads as case=5 does: only on a tick with a due pr, each gap doubled per paused tick, up to the 30-minute cap. the human unlocks at 07:40 and the clone pushes again. the push's `set` resets the pr's cadence, so the daemon resumes on the next tick and holds the token from then on.
