# case=3 · a watch that never reads ok ends at the idle ttl

covers: E3. sharp · critipath.

## .narrative

clone @:mechanic watches a pr whose every read faults (a 403, a malformed reply). today the idle clock (`poll.changed`) starts only at the first good read, so a watch with none never reaches the one-week ttl. it also never gets a poll gap, since the cadence is set only after a good read; it reads each tick, forever.

with the fix, a pr with no good read starts its idle clock at its first failed read, one tick after the watch is set; a fresh `set` restarts it. a watch with no good read for the idle ttl ends like any quiet pr, with the same idle note and rewatch command. a dark pr also earns the poll gap: each failed read doubles it, as a quiet read does.

in the meantime `get` names the fault on the row, as today. at the ttl the clone hears the extant idle note, which names the rewatch:

```
🐢 heads up dude...

🐚 git.pull.watch — #1222 quiet for 7 days; watch ended
   └─ rewatch: rhx git.pull.watch set --which 1222 --mode apply
```

(the extant `as_watch_closure_text … idle`, `git.pull.watch.alert.sh:217`)

so a watch that fails each read neither lives forever nor dies in silence.
