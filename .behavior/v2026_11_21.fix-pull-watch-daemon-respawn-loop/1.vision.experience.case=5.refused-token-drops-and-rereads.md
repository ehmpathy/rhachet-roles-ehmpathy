# case=5 · github refuses the held token: re-read once, then pause only if refused again

covers: E7, E7l, E16, E26. sharp · critipath.

## .narrative

`keyrack get` does not say when a token will die, so the daemon learns it from github: the next due read gets a 401. the daemon does not pause yet. it drops the held token, re-reads keyrack (the seaturtle key, then the grove key), and retries the read once with what it gets, in the same tick.

most refusals end there: the hourly seaturtle token has died, the grove token is granted, and the retry gets 200. no clone hears a word (E26). were the daemon to pause on the first 401 instead, every hourly token death would send every clone an `expired` note.

at 11h00 the grove token is revoked, and the seaturtle key is locked. the retry finds no token github accepts. now the daemon pauses, and each clone hears one paused note with the fix, as today: `expired` (`rhx keyrack fill ... --refresh`) where keyrack granted a token github refused, `locked` (`rhx keyrack unlock ...`) where keyrack granted none.

while paused, the daemon re-reads keyrack only on a tick where a pr is due. a paused tick counts as a quiet read of each due pr, so its gap doubles, up to the extant 30-minute cap. at 11h20 a human fills a fresh grove token and the clone pushes. the push's `set` resets the pr's cadence, as it does today, so the pr is due at the next tick. that tick reads keyrack, gets a token github accepts, and lifts the pause.

## .timeline

```ts
given('[case5] a daemon that holds a granted token', () => {
  when('[t0] github answers 401, and a fresh keyrack read gets a token github accepts', () => {
    then('the read retries once with the fresh token and succeeds', ...);
    then('no pause and no note', ...);
  });
  when('[t1] github answers 401 to the fresh token too', () => {
    then('one paused note per clone, cause expired, that names the refresh', ...);
  });
  when('[t1b] the fresh read finds no token granted', () => {
    then('one paused note per clone, cause locked, that names the unlock', ...);
  });
  when('[t2] ticks pass in the pause', () => {
    then('keyrack re-reads only on a tick with a due pr; each gap doubles, never past the cap', ...);
    then('no second paused note', ...);
  });
  when('[t3] a fresh token lands and a set runs', () => {
    then('the next tick re-reads keyrack and github accepts', ...);
    then('the pause lifts; the fresh token is held', ...);
  });
});
```
