## the change, by file

- `git.pull.watch.github.sh` — rc 6 for a 404; only the pull's own read passes it (`get_watch_pr_pull_file`), every sub-read maps it to a fault by default (`get_watch_pr_resource_file`)
- `git.pull.watch.alert.sh` — one switch over every end reason (`as_watch_closure_text`: merged · closed · idle · dark · gone, an unknown one fails loud); the 404 note in two forms by token source; a dark watch's end note names its last fault; each paused note says when alerts resume, and how to resume one now
- `git.pull.watch.get.sh` — the read-fault cure says a pr unread past the idle ttl ends its watch
- `howto.git-pull-watch.[lesson].md` — the brief: which records the hook revives, the 404 and idle rows, the held token, when a pause lifts
- `git.pull.watch.operations.sh` — `set_watch_pr_cadence_held`, `set_watch_pr_cadence_faulted`, and the gap math they share with `set_watch_pr_cadence` (`get_watch_pr_quiet_next`, `set_watch_pr_poll_next`); `is_watch_record_servable_by_key`, `get_watch_record_count_servable_of_clone`, and `is_watch_root_on_key`, which asks a root's key once per pass; `get_watch_record_fields`, the one record reader that splits on the unit separator, so an absent field never shifts the ones after it (the steal, the drain, and both reap passes read through it)
- `git.pull.watch.daemon.sh` — `gen_watch_token_held`, `get_watch_pr_state_logged`, `set_watch_gone_ended` (beside `set_watch_idle_ended`, both on the shared `set_watch_records_of_pr_ended`), `is_watch_pr_unprimed_and_readable`; the tick reads the token lazily and retries a 401 once; no idle end while reads are held (`is_watch_read_held`: a pause or a keyrack fault); a lifted pause, an ended keyrack fault, or the first reply after a box-wide outage makes each watched pr due at once (`set_watch_all_prs_due`), and a good read after a fault snaps that pr's gap back; a 404 lifts a pause; a retry whose fresh token is unchanged is skipped; the steal takes ended records, reaps a record only when it names a repo root that is gone, and leaves an unreadable one
- `sessionstart.git-pull-watch.sh` — counts older-key records by the shared predicate
- tests: `git.pull.watch.token.integration.test.ts` (new); `health`, `delivery`, `sessionstart` suites; `genWatchTestScene.ts` (a `forbidden` per-pr fault, a pr hidden from the grove token, and the pipe-safe exit)
