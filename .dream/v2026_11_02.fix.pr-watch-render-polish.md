## .the cue that fired

## .the gap, precisely

- `get` cures name only the first unwell or paused daemon; a stale daemon that is also paused gets
  two cures, one of which (unlock) cannot revive a dead pid (r011 nitpick.5)
- one command is spelled two ways in hints: dotted `rhx git.pull.watch.set` in verb refusals,
  spaced `rhx git.pull.watch set` in `get` and the dispatcher (r011 nitpick.4)
- `get --output json` mixes row shapes in `watches[]`: a full row beside
  `{ unreadable: true, record }` (r011 nitpick.6) — a json contract change
- the `(dir)` parenthetical on a watch line carries no label (r011 nitpick.1)
- `set` plan `found →` and `would move` lines, and the `moved` / replaced-daemon / paused json,
  are unsnapped (r010 nitpick.5; 5.3 i005 r010 nitpick.5)
- `del --output json` verdict is the prose `absent — no-op`, where `set` emits plain words; a
  consumer must match a unicode dash (5.3 i005 r011 nitpick.5) — a json contract question for the
  commander
- the hook's acceptance suite covers only its silent paths; its unreadable-record fault runs at
  integration only (5.3 i005 r010 nitpick.6)
- `get` stacks one `🥥 did you know?` block per unwell part; three in one render read as three
  headers (5.3 i005 r010 nitpick.7)
- an events-then-closure alert with the `(held N ticks; you were busy)` mark is unsnapped, and
  the ended watch's `get --output json` row is asserted, never snapped (5.3 i006 r010 nitpick.3)
- `git.commit.push` has no blackbox case through rhachet (5.3 i006 r010 nitpick.2)
- a plan-minded caller's hint names `--mode apply` (`--pr`, `--in`); for `del` it skips the plan
  the [t5] hint teaches (5.3 i006 r011 nitpick.2)
- each verb's `--help` opens on `usage:`, with no line that says what the verb does
  (5.3 i006 r011 nitpick.3)
- `del`'s no-op names naught of what it searched, and offers no list command; a mistyped `--pr`
  reads as calm as a true no-op (5.3 i006 r011 nitpick.4)
- the stranger-serial refusal says `registry`, not `RHACHET_CLONE_SERIAL`, and gives prose, not a
  command; its `DEAD` branch prints a capital state (5.3 i006 r011 nitpick.5)

## .the shape of the fix

- key each `get` cure by daemon: `daemon v<key> serves no watch` with its own log; skip the
  paused cure on a stale or absent daemon
- pick the dotted form in every hint (it names the skill file a reader can open)
- json: an unreadable row carries the full row shape with null fields and `unreadable: true`,
  under a json version bump
- label the parenthetical `root: <dir>`, or drop it when it equals the repo name
- lifecycle case4 and case14 snap their plan lines and the `moved` json
- del json: `verdict: "absent"` with the prose kept in the tree, under the same json version bump
- blackbox `sessionstart.git-pull-watch` seeds a record that will not parse, via a temp HOME and
  a clone serial, and snaps the `💥 MalfunctionError: … unreadable` tree
- `get`: one `🥥` header, each cure a labeled branch under it
- delivery case7c: hold an events alert, then a merge in the next tick, and snap the held
  combined alert; snap the ended json row with `ended` masked
- `blackbox/git.commit.push.acceptance.test.ts`: `--help` and one input refusal via rhachet
- each hint echoes the caller's own `--mode`; a bare caller gets the plan form
- a one-line `.what` above each `usage:`; move the `asSkillRender` anchor with it
- del no-op: `verdict: absent — no watch by this clone on <repo>#<pr>`, then
  `rhx git.pull.watch get` to list what it holds
- stranger serial: `RHACHET_CLONE_SERIAL=<serial> is no clone of <repo>`, then
  `npx rhachet clone list --output json`; lowercase the reach state

## .why it is not done in this round

each reshapes output pinned by snaps across four suites, and two touch the json a composer
parses; the l3 lane round is the last before the done gate, so a wide render change lands better
as its own reviewed change.
