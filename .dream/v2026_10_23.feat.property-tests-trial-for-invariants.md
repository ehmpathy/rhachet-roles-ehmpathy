- **kind** = feat

## .the cue that fired

route `v2026_10_23.fix-arch-fundamentals`, stone `1.vision`, lesson I12. the wisher's t07 (*"we define invariants and then test all the ways they could be violated"*) is the exact case property-based tests serve, and the vision deferred it (fulcrum F06).

## .the gap, precisely

the mechanic clamps invariants by hand-picked boundary cases (`rule.require.clamp-edge-cases`). a hand pick misses the break case the author did not imagine (case 3: the reset that breaks the count). no repo here uses a property-test library, so its cost and flake rate are unmeasured.

## .the shape of the fix

1. add `fast-check` (pinned) as a devDependency in one repo with a pure aggregate (a count, a sum, a dedupe)
2. write one property test per invariant: `fc.assert(fc.property(fc.array(level), (levels) => getBeginnerCount(levels) === levels.filter(isBeginner).length))`
3. measure: runtime added, flake count over 50 ci runs, defects found that the clamp tests missed
4. if it pays, write `rule.prefer.property-tests-for-invariants` (mechanic, ref) with the measured numbers

## .why it is not done in this round

**SAFE: yes.** **CLEAN: no** — a new dependency and a ci measure, beyond a briefs-only route (fulcrum F12). the call to defer is a judgment, so fulcrum F06 records it.
