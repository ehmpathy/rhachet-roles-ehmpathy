# 🌙 dream: name the meter by an explicit argument, not an ambient METER_SLUG

- kind: fix
- owner: ehmpathy/rhachet-roles-ehmpathy (mechanic skills)
- caught 2026-10-21, on route `.behavior/v2026_10_11.feat-git-branch-cutover`, stone 5.1

## .the cue that fired

peer review i004 r011 nitpick.6: `git.commit.uses.global.sh` and `git.commit.uses.org.sh` serve
both meters, steered by a shell var `METER_SLUG`. every commit-family caller must pin it by hand.

## .the gap, precisely

- `git.branch.uses.operations.sh` sets `METER_SLUG="git.branch.uses"` / `METER_NOUN="cutover"`
  at source time; the global + org readers read them ambient
- three commit-family callers pin `METER_SLUG=git.commit.uses` today; a fourth that forgets reads
  whatever the last sourced file set
- the cutover verbs source ~4k lines of commit-domain bash to reach ~5 leaves (gate, output
  leaves, level inference)
- the meter is the absent domain noun (peer review i005 r011 nitpick.8): the global + org readers
  are shared, the local half (`is_branch_meter_*`, the gate, the spend, the local handler) is a fork
- drift already shows inside the fork: the 0-byte meter file repair landed twice, as `[[ -s ]]` in
  `git.commit.operations.sh` and as `[[ -n ]]` in `git.branch.uses.operations.sh`
- `git.commit.bind.sh`, `git.commit.sponsor.sh`, and `git.commit.uses.local.sh` source the commit
  operations with no slug pin; three other commit-family sourcers pin it
- the deny list in `init.claude.permissions.jsonc` holds the meter mutations as a third hand copy

## .the shape of the fix

1. give the global + org readers a named arg: `check_global_blocker meter=<slug>`,
   `check_org_blocker meter=<slug>`; default to `git.commit.uses` when absent
2. pass `meter=git.branch.uses` from `guard_branch_uses_granted`; drop the `METER_SLUG` pins
3. lift the five leaves the cutover needs into a small `git.meter.operations.sh` that both
   meters source, so the cutover no longer sources the whole commit domain
4. make the meter a noun there: one `is_meter_readable meter=<slug>`, one gate, one spend, so the
   0-byte repair lives once; derive the deny-list rows from one source
5. the extant suites (`git.commit.uses`, `git.branch.uses`, `git.branch.cutover`) cover it

## .why it is not done in this round

safe, not clean: it ripples into the commit meter's files and callers, which this route only
reads (fulcrum F11, one copy of the readers). a contract change to the commit domain belongs in
its own change, with the commit suites as its gate.
