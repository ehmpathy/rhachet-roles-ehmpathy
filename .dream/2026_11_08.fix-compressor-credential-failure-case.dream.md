# 🌙 dream: the brain compressor proves it fails loud with no credential

- kind: fix
- owner: rhachet-roles-ehmpathy (librarian, brief.compress)
- caught 2026-11-08

## .the cue that fired

two peer lanes on the pressViaPipeline route (ergo-friction-hazards, behavior-intent-coverage) cited `rule.require.external-contract-integration-tests`: the live brain contract has no lack-of-credential case.

## .the gap, precisely

`compressViaBhrain` builds its brain with `genContextBrain({ creds: { keyrack: { owner: 'ehmpath', env: NODE_ENV === 'test' ? 'test' : 'prep' } } })` (`compress.via.bhrain.ts:364-373`). the owner and env are hardcoded, so a test cannot point it at a keyrack with no key. the only route to an absent key is to lock the shared `ehmpath` keyrack, and every clone on the box shares that unlock.

## .the shape of the fix

1. let `compressViaBhrain` take its creds source from `context` (default: the ehmpath keyrack), the same shape as pressViaPipeline's injected compressor
2. in `compress.via.bhrain.contract.integration.test.ts`, add a case that passes a creds source with no key and asserts the error names the absent key plus the `rhx keyrack unlock` fix, snapped
3. that case asks no brain, so it can run on ci with no gate

## .why it is not done in this round

the credential path is the compressor's contract, which has six callers. this diff does not touch it. a creds-injection change there is a contract change of its own.
