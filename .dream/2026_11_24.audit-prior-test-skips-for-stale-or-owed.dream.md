## .the cue that fired
5.3 verification on the push-help route: a full integration run reported 143 skipped; the 5.3 gate asks zero skips.

## .the gap, precisely
`describe.skip` sits on the whole `brief.compress`, `brief.condense`, `cluster`, `kernelize/clusterKernels`, and `.evals` llm suites. a bare `.skip` carries no reason, no owner, and no path to run it on purpose, so a reader cannot tell a cost-gated eval from dead code. the env gates (`skipIf(CI)`, `runIf(isGhAuthenticated)`, `runIf(isLiveTargeted)`) at least name their condition.

## .the shape of the fix
per `describe.skip`: either delete the suite (dead), or turn it into a named opt-in gate (e.g. `given.runIf(isLiveTargeted({ mechanism: 'llm' }))`, the pattern `git.pull.watch.github.real` uses) with a `.why` comment and a documented command to run it. then a default run reports zero bare skips, and every gated case names how to run it.

## .why it is not done in this round
fulcrum F5: the suites are paid llm runs, the `test` env lacks the key, and they span five owners; the route's wish is push's `--help`.
