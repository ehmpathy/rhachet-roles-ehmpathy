# 🌙 dream: the rebase plan meter reads uses, as apply does

kind: fix · owner: mechanic · caught 2026-11-14

## .the cue that fired
on #1206, `rhx git.branch.rebase begin` (plan) printed `meter └─ commits: allowed`; the next call, `--mode apply`, refused with `no commit uses left`. `rhx git.commit.uses get` showed `left: 0`.

## .the gap, precisely
`git.branch.rebase.begin.sh` plan mode reports the commit permission without the uses count, so a tree at zero uses plans as allowed and then refuses at apply. the plan promises what apply will not do.

## .the shape of the fix
plan reads the same meter guard apply runs: at zero uses, plan shows `commits: blocked (0 uses left)` and the same grant fix line apply prints. clamp: a temp repo at `uses: 0`, `push: allow`; plan must name the refusal. red before, green after.

## .why it is not done in this round
outside #1206's diff (the quota refusal text); a fix here widens a PR held on F1.
