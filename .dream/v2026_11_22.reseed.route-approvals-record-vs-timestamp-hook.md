# 🌙 dream: the route engine's approval record trips the timestamp hook

kind · reseed · owner · ehmpathy/rhachet-roles-bhrain (route engine) + ehmpathy/declapract-typescript-ehmpathy (`.husky/check.timestamps.sh`) · caught 2026-11-22

## .the cue that fired
a commit of `.route/<route>/.route/` would stage `approvals.jsonl`, whose rows carry `"at":"<iso instant>"`; the new `check.timestamps.sh` refuses any clock time in a staged non-.ts/.sh file and forbids every exemption.

## .the gap, precisely
past routes track their `.route/` engine state in git (e.g. `.behavior/v2026_02_24.mechanic-keyrack/.route/*`). so the two practices collide: the engine writes a raw instant into a tracked record; the hook blocks it with no seam. this route leaves `approvals.jsonl` unstaged, so its approval record lives only on the host.

## .the shape of the fix
the engine records the approval without a clock time (order is already the row order; a date stamp, if wanted, as `YYYY-MM-DD`, which the hook allows), or keeps engine state in a `.route/.gitignore`d file. either way a route can commit its own record.

## .why it is not done in this round
the fix lives in the route engine's repo.
