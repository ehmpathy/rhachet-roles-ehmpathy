# 🌙 dream: teesafe strips the final newline of what it writes

kind: fix · owner: mechanic · caught 2026-11-08

## .the cue that fired
`git show origin/main:package.json | rhx teesafe package.json` left a diff of `\ No newline at end of file`. so did `printf '\n' | rhx teesafe package.json --append`.

## .the gap, precisely
teesafe drops the final newline from stdin, in write mode and in append mode alike. a byte-exact restore through it is impossible, and `--append` of a bare newline is a no-op.

## .the shape of the fix
write stdin bytes verbatim (no `$(cat)` capture, which strips final newlines; stream via `tee` or `cat >`). add a clamp: pipe `a\n` in, assert the file holds exactly `a\n`.

## .why it is not done in this round
the defect is in a mechanic skill, apart from the pressViaPipeline fix; it would grow the nano diff.
