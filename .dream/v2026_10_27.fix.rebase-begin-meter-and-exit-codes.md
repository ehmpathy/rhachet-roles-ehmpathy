# 🌙 dream: git.branch.rebase begin keeps the promises its header makes

- kind: fix
- owner: mechanic (rhachet-roles-ehmpathy)
- caught 2026-10-27, at 1.vision of `v2026_10_27.feat-git-branch-merge`

## .the cue that fired

research for the merge verb read `git.branch.rebase.begin.sh` as the twin to mirror. its header
promises more than its code does.

## .the gap, precisely

- header (`:15`) says "decrements uses on successful rebase"; no line writes the meter
- `GIT_OUTPUT=$(git pull … --rebase 2>&1) || true` then `GIT_EXIT_CODE=$?` (`:240-241`) always reads 0
- every constraint guard exits 1 under a `hold up dude...` header, not `✋ ConstraintError` + exit 2
- the same exit-1-on-constraint shape repeats in `continue`, `abort`, `take`, `lock`
- `git.branch.rebase.lock.integration.test.ts:216,355,415` gate cases on `then.runIf(isPnpmAvailable)`:
  a silent skip `rule.forbid.failhide` forbids. ci had no pnpm on PATH, so they never ran there.
  the catchup pr puts pnpm on the integration runner, so the gate can drop to a fail-fast
- rebase's `get_conflict_files` reads `git diff --name-only` with no `-z`, so git quotes a
  non-ASCII name (`"caf\303\251.md"`) and `take` cannot match it; its pathspecs also read as globs.
  catchup reads paths via `-z` (`as_lines_from_nul`) and takes with `GIT_LITERAL_PATHSPECS=1`

## .the shape of the fix

1. decide: does a rebase spend a commit use? then either decrement or fix the header
2. capture the exit code before `|| true` swallows it
3. move constraint guards to `✋ ConstraintError` + exit 2; snapshot updates follow
4. clamp each: a test that fails on today's code
5. lift the readers both branch verbs share (`get_conflict_files`, `get_current_branch`) into a
   `skills/git.branch/` operations file both source; take catchup's `--git-path` rebase check and
   its `print_catchup_files_tree` (rebase's `print_files_tree` double-prints its count) as the
   shared form (fulcrum F17 of the catchup route); the shared reader is catchup's `-z` one, so
   the lift fixes the quoted-name defect in both verbs at once

## .why it is not done in this round

it changes the contract of a twin verb (exit codes callers may read) and needs a decision on the
meter; the merge route's scope is the new verb.
