## .the gap, precisely

`check.timestamps.lock.sh`:

- the disk read `TIMESTAMPS_LOCK_DISK=$(git hash-object -- "$TIMESTAMPS_LOCK_HOOK")` is unguarded and
  the file sets no `set -eu`. a failed git read leaves it empty, so the hook halts with
  `✋ ConstraintError: ... was changed` (exit 2) where it should halt `💥 MalfunctionError` (exit 1)
- `timestamps_lock_halt` reads two positional args (`$1` found, `$2` where)

`check.secrets.sh`:

- `grep -nIE -e "$regex" | head -n 1 | cut -d: -f1` with no `pipefail`: an invalid shape regex or a
  grep fault (exit 2) reads as "no match", so that shape silently stops scans

## .the shape of the fix

- lock hook: `set -eu`; `TIMESTAMPS_LOCK_DISK=$(git hash-object -- ...) || timestamps_lock_malfunction`;
  `timestamps_lock_halt found="..." where="..."` with an arg loop
- secrets hook: run grep alone, branch on its exit (0 match, 1 none, else `💥 MalfunctionError`);
  add a shape-table self-test (each regex compiles; each sample matches)
