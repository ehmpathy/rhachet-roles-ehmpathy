## .the gap, precisely
- stacked hints: `print_aside_hint` prints one `🥥 did you know?` block per hint. A run that both supersedes a fresh edit and meets a main-changed path shows two coconut headers back to back (unstaged case9 t0).
- superseded depth: the `superseded` block nests under `unstaged` on a put-back (case4 t2, case17). It is a top-level peer on a failure render (case23, case35). Its last child, `the latest fresh edit at each path kept in: …`, sits among paths and can read as one.
- header mode: guards render `git.branch.rebase begin` before the mode is read. Plan and apply outcomes render `begin --mode plan|apply`. So one apply run can show either header.
- set-aside order: a fresh not-held edit lists last (journey7/8, case4), while begin lists paths sorted (case26, journey5).
- long hints: case2, case4 t3, and the `--unstaged include` help line run past one screen width.
- alert far from its cure: the `⚠️ main also changed these paths` branch sits in the `unstaged` tree, while its fix command comes after the `git.output` frame, under `🐢 righteous!`. The `superseded` notice carries no `⚠️` though it holds a human's edit out of the tree.
- label restates its child: `unstaged (set aside)` over `set aside, put back` over `status: all put back`. And the `meter` branch shows in plan and `continue` renders, not in `begin --mode apply`.
- case16 keeps the older "already up to date" shape (`commits: 1 (ahead)` plus bare prose), unlike `ahead: 1 commit` and `🌊 ready to push` elsewhere.

## .the shape of the fix
- `print_aside_hint` gathers its tips into one coconut block, with numbered tips and the copy-paste commands last.
- one `superseded` depth everywhere (a peer of `unstaged`), with `kept in` lifted to its own labeled branch.
- guards read `--mode` first, so every header names the mode.
- one path order (sorted) for every set-aside list.
- hints wrapped as a label branch plus a command child.
- case16 moved onto the `ahead` / `🌊 ready to push` shape.
- each `⚠️` notice carries its fix command as a child branch, above `git.output`; `superseded` gets the same `⚠️`.
- one resnap of every git.branch.rebase suite. The pins to review: unstaged case4, case9 t0, case17, case23, case35; acceptance journeys 4, 6, 9, 10, 11.
