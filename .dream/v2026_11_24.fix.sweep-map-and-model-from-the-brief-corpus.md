## .the shape of the fix

per sense, the alternative each ban names:

| sense | swap |
|---|---|
| mental model | mental picture, grasp, expectation |
| domain model / model the domain | the domain objects / declare the domain |
| the model (an llm) | the brain |
| maps to / maps onto | matches, corresponds to, backs, gets |

the term hook already blocks both (`terms.blocklist.jsonc`), so each of these files nudges on its next edit. the sweep clears that friction ahead of time.

a later refinement: a record `scope` (prose files only), so `.map(` and `Map` in code stop the nudge. it needs its own fork-budget and blocklist suite cases.

## .why it is not done in this round

**SAFE: yes. CLEAN: no.** ~60 files across four roles, none in the route's scope. a corpus-wide rewrite inside this route would smuggle an unrelated change (`rule.prefer.wickup-touched-prose`).
