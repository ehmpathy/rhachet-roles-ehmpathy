## .the gap, precisely

`git.release` reads GitHub only through the `gh` CLI, over four read-only json surfaces:

| call | fields read | site |
|------|-------------|------|
| `gh pr list` | `number`, `title`, `headRefOid`, `mergeCommit` | `operations.sh:72,95,777,795` |
| `gh pr view` | `statusCheckRollup`, `autoMergeRequest`, `mergeStateStatus`, `state`, `title`, `mergeCommit` | `operations.sh:193`, `git.release.sh:757,963` |
| `gh run list` | `name`, `conclusion`, `status`, `url`, `startedAt`, `updatedAt` | `operations.sh:466,866` |
| `gh run view` | `jobs`, `startedAt`, `updatedAt` | `operations.sh:540,558` |

a field rename upstream ships green. three mock surfaces serve the 17 suites:

| surface | suites |
|---------|--------|
| shared `.test/infra/mockGh.ts` | 12 |
| bespoke inline mocks in `p2`, `p4` | 2 |
| no `gh` use | 3 |

a shape change must land in all three places. a repair to `mockGh.ts` alone leaves `p2` and `p4` green
against a stale contract.

already covered: a dead credential fails loud. `get_pr_for_branch` captures the `gh pr list` exit
code, and `git.release.p8.creds_absent.real_boundary.integration.test.ts` proves it with a real `gh`
and no credential. shape drift is the uncovered half.

## .the shape of the fix

one read-only contract suite — no write, no PR, no release:

1. call each surface against this repo with `--json <the exact fields above>`.
2. assert keys present, not values.
3. assert the nested shapes the skill reads: `mergeCommit.oid`, `jobs[].steps[].name`.
4. the write half of `git.release` stays mock-tested.

prerequisite: a read-only token in the `test` keyrack env and `GH_TOKEN` in
`.github/workflows/.test.yml`. today no token reaches the integration shards, so the suite would pass
locally and red in CI. do not substitute a stub: a stub cannot fail for the reason this test exists.
