## .the shape of the fix

a new `skeptic` role with three rules to start:

| rule | says |
|---|---|
| `rule.always.ask-whose-frame` | when a question arrives inside a context (a transcript, a quoted author, a prior thread), ask: does the question's scope equal the context's scope? a new question in an old thread is still new |
| `rule.always.weigh-by-today` | rank a topic by its relevance to today's reader, never by its prominence in the source |
| `rule.forbid.verified-as-representative` | a check of accuracy is not a check of selection. ask both: is the quote real, and is this the right set of voices? name the authors, eras, and lenses; flag a set from one source |

plus a `review.by` rubric so a route guard can add the skeptic as a peer lane on vision stones.
