# 🌙 dream: give the local meter one hardened read/write leaf

kind: fix · owner: mechanic · caught 2026-09-27

## .the cue that fired

peer `enroll-impl-arch-defects` on `fix-git-sponsor` 5.1 (i009): the global and org meters were
hardened in this branch (one capture, `jq -s -e` shape gate, temp + `mv` writes, a named
`💥 MalfunctionError` on a corrupt file). the local meter, `.meter/git.commit.uses.jsonc` — read on
every commit — got none of it.

## .the gap, precisely

- raw reads with no shape gate: `git.commit.set.sh` (`jq -r '.uses' "$STATE_FILE"` and siblings),
  `git.commit.push.sh`, `git.commit.uses.local.sh`
- whole-file heredoc writes with no temp + `mv`: `git.commit.uses.local.sh`, `git.commit.set.sh`
- failure: a truncated or corrupt file (crash mid-write, disk full) → the next commit's `jq` exits
  non-zero under `set -euo pipefail` → the skill dies on jq's raw parse error, with no class header,
  no file named, no remedy
- the root cause: three files each own a copy of the local meter's read and write, so they drift.
  the drift already shipped one defect — push's revoke dropped `stage` (fixed on this branch,
  clamp `git.commit.push` `[case14b]`)

## .already landed (fix-git-sponsor)

- the shape gate: `is_local_meter_readable` in the operations leaf; set, push, and `uses get` each
  refuse a damaged file first — exit 1, `💥 MalfunctionError:`, the file named, `uses del` then a
  fresh grant as the fix. clamps: set `[case53]`, push `[case14c]`, uses `[caseLocalMeterDamaged]`
- push's revoke rewrites `push` alone, atomically (`[case14b]`)

## .the shape of the fix (what remains)

1. one write leaf, `set_local_meter_state`, beside `is_local_meter_readable` (or in its split
   successor — see `v2026_09_27.fix.git-commit-operations-out-of-role-dir.md` step 5)
2. writes: build the object with `jq -n`, write to a temp beside the file, `mv` over it; rewrite
   only the fields the caller changes
3. route the heredoc writes in set and uses.local through it
4. one read leaf that returns uses/push/stage in one capture, so the three raw `jq -r` calls per
   consumer collapse to one. ⚠️ the local meter is now the ODD one out by construction: the
   sponsor state, the global blocker, and the org blocker each read their file once and derive
   every value from that capture, so a human's concurrent `set`/`del` cannot pair stale and fresh
   values. the local meter still opens its file four times per commit (the shape gate, then
   `.uses`, `.push`, `.stage`), so a grant that lands between them can mix old and new values
   (peer `enroll-impl-arch-defects`, i013)

## .why it is not done in this round

dirty: it rewires every quota write across three skills and their snapshots, and the wish never
touched the local meter. the two harms a human could meet — a raw crash on a damaged file, and
push's revoke that dropped `stage` — are fixed here; the atomic writes ride their own change.
