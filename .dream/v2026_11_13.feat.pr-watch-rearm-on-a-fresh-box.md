# 🌙 dream: a clone that resumes on a fresh box rearms its pr watch

- kind: feat
- owner: mechanic (rhachet-roles-ehmpathy, git.pull.watch)
- caught 2026-11-13

## .the cue that fired
the #1222 clone moved to a new box on 2026-11-13 (fresh worktree). `rhx git.pull.watch get` there: `no daemons, no watches`. the session-start hook revives a daemon only for a watch this box already holds, so a moved clone hears naught until its next push.

## .the gap, precisely
a watch is armed by `git.commit.push` (via `git.pull.watch set`) or a hand `set`. its record lives in the box's `~/.rhachet/storage/...`. a clone resumed elsewhere carries no record, and no hook arms one.

## .the shape of the fix
in `sessionstart.git-pull-watch.sh`: where this clone holds no watch, and the branch has an upstream on github, look up its open pull (one read, with the same keyrack token the daemon uses) and `set` it. silent when no open pull; one line when it arms one. clamp: a scene with a fresh home, an enrolled clone on a branch with an open pull → after the hook, `get` lists the watch.

## .why it is not done in this round
it adds a github read to every session start, and a token read before the session can work; that cost is the commander's call, not a 30-min cap edit. the cure for the four-day miss is the grove token; this gap opened only today.
