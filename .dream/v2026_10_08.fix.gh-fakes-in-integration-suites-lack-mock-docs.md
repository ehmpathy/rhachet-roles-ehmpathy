# 🌙 dream: the gh fakes in 14 integration suites carry no documented mock exception

kind: fix · owner: ehmpathy/mechanic · caught 2026-10-08

## .the cue that fired

5.3 peer `mech-test-scope-purity` nitpick.1 (i001, route `v2026_09_26.fix-blocklist-nudge`):
`rule.forbid.integration.mocks` allows a mock only with an inline `.mock =` / `.why =` / `.real =`
block where it is declared. these suites write a fake `gh` (and in the git.release scenes, `git`)
onto PATH with no such block.

## .the gap, precisely

- `skills/git.release/git.release.p1` … `p7` integration suites (12 files) — `writeSceneGhMock`,
  `fakeBinDir/gh`
- `skills/cicd.deflake/detect.integration.test.ts` — gh fake except `[case4]` (real API)
- `skills/git.commit/git.commit.sponsor.integration.test.ts` — `runAtMeWithGhStub`, except
  `[case9][t2]` (real gh)

a reader cannot tell an accepted exception from an oversight.

## .the shape of the fix

one doc block per fake factory (not per case), e.g. beside `writeSceneGhMock`:

```ts
/**
 * .mock = gh, as an executable on PATH that answers a scripted pr/check state
 * .why = the release states (a red check, a merge race, a stale tag) cannot be summoned
 *        from github on demand, and a real merge would ship a release
 * .real = `[case…]` / the acceptance suite drives the real gh
 */
```

for git.release, name the real twin, or add a `.real.integration.test.ts` that reads one live pr.

## .why it is not done in this round

SAFE yes, CLEAN no: the class predates this route, which touched only the timeout and status
lines in those files. a doc sweep across 14 suites is an unrelated change smuggled into this diff.
