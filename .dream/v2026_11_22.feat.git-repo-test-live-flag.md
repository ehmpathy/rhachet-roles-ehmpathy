# 🌙 dream: `git.repo.test` can run a live-gated suite

- kind: feat
- owner: ehmpathy/rhachet-roles-ehmpathy, the git.repo.test skill
- caught 2026-11-22

## .the cue that fired

`5.3.verification` of `fix-pull-watch-daemon-respawn-loop` owes zero skips. the 9 skips in the pull-watch suites are `git.pull.watch.github.real`, gated on `TEST_LIVE=github` by design. a driver has no paved command to set that var: `rhx git.repo.test` takes no env passthrough, and an env prefix (`TEST_LIVE=github npm run …`) is refused by the permission gate.

## .the gap, precisely

a live suite is reachable only by a human at a shell. so a buttonup stage cannot run it, and its skips read as a gap the driver cannot close.

## .the shape of the fix

`rhx git.repo.test --what integration --live github --scope … --mode apply`: a `--live <mechanism>` flag, from a closed set the suites name (`github`, …), that sets `TEST_LIVE` for the jest run and requires the keyrack unlock that suite needs. a clamp: the github.real suite reports 0 skipped under `--live github`, 9 without.

## .why it is not done in this round

it changes another skill's contract and its tests; the pull-watch change does not touch the live suite.
