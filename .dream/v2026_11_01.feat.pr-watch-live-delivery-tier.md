# 🌙 dream: an opt-in live delivery tier for git.pull.watch

kind: feat · owner: rhachet-roles-ehmpathy (role=mechanic, git.pull.watch) · caught 2026-11-01

## .the cue that fired

fulcrum F15 (QB3) took the lean: no live delivery tier in the first pr. the fake `rhachet` on PATH covers every `clone say` verdict, yet it cannot prove a real alert lands in a real clone's tty.

## .the gap, precisely

the one seam the default suite cannot reach: `clone say @:<serial>` from a detached daemon, cwd at a watch's repo root, into a LIVE enrolled clone.

## .the shape of the fix

- one `git.pull.watch.live.integration.test.ts`, off by default (env flag)
- enroll a haiku 5-5 clone, set a watch on a fixture pr, let one tick deliver
- assert the clone transcript holds the alert header
- bound: under $0.50 a run, no oauth token (the three tiers)

## .why it is not done in this round

delivery is `clone say`'s own contract, tested in rhachet; the commander ruled hows to their leans, and the lean defers this tier.
