## .the count is host-dependent

`201` counts tests that did skip, on one host where pnpm, yarn, and gh exist and `CI` is unset:

| kind | sites | skipped on that host? |
|------|-------|-----------------------|
| brain / perfeval `describe.skip` | 13 | yes — nearly all of the 201 |
| `runIf(pnpm\|yarn\|gh)` | 6 | no |
| `skipIf(CI)` | 2 | no |
| `skipIf(isYarnInstalled)` | 1 | yes |

the sites that skip in CI are exactly the ones that ran locally. a skip count measures a host, not a
codebase; any clamp on it needs a pinned host.

## .the shape of the fix

1. verdict each site: delete the skip, or cite beside it why it cannot run and what would let it.
2. start with `skipIf(!!process.env.CI)`: smallest, sharpest, no brain cost.
3. then provision pnpm/yarn/gh and let absence fail loud.
4. the brain suites last, with a budget in hand.
5. clamp: on a pinned host, the skip count falls by exactly the number un-skipped.

## .why it is not done in this round

  capability probes need host provision this route cannot make.
- **CLEAN?** no. no site sits in `claude.tools/`, the subsystem this route touches — which has zero
  skips of any kind.
