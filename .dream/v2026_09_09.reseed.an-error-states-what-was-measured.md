# 🌙 dream: an error states what it measured, never what it inferred about the host

**kind:** reseed · **owner:** ergonomist (`ehmpathy/role=ergonomist`) · **caught:** 2026-09-09

## .the cue that fired

a new guard refused a robot identity and explained itself like this:

```
🌊 you are on a cloud grove — the gh session here is the clone, not you.
```

⇒ **the skill runs no grove-detect.** it read a github session and found a robot. it learned naught
about which machine it stands on.

a human on a **laptop**, logged in to a bot account, would meet a message that asserts a falsehood
about their own hardware — and would then doubt the skill rather than the input they gave it.

## .the gap, precisely

🔴 **a guard can refuse correctly and explain itself falsely, and only the explanation reaches the
human.** the exit code was right in both the broken and the repaired version. every extant check
passes on both:

| rule | verdict on the bad text |
|---|---|
| `rule.require.errors-name-the-fix` | ✅ it names the fix |
| `rule.require.exit-code-semantics` | ✅ exit 2, correct |
| `rule.require.failloud` | ✅ loud, with context |
| `rule.require.status-feedback` | ✅ the human is informed |

⇒ **no rule grades whether the context an error supplies is TRUE.** they grade whether it is
present, actionable, and loud.

⚠️ and the drift is invisible to review by construction: an error string is data, not logic. a
reviewer reads the guard's **condition** to check it is right, then reads the message for tone. the
`.why` a message asserts is the one clause nobody diffs against the code above it.

🟡 **the same over-claim had already been caught once in this route, at the CLI-surface level** — a
flag was documented as *"LOCAL-ONLY"* when the guard actually sits on the **value**, never the
grove. the council struck it. it then grew back one layer down, inside an error string, where no
review lane reads.

⇒ **that recurrence is the argument for a rule.** a lesson that only lives in a council's minutes is
re-learned wherever the council did not look.

## .the shape of the fix

a `rule.require.*` in `ehmpathy/role=ergonomist/briefs/fundamentals/`, beside
`rule.require.errors-name-the-fix` — the natural home, since it is the half that rule lacks:

> **an error states what the code measured. where it offers a cause it did not measure, it frames
> it as a general fact, never as a claim about this host, this run, or this human.**

the test, per clause of a message: **"which line of code observed this?"**

- a line observed it → state it plainly
- no line observed it → either measure it, or reframe

the repaired text, as the worked example:

| | text | why |
|---|---|---|
| 👎 | `you are on a cloud grove — the session here is the clone` | asserts a grove that was never measured |
| 👍 | `on a cloud grove that session is the clone's, never yours` | a general fact; no claim about this host |

⇒ the fix is one word of grammar — an indicative about the reader's machine becomes a conditional
about a class of machine — and it costs the message no helpfulness at all.

⚠️ **the bound: this is not a mandate to strip context.** context is what makes an error
recoverable, and `rule.require.errors-name-the-fix` still governs. the target is a **fabricated**
cause, never a stated one.

⇒ severity: **nitpick** in general; **blocker** where the false claim would send the human to
diagnose the wrong subsystem (as the grove claim would).

## .why it is not done in this round

**SAFE: no. CLEAN: no.**

- **safe** — it is a rule for another repo's role, and it grades a surface (`error text`) that every
  extant skill already emits. authored here, it would bind naught
- **clean** — a new fundamental rule ripples into `def.ergonomic`'s rubric,
  `ref.ergonomics.fundamentals`' map, and the `see also` of three neighbor rules

⇒ **the local repair is done** — the message was corrected the moment it was seen
(`rule.always.fix-forward-under-scouts-honor`), and no test or snapshot pinned the old text. what is
deferred is only the generalization.

⇒ 🟡 no fulcrum is owed: an unmeasured claim in an error string is a defect, not a design fork.
