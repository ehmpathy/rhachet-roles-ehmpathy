# 🌙 dream: ship the live-brain test gate from one package, not a copy per repo

kind: reseed · owner: ehmpathy/test-fns (or ehmpathy/rhachet) · caught 2026-11-08

## .the cue that fired
the consistent-mechanisms review of route fix-press-via-pipeline-live-llm-gated: `src/.test/isBrainLiveScopeAll.ts` and `describeBrainLiveOnDemand.ts` mirror rhachet's private `src/.test/infra/` files line for line. rhachet's `dist` exports neither.

## .the gap, precisely
two repos now hold the same gate (flag name, closed set, error text, todo-row text). a change to one, such as a new scope value, will drift from the other. the kin live-llm suites (see the imagineIsContentAdmissible dream) will want the same gate in yet more repos.

## .the shape of the fix
export `isBrainLiveScopeAll` + `describeBrainLiveOnDemand` from a shared test package (test-fns fits: it already owns `given.runIf`). then replace the local copies in rhachet and rhachet-roles-ehmpathy with the import. keep the flag name `BRAIN_LIVE_SCOPE` and the `all`-only closed set.

## .why it is not done in this round
it is a change to another repo's public api, and a release of it, outside this nano fix.
