## .the cue that fired

## .the gap, precisely

- **metadata** came most reliably from the crossref api (`api.crossref.org/works/<doi>`): authors, title, venue, year, pages. no skill wraps it
- **bot walls** blocked direct fetches: dblp (Anubis), ACM (`Just a moment`, http 403), IEEE. the cure was a headful tab (`--session refs-headful`) where a human clears the captcha. the wisher's own words: clones should just ask for the captcha
- **grades** were assigned by hand: ✅ primary metadata + quote · ☑️ metadata verified, quote secondary or none · 🟡 unverified. no tool records which grade a fetch earned
- each ref file was hand-shaped (grade, cite, seen, quote, supports)

## .the shape of the fix

one skill, e.g. `rhx browser.cite --doi <doi> --into <dir>`:

1. crossref lookup → a `ref.<year>.<author>.md` stub with the full citation
2. try the publisher page for a quote, headless first
3. on a wall, switch to the headful session, print one line for the human (`🥥 clear the captcha in the open tab, then press enter`), and resume
4. write the grade the fetch earned, plus the url and date seen
5. idempotent: a re-run on an extant ref only fills absent fields

## .why it is not done in this round

**SAFE: yes. CLEAN: no.** it is a new skill in another repo; this route needed the refs, not the tool.
