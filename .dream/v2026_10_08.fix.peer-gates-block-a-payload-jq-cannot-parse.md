# 🌙 dream: the peer PreToolUse gates block a payload jq cannot parse

kind: fix · owner: ehmpathy/mechanic · caught 2026-10-08

## .the cue that fired

peer review i014 (r11) graded it a `[blocker][urgent]` on the suspicious-syntax gate: its payload
read swallowed a jq parse failure into an empty command, read as "not a Bash call", and permitted.

## .the gap, precisely

these gates still read the payload as `$(echo "$STDIN_INPUT" | jq -r '…' 2>/dev/null || echo "")`,
so a payload jq cannot parse permits in silence:

- `pretooluse.forbid-stderr-redirect.sh:40`
- `pretooluse.forbid-test-background.sh:55,63`
- `pretooluse.forbid-tmp-writes.sh:50,80`
- `permissionrequest.decide-permissions.sh:79` (a PermissionRequest hook: there, "permit" means
  "lift to the human", so the stakes differ — decide its contract on its own)

`pretooluse.forbid-cross-repo-access.sh` and `pretooluse.forbid-shouted-readme.sh` fail OPEN, loud,
by a recorded contract (`pretooluse.jq-parse-error-fails-open.integration.test.ts`: a jq release
whose exit code moved once blocked every tool call). leave those unless that contract is revisited.

## .the shape of the fix

per gate, the read the suspicious-syntax and sedreplace gates now use:

```bash
if ! COMMAND=$(jq -r '.tool_input.command // empty' <<< "$STDIN_INPUT" 2>&1); then
  payload_crash="💥 MalfunctionError: PreToolUse payload is not valid json (${COMMAND%%$'\n'*}); the command stays blocked"
  printf '%s\n' "$payload_crash" || true
  printf '%s\n' "$payload_crash" >&2 || true
  exit 2
fi
```

plus one `[caseN] a PreToolUse payload jq cannot parse` per gate, proven to bite. a shared
`get_payload_field` in a hook lib would collapse the copies (with the forbid-terms
`set_hardnudge_payload`, F35).

## .why it is not done in this round

dirty: four gates this route never touched, each with its own suite; and the cross-repo contract
above shows the fail-open/fail-closed call is a per-gate judgment, not a sweep. this round fixed
the two gates the route touched (suspicious-syntax `[case21]`, sedreplace `[case8]`).
