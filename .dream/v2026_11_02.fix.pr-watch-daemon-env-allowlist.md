# 🌙 dream: spawn the shared daemon on an env allowlist

- kind: fix
- owner: mechanic (rhachet-roles-ehmpathy, git.pull.watch)
- caught 2026-11-02

## .the cue that fired

5.1 i006 r011 nitpick.8: the daemon and its `rhachet` and `gh` children inherit the spawner's
whole environment.

## .the gap, precisely

the named hazard, the spawner's `RHACHET_CLONE_SERIAL`, is dropped at spawn this round
(`env -u`). any other session var a clone carries still rides into a daemon every clone shares.

## .the shape of the fix

- spawn via `env -i` with an allowlist: `HOME`, `PATH`, `TERM`, `TMPDIR`, `GIT_PULL_WATCH_*`
- first, a probe of what `rhx keyrack get` and `clone say` need from the env on linux and macos
  (an agent socket, an xdg dir); each need joins the allowlist with a note
- a clamp: a spawner var outside the list is absent in the daemon's `/proc/<pid>/environ`

## .why it is not done in this round

an allowlist that misses a var keyrack needs would pause every watch on the box; that probe
needs real keyrack on both platforms, beyond this round's reach.
