## .the gap, precisely

`git.branch.rebase.continue.sh:169` runs `GIT_OUTPUT=$(git rebase --continue 2>&1) || true`. the
exit code is dropped. when git refuses with no conflict and no unstaged path (a rejected hook, an
empty commit), the skill renders `righteous!` + `status: in progress` and exits 0. the git output
still prints, so the text shows, but the status and exit lie.

## .the shape of the fix

capture the exit (`|| GIT_EXIT=$?`). when it is non-zero, no conflict waits, and the rebase did not
advance, render a distinct status (the F11 call: `halted` or another word) as a `💥
MalfunctionError` with the git output, and exit 1. clamp with a temp repo whose pre-commit hook
rejects: assert the status line and exit 1; revert the fix and watch it go red.

ruled). the fix belongs to that route, not to the meter split.
