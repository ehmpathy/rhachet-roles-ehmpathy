## .the gap, precisely

- `src/domain.roles/mechanic/skills/claude.tools/sedreplace.sh:148` — `find_claude_dir`, forks
  `dirname`, and creates `<git root>/.claude` when none is found
- `src/domain.roles/mechanic/inits/claude.hooks/pretooluse.forbid-terms.gerunds.sh:149` —
  in-shell strip; creates `$PWD/.claude` when none is found
- `src/domain.roles/mechanic/inits/claude.hooks/pretooluse.forbid-terms.blocklist.sh:260` — same
  shape as gerunds
- all three keep nudge state (`*.nudges.local.json`) in the walk-up dir. for a hash-actor clone
  (`$CLAUDE_CONFIG_DIR` set), that is the repo actor's dir, not the clone's own. the permission
  hook's nudge file moved to the config dir in #895; these did not

## .the shape of the fix

1. lift `get_permissions_walkup_dir` / `get_permissions_config_dir` into a shared
   `claude.dirs.operations.sh` (the permission lib then sources it)
2. each of the three sources it; keep its own not-found fallback as one explicit line at the call
   site (create in `$PWD` vs git root), so the fold is a pure move
3. write each nudge file into `get_permissions_config_dir` (mkdir -p first), as the check hook does
4. extend each suite's hermetic env to scrub `CLAUDE_CONFIG_DIR` (see `genHookEnv`)

## .why it is not done in this round

safe, but not clean: three files and three suites outside #895's diff, two distinct not-found
fallbacks, and a move of nudge state for every hash-actor clone. see fulcrum F9.
