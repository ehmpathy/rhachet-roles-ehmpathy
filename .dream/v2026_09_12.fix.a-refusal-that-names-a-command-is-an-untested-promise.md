# 🌙 dream: audit every curated refusal against the command it names

- **kind** = fix
- **owner** = ehmpathy/rhachet-roles-ehmpathy
- **caught** = 2026-09-12

## .the cue that fired

`behavior-intent-coverage` (i018 r008) graded a nitpick that named the CAUSE of a blocker four
other lanes had found:

> del's remedy for a present-but-corrupt sponsor file is advertised but never tested
> end-to-end

⇒ the corrupt render said *"run `git.commit.sponsor del`"*. `del` gated on `-f`, so on the one
state that render fires for — a directory at the state path — it printed **"groovy, already
clear"** and removed no entry. the human runs the repair they were handed, it no-ops, and the
next `set` dies at `mv` with a raw system error.

🔴 **the defect was in the code for one round and invisible to a green suite**, because the
two halves were tested separately and never joined:

| test | covered |
|---|---|
| `[case11]` | the corrupt **render** |
| `[case6][t0/t1]` | `del` on a **bound** sponsor, and on an **unbound** tree |
| — | 🔴 **the edge between them: the corrupt state → the command the render names** |

## .the gap, precisely

> **an error message that names a command is a COVERAGE OBLIGATION.** the refusal asserts that
> the command works on *that* state. if no test exercises `state → named command`, the
> assertion is prose no run has ever backed.

the one instance is repaired (`[case6][t2]`). ⚠️ **the audit of every other refusal is not
done**, and the skills are dense with them. checkable evidence — each of these names a command
inside a refusal, and each pair is a transition no test is known to walk end to end:

- `git.commit.sponsor get` corrupt → names `cat .meter/…`, `sponsor del`, and **both bind
  forms**. ⇒ the `del` half is now covered; the **bind-after-corrupt** half is not
- `git.commit.set` no-sponsor refusal → names both bind forms. is there a test that binds via
  the printed command and then commits?
- `git.commit.set` corrupt-sponsor refusal → same three-command remedy as `get`
- `git.commit.uses get` corrupt-global → names `cat …` and `git.commit.uses allow --global`
  (both added i018). **neither is walked**
- the `@me` refusals → name `gh auth login` and the two bind forms
- the actor-guard refusals → name the two bind forms, addressed to a human

## .the shape of the fix

per refusal: read the commands it prints, then assert each is a REACHABLE transition from the
state that produced the refusal.

1. enumerate — grep `print_instruction` and `print_coconut_hint` call sites; each is a
   (state, command-list) pair
2. per pair, ask the coverage question: **does a test enter that state and then run that
   command?**
3. where the answer is no, write the transition test. the shape is already paved by
   `[case6][t2]`: seed the damaged state, `spawnSync` the named command, assert BOTH the
   outcome and the render
4. 🔴 where the transition **cannot** succeed, that is a live defect, not a test gap — the
   `del` case proves the class is real rather than theoretical

⚠️ **the asserts must be paired.** `[case6][t2]` needed `not.toContain('already clear')` AND
`existsSync === false`, because the defect passed either one alone. a refusal-promise test
that checks only the exit code will pass in both worlds.

## .why it is not done in this round

**SAFE: yes. CLEAN: no.**

- the enumeration spans `git.commit.sponsor`, `git.commit.set`, `git.commit.uses.local`, and
  `git.commit.uses.global` — four skills, and three of them are outside this wish's subject
- it is an unbounded count of new tests, each with its own state seed. a plausible dozen
- ⇒ it would balloon a diff that eleven review lanes are mid-way through their read of

🟡 **the instance the lane found IS fixed in this round** — the deferral is the *sweep*, never
the defect. and a fulcrum is owed beside this dream, because the dirt call is a judgment: see
the i018 yield.

## .the generalization worth the record

three rounds of this lane family found the same class at a wider radius each time:

| round | the raw crash / failhide lived in | what had just been hardened |
|---|---|---|
| i017 | the reader's own `-f` absence test | the parse |
| i017 | the `cat` the reader calls | the parse |
| i018 | 🔴 **the command the reader's REFUSAL names** | the reader itself |

⇒ **a curated refusal makes a promise about the command it names. that command is inside the
contract, not outside it.** to harden a reader and leave its advertised remedy unexamined is
to move the raw crash one step down the path the human was just told to walk.
