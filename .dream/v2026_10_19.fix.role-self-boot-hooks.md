the rhachet bump in this tree (package.json was modified before the route began) adds an
introspect check. it flags four `onBrain.onBoot` hooks as redundant, since boot.md already renders
these roles:

- architect onBoot[0]: `rhachet roles boot --repo ehmpathy --role architect`
- ergonomist onBoot[0]: `… --role ergonomist`
- mechanic onBoot[1]: `… --repo .this --role any --if-present`
- mechanic onBoot[2]: `… --repo ehmpathy --role mechanic`

until removed, every `pnpm install` here fails at `prepare`, and so does CI's build:complete.

## .the shape of the fix

delete those four hooks from the role registry definitions (src/domain.roles/{architect,ergonomist,mechanic}),
rebuild, re-run `npx rhachet repo introspect` to green. confirm the `.this/any` briefs still boot
through boot.md (they appear in this session's boot, so they do).
