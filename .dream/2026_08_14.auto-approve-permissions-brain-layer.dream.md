dream = the phase-2 brain layer behind the permission-decide seam

## .what

add a brain decider behind the `PermissionRequest` seam's LIFT branch: for the novel tail
the deterministic decider cannot classify (today it lifts to the human), an inline haiku call
renders a verdict — approve the provably-safe, deny the dangerous, lift only the genuinely
unsure to the human.

## .why

phase 1 (shipped) auto-approves ONLY a clean single `rhx` call and denies obvious chains +
privilege-escalation subcommands; every other flagged command lifts to a human. that is the
safe beachhead, but it leaves G1 (unattended autonomy) only partly delivered — many benign
commands still stall on a human. a brain behind the same seam widens the safe-auto set for the
novel tail without a contract change: the decider already emits allow/deny/lift, so the brain
just supplies the verdict where the deterministic rules abstain.

## .the shape

- the seam stays identical (nested `decision.behavior` schema, proven on 2.1.87)
- the deterministic rules run first (sub-ms): chain -> deny, privilege-escalation -> deny,
  clean rhx -> allow. only the LIFT tail reaches the brain.
- the brain = an inline haiku call (fastest model, ~sub-second). no clone, no socket, no
  external transport — self-contained, behind the same LIFT seam.
- fail-safe preserved: any brain error, timeout, or low-confidence -> lift to the human, never
  a hang, never a rubber-stamp.

## .the gate (why deferred)

- **Q4 (the race)**: whether a slow (~1-2s) hook still suppresses the prompt on 2.1.87 bounds
  whether an inline haiku call is viable without a pre-warm. the `slow`-mode probe ran; the
  human's prompt-vs-silent read is still an open empirical item (`probe/findings.md`).
- **the conservatism dial (Q8, wisher)**: approve-biased (max autonomy) vs deny/lift-biased
  (max safety) is a G1-vs-G4 values choice the wisher sets before a brain widens the surface.
- **DENY live-behavior (open empirical item)**: the seam's `allow` is proven to suppress; the
  live behavior of `deny` on 2.1.87 is not yet traced. a brain that denies more must rest on a
  proven deny path — recorded in `findings.md` as an open item.

## .phase 3 (optional, later)

a warm reviewer clone as a latency swap behind the same LIFT seam — only if an inline haiku
call proves too slow against a PROVEN race. it buys warmth at the cost of a whole external
transport + lifecycle; it is not a dependency, just a swap.
