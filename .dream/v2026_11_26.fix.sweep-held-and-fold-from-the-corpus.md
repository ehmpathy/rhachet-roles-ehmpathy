## .the cue that fired

route `v2026_10_23.fix-arch-fundamentals` banned these terms in `terms.blocklist.jsonc`: `holds?|held` is one record, and `folds?|folded` another. blocklist `[case36]` and `[case37]` clamp them. the corpus still uses them, so each of those files nudges on its next edit.

## .the gap, precisely

measured 2026-11-26 via `rhx grepsafe --pattern '\b(holds?|held)\b' --path src/domain.roles --output pipeable | wc -l`: 996 lines. 220 are in architect and ~336 in mechanic; the rest are in other roles. `fold` has ~60 hits. verbatim quotes and the clamp cases themselves are exempt.

- `hold · holds`: most uses are the verb for "is true" (`the invariant holds`) or "contains" (`the inventory holds one entry per constraint`). the architect briefs this route added use it heavily: catalogs, members, rules
- `held`: hook error strings and their snapshots (`the nudge record lock stayed held …` in `pretooluse.check-permissions.sh` + snap; `_hardnudge.lib.sh`), test titles (`[t4] … held the only allow`), code comments across `git.commit`, `set.package`, `git.repo.test`; briefs: `rule.require.discoverability` (+ `.min`), `rule.prefer.wet-over-dry`, `rule.require.git-release-confidence`, ecologist `distilisys` (`a belief held by an actor`)
- `fold`: `permissions.get.sh` (`FOLD_AT`, "each group folded"), the rhx canonicalizer in `permissionrequest.decide-permissions.sh` and its tests, `pretooluse.forbid-cross-repo-access.sh`, `grepsafe.sh`, `asTallyByTool.ts`

## .the shape of the fix

per sense, the alternative each ban names:

| sense | swap |
|---|---|
| a law still true (`the invariant holds`) | is true, applies, stands |
| a container's contents (`the inventory holds one entry`) | contains, carries, has |
| a duty kept (`the guard holds the stone`) | keeps, blocks, stops |
| a lock held | a lock kept, a lock not yet released |
| a value held in memory, in a closure | kept |
| held apart, held still | kept apart, kept still |
| a claim held, a gate that held | a claim that is true, a gate that stayed shut |
| a belief held by an actor (ecologist) | a belief an actor keeps, claims |
| fold a list (`FOLD_AT`) | collapse past `COLLAPSE_AT` |
| fold a command to its canonical form | reduce, rewrite, canonicalize |
| fold into the exit-1 path | merge into |

each use needs its own sense read, so the sweep is a per-line rewrite, never a sedreplace. a change to an error string moves its snapshot: resnap and review each.

## .why it is not done in this round

**SAFE: yes. CLEAN: no.** ~1,050 lines across every role, and the error strings ripple into snapshots. a corpus-wide rewrite inside this route would smuggle an unrelated change (`rule.prefer.wickup-touched-prose`). the route's own architect briefs are the one in-scope slice, and they can be swept apart from the rest.
