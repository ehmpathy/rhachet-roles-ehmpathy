# 🌙 dream: three gerund suggestion arms are dead code, so a refused human is handed the wrong alternative

- **kind** = fix
- **owner** = ehmpathy/rhachet-roles-ehmpathy
- **caught** = 2026-09-12

## .the cue that fired

**four reviewer lanes, across two rounds, converged on one finding** — i009 `r010`
(enroll-impl-behavior-intent), i009 `r011` (enroll-impl-arch-defects), i010 `r006`
(arch-hazards-maintenance), i010 `r009` (ergo-friction-hazards).

🔴 **and the first two went unanswered, which is why the second two exist.** `r010` and `r011`
landed after the round's `.taken` sweep had already run, so no response was on record. `r006` said
so outright: *"no `.taken` response is on record, so it remains open."*

⇒ the drive predicted this in its own yield one round earlier — *"a nitpick with no `.taken` does
not decay; it is re-derived from the code by every lane that can see it, every round, at full cost
to each."* **two lanes then paid that cost to re-derive it.**

## .the gap, precisely

`pretooluse.forbid-terms.gerunds.sh` picks the `→ consider:` alternative from a ~106-arm `case`.
bash `case` takes the **first** glob that matches, and three arms are unanchored substring globs
placed ahead of a longer word that contains them:

```bash
397:  *connecting*)    echo "  ⛔ $gerund → consider: connect, connected, connector" ;;
398:  *disconnecting*) echo "  ⛔ $gerund → consider: disconnect, disconnected" ;;   # ← unreachable
428:  *wrapping*)      echo "  ⛔ $gerund → consider: wrap, wrapped, wrapper" ;;
429:  *unwrapping*)    echo "  ⛔ $gerund → consider: unwrap, unwrapped" ;;          # ← unreachable
430:  *locking*)       echo "  ⛔ $gerund → consider: lock, locked, locker" ;;
431:  *unlocking*)     echo "  ⛔ $gerund → consider: unlock, unlocked" ;;           # ← unreachable
```

⚠️ **the verdict is correct in every case** — it blocks, and it names the term. only the recovery
advice is wrong, and it is wrong in the one direction that matters: **it inverts the sense.** a
human told to replace `unwrapping` with `wrap` is handed a word that means the opposite.

## 🔴 .the evidence is first-hand — the hook refused THIS FILE and proved the defect while it did

the gerunds hook blocked the write of this dream. its refusal message is the reproduction:

```
detected gerunds:
  ⛔ disconnecting → consider: connect, connected, connector     ← should read: disconnect
  ⛔ unwrapping    → consider: wrap, wrapped, wrapper            ← should read: unwrap
  ⛔ unlocking     → consider: lock, locked, locker              ← should read: unlock
  ⛔ rebinding     → consider: bind, bound, binder               ← should read: rebind
```

⇒ **no fixture, no harness, no reasoning from source.** the live hook, on a real write, handed back
three inverted alternatives in one message.

### 🔴 and it disclosed a FOURTH that a source read had missed

the same message carries `rebinding → bind, bound, binder`. a grep of the arm list had already
checked for a fourth pair and reported **none** — correctly, because there is no `*rebinding*` arm
to be shadowed. so this is the *other* half of the same shape defect:

| shape | today |
|---|---|
| an arm exists and is **unreachable** | `disconnecting`, `unwrapping`, `unlocking` — 3 found |
| no arm exists, and a **broader** arm silently absorbs the word | `rebinding` → `*binding*`. population unknown |

⚠️ **the second class is strictly larger and wholly uncounted.** the first is findable by a grep of
patterns against patterns; the second needs a walk of every word a human might write. ⇒ the "three
shadowed arms" framing that four lanes used — and that this dream opened with — **undercounts the
defect**, and only a live run disclosed it.

🔴 **the lesson is about the method, not the count.** a source read answers *"which arms are
dead?"* and cannot answer *"which words get the wrong advice?"* — the second is the question a
human actually suffers, and it was answered by accident, by the hook, on this file.

## .why no test caught it

`[case13]` exercises `loading`, `parsing`, and the `*` fallback via `sibling` — **3 of ~106 arms**.
none of the shadowed pairs. ⇒ the class has no clamp surface at all, which is why it survived nine
review rounds.

## .it predates this diff — verified by a reviewer, not taken on trust

`r010` ran `git diff main -- pretooluse.forbid-terms.gerunds.sh` and reports the `case` block
**byte-identical to main**. the fork-storm rewrite never touched these lines; it rewrote the file
around them, which is what drew a fresh read of an old defect.

## .the shape of the fix

| # | shape | verdict |
|---|---|---|
| 1 | reorder — put `*unwrapping*)` ahead of `*wrapping*)`, etc. | 🔴 closes 3 of the dead arms and **none** of the `rebinding` class |
| 2 | anchor the globs — `unwrapping)` rather than `*unwrapping*` | 🟡 kills the substring class, and loses the suffix tolerance the `*…*` form buys |
| 3 | 🔴 a bash associative array, `word → suggestion`, keyed by exact match after a suffix strip | ✅ **the one.** a duplicate key is a *visible overwrite* rather than a silent shadow, and an absent key falls to the generic `*` advice rather than to a near-miss word |

⇒ `r011` named shape 3 and named why: **this is not three typos, it is a shape defect.** a linear
`case` with no uniqueness check makes shadowing available to every arm added the same way.

🔴 **and the `rebinding` finding decides between the shapes.** shape 1 was the cheap favourite and
it repairs only the arms that exist; a word with no arm of its own still collects the wrong advice
from whichever broader glob it happens to contain. **only an exact-match table fixes both halves.**

⚠️ whichever shape lands owes a clamp — a test that walks **every** arm and asserts each is
reachable, plus a handful of prefixed words (`rebinding`, `unlocking`, `disconnecting`) asserted
against their intended advice. that test is the durable half; the reorder is the disposable half.

## .why it is not done in this round

the SAFE/CLEAN test, run honestly:

| question | answer |
|---|---|
| **SAFE?** | 🔴 **no.** it changes the text of a block message |
| **CLEAN?** | ✅ yes — three line swaps, in a file this diff already rewrites |

### 🔴 the decisive reason is acceptance #4, and no reviewer named it

three lanes argued *"out of blast radius"*; one argued the opposite — *"a reordered
`*unwrapping*)`-before-`*wrapping*)` arm would close the misleading pair at zero cost."*

**both framings miss the binding constraint.** acceptance #4:

> the block messages are unchanged in substance: the same detected terms, **the same per-term
> alternatives**, the same rationale line

⇒ the `→ consider:` text **is** the per-term alternative. to reorder is to change it for three
terms. **the repair is not merely out of scope — it is positively forbidden**, and "zero cost" is
the exact framing acceptance #4 exists to refuse.

⚠️ **so the four lanes reached the right verdict by a reason that would not have held.** "out of
blast radius" is a judgment a council could overrule; acceptance #4 is a line the wisher wrote. a
correct conclusion that rests on a weaker premise is fragile — the next reviewer who rebuts the
premise concludes the fix is free.

### the family it belongs to

the third defect this wish must **preserve** rather than repair:

| defect | ruled by |
|---|---|
| the malformed-blocklist failhide | A8 / F5 — the wisher, explicitly |
| the `-ing`-word scan that flags `sibling`, `ceiling`, `during` | Q10 — acceptance #2, "either direction" |
| 🔴 **the shadowed suggestion arms** | acceptance #4, "the same per-term alternatives" |

⇒ each is a defect a careful engineer would fix on sight, and each is frozen by the wish. **that is
what a freeze costs, and it is the right price for a cost change** — *"a behavior change smuggled
into a cost change is unreviewable."*

## .the note worth a keep beyond the fix

🔴 **an ordered dispatch table with overlapped patterns has no failure mode — it has a silent
preference.** the shadowed arm is not an error, it is simply never chosen, so every tool that would
report a defect reports a healthy file: bash parses it, `shellcheck` passes it, the tests pass, and
the arm sits there and reads exactly like live code.

> the tell is that one arm's *pattern* contains another arm's *pattern* as a substring. that is a
> grep, and it is a grep nobody runs, because a `case` looks like a lookup table and behaves like
> an if/elif chain.

⚠️ **and the `rebinding` half has no tell at all.** there is no arm to compare against — the defect
is visible only when a human writes a word the table never anticipated and reads the advice it got
back. ⇒ static inspection cannot find that class; only a run can.

⚠️ the third note, about the review loop: **the finding cost four lanes because two of them were
never answered.** the defect was correctly identified on its first sighting, with the correct
remedy attached. what failed was not detection — it was the `.taken`.
