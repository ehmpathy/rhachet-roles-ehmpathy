# 🌙 dream: the rhachet 1.50 actor migration must not commit a host-local settings link

kind: fix · owner: ehmpathy/rhachet (upstream) + this repo's bump · caught 2026-10-20

## .the cue that fired

`getMechanicRole.permissions-propagate` failed locally with every declared allow and deny absent from
`.claude/settings.json`. the worktree held an uncommitted rhachet 1.48.1 → 1.50.0 bump plus its actor
migration.

## .the gap, precisely

the migration moves the repo brain dir from `.agent/.actors/actor.via.slug=.default/brain/.claude/`
to `.agent/.actors/actor.via.repo=ambient/brain/.claude/`. in the new dir:

- `settings.json -> settings.of.grove.json`
- `settings.of.grove.json -> /home/vlad/.claude/settings.json` (absolute, host-local)
- the repo's real permissions live in `settings.of.repo.json`
- the dir's `.gitignore` un-ignores all three

so a commit of the migration ships a link into one human's home dir. on any other host (CI
included) `.claude/settings.json` dangles, and every test that reads it fails:

- `getMechanicRole.permissions-propagate` (the allow + deny gates)
- `permissionrequest.decide-permissions` `[case12]` (the real registered hook command)

the bump also changes boot output: refs render grouped as `<briefs.ref base=…>`, so
`boot.yml.integration.test.ts` `ref briefs are emitted as path-only links` must accept that form.

## .the shape of the fix

1. upstream: settings.json in a committed brain dir must be a real file, or a relative link to a
   committed file (`settings.of.repo.json`). never an absolute link out of the tree
2. here: land the bump in its own PR, run `rhx git.repo.test --what integration --scope 'path://permissions'`,
   and widen the boot test regex to `/<briefs?\.ref\b/`

## .why it is not done in this round

this round's wish is nano: one verb. the bump arrived in the tree before the round began, and a fix
spans an upstream repo. it is dirty to pull in, so it is deferred (fulcrum F6). the git.package.patch PR
ships only the verb plus the four allow lines, added by hand to HEAD's tracked settings file.
