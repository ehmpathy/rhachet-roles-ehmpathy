# 🌙 dream: git.package.patch render shapes, a polish pass

kind = polish · owner = ehmpathy/rhachet-roles-ehmpathy (mechanic) · caught 2026-11-16

## .the cue that fired

the 5.3 verification round i005 (`enroll-verif-snapshot-blemishes`, `enroll-verif-snapshot-coverage`)
raised render points, each graded `[nitpick][better]`, after every review lane had spent its budget.

## .the gap, precisely

- placeholder shapes mix in one paste-ready line: `--package <name>` beside `--why '<why>'`; the why
  placeholder reads both `'<why this patch is needed>'` and `'<why>'`; `<in-tree dir>` holds a space;
  the dispatcher hint appends `(or: commit, help)` to a command
- `installed:` and `open:` repeat a key per value, where a label should own child branches
- a few headers carry what, why, and state in one 140–190 char line; one chains three steps
- `is-odd is not installed` covers two causes (declared but not installed · not a dependency)
- `given:` and `real:` print the same masked path when they are equal
- begin's malfunction has no 🥥 hint; commit's malfunctions do
- the `Bash(npx rhachet run --skill git.package.patch:*)` allow line is never exercised by a test
- the hook acceptance `[case21]` snap entries were hand-placed before `[case19]` (F16); a jest `-u`
  at the committed rhachet will reorder them

## .the shape of the fix

- quote every placeholder in a runnable line; one form per concept (`'<why>'`, `'<issue-url>'`)
- `├─ installed` / `│  ├─ is-number@7.0.0` child branches; same for `open`
- split a long header into the header plus a `cause` branch; each step a peer branch
- header names the cause: "is declared but not installed" vs "is not a dependency"
- print `real:` only where it differs from `given:`
- `refuse_malfunction` in begin gets the rerun hint commit uses
- `[t7]` gains a then that runs `npx rhachet run --skill git.package.patch begin …` and expects a
  silent pass
- resnap the hook acceptance suite once the F6 bump lands, so jest owns the entry order

## .why it is not done in this round

each is cosmetic (no nameable shipped harm), and the review budget is spent: past the meter only harm
earns a round. several touch many snapshots across both suites, so the pass is cleaner as its own
change than ridden along a verification stone.
