## .the gap, precisely

the meter is one domain — "may this tree do X now" — with two meters (commit, release) and three
levels (global, org, local). its readers live inside the commit family's file, beside the
sponsor and identity operations that are commit-only. so every meter consumer imports the commit
family's internals.

checkable:

```sh
rhx grepsafe --pattern 'git.commit/git.commit.operations.sh|COMMIT_SKILL_DIR/git.commit' --path src/domain.roles/mechanic/skills
```

## .the shape of the fix

1. create `skills/git.meter/git.meter.operations.sh` with the meter vocabulary only:
   `set_meter_scope`, `check_global_blocker`, `check_org_blocker`, `get_one_commit_local_grant`,
   `get_one_release_local_uses`, `print_global_corrupt_note`, `print_org_corrupt_body`,
   `print_local_meter_damaged_fix`, `as_meter_uses_json`, `as_meter_uses_display`,
   `as_commit_held`, `as_commit_push_display`, `as_global_block_display`, and the shared
   path constants
2. move the global and org handlers to `git.meter/git.meter.uses.global.sh` and
   `git.meter.uses.org.sh`; both meter dispatchers exec them with `--meter commit|release`
3. leave sponsor + identity in `git.commit.operations.sh`, which then sources the meter file
4. re-point every consumer (stage, rebase begin, release gate, release.uses, commit set/push/uses)
5. decide the home of `is_rebase_in_progress`: `git.stage.add.sh` sources
   `git.branch.rebase.operations.sh` for it (F12). a shared `git.repo.state` probe, or a
   stage-side contract, removes that edge too
6. keep the suites' spawn paths green; the behavior must not move — a pure relocation
7. as the render leaves move, render the remedies of `print_global_corrupt_note`,
   `print_org_corrupt_body`, and `print_sponsor_corrupt_render` through `print_coconut_hint`
   (today: a colon lead-in plus bare `$ cat` / `$ rm -r` lines). their snapshots span every
   meter suite and the p1–p8 release suites, so they re-snap with the lift (i003 repo-rules n1)
8. add `as_release_local_display status= uses=` and `as_org_block_display status= reason=`
   beside `as_global_block_display`, so `git.release.uses get` reads as three named labels
   (i003 mech-decode-friction n2)

the clean test: after the lift, no skill outside `git.commit/` sources a `git.commit/` file for
meter logic.

## .why it is not done in this round

safe, not clean. the lift touches four skill families, about forty interleaved functions, and the
suites that spawn the handlers by path. it is a relocation with no behavior change, so it rides
best as its own reviewable diff. fulcrum: `F23` in the route that found it.
