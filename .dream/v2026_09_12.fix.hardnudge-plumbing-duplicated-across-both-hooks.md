## .the shape of the fix

`source` is a bash **builtin** — zero forks, zero execs — so this is free under acceptance #1 / #6.

```sh
source "${BASH_SOURCE[0]%/*}/_hardnudge.lib.sh"
```

extract: `find_claude_dir` · the stdin/tool/path/content extraction · the nudge read/sweep/write
trio, **parameterized on the nudge file**:

```sh
read_nudge  "$NUDGE_FILE" "$NUDGE_KEY"
sweep_nudge "$NUDGE_FILE"
write_nudge "$NUDGE_FILE" "$NUDGE_KEY" "$NOW" "$FILE_PATH" "${TERMS[@]}"
```

⚠️ **every seam the merge (F1) was rejected to protect stays intact, and one gets STRICTER**: each
hook passes its **own** `NUDGE_FILE`, so a parameterized signature guards the two-clock separation
against a copy-paste mistake rather than eroding it. detection logic, config format, and block
message stay wholly per-hook.

### the cheaper half, to do first

the **test harnesses** carry the same duplication — `runHook`, `asWriteJson`, `asEditJson`,
`genTempCwd`, `genAgedNudge` — in TypeScript, with **no fork cost and no path hazard**. a shared
`hookTestHarness.ts` is CLEAN on its own and needs none of the machinery below.

## 🔴 .why it is not done in this round

**SAFE: yes. CLEAN: no** — and the dirt is a hazard the extraction would **author**.

a sourced library must be **found at runtime**. that is a new path dependency, and this wish already
documented exactly what a wrong one does (`getMechanicRole.ts`, the `asHookCommand` note):

> *"a path that does not exist fails with a non-2 exit, and claude code reads non-2 as **not
> blocked** — so a typo RETIRES a gate rather than breaks it."*

| | today | with a sourced lib |
|---|---|---|
| a bad path retires | **one** hook | 🔴 **both**, at once |
| what must reach `.agent/` | each hook + its `.jsonc` | those **plus a third file nobody invokes directly** |
| who would notice | `getMechanicRole.hooks-reachable` | ⚠️ **no test today** — it reads `settings.json` commands, and a lib is named in no command |

⇒ the extraction trades independent failure for **shared** failure, through the precise mechanism
this drive spent a round to guard against.

the rest of the CLEAN debt: a new `build:complete:dist` include · a new ported path · a widened reach
assertion that follows a `source` line · coverage for the lib itself. ⇒ it ripples into files a
fork-count wish never intended to open.

## .the checklist, when it is done

1. **harness first** — `hookTestHarness.ts`. cheap, CLEAN, and it shortens every later diff
2. `_hardnudge.lib.sh`, parameterized on `NUDGE_FILE` — never a shared default
3. add it to `build:complete:dist`, and confirm it lands in `.agent/`
4. 🔴 **widen `getMechanicRole.hooks-reachable.integration.test.ts` to follow `source` lines**, so an
   absent lib is caught rather than silently opened. **do this in the same diff** — the guard is what
   makes the extraction safe, so it is not a follow-up
5. prove it: delete the lib, watch the reach assertion go red, restore
6. then take the swallow fix once, at one site
