# 🌙 dream: teesafe answers --help

kind: fix · owner: ehmpathy/rhachet-roles-ehmpathy (`src/domain.roles/mechanic/skills/claude.tools/teesafe.sh`) · caught 2026-11-02

## .the cue that fired
`rhx teesafe --help` exited 2 with `error: unknown option: --help`, under a `✋ blocked by constraints` banner.

## .the gap, precisely
`rule.require.help-on-demand`: every command carries `--help` / `-h` with what it does, its inputs, and an example. teesafe treats `--help` as an unknown flag; the usage lines it prints after the error are the only help, and they arrive as a refusal.

## .the shape of the fix
add a `--help|-h)` case to teesafe's parser that prints `.what`, usage (`cmd | teesafe <file>`, `--into`, `--idem findsert|upsert|append`), and one example, then exits 0. clamp it with a case in teesafe's integration test.

## .why it is not done in this round
another skill, outside this route's files; it would ride a pr about rebase.
