# 🌙 dream: the achiever's per-route goals dir should be gitignored at birth

- kind: reseed
- owner: ehmpathy/rhachet-roles-bhrain (role=achiever)
- caught 2026-11-25

## .the cue that fired

a stage of a route dir swept up the achiever's goals dir. its asks inventory holds a verbatim human message with a clock time, and the timestamp hook refused the commit. the goal guard forbids a clone to name that dir, and no paved command unstages it. so a human had to run the unstage.

## .the gap, precisely

the goals dir is session state, written by the achiever's hooks. no other route in this repo tracks one. it has no `.gitignore`, so `git add <route>` stages it.

## .the shape of the fix

the achiever findserts a `.gitignore` (`*`) in each goals dir it creates, as the mechanic's `.meter` dirs do (`findsert_gitignored_dir`). a clamp: a stage of a route dir with a goals dir stages no goals file.

## .why it is not done in this round

the fix lives in another repo's role.
