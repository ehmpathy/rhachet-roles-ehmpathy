# 🌙 dream: `git.repo.test --scope` reports a match set that differs from the set it runs

- **kind** = fix
- **owner** = ehmpathy/rhachet-roles-ehmpathy
- **caught** = 2026-09-20

## .the cue that fired

a one-file scope ran the whole integration corpus, brain-call suites included, and spent real money:

```
$ rhx git.repo.test --what integration --scope 'path://grepsafe' --mode apply
   ├─ scope: path://grepsafe
   │  └─ matched: 87 files          # every integration test in the repo
```

## .the gap, precisely

the `matched:` line does not derive from the set handed to jest. it errs both ways:

| invocation | `matched:` | actually ran |
|---|---|---|
| `--scope 'path://grepsafe'` (part of one test's path) | 87 | 87 |
| `--scope 'path://src/…/claude.tools/grepsafe'` | 1 | 1 |
| `--scope 'path://git.branch.rebase.abort' --scope 'path://git.branch.rebase.continue'` | 1 | 2 |

- a bare word widens to the full set. a false *all* costs more than a false zero: it spends brain
  budget on unrelated suites.
- stacked scopes run correctly but report only the first scope's hit.
- the allowlist teaches the bare-word form (`--scope 'name://invoice'`), so callers hit this.

the three measurements are the claim. the mechanism is a hypothesis: nobody has read the matcher.

## .the shape of the fix

1. read the `--scope` matcher in `src/domain.roles/mechanic/skills/git.repo.test/git.repo.test.sh`.
2. derive `matched:`, `files`, and the jest argv from one list.
3. a scope that matches zero files says so and runs none — never widens to the full set.
4. make `path://grepsafe` match its one file, as the longer path already does.
5. clamp: one-file scope runs one file; stacked scopes report both; zero-match scope reports zero.
   prove teeth by a revert to the fallback.

## .why it is not done in this round

- **SAFE?** no. it changes which tests run for every caller. a wrong turn silently shrinks CI coverage.
- **CLEAN?** no. `git.repo.test` shares no code with `grepsafe`. it would pull an unrelated skill into
  a route bound to one defect fix.

no test goes red for it, so the 5.3 gate's mandate does not reach it.
