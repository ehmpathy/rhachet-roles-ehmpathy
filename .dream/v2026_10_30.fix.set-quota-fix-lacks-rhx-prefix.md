# 🌙 dream: git.commit.set's quota fix lines lack the `rhx` prefix

kind: fix · owner: mechanic · caught 2026-10-30

## .the cue that fired
a real walk of `rhx git.commit.set --mode apply` with zero uses left, in a tree with no director,
printed:

```
🐚 git.commit.set
   └─ ✋ ConstraintError: no commit uses left

ask your human to grant more:
  $ git.commit.uses set --quant N --push allow|block
```

`git.commit.uses` is not on PATH; the human must type `rhx git.commit.uses …`. the same refusal on
`git.branch.rebase begin` prints `$ rhx git.commit.uses set --quant N --push allow`, so the two
surfaces disagree, and set's line fails a copy-paste.

## .the gap, precisely
the human fix lines in `src/domain.roles/mechanic/skills/git.commit/git.commit.set.sh` (the
uses-out, push-blocked and no-quota refusals; passed as `human_cmd=` to `print_quota_grant_fix`)
omit `rhx`. the set snapshots on main pin those bytes.

## .the shape of the fix
prefix `rhx ` on each set human line; update the set snapshots and the skills suite's `none` scenes;
match rebase and release so every surface prints one runnable form.

## .why it is not done in this round
the wish fixes the no-director text as it stands on main (F4, ruled: the extant fix stays). a change
to those bytes is a separate, small pr.
