# 🌙 dream: `rmsafe` keeps the reason when a glob expansion fails

- **kind**: repair
- **owner**: `ehmpathy/rhachet-roles-ehmpathy`
- **caught**: 2026-09-21
- **status**: the globstar defect is repaired in `v2026_09_03.fix-grepsafe-slashed-glob`. the discarded
  reason is owed

## .the cue that fired

`rmsafe [case11][t2]`, `[case15][t5]`, and `[case15][t5.5]` went red: `rmsafe --path '**/*.bak'` left
the nested `.bak` on disk.

## .the gap, as caught

`expand_glob_to_files` expanded through `compgen -G`, which ignores the `globstar` shopt set at line
35. `**` read as `*`, one level deep. a caller read a clean report while files meant to be gone
remained — a false zero in a tool that deletes.

`compgen -G` also does quote removal, which the escape contract needs: `'doc.\[ref\].md'` names a
literal bracket file. a plain bash expansion treats `\[` as quoted, sees no glob, and returns the word
with its backslashes, which matches no file. `eval` would do the removal, and `eval` on a caller
pattern in a delete tool is arbitrary command execution.

## .the repair, as landed

a two-pass expansion:

1. bash's own pathname expansion. honors globstar; reaches nested files.
2. `compgen -G`, only where pass 1 matched no extant file. does the quote removal pass 1 skips.

pass 2 is a fallback, never a union: it runs only where pass 1 found none to delete, so it can never
widen a delete pass 1 settled.

| state | result |
|-------|--------|
| both passes | 63 passed |
| pass 2 disabled | 1 red — `[case13][t2]`, the escape case |
| pass 1 disabled | 3 reds — the original globstar set |

negative arm: `[case11][t2]` holds `other/deep/nested/keep.bak`, a `.bak` at the same depth outside
the named root. it goes red if `**` over-widens.

## .what is still owed

`rmsafe.sh` pass 2 still reads `compgen -G "$pattern" 2>/dev/null`. an unreadable directory, a bad
pattern, and a clean empty match all collapse to "no file matched", with the reason lost.

fix shape: capture stderr to a sink, as `grepsafe.sh`'s `expand_root_or_reason` does, and report it.
clamp an unreadable-dir case apart from an empty match.

🟡 **verify the premise first.** bash pathname expansion, `compgen -G` included, skips an unreadable
dir without a word to stderr — so there may be no reason to capture, and the sink would stay empty.
if so, the reason must be probed (e.g. `-r` on each literal parent of the pattern), not captured.
unmeasured as of 2026-09-28.

## .why it is not done in this round

- **SAFE?** no. it changes the refusal output of a tool that deletes.
- **CLEAN?** no. it adds a new output path, tests, and snapshots outside the grepsafe defect.

## .the lesson

a refutation must state what it did not test. the first attempt measured one candidate, found it
worse, and was read as "no repair" — while the two-pass candidate sat unprobed in the same note.
