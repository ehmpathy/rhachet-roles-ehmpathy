# 🌙 dream: sedreplace matches a pattern that opens with a dash

- kind: fix
- owner: mechanic (claude.tools/sedreplace.sh)
- caught 2026-11-02

## .the cue that fired

the rename of `--to` to `--into` across a test file (#1173 review, vision line 21) reported
`no files contain pattern`, both as `--old '--to'` and as `--old @stdin` fed `--to`. the file held
the string 19 times. the rename fell back to the Edit tool.

## .the gap, precisely

`rhx sedreplace --old '--to' --new '--into' --glob '<file>'` → `result: no files contain pattern`,
while `rhx grepsafe --pattern '--to\b' --path <file>` finds 19 lines. a pattern whose first char is
`-` is likely passed to the file search as an option, not a pattern.

## .the shape of the fix

pass the pattern after `--` (or via `-e`) in the file search and the replace, e.g.
`grep -lF -- "$OLD"`; add a caselist row for a dash-first pattern to the sedreplace test.

## .why it is not done in this round

safe, but not clean: it opens another skill and its suite inside a pull scoped to the pull verbs.
