## .the partial diagnosis — `rmsafe`, as the worked example

all three `rmsafe` failures are **glob** cases, and all three fail the same way:

| case | assertion | result |
|---|---|---|
| `[case11][t2]` recursive glob `**/*.bak` | `expect(existsSync(nested)).toBe(false)` | `true` |
| `[case15][t5]` glob spans trackable + not | same shape | `true` |
| `[case15][t5.5]` glob, none trackable | same shape | `true` |

⇒ **the file was never removed.** a glob that expands to zero matches under `nullglob` yields
exactly this, silently.

✅ **and it is DETERMINISTIC, never a flake** — a re-run under a narrow scope reproduced exactly
`60 passed, 3 failed`. so no deflake is owed; a real defect is.

### 🔴 the checkable asymmetry that points at the cause

four peer skills enable the same two shell options. **one guards the call and three do not:**

```
globsafe.sh:37   shopt -s globstar nullglob 2>/dev/null || true    ← guarded
rmsafe.sh:35     shopt -s globstar nullglob                         ← bare
cpsafe.sh:34     shopt -s globstar nullglob                         ← bare
mvsafe.sh:34     shopt -s globstar nullglob                         ← bare
```

that one file carries a guard is evidence somebody already met a host where the `shopt` did not
take. ⇒ **the hypothesis to test first is a `globstar` that is absent or inert** (bash < 4, or an
`sh`-invoked path), which under `nullglob` turns "no match" into a **silent no-op** rather than an
error.

⚠️ **stated as a hypothesis, never a conclusion.** I did not confirm the host's bash version — the
permission layer denies `bash --version` to this clone, and I declined to spiral on a file this
wish does not own. the asymmetry is checkable in one line by anyone who can read it.

## .the shape of the fix

1. **confirm the host tool versions** — `bash --version`, `jq --version`. two numbers settle
   whether all twelve share one cause (host drift) or whether there are several
2. **`rule.forbid.bare-host-deps` already names this class.** the repair is not to widen a
   version allowlist per site, but to make each skill **assert its host contract at the top** and
   fail loud when it is unmet. a `shopt` that silently does not take, under `nullglob`, is the
   same failhide shape as the jq exit-code table: careful-read code whose failure mode is a quiet
   permit
3. **the clamp that is owed** — each of these suites asserts an *outcome* and none asserts the
   *mechanism*, which is why they went red on a host change rather than on a behavior change. a
   test that stubs the host tool to an unexpected version or exit code would hold the contract
   honest across the next drift
4. **triage the residual 9** — `git.release` (7) and `git.repo.test.scope` (6) are the bulk; both
   are heavy process-spawn suites and may share a third cause entirely
