# 🌙 dream: route.reminder reads a withheld say as a dead session

kind: reseed · owner: rhachet-roles-bhrain (role=driver, route.reminder) · caught 2026-10-31

## .the cue that fired

the pr-watch blueprint read rhachet@1.50.1's `clone say` exit map: `withheld` (a modal, a dirty box, an unrecognized screen) is `klass: 'constraint'` → exit 2 (`computeCloneSayReport.js:178-182`). a dead or deaf clone also throws a ConstraintError → exit 2 (`asCloneReachError.js:102`). bhrain's `sayToClone.js` maps exit 2 to "the clone is dead".

## .the gap, precisely

a reminder that fires while the driver sits at a permission modal gets `withheld`, exit 2. the daemon reads that as session-dead and self-exits. the reminder dies at the exact moment the session is stalled — the case it exists for.

## .the shape of the fix

- call `clone say --output json` and branch on the verdict, not the exit code: reach error → dead; `withheld` → retry next tick
- clamp: a fake `rhx` that returns `withheld` with exit 2; assert the daemon stays alive

## .why it is not done in this round

the reminder lives in rhachet-roles-bhrain. the pr-watch blueprint avoids the same misread (QB4).
