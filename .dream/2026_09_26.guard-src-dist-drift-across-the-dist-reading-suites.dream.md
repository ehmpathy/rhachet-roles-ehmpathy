# 🌙 dream: guard `src`↔`dist` drift across every suite that runs the built copy

- **kind**: fix
- **owner**: unclaimed
- **caught**: 2026-09-26, at the `5.3.verification` gate of
  `.behavior/v2026_09_03.fix-grepsafe-slashed-glob`

## .the cue that fired

`git.release.p8` went red in 3 steps with the pre-repair symptom. `src/` held the repair. `dist/`
held `if false; then` in place of both guards — a revert-to-red probe edited into `dist/` and never
restored. the suite read it as a product defect.

## .the gap, precisely

all 12 `git.release` suites run `dist/…/git.release.sh`. `dist/` is gitignored
(`.gitignore:25:dist`; `git ls-files dist` → no rows). build freshness is an unasserted precondition
of every verdict:

| drift | what a reader concludes |
|---|---|
| `dist` behind `src` | a false red: the product looks broken; the repair is in `src` |
| `dist` ahead of `src` (a hand-edit) | a false green: the suite passes against unreviewed code |

the false green is worse: it raises no question.

## .what already landed

`p8` asserts its own precondition over the two files it turns on:

```ts
then('the dist build this suite runs is current with src', () => { … });
```

proven: a one-line append to the `dist` copy reddens that step alone and prints
`"dist is behind src — run \`npm run build\`, then re-run"`. the other 11 suites stay exposed.

## .the shape of the fix

| # | shape | cost |
|---|---|---|
| A | shared `.test/infra/assertDistIsCurrent({ names })`, called by each suite that runs `dist/` | 12 one-line calls + 1 helper |
| B | a jest `globalSetup` that compares the whole built tree and fails the run | covers every suite, future ones too; touches shared config |
| C | `git.repo.test --what integration` builds first | removes the class; adds build time to every run |

B closes the class; A is the safe increment. the build copies `*.sh` via `rsync -a`, so byte-equality
is the right test.

## .why it is not done in this round

- **SAFE?** yes — an added assertion touches no product behavior.
- **CLEAN?** no. A ripples into 12 files outside this route; B and C edit shared test infrastructure.

the `p8` guard rode along because `p8` is this route's own new file.

## .the lesson

a revert-to-red probe is an edit, and an edit owes a restore.
