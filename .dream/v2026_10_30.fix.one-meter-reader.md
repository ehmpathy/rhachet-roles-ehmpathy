# 🌙 dream: one reader for the commit quota meter

- kind: fix
- owner: rhachet-roles-ehmpathy, mechanic
- caught 2026-10-30

## .the cue that fired
review i007 (enroll-impl-arch-defects, items 1 and 2): seven files read the quota meter's `uses`,
`push` or `stage` with their own `jq`, with defaults that disagree.

## .the gap, precisely
- readers: `git.commit.set.sh`, `git.commit.push.sh`, `git.branch.rebase.begin.sh`,
  `git.branch.rebase.operations.sh` (`is_push_allowed`, `// "block"`), `git.release.sh`,
  `git.stage.add.sh`, `git.commit.uses.local.sh`; plus `get_one_meter_field` in
  `git.commit.director.operations.sh` (`// ""`)
- `git.stage.add.sh` prints the same refusal twice (meter absent; stage not allowed); a damaged meter
  there crashes `jq` under `set -e` instead of a named refusal

## .the shape of the fix
1. lift `get_one_meter_field` into `git.commit.operations.sh` beside `is_local_meter_readable`; the
   director file calls it
2. migrate each reader as it is touched; settle one default per field
3. in `git.stage.add.sh`, read stage once through the shared reader (absent → block) and refuse once;
   a damaged meter takes the extant `MalfunctionError` path the other skills use

## .why it is not done in this round
step 3 changes stage behavior on a damaged meter, and F9 sends behavior changes found in review to
dreams; steps 1-2 move a reader across seven files, a ripple beyond this pr's refusal text (F8).
