# 🌙 dream: sedreplace exits 1 on a file with merge conflicts in the index

- kind: fix · owner: ehmpathy/rhachet-roles-ehmpathy (mechanic/claude.tools/sedreplace) · caught 2026-10-13

## .the cue that fired

mid-rebase, `rhx sedreplace --mode apply` on a conflicted file exited 1 after it applied the edit.

## .the gap, precisely

the file list comes from git; an unmerged path appears once per index stage (1, 2, 3), so the
same file is listed 3 times. the first pass edits it; the next pass finds no match and fails.
the edit lands, yet the exit says it failed — a caller that trusts the exit code re-runs or halts.

## .the shape of the fix

dedupe the file list (`sort -u`, or `git ls-files -z | sort -zu`) before the replace loop, plus
a test that builds a repo with an unmerged path and asserts exit 0 and one edit.

## .why it is not done in this round

a skill fix outside this route's scope, with its own test harness; not clean to pull in.
