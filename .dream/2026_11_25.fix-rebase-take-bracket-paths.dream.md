# 🌙 dream: git.branch.rebase take settles a path with brackets in its name

kind: fix · owner: mechanic · caught 2026-11-25

## .the cue that fired

a rebase of #1206 onto main stopped on `howto.git-commit-set.[lesson].md` and its `.min` twin. `rhx git.branch.rebase take --whos theirs <path>` left both conflicted, whether the path was passed plain or with escaped brackets. each had to be settled by hand, then staged via `rhx git.stage.add`.

## .the gap, precisely

`take` hands the path to git as a pathspec. git reads `[lesson]` as a glob character class, so the pathspec matches no file, and the conflict stands.

## .the shape of the fix

pass each path as a literal pathspec (`:(literal)<path>`, or `GIT_LITERAL_PATHSPECS=1`) in every git call `take` makes. add a clamp: a temp repo with a conflict at `x.[lesson].md`, then `take --whos theirs` settles it.

## .why it is not done in this round

the fix touches another skill's git calls and needs its own clamp test. this round re-applies #1206 onto main.
