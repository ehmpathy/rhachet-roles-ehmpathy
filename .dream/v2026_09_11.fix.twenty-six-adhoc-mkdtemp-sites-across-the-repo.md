# 🌙 dream: retire the 26 adhoc `mkdtempSync` sites that bypass `genTempDir`

- **kind** = fix
- **owner** = ehmpathy/rhachet-roles-ehmpathy
- **caught** = 2026-09-11

## .the cue that fired

a self-review of `v2026_09_09.fix-hook-fork-storm` ran a **positive control** on its own verdict.
the claim under audit was *"no `mkdtempSync` anywhere in the diff"* — which had been recorded on a
search that returned zero.

⚠️ **a zero from a search is indistinguishable from an unread file**, so the probe was re-run
repo-wide to prove the instrument worked. it did: **26 hits, across 10 files.** the diff was clean;
the repo was not.

⇒ **the cue was a control run to validate a tool, never a hunt for this defect.** without it the
26 stay invisible, because every rule check in that review was correctly scoped to the diff.

🔴 **and one is worse than the rest.** `skills/claude.tools/teesafe.integration.test.ts:318`:

```ts
const tempDir = fs.mkdtempSync('/tmp/teesafe-no-git-');
```

a **hardcoded `/tmp` prefix**, which ignores `TMPDIR` and writes outside any repo-scoped store. that
one also trips `rule.require.hermetic-tests`, and the repo's own `pretooluse.forbid-tmp-writes`
hook forbids exactly this shape from a Bash call.

### checkable evidence

```
Grep 'mkdtempSync' in src/  →  26 matches, 10 files
Grep 'genTempDir'  in src/  →  present only in the 3 forbid-terms suites
```

⇒ `genTempDir` from `test-fns` is used in **one** corner of the repo; everywhere else predates it.

## .the shape of the fix

per site: `fs.mkdtempSync(path.join(os.tmpdir(), 'slug-'))` → `genTempDir({ slug: 'slug' })`, then
drop the now-unused `os` / `fs` imports.

⚠️ **the `git.branch.rebase` suites are the careful half — 18 of the 26.** they build real git
worktrees, and several pair a main dir with a worktree dir whose *relative* positions matter.
`genTempDir` offers clone/symlink/git options that may serve directly; a mechanical swap that
ignores them will pass locally and behave differently under a `TMPDIR` that is a symlink.

⇒ suggested order: the 8 easy sites first (`set.package`, `cicd.deflake`, `declapract.upgrade`,
`git.repo.get`, `runRubricReview`), then `teesafe:318` on its own (it is a behavior fix, not a
cleanup), then the 18 git-worktree sites as a focused pass with the suites re-run per file.

## .why it is not done in this round

the SAFE/CLEAN test, run honestly:

| question | answer |
|---|---|
| **SAFE?** | 🔴 **no.** 18 of 26 sit in git-worktree integration tests this wish has never read. a swap that changes how two temp dirs relate to each other breaks a suite in a way that reads as flake |
| **CLEAN?** | 🔴 **no.** it ripples into 10 files across 5 skill families, none of which this wish opens. the diff is a fork-count fix on 2 hooks |

⇒ both no ⇒ defer, and record. ⚠️ **no fulcrum is owed**: the deferral is for SIZE and SAFETY, never
a judgment call on ripple cost that a council could overrule.

## .the note worth a keep beyond the fix

**the defect was found by a control, not by a search for it.** the practice that produced it is one
line:

> a search that returns zero owes a positive control — a query against the same target whose answer
> cannot be zero. if the control also returns zero, you measured your instrument, never the artifact.

⇒ that practice cost one extra grep and turned a recorded ✅ into 26 real sites plus one hermeticity
defect.
