### C1 · slow-test report fails a shard whose tests were all skipped
- **what**: `suite / test-shards-integration (explicit, 0, …brief.condense.integration.test.ts)` failed: `slow-test report parsed 0 durations from 1 test files`; jest itself passed (`27 skipped, 27 total`)
- **how**: `.github/workflows/report-slow-tests.sh` is new with this upgrade (absent on origin/main, which inlined a `jq … perfStats.runtime` loop)
- **why**: the report reads a zero-duration result as jest schema drift; a file whose every test is skipped never runs, so it carries no duration. the explicit shard held only such a file
- **fix**: count only files where a test passed or failed; a shard of skipped files alone exits 0, like an empty one. pinned by `blackbox/report-slow-tests.integration.test.ts` (skipped-only → 0, ran without durations → 1, ran 12s → 0 + rank, empty → 0); proven to bite: guard removed → case1 red; restored → green

### C2 · cached brain calls return a json string (`pressViaPipeline` red in `test-evaluation`)
- **what**: `TypeError: Cannot read properties of undefined (reading 'match')` at `pressViaPipeline.ts:100`: `result.compressed` undefined
- **how**: the upgrade bumped `with-simple-cache` 0.16.2 → 0.17.3 and `simple-on-disk-cache` 1.7.10 → 1.8.1 (origin/main pins the old pair; a sibling branch on the old pair passes this suite in ci)
- **why**: with-simple-cache's value serde is a no-op by default in both versions (`serde/defaults.js`, 0.16.2 and 0.17.3 alike), and both re-read the cache right after each set. simple-on-disk-cache reads an object value back as its json string (1.7.10 `cache.js:154`; 1.8.1 `envelope/asValueFromEnvelope.js:21`). 1.7.10 masked that in-process: `setWithMemory` kept the raw object in a memory layer, so the re-read returned the object. 1.8.1 reads through to the envelope, so every wrapper with no explicit value serde now gets a json string, and `.compressed` is undefined. reproduced with no brain: both a miss and a hit returned `"{\"compressed\":…}"`. latent on main too: a warm cache from a prior process already returned strings under 1.7.10
- **fix**: explicit `serialize.value: JSON.stringify` + `deserialize.value: JSON.parse` at all 12 `withSimpleCacheAsync` call sites (7 files: compressViaBhrain, extractKernels, clusterKernels, and their perfeval/eval twins). clamp: `compress.cache.serde.integration.test.ts`, proven to bite (serde removed → red; restored → green)
